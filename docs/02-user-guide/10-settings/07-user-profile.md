# 用户档案

用户档案是你在 DesireCore 中的身份信息。智能体会根据你的档案来称呼你，你也可以自定义头像让界面更有个人特色。

## 编辑个人信息

1. 点击应用左上角的 **头像** 或 **名称** 区域
2. 进入个人资料编辑面板

在这里你可以修改以下信息：

- **名称**：智能体称呼你时使用的名字
- **头像**：你在对话界面中显示的头像

## 设置头像

DesireCore 支持自定义头像：

1. 在个人资料面板中，点击头像区域
2. 选择一张本地图片上传
3. 支持的图片格式：JPEG、PNG、WebP

头像会保存在本地的 `~/.desirecore/config/avatar/` 目录中。

:::tip
推荐使用正方形图片作为头像，系统会自动裁剪为圆形显示。
:::

## 显示名称

你的显示名称会出现在：

- 对话界面中你的消息旁
- 智能体回复中对你的称呼

修改名称后点击 **保存** 即可生效。

## 用户档案与智能体记忆

你的用户档案不仅是一个显示名称——它还是智能体了解你的基础。

### profile.md：你的数字画像

DesireCore 在本地维护一份 `profile.md` 文件（位于 `~/.desirecore/users/<你的ID>/profile.md`），记录你的客观属性：

- 姓名、称呼偏好
- 职业、专业领域
- 沟通风格偏好

智能体在对话中会参考这份画像来调整回复的语气和内容深度。例如，如果你标注自己是资深开发者，智能体在回答技术问题时会更直接、少做基础概念解释。

### 画像如何形成

- **你主动告知**：在对话中说"记住我叫张三，我是做后端开发的"，智能体会写入画像
- **你手动编辑**：直接在设置中修改个人信息
- **智能体学习**：在长期对话中，智能体可能识别到你的偏好并记录（需经你确认）

:::info
画像信息完全存储在本地，你可以随时查看和编辑。删除画像文件后，智能体将不再参考历史信息，回到初始状态。
:::

### 与智能体私有记忆的区别

| 项目 | 用户画像（profile.md） | 智能体私有记忆（memory/） |
|------|----------------------|------------------------|
| 内容 | 你的客观属性 | 你与该智能体的互动经验 |
| 共享范围 | 所有智能体可见 | 仅该智能体可见 |
| 示例 | "用户是 Python 开发者" | "用户喜欢我先给代码再解释" |
| 存储位置 | `users/<ID>/profile.md` | `users/<ID>/agents/<agentID>/memory/` |

## 游客模式与登录

你可以不登录使用本地对话、智能体和文件。登录账号后，还可以使用订阅、credit 和部分在线服务。

| 使用方式 | 可用内容 |
|---|---|
| 游客模式 | 本地对话、智能体和文件；无需注册账号 |
| 登录账号 | 账号资料、官方云端算力、订阅、credit 和部分在线服务 |

## 注册和登录

使用邮箱注册或登录账号。注册时验证邮箱并确认密码；忘记密码时，可通过邮箱验证码找回。

登录后，DesireCore 会自动同步账号相关资源：

- 官方云端模型 provider
- credit 余额和临期额度
- 订阅状态
- 可用的合作伙伴模型

## 绑定邮箱与合并账号

登录后，按以下步骤绑定或更换邮箱：

1. 打开个人资料面板，找到账号信息。
2. 填写新邮箱，完成界面要求的验证码验证。
3. 绑定成功后，可使用该邮箱和密码登录。

### 邮箱已被另一个账号使用

界面会引导你合并账号。确认两个账号都属于你，再选择要保留的账号，并完成验证。

合并前请核对：

- 未保留的账号将永久注销，合并无法撤销。
- 余额、订单和用量记录会转入保留的账号。
- 登录方式是否迁移，以合并界面中的选项为准。

## 自助开票

登录后，在个人资料面板打开「发票」：

1. 选择当前账号可开票的已付款订单，可单笔申请，也可批量申请。每张发票对应一个订单。
2. 选择或新建个人 / 企业抬头。
3. 选择普通发票或符合条件的增值税专用发票，填写接收邮箱；备注可不填。
4. 提交申请，在「开票记录」中查看状态和详情。

| 你要做什么 | 操作说明 |
|---|---|
| 管理抬头 | 可新建、编辑、删除，或设为默认抬头 |
| 申请专用发票 | 使用企业抬头，并填写完整的相关信息 |
| 撤销申请 | 仅在申请状态允许撤销时操作 |
| 再次接收发票 | 提交「重新发送」请求；不会立即发送 |

申请通常在 1–2 个工作日内处理。开具后，税务局会向接收邮箱发送 PDF、OFD 或 XML 文件；未收到时也请检查垃圾邮件。

## 登出

登出会清理本地的云端 provider 会话状态，避免继续使用过期 token。你的本地对话、智能体、文件和自定义 API Key 不会因为登出而被删除。

:::info 本地优先
登录只影响账号、订阅和云端算力等在线能力。你的核心数据仍保存在本地设备上。
:::
