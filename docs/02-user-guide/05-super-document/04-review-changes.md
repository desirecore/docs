# 逐条审阅

审阅是超级文书的核心交互。智能体提出修改建议后，你可以逐条审查每一处变更，决定接受、拒绝或进一步编辑。

## 审阅模式介绍

当智能体完成修改后，超级文书自动进入审阅模式。此时：

- 所有修改以 Diff 形式高亮显示
- 第一处修改被自动选中
- 编辑器顶部显示审阅进度条（例如"0/8 已审阅"）
- 每处修改旁边出现操作按钮

你可以从任意一处修改开始审阅，不必按顺序。

## 接受/拒绝单条修改

对于每一处修改，你有三个选项：

### 接受

点击绿色的"接受"按钮（或按 `Enter`），该修改立即生效：

- 如果是新增内容，绿色高亮消失，内容融入正文
- 如果是删除内容，红色标记的内容被移除
- 如果是替换，原文被新内容替代

### 拒绝

点击红色的"拒绝"按钮（或按 `Backspace`），恢复原文：

- 新增的内容被移除
- 删除的内容被恢复
- 替换的内容恢复为原文

### 编辑

点击"编辑"按钮（或按 `E`），在智能体修改的基础上手动调整：

1. 该处修改进入可编辑状态
2. 你可以修改文字内容
3. 按 `Esc` 取消编辑，按 `Enter` 确认

:::tip 什么时候用编辑？
当智能体的修改方向是对的，但措辞还需要微调时——比如 AI 把"好"改成了"卓越"，你觉得"优秀"更合适。
:::

## 批量操作

如果修改数量较多，你可以使用批量操作提高效率：

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 接受全部 | `Ctrl+Shift+Enter` | 一键接受所有待审阅的修改 |
| 拒绝全部 | `Ctrl+Shift+Backspace` | 一键拒绝所有待审阅的修改 |

:::warning 谨慎使用批量操作
批量接受或拒绝操作是可以撤销的（`Ctrl+Z`），但建议至少快速浏览一遍再做决定。
:::

你也可以先逐条审阅重要的修改，然后对剩余的修改使用批量操作。

## 编辑后重新提交

有时候，你对智能体的修改进行了大量手动编辑，或者拒绝后希望智能体换个方向重写。这时可以：

### 方式一：对话中追加指令

审阅完成后，直接在对话中告诉智能体你的新要求：

> "第三段我改了方向，你按新的思路把第四、五段也调整一下。"

智能体会基于你编辑后的最新版本继续工作，产生新一轮 Diff。

### 方式二：部分接受后要求重做

1. 对不满意的修改选择「拒绝」
2. 在评论中说明原因："这段太冗长了，精简到两句话"
3. 完成本轮审阅后，智能体会看到你的评论
4. 下一轮修改中，智能体会参考评论重新处理被拒绝的部分

### 方式三：回退到上一版本重来

如果整轮修改方向都有偏差：

1. 点击「拒绝全部」（`Ctrl+Shift+Backspace`）
2. 或进入版本历史，回退到修改前的版本
3. 重新描述你的需求，让智能体从头来过

:::tip 不会丢失任何版本
即使你拒绝了所有修改，智能体的原始建议仍保留在版本历史中。万一后来觉得"其实那版也不错"，随时可以恢复。
:::

## 审阅工作流建议

根据文档类型和修改规模，推荐不同的审阅策略：

| 场景 | 建议策略 |
|------|----------|
| 短文档、少量修改（≤5 处） | 逐条审阅，每处都仔细看 |
| 长文档、大量润色（20+ 处） | 先快速浏览全局，重点看结构性修改，细节用批量接受 |
| 合同/法律文件 | 逐字逐句审阅，不放过任何修改 |
| 初稿生成 | 重点看结构和方向，措辞细节可以后续迭代 |
| 多轮迭代后期 | 关注增量修改（Diff 只显示本轮变更），快速确认 |

## 添加评论和反馈

审阅过程中，你可以针对某一处修改添加评论。这些评论会被传递给智能体，作为下一轮修改的参考：

1. 选中一处修改
2. 点击"评论"按钮
3. 输入你的反馈，例如："这里改得太正式了，保持原来的语气就好。"
4. 智能体会在下一轮修改中参考你的评论

:::info 评论不只是给智能体看
评论也会保留在版本历史中。如果你在团队中使用超级文书，其他人可以看到你的审阅意见。
:::

## 快捷键速查

| 操作 | 快捷键 |
|---|---|
| 接受当前修改 | `Enter` |
| 拒绝当前修改 | `Backspace` |
| 编辑当前修改 | `E` |
| 接受全部 | `Ctrl+Shift+Enter` |
| 拒绝全部 | `Ctrl+Shift+Backspace` |
| 跳转到下一个修改 | `]` |
| 跳转到上一个修改 | `[` |
