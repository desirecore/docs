# 逐条审阅

在审阅面板中检查智能体的修改，接受需要保留的内容，拒绝不需要的内容。

## 打开审阅面板

智能体提出修改后，文档会高亮显示差异。待输出完成后，再确认变更；输出期间审阅按钮暂不可用。

1. 在文档内容区找到默认收起的审阅浮层。
2. 点击待审阅计数，展开操作面板。
3. 选择需要检查的修改，使用接受或拒绝按钮。

待审阅计数显示还剩多少处修改没有处理。你不必按顺序审阅，可以先看影响较大的段落。

| 查看方式 | 差异显示位置 |
|---|---|
| 行内模式 | 直接显示在正文中 |
| 并排模式 | 显示在独立差异面板中 |

同一批修改只显示一套审阅界面。面板获得焦点后，按 `Esc` 可收起面板并返回入口。你可以从任意一处修改开始审阅。

## 接受/拒绝单条修改

检查差异后，选择接受或拒绝。需要改写时，可继续向智能体说明要求。

### 接受

点击绿色的"接受"按钮，该修改立即生效：

- 如果是新增内容，绿色高亮消失，内容融入正文
- 如果是删除内容，红色标记的内容被移除
- 如果是替换，原文被新内容替代

### 拒绝

点击红色的"拒绝"按钮，恢复原文：

- 新增的内容被移除
- 删除的内容被恢复
- 替换的内容恢复为原文

### 需要进一步修改时

如果修改方向正确但措辞仍需调整，可以在对话中指出具体段落和修改要求。确认本轮变更后，再让智能体继续修改；新的建议仍需审阅。

你也可以直接在文档中编辑文字。待审阅项未处理完或智能体仍在输出时，保存不可用；完成审阅后再保存手动修改。

## 批量操作

行内模式下，当待审阅项超过一处且智能体已经结束输出时，展开审阅面板可使用批量按钮。

| 操作 | 结果 |
|---|---|
| 点击「接受全部」 | 接受所有待审阅修改 |
| 点击「拒绝全部」 | 拒绝所有待审阅修改，恢复对应原文 |

先检查需要保留或拒绝的关键修改，再处理剩余项。若按钮暂不可用，等待智能体输出和当前审阅操作完成后再试。

修改较少时，逐项检查通常最快；修改较多时，先浏览全文，再逐项处理重要段落，对其余修改批量接受或拒绝。批量操作会处理所有待审阅项，点击前先确认它们都适用同一决定。

## 反馈修改要求

在同一对话中说明需要调整的位置和要求，例如：「第二段太正式，请保留原来的语气。」智能体会据此继续修改文档。

## 键盘操作

使用 `Tab` 聚焦审阅按钮，按 `Enter` 或空格激活当前按钮。在审阅浮层内按 `Esc` 可收起面板；正文编辑时的 `Enter` 和 `Backspace` 仍用于编辑文字。


## 按键操作

| 按键 | 作用 |
|---|---|
| Tab | 聚焦下一个审阅控件 |
| Enter 或空格 | 激活当前聚焦的按钮 |
| Esc | 收起已获得焦点的审阅浮层 |
| 正文中的 Enter / Backspace | 换行 / 删除光标前的字符 |

## 审阅后保存或继续修改

1. 检查待审阅项是否已经处理完。
2. 使用编辑器的保存入口或 `Cmd/Ctrl + S` 保存文档。
3. 如需继续修改，在同一对话中提出下一轮要求，或直接编辑正文。

若保存时提示仍有待审阅项，先接受或拒绝剩余修改。智能体仍在输出时也不能保存，请等待输出完成。

需要回看之前的内容时，使用「历史」按钮；具体操作见[版本历史](./05-version-history.md)。
