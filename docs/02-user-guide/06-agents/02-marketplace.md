# 智能体市场

在智能体市场（Agent Market）中，你可以查找和安装官方或社区提供的智能体、团队、技能和应用。打开详情可查看来源、维护者、版本和可用操作。

## 进入市场

点击主导航栏中的「市场」图标即可进入。市场条目可以按类型浏览，也可以搜索或筛选：

| 类型 | 内容 |
|---|---|
| **Agent** | 可安装和使用的智能体 |
| **团队** | 由组长和成员组成的协作配置 |
| **Skill** | 可安装到全局或指定智能体的技能 |
| **应用与服务** | 可安装的集成应用，以及应用可能提供的服务 |

## 浏览和搜索

### 分类浏览

分类取决于条目类型和发布者填写的信息，可能随目录内容变化。常见分类包括：

| 分类 | 说明 |
|---|---|
| 效率 | 提升工作效率的工具型智能体 |
| 开发 | 软件开发辅助 |
| 沟通 | 语言和沟通相关 |
| 学习 | 知识和学习辅助 |
| 创意 | 创意和设计相关 |

### 搜索和过滤

- **关键词搜索**：在名称、描述、标签中搜索
- **过滤条件**：按分类、安装状态、来源仓库筛选
- **排序方式**：按更新时间、名称或热度排序
- **来源状态**：区分官方、社区、受信任仓库和自定义仓库

### 项目卡片

点击卡片进入详情页，查看完整介绍、功能特性和变更日志。卡片显示名称、简介、维护者、内容来源、版本和分类；图标角标及独立文字提示说明获取状态。

| 条目状态 | 卡片上的操作 |
|---|---|
| 可安装 | 「安装」 |
| 有可用更新 | 「更新」 |
| 已安装 | 「管理」，或可用的「打开」 |
| 正在安装 | 显示进度，暂时禁用重复操作 |
| 仅收录或暂不可获取 | 查看详情 |

已安装条目的「更多操作」菜单提供当前可用的管理、详情和卸载入口。智能体、团队和技能可以直接在市场中管理；应用和服务的管理操作会转到资源中心。

团队卡片分别预览组长和其余成员，不重复显示组长。团队总人数与未显示头像的数量分开标注。维护者身份认证标记不代表许可或安装安全保证。

## 安装内容从哪里下载

市场目录保存条目的说明、来源、版本、校验信息和安装入口。部分条目的实际内容保存在发布者的仓库中，安装时才下载。目录也提供来源、校验和许可提示。

:::info 目录术语
技术资料中的 metadata registry 指市场目录，pointer 指目录中指向实际内容的记录。
:::

## 安装条目

### 安装步骤

1. 搜索或浏览条目，打开想要安装的智能体或团队详情，查看用途、来源和版本。
2. 点击「安装」，按提示确认所需选项。
3. 等待下载和配置完成，查看依赖检查结果。
4. 安装成功后，在对话页面切换到新智能体开始使用；依赖未完成时，先按下节补齐所需技能。

Skill 安装时可以选择全局安装或安装到指定智能体。市场中的应用安装会让你选择目标设备，随后由核心智能体执行安装并显示进度；完成后可在 [应用与服务目录](../09-capabilities/09-app-service-catalog.md) 查看按来源和设备记录的安装状态。应用可能提供服务，但并非每个应用都会派生服务。

:::info 安装完成后到哪里查看
智能体配置保存在本地文件中（AgentFS）。技能可在 [技能管理](./07-skills-management.md) 中查看；应用安装结果可通过 [应用与服务目录](../09-capabilities/09-app-service-catalog.md) 中的核验记录确认完成。
:::

### 高风险技能确认

如果智能体包含高风险技能（如文件写入、命令执行），安装时会弹出安全确认对话框，告知你涉及的敏感操作。你需要明确确认后才能继续安装。

### 依赖检查

安装或更新后，打开智能体详情，检查依赖技能是否完整。「Agent 已安装，依赖未完成」表示智能体已安装，但列出的技能仍需处理。

1. 查看缺失技能及原因。
2. 对可重试项，点击「补装缺失依赖」。
3. 点击「刷新依赖状态」重新核对。

补装失败时，已完成的依赖会保留，界面会显示失败原因。工具或连接的环境准备仍需按各自要求完成。

### 调整下载和解压限制

1. 打开市场设置，管理来源仓库。
2. 点击「来源下载与解压设置」。
3. 调整所需上限并保存。设置用于新请求；遇到超限提示时，可调整预算后重试。

| 设置 | 可调整内容 |
|---|---|
| ZIP 下载、网页 / Markdown 下载 | 分别设置大小上限，或选择不限下载大小 |
| 解压总大小、单文件大小、ZIP 条目数 | 独立设置上限，下载不限大小时仍生效 |

### 查看进度或取消获取

获取面板显示下载、检出、验证、解压和安装进度，并在可用时显示字节数或 Git 对象数。使用此前已验证的下载内容时，会显示缓存提示。

| 面板提示或操作 | 处理方式 |
|---|---|
| 「取消获取」 | 点击取消当前获取；进入安装阶段后可能无法取消 |
| 进度连接暂时中断 | 等待界面重新连接 |
| 「结果待确认」 | 先刷新市场核对实际安装状态，再决定是否重试 |

## 导入智能体

除了从市场安装，你也可以从本地或公开地址导入智能体：

| 方式 | 说明 |
|------|------|
| 文件夹导入 | 选择本地 AgentFS 文件夹 |
| ZIP 导入 | 选择打包后的智能体压缩包 |
| 公开 URL 导入 | 输入公开仓库或可访问的智能体地址 |

导入时系统会检查 `agent.json`、仓库结构和智能体 ID。如果本地已经存在同 UUID 或同路径智能体，界面会提示你选择覆盖、跳过或保留现有内容。

## 更新和卸载

### 更新

系统会自动检测已安装智能体的可用更新：

- 启动时自动检查
- 市场卡片的图标角标提示可用更新，并提供「更新」操作
- 点击"更新"按钮查看变更日志后确认更新

:::info 有本地修改时
更新会检查本地修改。需要处理的差异或冲突会显示在界面中；请查看后再选择保留本地、采用远端或手动合并。涉及重要配置时，可先通过 [版本管理](./08-version-control.md) 查看历史或导出备份。
:::

如果本地修改和远端更新冲突，系统会进入冲突解决流程，而不是直接覆盖你的文件。详见 [版本管理](./08-version-control.md)。

### 为什么显示「更新已暂停」

从市场安装、内容来自发布者仓库的智能体，会更新到市场当前审核通过的版本。发布者仓库出现新提交后，仍需等市场审核和收录该版本。

目录暂不可用、条目不可获取或版本校验不一致时，界面会显示「更新已暂停」及原因。暂停不表示已是最新版本：请按提示恢复来源或升级客户端，再检查更新。

### 卸载

1. 在市场中找到已安装的智能体，打开「更多操作」菜单
2. 选择"卸载"
3. 可选择是否保留配置文件
4. 确认后完成卸载
