# 智能体如何记住你

DesireCore 会把经你审阅的偏好和经验保存为记忆，供后续对话参考。聊天记录保存逐条消息；记忆保存从对话中整理出的信息。经你确认的信息积累下来，智能体也会更了解你的偏好和背景。就像下次联系熟悉的客服时，不必重新介绍每个细节。

## 记忆 vs 聊天记录

| | 聊天记录 | 记忆 |
|---|---|---|
| 保存内容 | 对话中的消息 | 从对话整理出的偏好、事实和经验 |
| 使用方式 | 延续当前对话 | 在后续对话中检索并参考 |
| 管理方式 | 按会话查看 | 可逐条查看、编辑、固定或删除 |

可以把聊天记录看作录像，把记忆看作从中整理出的个人笔记。

## 记忆从哪里来

每次对话结束后，系统会自动复盘，整理本次交流中的信息并生成待审阅的记忆：

1. **对话结束** — 你和智能体完成一次交流
2. **自动复盘** — 智能体分析本次对话，提取有价值的信息
3. **生成候选记忆** — 系统生成若干条候选记忆条目
4. **你来审阅** — 你可以接受、拒绝或编辑这些条目
5. **正式记忆** — 通过审阅的条目写入智能体的记忆库

:::tip 你始终掌控
智能体不会偷偷记住什么。每一条新记忆都会经过你的审阅，你可以随时查看、修改或删除任何记忆。
:::

## 记忆如何影响智能体

你接受的记忆可能会在之后的对话中被检索和引用，例如：

- **回应风格**：参考你偏好的简洁或详细程度
- **项目背景**：回顾已保存的项目情况
- **截止日期**：在合适的后续对话中提醒你之前提到的日期
- **历史决定**：查找之前保存的选择或结论

例如，你告诉法律顾问自己是科技公司的 CTO，并接受了这条记忆；之后讨论相关问题时，智能体可以参考这项信息。

## 手动多会话中的记忆范围

在手动多会话模式下，自动注入的会话摘要和活跃话题以当前会话为范围。同一智能体的其他会话，即使属于同一个项目，也不会被直接当作当前正在讨论的内容。需要参考另一段历史时，可以明确让智能体回顾那次对话；原始历史仍会保留，这个范围限制不等于删除历史或隔离全部长期记忆。

## 记忆的三个域

三域记忆模型把信息放在不同范围中。可以把它理解成大脑里的几类记忆：

- **核心记忆**：智能体自带的专业知识和规则，类似它的基础认知
- **关系记忆**：用户与某个智能体互动中整理的信息，像双方往来的个人笔记
- **共享记忆**：多个智能体都能参考的信息，像团队共用的手册

## 系统如何整理记忆

随着时间推移，系统会像人的记忆一样整理条目，减少旧信息干扰：

- 经常使用的记忆会优先检索。
- 久未使用的记忆可能被压缩归档。
- 不再相关的记忆可能被清理。

### 固定一条记忆
如果某条记忆对你特别重要，可以将它标记为“固定”（Pin），避免系统自动清理。你仍可在记忆管理页取消固定、编辑或删除它。
