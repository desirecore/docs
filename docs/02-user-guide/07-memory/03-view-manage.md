# 查看与管理记忆

智能体的记忆完全透明可控。你随时可以查看智能体记住了什么，修改不准确的内容，或删除不再需要的记忆。

## 进入记忆管理

你可以通过以下方式访问智能体的记忆：

1. 打开智能体详情页
2. 切换到**记忆**标签页
3. 你会看到按域分类的记忆列表

记忆管理界面展示三个域的内容：

- **关系记忆** — 你和这个智能体之间的互动经验
- **共享记忆** — 跨智能体共享的知识
- **核心记忆** — 智能体的出厂知识（通常为只读）

## 查看记忆内容

每条记忆包含以下信息：

- **内容摘要** — 记忆的核心要点
- **类型标签** — preference / fact / decision / commitment / milestone / lesson
- **重要性评分** — 系统根据内容自动评定的重要程度
- **创建时间** — 记忆的生成时间
- **来源会话** — 这条记忆是从哪次对话中提炼出来的

:::tip 追溯来源
点击"来源会话"链接，可以回到产生这条记忆的原始对话上下文，了解完整的讨论背景。
:::

## 搜索记忆

当记忆条目较多时，你可以使用搜索功能快速定位：

**自然语言搜索** — 在搜索框中输入你想查找的内容：

- "关于报告格式的偏好"
- "项目 Alpha 的决策"
- "上次讨论的技术方案"

系统会在所有域中进行语义搜索，返回最相关的结果。高置信度的记忆会优先展示。

**按类型筛选** — 搜索框下方提供类型过滤器：

| 类型 | 含义 | 示例 |
|------|------|------|
| `fact` | 客观事实 | "用户在北京工作" |
| `preference` | 主观偏好 | "喜欢简洁的代码风格" |
| `decision` | 已做决策 | "后端选用 Go 语言" |
| `commitment` | 已承诺事项 | "下周三前交付初稿" |
| `milestone` | 重要事件 | "v2.0 正式上线" |
| `lesson` | 经验教训 | "周五下午不宜做重大部署" |

**按时间排序** — 支持按创建时间正序/倒序排列，方便查看最近的记忆变化。

**按域过滤** — 可以只看关系记忆、共享记忆或核心记忆中的某一个域。

## 编辑记忆

如果发现某条记忆不够准确，你可以直接编辑：

1. 找到需要编辑的记忆条目
2. 点击编辑按钮
3. 修改记忆内容
4. 保存修改

:::info 哪些可以编辑
你可以编辑**关系记忆**和**共享记忆**中的内容。核心记忆由智能体开发者定义，通常不支持用户编辑。
:::

## 删除记忆

如果某条记忆不再需要或你不希望智能体记住：

1. 找到要删除的记忆条目
2. 点击删除按钮
3. 确认删除

删除后，这条记忆将不再影响智能体的行为。

:::warning 删除不可撤销
删除记忆后，智能体将无法再引用这条信息。请确认你不再需要它。不过，记忆的历史记录仍保留在版本控制中，技术上可以恢复。
:::

## 标记重要记忆

对于特别重要的记忆，你可以将其标记为**固定（Pin）**：

1. 找到重要的记忆条目
2. 点击固定/置顶按钮（📌 图标）
3. 该记忆将获得"永不遗忘"保护

被固定的记忆不会因自动遗忘机制而被压缩或清理。适合用于：

- 关键的业务决策
- 重要的个人偏好
- 不能遗忘的承诺和约定

**取消固定（Unpin）：**

当某条记忆不再需要"永不遗忘"保护时：

1. 找到已固定的记忆（带有 📌 标记）
2. 再次点击固定按钮即可取消
3. 取消后，该记忆恢复正常的生命周期管理

:::tip 固定数量建议
固定记忆会始终占据智能体的上下文窗口。建议只固定真正关键的 5–10 条，避免过多固定导致上下文拥挤。
:::

## 批量管理

当需要整理大量记忆时，可以使用批量操作：

1. 点击列表顶部的「批量选择」开关
2. 勾选需要操作的记忆条目（或点击「全选」）
3. 底部工具栏出现批量操作按钮：
   - **批量删除** — 一次性清理多条过时记忆
   - **批量固定** — 将一组相关记忆设为重要
   - **批量取消固定** — 释放不再需要保护的条目

**典型整理场景：**

- 项目结束后，批量删除该项目的临时决策记忆
- 年初整理时，把过时的偏好和承诺清理掉
- 将一组核心业务规则批量固定

## 审阅候选记忆

每次对话结束后，系统可能会生成候选记忆供你审阅：

1. 对话结束时，界面底部弹出记忆审阅面板
2. 每条候选记忆显示：
   - 记忆内容预览
   - 建议写入的域
   - 记忆类型和重要性评分
3. 你可以对每条候选记忆进行操作：
   - **接受** — 确认记录这条记忆
   - **编辑后接受** — 修改内容再记录
   - **拒绝** — 不记录这条信息

:::tip 批量操作
如果候选记忆较多，你可以使用"全部接受"或"全部拒绝"来快速处理。
:::
