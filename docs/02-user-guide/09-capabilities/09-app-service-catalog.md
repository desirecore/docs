# 应用与服务目录

在应用与服务目录中，你可以安装应用、查看安装记录、管理服务运行状态，并处理待审批请求。

## 目录里有什么

| 条目 | 说明 |
|------|------|
| 应用 | 可安装的第三方能力包或集成入口 |
| 服务 | 应用安装后注册出的 MCP、HTTP 或本地服务 |
| 待审批项 | 服务注册、调用、提权或测试连接时需要你确认的请求 |
| 安装记录 | 已安装、失败、运行中、已停止、可更新等状态 |

## 安装流程

1. 在市场或应用目录中打开应用详情。
2. 点击「安装」，选择目标设备。
3. 等待核心智能体执行安装，查看进度。
4. 完成后，核对目录中的安装记录，确认来源和设备。

应用安装和更新由智能体执行。任务取消、发送失败或智能体中断时，请先核对安装记录，再决定是否重试。

部分应用会提供服务，安装后系统会自动发现并注册。需要权限的服务会进入待审批面板；审批通过后，智能体才能调用。并非每个应用都会提供服务。

安装完成后，打开条目详情查看可用操作，例如启动、停止、重启或更新。

安装失败时，打开详情查看原因和日志。界面提供「重试」时，再决定是否重新安装。

## 服务审批

服务请求访问资源或执行操作时，会显示待审批项。打开请求详情，核对来源和权限，再决定是否批准。

| 请求 | 你需要核对什么 | 风险等级 |
|----------|----------|----------|
| 注册服务 | 应用要连接哪个服务、用途是什么 | 低 |
| 调用外部接口 | 要访问哪个第三方服务 | 中 |
| 访问本地文件或端口 | 要读取或修改哪些本地资源 | 中 |
| 申请更高权限 | 为什么需要额外权限，影响哪些操作 | 高 |
| 健康检查 | 服务会检查什么状态 | 低 |

你可以查看详情、批准或拒绝请求。需要授权的服务在你批准前不能供智能体使用。

:::tip 批量审批
如果你信任某个应用的全部服务，可以在审批面板中选择「信任此应用」，后续该应用的新服务注册将自动通过。
:::

## 状态与排障

常见状态包括：

| 状态 | 含义 | 下一步 |
|------|------|------|
| Installed | 已安装，不一定正在运行 | 打开详情查看可用操作 |
| Running | 服务正在运行 | 不可调用时检查审批和健康状态 |
| Stopped | 已停止 | 需要使用时，在详情中查看启动操作 |
| Failed | 安装或启动失败 | 查看错误摘要和日志，再决定是否重试 |
| Update available | 有可用更新 | 打开详情，选择「更新」 |
| Pending approval | 等待你审批 | 前往待审批面板查看并处理请求 |

## 常见问题

**Q: 服务显示 Running 但智能体说无法调用？**

检查该服务是否已通过审批。未审批的服务虽然进程在运行，但智能体无法访问其能力。前往审批面板查看是否有待处理项。

**Q: 为什么同一个应用有多条安装记录？**

安装记录按来源和目标设备分别管理。请在详情中核对这两项，再对正确的实例执行更新或卸载。

**Q: 卸载应用会影响已产生的数据吗？**

卸载应用会停止其派生服务。确认前请查看对话框列出的影响：关联的智能体会失去该应用入口，智能体及其数据会保留。若需要清理其他本地文件，请按应用说明处理。
