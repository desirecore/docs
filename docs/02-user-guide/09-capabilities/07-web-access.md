# Web Access

Web Access v2 让智能体在需要时使用受控浏览器访问网页。它适合普通网页抓取无法覆盖的场景：动态页面、需要登录的后台、复杂表单、单页应用、内网系统和需要截图验证的页面。

## 启用方式

Web Access 是 Skill-scoped 能力，默认不会暴露给所有智能体。启用步骤：

1. 打开左侧导航栏 → **智能体** → 选择目标智能体
2. 进入「技能」标签页
3. 搜索并启用 **web-access**（联网访问）技能
4. 启用后，该智能体的工具列表将新增浏览器控制、CDP 代理、站点经验和本地书签相关工具

:::tip 为什么是技能级别控制？
这种设计可以避免普通任务误用浏览器工具。只有你明确启用了 web-access 技能的智能体，才可能在任务中操作浏览器——你始终清楚哪个智能体拥有这项能力。
:::

启用后，你可以直接在对话中让智能体访问网页，例如：

> "帮我登录公司 OA 后台，查看本周未审批的报销单"
> "打开 Jira 看板，截图当前 Sprint 进度"

## 能做什么

| 能力 | 说明 |
|------|------|
| 标签页控制 | 打开、列出、切换和关闭浏览器标签页 |
| 页面操作 | 点击、滚动、输入、选择元素 |
| 截图观察 | 截取页面或元素状态，辅助视觉判断 |
| CDP 代理 | 通过 Chrome DevTools Protocol 读取更细的页面状态 |
| 文件上传 | 在需要时选择本地文件上传，通常需要确认 |
| 本地书签 | 查询 Chrome / Edge 等浏览器的书签和历史线索 |
| 站点经验 | 记录某个站点的登录入口、选择器、操作路径和注意事项 |

## SitePattern

SitePattern 是站点经验记录。它帮助智能体记住某个网站如何使用，例如：

- 登录入口和常见跳转
- 搜索框、筛选器、导出按钮的位置
- 常见错误和弹窗处理方式
- 哪些页面需要等待动态加载

写入站点经验前会进行校验，避免把无效或过度宽泛的规则保存下来。

### SitePattern 实际用例

**场景 1：公司内网 ERP 系统**

当智能体第一次成功操作某 ERP 系统后，会自动记录经验：

```
站点：erp.internal.company.com
- 登录入口：/login（SSO 跳转后回到 /dashboard）
- 采购单列表：侧栏 → 采购管理 → 采购订单 → 全部
- 导出按钮在列表右上角，class="btn-export"
- 表格加载约需 3 秒，需等待 .table-body tr 出现
- 常见弹窗："会话超时"→ 点击"重新登录"按钮
```

下次再访问时，智能体无需重新摸索路径。

**场景 2：SaaS 后台定期截图**

```
站点：analytics.saas.com
- 登录后默认在 Overview 页
- 周报入口：顶部 Tab → Reports → Weekly
- 日期选择器需先点击 input，再选 .calendar-grid 中的日期
- "Generate PDF" 按钮需等数据加载完（.loading-spinner 消失）
```

:::tip
你也可以主动告诉智能体："记住这个网站的操作方式"，它会将你的描述整理为 SitePattern 保存。
:::

## LocalBookmarks

LocalBookmarks 可以从本机浏览器书签和历史中寻找 URL 线索。它不会自动登录网站，也不会绕过权限；只是帮助智能体找到你常用系统的入口。

## 安全边界

- 默认只允许 `http` 和 `https` URL
- 上传文件、提交表单、删除或发布内容等有外部影响的操作会触发审批
- 浏览器会尽量隔离会话标签页，避免不同任务互相污染
- 截图和页面内容会进入当前任务上下文，请避免在敏感页面开启无关任务

## 与 WebFetch / WebSearch 的关系

DesireCore 提供三种联网能力，适用于不同场景：

| 工具 | 适用场景 | 是否需要浏览器 | 典型延迟 |
|------|----------|:---:|------|
| `WebSearch` | 查找公开信息、新闻、技术文档 | ❌ | 1–3 秒 |
| `WebFetch` | 读取已知 URL 的静态正文内容 | ❌ | 2–5 秒 |
| Web Access | 操作动态页面、登录态后台、SPA | ✅ | 5–30 秒 |

### 如何选择

```
需要获取网页信息？
├─ 不知道具体 URL → WebSearch（搜索关键词）
├─ 已知 URL，内容是静态的 → WebFetch（直接抓取正文）
└─ 页面需要登录 / 是 SPA / 需要点击操作 → Web Access（打开浏览器）
```

**原则：能用轻量工具解决的，不启动浏览器。** Web Access 消耗更多资源且速度较慢，只在必要时使用。

### 典型使用场景

| 场景 | 推荐工具 | 原因 |
|------|----------|------|
| 查找某框架的最新版本号 | WebSearch | 公开信息，搜索即可 |
| 读取一篇博客文章内容 | WebFetch | 静态页面，直接抓取 |
| 登录公司 OA 审批流程 | Web Access | 需要登录态 + 表单交互 |
| 截取 SPA 仪表盘数据 | Web Access | 动态渲染，需等待 JS 执行 |
| 在内网 Wiki 搜索并编辑文档 | Web Access | 登录 + 动态加载 + 写入操作 |
| 下载公开 PDF 白皮书 | WebFetch | 直接 URL，无需浏览器 |
