# 媒体生成

DesireCore 可以通过已配置的媒体 provider 生成图片、视频，并对已有图片做美化或修复。媒体生成通常由技能或智能体在合适的任务中调用。

## 前置条件

你需要在「设置 > 算力服务」中启用支持对应服务类型的 provider：

| 服务类型 | 用途 |
|----------|------|
| `image_gen` | 文生图、图生图、多图融合 |
| `video_gen` | 文生视频、图生视频、首尾帧视频 |
| `image_understanding` / `ocr` | 生成后复核、图片理解 |

官方云端算力、第三方 API Key 和自定义 OpenAI-compatible provider 都可以作为来源，具体取决于供应商能力。

## GenerateImage

`GenerateImage` 用于生成或编辑图片。常见能力包括：

- 根据文本提示词生成图片
- 使用一张或多张参考图生成新图
- 调整风格、构图、尺寸和细节
- 自动保存输出并在聊天中展示

### 支持的供应商与模型

| 供应商 | 模型 | 特色 | 适用场景 |
|--------|------|------|----------|
| MiniMax | image-01 / image-01-live | 单主体一致性好，支持画风预设 | 角色设计、品牌素材、风格化插画 |
| Volcengine（火山引擎） | Seedream 4.0 | 真正的图生图 / 多图融合，最多 10 张参考 | 产品合成、多元素组合、局部重绘 |
| DashScope（阿里云） | wan2.7-image | 中文理解优秀 | 中文场景描述、国风素材 |
| DesireCore Cloud | 官方云算力（多模型路由） | 自动选择最优模型 | 通用文生图，无需自行配置 Key |
| new-api | OpenAI images 兼容 | 自定义渠道路由 | 企业私有部署 |

### 关键参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `prompt` | 图片描述文本（必填） | — |
| `image` / `images` | 参考图（dc-media:// / 路径 / URL / base64） | 无 |
| `aspect_ratio` | 宽高比（1:1, 16:9, 9:16, 4:3, 3:4 等） | 1:1 |
| `size` | 输出尺寸（1K / 2K / 4K），Seedream 用 | 2K |
| `n` | 生成数量（1–9） | 1 |
| `style` | MiniMax 画风（漫画/元气/中世纪/水彩） | 无 |
| `provider` | 指定供应商 | 按已配置服务自动选择 |

### 使用示例

**文生图：**
> "帮我生成一张赛博朋克风格的城市夜景，霓虹灯映照在雨后的街道上"

**图生图（风格转换）：**
> "把这张照片转成吉卜力动画风格"（附带一张参考图）

**多图融合：**
> "把这三张产品图融合成一张宣传海报"（附带多张参考图）

**指定画风：**
> "用漫画风格画一只在书房看书的橘猫"

## GenerateVideo

`GenerateVideo` 用于生成视频。常见能力包括：

- 文生视频
- 以图片作为首帧或参考素材生成视频
- 使用首尾帧约束镜头变化
- 多图主体参考生成（保持角色/物体一致性）
- 参考视频/音频风格迁移
- 输出后作为媒体文件附加到对话

### 支持的供应商与模型

| 供应商 | 模型 | 特色 |
|--------|------|------|
| MiniMax | Hailuo-02 / S2V | 首尾帧控制、多图主体参考 |
| Volcengine | Seedance | 多图 + 首尾帧 + 参考视频/音频 |
| DashScope | 快乐马 happyhorse-1.1 | i2v 首帧 / r2v 多图参考 |
| DesireCore Cloud | 多模型（快乐马、Seedance 等） | 官方云算力，自动路由 |
| new-api | OpenAI Video 兼容 | 自定义渠道路由 |

### 关键参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `prompt` | 视频描述文本（必填） | — |
| `first_frame` | 首帧图片 | 无 |
| `last_frame` | 尾帧图片（仅部分模型支持） | 无 |
| `images` | 多图参考（≤9 张） | 无 |
| `reference_videos` | 运镜/风格参考视频（≤3） | 无 |
| `reference_audios` | 音轨参考（≤3） | 无 |
| `duration` | 时长（秒） | 按模型默认 |
| `aspect_ratio` | 宽高比（16:9 / 9:16 / 1:1） | 16:9 |
| `resolution` | 分辨率（720P / 1080P） | 按模型默认 |

### 使用示例

**文生视频：**
> "生成一段 5 秒的视频：一只金色拉布拉多在夕阳下的海滩奔跑，慢镜头"

**图生视频（首帧驱动）：**
> "以这张风景照为起始，生成镜头缓慢推进的视频"（附带首帧图）

**首尾帧约束：**
> "从白天过渡到夜晚，首帧是白天的城市，尾帧是同一城市的夜景"（附带两张图）

:::note 异步生成
视频生成通常需要 1–5 分钟。提交后系统会后台处理，完成后自动在对话中展示视频。
:::

## BeautifyImage

`BeautifyImage` 用于优化已有图片，例如：

- 图片居中和裁切
- 去除多余边框
- 质量增强或尺寸调整
- 输出体积保护，避免生成异常大文件

## 审批与费用

媒体生成可能消耗 API 额度或账号 credit。涉及付费 provider、上传参考素材或写入本地文件时，系统会按风险和权限策略请求确认。

## 使用建议

- 需要“看懂图片”时使用视觉模型，而不是图像生成模型
- 需要聊天回复时选择 chat 模型，图像/视频生成模型不会出现在普通对话模型选择器中
- 对正式素材，生成后让智能体用视觉理解工具复核一次，检查文字、构图和明显错误
