# Markdown 与图表渲染

Companion 的回复会以 Markdown 富文本展示。你可以直接阅读标题、列表、表格、代码块、数学公式和图表，也可以把内容复制为纯文本或保留 Markdown 格式。

## 支持的内容

| 内容类型 | 支持方式 |
|----------|----------|
| 标题、列表、引用 | 按 Markdown 结构渲染 |
| 表格 | 自动保持列对齐，窄屏下可横向滚动 |
| 代码块 | 语法高亮，支持一键复制 |
| 数学公式 | 支持行内和块级 KaTeX / LaTeX |
| Mermaid 图表 | 在消息内渲染，可打开全屏预览 |
| 图片附件 | 在消息中展示缩略图，可点击预览 |
| `.md` 文件路径 | 可信助手回复中的本地 Markdown 路径可点击打开 |

## Mermaid 图表

当回复中包含 Mermaid 代码块时，DesireCore 会自动渲染为图表。点击图表可以打开全屏预览：

- 鼠标滚轮缩放
- 拖拽平移画布
- 双击或点击重置按钮恢复适配屏幕
- 关闭预览后回到原对话位置

如果 Mermaid 代码存在语法错误，消息会保留原始代码块，方便你让 Companion 继续修正。

## 数学公式

DesireCore 支持常见 LaTeX 写法：

- 行内公式：`$E = mc^2$`
- 块级公式：`$$\int_a^b f(x) dx$$`

长公式会在气泡内横向滚动，不会撑破消息布局。

## 文件路径和链接

助手回复中的本地 `.md` 文件路径会显示为可点击链接。点击后，DesireCore 会在应用内打开对应文件或跳转到系统文件位置。

:::info 安全边界
路径点击只对可信助手回复中的本地 Markdown 路径启用。普通文本、用户消息和不明确的路径不会自动执行任何操作。
:::

## 复制内容

消息操作栏提供两种复制方式：

| 操作 | 结果 |
|------|------|
| 复制 | 复制适合粘贴到聊天或普通文档的纯文本 |
| 复制 Markdown | 保留标题、列表、代码块、表格和图表源码 |

当你要把回复继续交给其他 Markdown 编辑器处理时，优先使用「复制 Markdown」。

## 渲染效果示例

以下是 Companion 回复中常见的渲染效果。你在聊天区域看到的将是已排版的富文本，而非原始标记。

### 代码块渲染

输入：

````markdown
```python
def hello():
    print("Hello, DesireCore!")
```
````

渲染效果：带有语法高亮的代码区域，右上角有「复制」按钮，点击即可复制代码内容。支持 Python、JavaScript、TypeScript、Bash、JSON、YAML 等主流语言的语法高亮。

### 表格渲染

Markdown 表格会自动对齐列宽。当表格较宽时（如超过 5 列），气泡内会出现横向滚动条，不影响整体消息布局。

### Mermaid 图表示例

输入：

````markdown
```mermaid
graph LR
    A[用户提问] --> B[Companion 分析]
    B --> C[调用工具]
    C --> D[生成回复]
```
````

渲染效果：在消息气泡内直接显示流程图。点击图表可进入全屏预览模式，支持缩放和平移。

### 数学公式示例

输入 `$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$` 会在消息中渲染为排版整齐的数学公式。块级公式（`$$...$$`）会独占一行居中显示。

## 渲染异常处理

| 情况 | 表现 | 处理方式 |
|------|------|----------|
| Mermaid 语法错误 | 显示原始代码块 | 让 Companion 修正语法 |
| 公式格式不支持 | 显示原始 LaTeX 文本 | 改用 KaTeX 支持的语法 |
| 图片加载失败 | 显示占位图标 | 检查文件路径是否有效 |
| 超长代码块 | 气泡内纵向滚动 | 点击复制后在编辑器查看 |

:::tip 获取最佳渲染效果
如果 Companion 的回复格式不理想，可以明确要求它"用 Markdown 表格/代码块/Mermaid 图表重新组织回复"。Companion 会根据你的偏好调整输出格式。
:::
