# 管理对话

DesireCore 的对话以 Companion 为单位组织。在手动多会话模式下，同一个 Companion 可以拥有多个独立会话，并按 Project（项目）组织；先选择智能体，再在会话列中切换具体会话。

## 对话列表

左侧面板（宽度 290px）展示你所有的对话列表。

### 列表结构

对话列表按 Companion 类型分为两个区域：

- **通用 Companion** --- 位于列表顶部，无分组标题。如 DesireCore 通用助手
- **专业 Companion** --- 位于「专业 Agent」分隔标题下方。如法律助手、房产顾问等

### 对话项信息

每个对话项显示：

- Companion 头像（通用为圆形，专业为圆角方形）
- Companion 名称
- 最后一条消息的预览
- 最后消息的时间
- 未读消息角标（红色圆形，显示未读数）

### 切换对话

点击对话列表中的某一项即可切换到该 Companion 的对话。切换时：

- 右侧聊天面板内容自动更新
- 目标对话的未读计数清零
- 消息列表自动滚动到底部
- 消息使用 `fadeUp` 动画依次入场

## 新建对话

在对话列表头部点击「+」按钮可新建对话。新建对话后会自动切换到该对话窗口。

:::info
自动会话模式与手动多会话模式的列表组织不同。手动模式下，请按下文的「新建和整理会话」操作。
:::

## 手动多会话与 Project

### 新建和整理会话

1. 选择智能体，在它的会话列中找到 Project（项目）。
2. 从 Project 行新建会话，或通过项目选择器选择项目；不需要项目时选择「不在项目里工作」。
3. 发送首条消息后，空白草稿会保存为会话。

会话支持重命名、置顶、移动到项目和归档。需要恢复时，打开「已归档会话」并选择「恢复」。列表可按项目分组或显示为一个列表，并按创建时间、最近更新或手动顺序整理。

### 设置项目工作目录

Project 可包含多个工作目录。将其中一个设为首选工作目录后，该项目下的本地会话会使用它执行任务。在工作目录菜单中更改项目主路径，会影响该项目下的本地会话。

Project 也可以不绑定目录。如果当前会话提示项目无目录、目录不可用或项目已移除，请补齐目录、将会话移动到其他项目，或解除项目绑定，再使用目录能力或新建终端。

### 管理项目与删除会话

打开 Project 行的菜单，可编辑、置顶项目，在系统文件管理器中显示首选目录，归档项目下的聊天，或移除项目。

| 操作 | 结果 |
|---|---|
| 归档会话 | 可从「已归档会话」恢复 |
| 移除项目 | 保留磁盘目录和已有会话；受影响会话需调整绑定后才能继续使用目录能力 |
| 删除绑定 worktree 的会话 | 先选择保留或删除工作树；可选择备份聊天记录 |

## 清除对话历史

如果你想清除与某个 Companion 的所有对话记录：

1. 在聊天头部点击「更多」按钮（三个圆点图标）
2. 在弹出菜单中选择「清除聊天记录」
3. 确认后，该 Companion 的所有历史消息将被清除

:::warning
清除聊天记录是不可逆操作。清除后无法恢复历史消息，但 Companion 学到的知识（Playbook）不受影响。
:::

## 上下文管理

不要把「清除聊天记录」当作日常上下文管理手段。较新的 DesireCore 提供了更温和的方式：

| 操作 | 作用 | 是否保留可见历史 |
|------|------|------------------|
| `/new` | 开启新的上下文边界，适合换话题 | 是 |
| `/compact` | 手动压缩旧上下文，适合长任务 | 是 |
| 自动压缩 | 上下文接近上限时后台整理 | 是 |
| Rewind | 回到某条用户消息前的检查点 | 保留旧分支 |
| 清除聊天记录 | 删除当前 Companion 的历史消息 | 否 |

详见 [上下文控制](./09-context-control.md) 和 [Rewind 与 Checkpoint](./10-rewind-checkpoints.md)。

## 删除智能体及其对话

如果你想彻底删除一个 Companion 及其对话：

1. 在聊天头部点击「更多」按钮
2. 选择「删除智能体」
3. 可以选择是否同时删除运行记录
4. 确认后，该 Companion 和对话将从列表中移除

## 对话上下文

DesireCore 的对话支持跨会话的上下文延续：

- 重新打开同一会话会恢复其历史；手动模式中的不同会话分别维护上下文
- Companion 可以引用之前的对话内容和学习成果
- 每个会话（Session）有独立的 Run ID，但共享 Companion 的长期记忆

### 话题恢复

如果 Companion 之前在处理某个话题（Matter），你可以通过运行状态面板查看未完成的话题，并选择恢复继续处理。

## 在线状态

对话列表中每个 Companion 旁边会显示在线状态指示：

| 状态 | 指示 | 含义 |
|------|------|------|
| 在线 | 绿色圆点 + 呼吸动画 | Companion 已启动，随时可以交互 |
| 工作中 | 橙色圆点 | Companion 正在执行任务 |
| 离线 | 灰色圆点 | Companion 未启动 |

如果 Companion 处于离线状态，在聊天头部会显示开机按钮，点击即可启动。
