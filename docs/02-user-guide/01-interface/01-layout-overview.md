# 主界面布局

DesireCore 采用**单窗口三栏布局**，所有功能都在一个窗口内完成，无需在多个窗口之间切换。

对话界面展开右侧工具工作区后，面板顶部会显示一排**工作区标签**。每个标签对应一个文件、终端、网页或审阅页面；点击标签即可切换，也可以新建或关闭标签。它们与左侧的“对话、资源、应用”等功能导航不同：功能导航切换模块，工作区标签切换当前对话里的资源。

## 三栏职责

### 左侧：导航栏（NavRail）

宽度固定为 **62px**，是整个应用的功能入口。从上到下依次排列着 Logo、功能导航按钮和底部工具区。详见[左侧导航栏](./02-navigation-rail.md)。

### 中间：内容列表区

默认宽度 **290px**，根据当前所在的功能模块显示不同内容：

| 导航 Tab | 中间栏显示内容 |
|----------|--------------|
| 对话 | 对话列表（按智能体分组） |
| 关系 | 智能体/联系人关系图 |
| 资源 | 资源管理器 |
| 应用 | 已安装应用列表 |
| 市场 | 智能体/技能市场 |
| 活动 | 活动记录时间线 |

当你处于"对话"Tab 时，这里显示的就是你和所有智能体的对话列表。

### 右侧：主内容区

占据窗口剩余空间，是你的主工作区域。在对话模式下，这里是聊天区域；切换到其他 Tab 时，会显示对应功能的完整界面。

在对话模式下，右侧工具工作区展开为聊天区旁的面板，面板顶部显示资源标签。打开文件、终端、网页或审阅时，会出现对应的标签；点击标签切换资源，关闭标签时按资源类型处理尚未保存或仍在运行的内容。工作区标签会随会话恢复，重新打开会话时可继续访问已登记的资源。

## 文件工作区

打开文件标签后，在内容区点击「文件操作」浮动按钮，查看当前格式支持的操作。Markdown、超级文书、代码、PDF 和画板使用同一入口，具体编辑和预览能力因格式而异。

| 需要做什么 | 操作或界面表现 |
|---|---|
| 查看文档目录、任务关联或文件动作 | 打开「文件操作」，选择当前格式提供的操作 |
| 定位文档章节 | 展开默认收起的目录 |
| 翻阅 PDF | 使用预览中的分页导航 |
| 用键盘操作菜单 | 聚焦入口并打开菜单；关闭后焦点返回入口 |
| 在窄面板中切换标签 | 当前标签会自动滚动到可见位置；文件操作不占用标签栏宽度 |

### 终端接回后的输出提示

应用重启后接回终端，如果离线期间的输出超出保留上限，当前终端标签会显示「接回时有输出被省略」，并注明省略的字节数。此时回放的内容不完整。查看提示后，可点击「知道了」关闭。

## 响应式行为

DesireCore 会根据窗口大小自动调整布局：

- **导航栏**始终保持 62px 宽度
- **对话列表**在窗口较窄时可以折叠
- **聊天区域**自适应剩余宽度
- 窗口最小尺寸为 **960 x 640 像素**
- 聊天头部在窗口宽度不足 640px 时进入紧凑模式（compact mode），部分按钮会收入"更多"菜单

:::info 翻转视图
在对话界面中，点击头部的"沉浸式交互"按钮可以翻转到数字人界面（Digital Human），这是一个独立的 3D 交互视图。翻转动画约 1 秒，背景色会随之切换。详见[数字人界面](./05-digital-avatar.md)。
:::

## 设计风格

DesireCore 的界面采用 **Liquid Glass** 设计语言，你会注意到以下视觉特征：

- **半透明玻璃材质**：面板和卡片带有高斯模糊效果，背景色彩隐约可见
- **精细边框**：面板之间使用 0.5px 的细分隔线
- **高光反射**：部分元素顶部有微妙的光泽效果
- **柔和阴影**：多层阴影营造出悬浮感
