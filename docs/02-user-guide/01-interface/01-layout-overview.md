# 主界面布局

DesireCore 主窗口为**单窗口四区布局**：左侧窄导航栏、中间智能体/对话列表、右侧主聊天区，以及窗口最底部的状态栏。日常发任务、看回复都在「对话」模式中完成，无需另开窗口。

![DesireCore 对话模式主界面：左导航、中间列表、右侧聊天与底栏](/img/user-guide/interface/main-layout-chat.png)

对话界面若展开右侧工具工作区，面板顶部会出现一排**工作区标签**（文件、终端、网页、审阅等）。点击标签可切换当前对话里的资源。它们与左侧**功能导航**不同：功能导航切换模块，工作区标签切换本会话内的资源。

## 分区一览

| 区域 | 对话模式下的作用 |
|------|------------------|
| 左侧导航栏 | 切换功能模块（当前为「对话」）；底部有通知、设置等入口 |
| 中间列表 | 搜索与选择智能体 / 对话；常见「专业 Agent」等分组 |
| 右侧主区 | 聊天头部、消息流、输入区；可展开文件等工作区 |
| 底栏 | 终端入口、常用快捷键提示、后台任务状态 |

中间栏可折叠；左侧导航栏保持较窄的固定宽度；右侧主区随窗口剩余宽度自适应。各模块入口细节见 [左侧导航栏](./02-navigation-rail.md) 与 [功能入口与操作路径](./07-feature-entry.md)。

## 左侧：导航栏

窗口最左侧是一列图标导航：顶部为头像与模块入口，其中**对话**（气泡）在对话模式下高亮；中段为其他功能入口；底部常见通知铃铛（可带未读角标）与设置等。

点击左侧其他入口会更换中间栏与右侧主区内容；具体按钮名称与路径以实机为准，见 [左侧导航栏](./02-navigation-rail.md)、[功能入口](./07-feature-entry.md)。通知见 [通知中心](./06-notifications.md)。

## 中间：智能体 / 对话列表

**对话模式下，中间栏是智能体与对话列表**，不是旧版文档中的「关系 / 资源 / 应用 / 市场 / 活动」矩阵。

典型结构：

- 顶部：搜索框、「+」新建、列表折叠/展开控件
- 列表：近期对话（如 DesireCore、通用助手等）
- 分组：**专业 Agent** 等分区下列出专用智能体；每项含名称、最近消息摘要与时间

选中某一智能体后，右侧主区切换到对应聊天。列表交互详见 [对话列表](./03-conversation-list.md)。

## 右侧：聊天主区

### 头部

左侧显示当前智能体名称与在线状态（如「在线」）；右侧常见 **沉浸式交互** 等操作。点击「沉浸式交互」可进入数字人界面，详见 [数字人界面](./05-digital-avatar.md)。

### 消息区

消息流中除普通回复外，还常见：

- **命令执行**折叠条（如「执行了 2 条命令」）
- 附件链接（Markdown / PDF 等）
- **文件编辑卡片**（如「已编辑 1 个文件」），右侧可 **审阅 / 撤销**

消息与卡片说明见 [聊天区域](./04-chat-area.md)。

### 输入区

底部输入区用于发消息与附件，大致包括：

| 控件 | 说明 |
|------|------|
| 文本框 | 占位「输入消息…」；`Enter` 发送，`Shift+Enter` 换行 |
| 附件 / 工具入口 | 「+」、图片等（以实机图标为准） |
| 审批 / 放行 | 如「全部放行 · 无限制」（具体选项随策略变化） |
| 工作目录 | 显示当前目录（路径过长时截断） |
| 模型 | 当前模型名（截图示例为 DeepSeek V4.1） |
| 麦克风 / 发送 | 语音与发送按钮 |

行首输入 `/` 可调出斜杠命令；快捷键提示也在底栏可见。发送与附件细节见 [发送消息](../02-conversations/01-sending-messages.md)。

## 底栏

窗口最底部为状态栏：

- **左侧**：终端入口（「终端」）
- **中部**：快捷键提示，如 `/ 命令`、`Enter` 发送、`Shift+Enter` 换行
- **右侧**：连接与后台状态（如「无后台任务」）

## 文件工作区

打开文件标签后，在内容区使用「文件操作」入口查看当前格式支持的操作。Markdown、超级文书、代码、PDF、画板共用该入口，编辑与预览能力因格式而异。

| 需要做什么 | 操作或界面表现 |
|---|---|
| 查看目录、任务关联或文件动作 | 打开「文件操作」，选当前格式提供的项 |
| 定位文档章节 | 展开默认收起的目录 |
| 翻阅 PDF | 使用预览中的分页导航 |
| 用键盘操作菜单 | 聚焦入口并打开菜单；关闭后焦点返回入口 |
| 在窄面板中切换标签 | 当前标签会滚入可见区；文件操作不占标签栏宽度 |

### 终端接回后的输出提示

应用重启后接回终端，若离线期间输出超出保留上限，当前终端标签会提示「接回时有输出被省略」并注明省略字节数。回放内容可能不完整；确认后可关闭提示。

## 响应式行为

- 左侧导航栏较窄、宽度基本固定
- 中间列表可在窗口变窄时折叠，给主区腾空间
- 右侧聊天区占用剩余宽度
- 窗口过窄时，聊天头部部分按钮可能收入「更多」类菜单

最小可用窗口尺寸与紧凑模式阈值可能随版本调整，以实机为准。
