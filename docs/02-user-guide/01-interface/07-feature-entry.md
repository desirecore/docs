# 功能入口与操作路径

本页只回答一件事：**我想做某件事，该从哪进、最短怎么走。**  
界面分区、按钮说明见 [主界面布局](./01-layout-overview.md) 和 [左侧导航栏](./02-navigation-rail.md)。

左侧主导航（自上而下，文案以实机 / zh-CN 为准）：

| 入口 | 用来做什么 |
| --- | --- |
| 头像（顶部） | 打开个人资料；游客模式提示 |
| 对话 | 选智能体、发任务、看回复 |
| 全局任务板 | 能力开启时固定出现在对话下方（内置应用，非旧「关系」Tab） |
| 资源管理器 | 管理已有智能体、技能、自动化、服务、提示词等 |
| 市场 | 浏览并安装数字员工、团队、技能、应用或服务（插件经「产品类型」筛选） |
| 应用 | 「应用」与「插件」两个页签：打开应用、管理插件（工作区标题为「应用与插件」） |
| 自定义应用钉选 | 主导航中段可钉常用应用；可从「我的应用」拖入 |
| 通知（底部） | 通知中心 |
| 运行中心（底部） | 合并原「活动」与「任务管理器」：任务 / 活动 / 系统 / 诊断 |
| 更多（底部菜单） | 设置、资料 / 登录、钱包与算力（按登录态显示） |

:::note 已迁出主导航的入口
- **智能体社会化关系**（旧称「关系」）：不再是固定 NavRail Tab，而是内置应用「agent-society」，从「应用」或钉选进入。  
- **设置**：不在主导航底部单独齿轮位，而在「更多」菜单中。
:::

## 按任务找入口

| 我想做什么 | 从哪里进入 | 最短路径 |
| --- | --- | --- |
| 和智能体开始对话 | 对话 | 左侧选智能体 → 底部输入 → 发送；见 [发送消息](../02-conversations/01-sending-messages.md) |
| 查找或管理历史对话 | 对话 | 列表或搜索 → 点开对话；归档等见 [管理对话](../02-conversations/06-managing-conversations.md) |
| 调用斜杠命令 | 对话 | 输入框行首输入 `/` → 选命令 → 发送（内置：`/skill` `/new` `/compact` `/reset` `/recall` `/rewind` `/steer` `/subtask` `/help`；另有 `/skill:…` 与 `/技能名`） |
| 切换文件、终端或网页 | 工作区 / 资源 | 对话右侧工作区切标签；或「资源管理器 → 文件」进文件工作台；见 [主界面布局](./01-layout-overview.md) |
| 审阅文档修改 | 文档内容区 | 展开待审阅 → 接受或拒绝；见 [逐条审阅](../05-super-document/04-review-changes.md) |
| 管理智能体 | 资源 | 导航「资源管理器」→ 智能体；见 [智能体](../06-agents/01-agent-types.md) |
| 编辑系统提示词 | 资源 | 资源 → 提示词（全局 / 团队 / 智能体） |
| 导入或配置技能 | 资源 / 市场 | 已有技能：资源 → 技能；获取新技能：市场 → 技能；见 [技能管理](../06-agents/07-skills-management.md) |
| 查看或设置自动化 | 资源 | 资源 → 自动化；见 [自动化](../08-automation/) |
| 管理服务连接与诊断 | 资源 | 资源 → 服务；见 [应用、插件与服务](../09-capabilities/09-app-service-catalog.md) |
| 打开已安装应用 | 应用 | 导航「应用」→「应用」页签 → 打开 |
| 启用或配置插件 | 应用 | 导航「应用」→「插件」页签 → 启停与配置；可用页内市场按钮发现插件 |
| 安装新的应用 / 插件 / 智能体 | 市场 | 导航「市场」→ 选类型（数字员工 / 团队 / 技能 / 应用 / 服务）→ 安装；插件：市场筛「产品类型：插件」或从插件页「市场」按钮进入 |
| 查看执行与后台任务 | 运行中心 | 导航栏底部「运行中心」→ 任务 / 活动 / 系统 / 诊断 |
| 看智能体协作关系 | 应用（内置） | 「应用」中打开「智能体社会化关系」，或钉到主导航 |
| 打开全局任务板 | 主导航 | 能力开启时主导航「全局任务板」；否则从应用能力入口启用 |
| 改主题、模型算力、快捷键等 | 设置 | 导航栏底部「更多」→ 设置 |
| 切换实例 | 实例选择器 / 设置 | 启动时的实例选择器，或设置 → 连接相关项 |

## 对话：发任务与看结果

对话页分三块（与上图对应）：

| 区域 | 作用 |
| --- | --- |
| 左侧列表 | 选智能体或历史对话；可用搜索 |
| 中间记录区 | 看回复、执行过程、结果卡片 |
| 底部输入区 | 发消息、附件、斜杠命令 |

日常路径：左侧选人 → 底部说明任务 → 在记录区看结果；不够就接着补充。  
列表细节见 [对话列表](./03-conversation-list.md)，消息与卡片见 [聊天区域](./04-chat-area.md)。

## 资源：管已经在系统里的东西

点导航「资源管理器」（Boxes 图标）进入资源选择器。这里管的是**已经装好或接好的资源**，不是去商店逛新东西。

常见卡片（名称以界面为准；邮箱 / 对象存储 / 工作流可能受能力或部署开关影响而不显示）：

| 卡片 | 典型用途 |
| --- | --- |
| 智能体 | 查看、进入管理 |
| 提示词 | 全局 / 团队 / 智能体三层系统提示词 |
| 应用 | 已安装应用实例、健康与生命周期 |
| 服务 | MCP / HTTP 等已接入服务与审批 |
| 文件 | 文件工作台（工作目录、编辑与预览） |
| 技能 | 查看、导入、启用、分配 |
| 自动化 | 定时 / Webhook / 心跳 |
| 工作流 | 多步骤流程（部署启用时） |
| 算力 | 模型与算力来源 |
| 账号 | 站点账号与取值授权 |
| 邮箱 | 已连接邮箱（能力开启时） |
| 存储 | 对象存储连接（能力开启时） |
| 代码托管 | 已连接的代码托管 |

![资源管理器示意](/img/user-guide/feature-entry/resource-manager.png)

和「应用 / 市场」怎么分：

| 我要… | 去哪 |
| --- | --- |
| 配置、启用、排查已有资源 | 资源管理器 |
| 打开已装应用，或管插件贡献 | 应用（两个页签；标题「应用与插件」） |
| 发现并安装新能力 | 市场 |

## 应用、插件与市场

- **应用**页签：打开、整理已安装的独立应用。  
- **插件**页签：看接入状态，启用或停用贡献，改配置；可用市场按钮跳转并筛「产品类型：插件」。  
- **市场**：主分类为数字员工、团队、技能、应用、服务；插件不是顶层分类，而是应用类下的产品类型筛选。

安装不等于已授权调用；服务是否可调，仍以资源里的连接、审批和当前智能体权限为准。细则见 [应用、插件与服务](../09-capabilities/09-app-service-catalog.md)。

## 常见问题

| 问题 | 怎么处理 |
| --- | --- |
| 左侧找不到某个智能体 | 先在对话列表搜索；仍没有则到「资源 → 智能体」看是否已创建或启用，或到市场安装 |
| 输入 `/` 没有命令列表 | 确认光标在输入框**行首**再输入 `/`；仍没有可试 `/help`，并以当前版本列表为准 |
| 技能导入后找不到 | 「资源 → 技能」核对是否导入成功、是否启用；对话里也可用 `/skill` 查找 |
| 应用装完不知道从哪打开 | 「应用 → 应用」页签；插件则在「插件」页签；也可钉到主导航 |
| 服务显示在线但智能体调不了 | 在线 ≠ 当前智能体有权；查资源里的服务连接、审批与工具范围 |
| 想装新东西却在资源里找 | 获取走「市场」；资源只管理已有项 |
| 找不到「关系」或「活动」Tab | 「关系」已改为内置应用「智能体社会化关系」；「活动」已并入底部「运行中心」 |
| 找不到设置齿轮 | 底部「更多」→ 设置 |
