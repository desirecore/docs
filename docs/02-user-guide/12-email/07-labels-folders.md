# 标签和文件夹

邮件多了之后，找到特定邮件会越来越难。DesireCore 提供了灵活的标签系统，帮助你分门别类地整理邮件。

## 文件夹

每个邮箱账户都有一组文件夹，在邮件视图的水平标签页中展示。默认显示四个最常用的文件夹：

| 文件夹 | 说明 |
|-------|------|
| 📥 收件箱 | 收到的邮件 |
| 📤 已发送 | 你发出的邮件 |
| 📝 草稿 | 未发送的草稿 |
| 🗑️ 回收站 | 已删除的邮件 |

文件夹结构与邮箱服务商的原生结构对应，添加账户时自动从服务器同步。

## 标签的类型

DesireCore 中有三种标签：

| 标签类型 | 来源 | 说明 |
|---------|------|------|
| **系统标签** | 邮箱服务商 | Gmail 的收件箱、已加星标、重要等，由邮箱自带 |
| **账户标签** | 用户创建 | 绑定在特定邮箱账户下的自定义标签 |
| **全局标签** | 用户创建 | 跨所有邮箱通用的标签，在统一收件箱中特别有用 |

## 创建和管理标签

### 创建标签

你可以在标签管理中创建新标签，设置：

- **标签名称** — 如「待回复」、「项目 A」、「重要客户」
- **颜色** — 从 10 种预设颜色中选择（红、橙、黄、绿、青、蓝、靛、紫、粉、灰）
- **范围** — 仅当前邮箱，或全局通用
- **可见性** — 是否在标签列表中显示
- **排序权重** — 调整在列表中的显示顺序

### 编辑和删除标签

你可以随时修改标签的名称、颜色和排序。删除标签不会删除邮件本身——邮件只是不再带有这个标签。

## 为邮件添加标签

在邮件预览面板的工具栏中，有标签/分类下拉菜单：

- **Gmail 账户** — 显示标签多选器，可以为邮件勾选多个标签
- **Outlook 账户** — 显示分类选择器，功能与标签类似
- **IMAP 账户** — 不支持标签操作

一封邮件可以同时带有多个标签。

## 标签同步

标签数据需要在本地和邮箱服务器之间保持同步。不同邮箱的同步机制有差异：

### Gmail 标签

| 方向 | 说明 |
|------|------|
| 服务器 → 本地 | 添加账户时自动拉取所有标签；每次邮件同步时增量更新 |
| 本地 → 服务器 | 在 DesireCore 中新建/重命名/删除标签，即时同步回 Gmail |
| 冲突处理 | 服务器侧优先——如果你在 Gmail 网页端删除了标签，下次同步后本地也会移除 |

**同步时机：**
- 添加账户时：全量同步
- 每次邮件同步时：增量同步（只处理变化的标签）
- 手动触发：标签管理页面 → 「同步标签」按钮

### Outlook 分类

| 方向 | 说明 |
|------|------|
| 服务器 → 本地 | 添加账户时拉取所有分类（Categories） |
| 本地 → 服务器 | 在 DesireCore 中为邮件添加/移除分类，同步回 Outlook |
| 限制 | Outlook 不支持在 API 中新建分类颜色，新建分类需在 Outlook 客户端完成 |

:::info Outlook 的"分类"vs Gmail 的"标签"
功能几乎等价，只是命名不同。DesireCore 统一以"标签"展示，底层自动适配各邮箱的 API。
:::

### IMAP 邮箱

IMAP 协议本身不支持标签。对于 QQ 邮箱、163 邮箱等 IMAP 账户：

- 文件夹结构可以正常同步（收件箱、已发送等）
- 不支持标签的创建和同步
- 可以使用 DesireCore 的**全局标签**在本地进行分类（不上传到服务器）

### 全局标签（本地标签）

全局标签是纯本地概念，不与任何邮箱服务器同步：

- 创建后立即生效，无需等待同步
- 适用于所有邮箱（包括 IMAP）
- 在统一收件箱中可按全局标签筛选
- 数据存储在本地，卸载应用会丢失

:::tip 全局标签的妙用
如果你有多个邮箱，可以创建全局标签（如「紧急」、「本周处理」），在统一收件箱中跨邮箱筛选邮件。即使 IMAP 邮箱不支持服务端标签，全局标签也能帮你统一管理。
:::

## 创建自定义标签的详细步骤

以 Gmail 账户为例：

1. 打开邮件视图 → 点击右侧面板的「标签管理」图标
2. 点击「新建标签」按钮
3. 填写标签信息：
   - **名称**：输入标签名（如"项目 Alpha"）
   - **颜色**：从色板中选择（同步后 Gmail 网页端也会显示对应颜色）
   - **范围**：选择"仅当前账户"或"全局"
4. 点击「创建」
5. 标签立即出现在标签列表中，并同步到 Gmail 服务器

:::note 标签命名规则
- 不能与系统标签重名（如"收件箱"、"已加星标"）
- 支持中文、英文、数字和连字符
- 长度不超过 50 个字符
:::
