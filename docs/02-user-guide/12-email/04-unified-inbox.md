# 统一收件箱

当你绑定了两个或以上邮箱时，**统一收件箱**让你无需在不同账户之间来回切换，即可在一个列表中浏览所有邮件。

## 进入方式

在账户管理首页，点击顶部的「统一收件箱」卡片即可进入。这张卡片只在你有两个以上邮箱时才会出现。

## 页面全貌

![统一收件箱](/img/user-guide/email/unified-inbox.png)

### 顶部栏

顶部显示所有账户的汇总信息：

- **未读/总数统计** — 所有账户的邮件汇总
- **账户数** — 当前聚合了几个邮箱
- **同步状态** — 同步进行中时显示脉冲动画
- **撰写** — 打开写信弹窗
- **同步全部** — 同时触发所有账户的邮件同步

### 文件夹标签页

通过水平标签页切换文件夹（收件箱、已发送、草稿、回收站），切换后邮件列表自动刷新。

### Provider 过滤

文件夹标签页下方提供按邮箱类型筛选的按钮：

![Provider 过滤](/img/user-guide/email/provider-filter.png)

- 默认显示「全部」，即所有邮箱的邮件混合排列
- 点击某个 Provider 后，只显示该类型邮箱的邮件
- 每个按钮上的数字是对应类型的邮件数量

### 授权失败提示

如果某些账户的授权已过期，页面顶部会浮动显示醒目的提示横幅，点击「重新登录」返回账户管理首页重新授权。

## 邮件列表

所有邮箱的邮件按时间倒序混合排列。每封邮件带有 **Provider 徽章**用于区分来源：

- Gmail — 红色徽章
- Outlook — 蓝色徽章
- IMAP — 紫色徽章

未读邮件的主题以加粗样式显示，左侧有未读指示点。

向下滚动到列表底部时，会自动加载更多邮件。

## 排序与筛选

### 排序方式

点击列表顶部的排序按钮，可以切换排列方式：

| 排序方式 | 说明 |
|----------|------|
| 时间（默认） | 最新邮件在最上方 |
| 发件人 | 按发件人名称字母排序 |
| 主题 | 按邮件主题字母排序 |

### 筛选组合

Provider 过滤可以与文件夹标签页组合使用。例如：

- 「收件箱 + Gmail」— 只看 Gmail 收件箱中的邮件
- 「已发送 + 全部」— 查看所有邮箱发出的邮件
- 「草稿 + Outlook」— 只看 Outlook 中未发送的草稿

### 搜索

在列表顶部的搜索框中输入关键词，可以跨所有邮箱全文搜索：

- 支持发件人、主题、正文关键词匹配
- 搜索结果实时显示，高亮匹配文本
- 清除搜索框即恢复完整列表

## 标记与批量操作

### 单封操作

在邮件列表中，每封邮件支持快捷操作（悬停或右键）：

- **标记已读/未读** — 切换阅读状态
- **加星标** — 标记为重要（同步回原邮箱）
- **归档** — 从收件箱移除（不删除）
- **删除** — 移入回收站

### 批量操作

1. 长按或右键一封邮件 → 选择「多选」
2. 勾选需要操作的邮件（或点击「全选」）
3. 底部出现批量操作栏：
   - **标记已读** — 批量清除未读状态
   - **删除** — 批量移入回收站
   - **归档** — 批量归档

:::tip 统一收件箱中的批量操作
批量操作会分别作用于各邮箱。例如，同时选中 Gmail 和 Outlook 的邮件执行「删除」，两个邮箱中的对应邮件都会被移入各自的回收站。
:::

## 查看邮件详情

点击邮件列表中的任意一封，会进入邮件详情视图，显示完整的邮件正文、附件、标签等信息。打开邮件时会自动标记为已读。

在详情视图中，你可以直接回复或转发邮件。
