# DesireCore v10.0.97

**发布日期**: 2026-07-29

## 新功能
- **排队消息可视化**：流式输出期间发送的消息，现在以队列列表的形式显示在输入框上方，支持编辑、删除、干预（作为 steer 注入当前回合）、以及中止当前输出并改发该条消息，不再无差别乐观插入聊天流。
- **一条会话支持两路并发流**：同一会话中，用户发言与后台来信或委派汇报可以同时进行，流式输出不再互相串字，停止/继续操作只作用于用户自己的那一轮。
- **Agent 列表忙碌状态动态显示**：侧栏、People 列表和资源面板中，忙碌的 Agent 会显示动态 ››› 流动指示与实时活动文字（如"使用 Bash"），任务结束后自动复原。
- **终端标签数字角标**：按住 Cmd/Ctrl 键时，终端标签栏会显示对应数字角标，让用户知道按哪个数字键可以快速切换到目标终端。
- **任务进行中禁止计算机休眠**：新增电源设置分区，总开关默认开启——Agent 运行任务、终端有活动或应用下载更新时，自动阻止系统进入闲置休眠，任务结束后立即释放。
- **Agent 可自主克隆与管控团队仓库**：ManageAgent 新增克隆、ManageTeam 新增查询/拉取/推送/fork 动作，并引入团队仓库 git 规则提示词，补齐 Agent 在团队协作中的闭环操作能力。
- **允许删除 Agent 默认工作目录**：默认系统工作目录现在可删除，支持将智能体配置为仅在用户指定的项目目录中工作，同时收紧无工作目录时的路径兜底安全防护。
- **后台更新完成弹窗提醒**：选择"后台更新"后，下载完成时会在桌面弹出全局持久 toast，提示更新已就绪并提供"立即重启"入口。
- **子智能体状态栏区分**：聊天区右上角状态栏拆分为"已委派智能体"（真实头像）与"子智能体"（临时子任务）两个语义正确的分组，折叠胶囊同步显示三段计数。
- **SendMessage 来信显示发送方**：其他 Agent 发来的消息现在会实时出现在目标聊天中，并正确显示发送方的头像与名称，不再默默吞掉或切回才显示。
- **运行环境新增 GitHub CLI 检测**：算力设置-运行环境页新增 gh（GitHub CLI）安装检测卡片。

## 修复
- **running 状态不再永久锁死会话**：Agent 查询意外卡死时，会话不再永远无法再发新消息，系统会在 5 分钟后自动回收僵死的运行状态并允许原地续聊。
- **停止生成后排队消息不再从界面消失**：流式输出中发送新消息并点停止后，排队消息气泡现在会正确保留并最终发出，不会因快照时序偏差被错误丢弃。
- **清空聊天记录后第一条消息不再被覆盖**：清空聊天后立即发出的消息现在会与 greeting 正确合并显示，不再被 greeting 整份覆盖导致静默消失。
- **中止与快速连发不再产生两个并发查询**：修复了停止生成后短期内发出的消息绕过排队、与会话内正在进行的查询形成双并发的隐患，引入会话级派发闸门确保始终只有一个查询在途。
- **工具创建的 Agent 提示词不再落盘为 JSON**：通过 ManageAgent 创建的智能体，其 persona.md 现会正确保存为分层 Markdown 而非裸露的 JSON 字符串，系统提示词因此不再丧失结构语义而失效。
- **追问多题场景提交按钮不再"假禁用"**：答完当前题但尚有未答题时，提交按钮改为橙色可点的"去回答 →"，并新增上一题/下一题翻页箭头，用户不再因看到灰色禁用态而找不到继续答题的入口。
- **委派/async 任务失败后正确显示失败状态**：委派子任务因模型错误等失败时，卡片现在会显示红色"已失败"终态，而非一直卡在"处理中"或误判为"已完成"。
- **暂停按钮不再因事件透传导致失效**：点暂停时不再因事件对象进入 socket payload 造成爆栈，暂停现在稳定生效。
- **目标 run 仍在执行时不再丢消息**：遇到"所选历史分支仍在运行"时，消息不再彻底消失，而是返回排队列表并由终态事件自动触发重发。
- **上下文管理 (ManageContext) 不再破坏话题记账与回想**：修复了 reset 后关联话题 messageRange 遗漏消息、归档丢弃回复、回想信息错乱以及上下文边界不一致等 11 处缺陷，重置语义实现锚点化。
- **Canvas 窗口按会话隔离**：多个智能体并发使用 Canvas（HTML 呈现/截图）时，各自拥有独立窗口，不再互相覆盖页面和截图串台。
- **修复 Markdown 有序/无序列表序号不显示**：聊天气泡、通知预览和邮件正文中的有序/无序列表现在正确显示序号和项目符号。
- **Windows 升级增加原生模块完整性校验**：升级后更可靠地检测 sharp、node-pty 等原生模块文件是否写入完整，防止安全软件拦截后误报"升级完成"导致的启动崩溃。
- **视频重启后不再变成破图**：修复了工具生成的视频首次播放正常、重启应用后因媒体类型被错误固定为"图片"而无法播放的问题，已落库的旧数据在渲染时会自动纠偏。
- **追问卡片不再撑爆输入框**：多题追问卡片现在有最大高度限制（44vh / 420px），超长题目区域可滚动，标题栏和提交栏始终可见，不会再整块挤出窗口。
- **句中空格后不再误弹斜杠命令面板**：输入 `2: /` 等句中空白后的斜杠现在不会弹出命令面板，触发严格限定在输入框开头。
- **通知已读后角标静默刷新**：标记通知已读或 Agent 改写通知文件后，前台未读角标与通知中心现在会实时更新，无需重启应用。
- **Agent 报错对 Agent 自身可见**：Agent 通过 InspectRuns 等工具查看历史时，现在能看到包含失败标记、错误码和被中断提示的准确记录，不再将错误轮次误读为正常完成。
- **终端背景不透明化**：修复了终端内容区半透明背景导致对比度计算失真、以及亮色模式下部分 ANSI 颜色几乎不可见的问题，并补齐 ANSI 16 色调色板与 COLORFGBG 注入。
- **工作目录"在文件管理器中打开"功能统一修复**：输入框胶囊、环境状态挂件、资源面板等多处工作目录入口现在均可正常打开文件管理器并显示错误提示。

## 改进
- **团队仓库 git 防护重构**：从解析终端命令文本拦截改为 Git 协议层加固与环境变量注入，配合提示词引导自查，减小对正常 Bash 操作的误拦并提升防护覆盖面。
- **ManageAgent 生命周期操作前强制加载内置技能**：create / update / delete 之前现在需要先加载对应的内置技能取得完整操作指引，避免越过需求收集和安全确认步骤。
- **增量上下文管理功能增强**：pin 支持内容快照跨边界保留，discard 结果在刷新后保持正确状态，压缩、回撤与重置等上下文操作更加可靠。
- **终端视口统一**：所有终端（包括后台、冷终端和 Agent 隐藏终端）现在跟随面板统一尺寸，不再因切标签或初始尺寸不一致导致 TUI 排版错乱。
- **续写状态文案友好化**：活动徽章和按钮将"续写 (length)"等生硬措辞改为"正在处理"并弱化展示具体原因。
- **工作目录打开与错误提示统一**：四处工作目录 UI 中的"打开文件夹"功能统一使用公共入口，失败时给出明确 toast 提示。
- **SendMessage 汇报语义澄清**：通过 notify_only 和 wait 参数显式声明汇报要不要让对方起一轮、是否等待回复，不再靠代码推断。
- **入站查询改为兄弟 run**：其他 Agent 发来的查询不再抢占用户当前会话的 run，改为在同一会话下新建独立 run，避免转录混入和上下文搅乱。
- **Greeting 显示与 run 归属优化**：清空聊天后 greeting 与用户首条消息的合并逻辑更加健壮，解决了 runId 覆盖、流式索引偏移等一系列竞态问题。
- **推送消息折行/排序与离线回填增强**：改进了多段消息的内容签名匹配、跨机时钟偏差下的索引排序以及回填归属判定，使消息时间线更加稳定一致。
