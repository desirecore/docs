# DesireCore v10.0.96

**发布日期**: 2026-07-24

![v10.0.96 更新概览](/img/changelog/v10.0.96.png)

## 新功能
- **分步问答**：追问交互改为分步问答，吸附在输入框上方，支持打字直接作答、跳过和部分提交。
- **同轮技能工具解锁**：激活技能提供的隐藏工具（如代码智能解锁的 Lsp）在同一轮对话内即可直接调用，无需等待下一轮。
- **自动化信息增强**：自动化卡片和调度列表标题处展示关联的 Agent 头像；Agent 档案新增自动化信息卡片；聊天区右上角新增环境状态部件，展示自动化、子智能体和工作目录。
- **网络搜索多级回退**：网络搜索工具现在支持当前模型、备选模型、独立 API 和浏览器子智能体四级回退渠道，提高搜索可靠性。
- **资源管理器友好视图**：代理文件系统的文件树显示语义化友好名称和图标；左侧栏新增工作目录区，可一键在系统文件管理器中打开。
- **终端体验增强**：终端支持发送多行内容；新增 Cmd+T、Cmd+W、Cmd+1~9 等 Warp 风格快捷键（可自定义）；分栏模式下顶部可拖拽窗口；正常退出的终端标签自动关闭，关闭有运行中任务的终端会二次确认。
- **统一等待策略配置**：可在 agent.json 中统一配置追问超时、工具执行审批等待时间、服务审批等待时间和跨团队委托确认等待时间。

## 修复
- 修复 Windows 下导入团队 ZIP 时因文件占用导致数据静默丢失的问题；同时修复无全局 Git 身份时团队提交失败的错误。
- 修复 Agent 流式输出时发送新消息并点击停止后，该消息从界面消失的问题。
- 修复描述中包含“DesireCore”的专业代理被错误归类为通用代理，导致侧边栏分组混乱的问题。
- 修复追问题中多选题的勾选框图标错误和选项预览内容丢失的问题。
- 修复 draw.io 图表全屏编辑时顶部按钮（复制、发送、关闭）被拖拽区域遮挡而无法点击的问题。
- 修复聊天静置在底部时“回到顶部”按钮依然一直显示的问题。
- 修复手机验证码发送后冷却倒计时未按真实剩余时间恢复的问题。
- 修复内置 Bash 工具在登录环境抓取失败时，PATH 回退列表缺少 `~/.local/bin`，导致 pipx 等用户工具找不到命令。
- 修复 People 详情面板和权重趋势图中关系强度数值显示为未格式化的长浮点数的问题。

## 改进
- 已跳过更新或处于冷却期时，手动检查更新会提示“另有新版本可用”，不再笼统显示“已是最新版本”。
- 思考深度选项从“最浅/浅/中/深/最深/最大”改为“极速/快速/均衡/深入/最深/极限”，默认选项突出“均衡”而非“中”。
- 聊天输入框下方的模式、目录和模型选择器在窗口较窄时自动收起文字仅显示图标，避免溢出被裁切。
