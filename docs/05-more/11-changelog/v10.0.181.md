# DesireCore v10.0.181

**发布日期**: 2026-10-13

![v10.0.181 更新概览](/img/changelog/v10.0.181.png)

## 新功能
- **Agent 开发工作台与我的应用发布**：现在可以让智能体在授权工作目录中创建应用，并以固定版本发布到“我的应用”，支持静态网页、原生任务和 Docker 容器运行，以及版本历史、实例数据和设备偏好管理。
- **内网仓库分发与离线种子**：支持通过统一配置将市场、配置中心、注册表和核心智能体切换到内网 Git 服务，并支持离线种子同步，便于内网环境使用。
- **紧凑工具调用提示与单层思考记录**：聊天中直接以“动作 + 对象 + 结果”形式展示每次工具调用，思考记录统一为单层折叠卡片，并记住展开偏好。
- **工具说明分页续读与上下文钉住**：长工具说明支持按版本有界分页读取，并可将本轮已完成的工具结果钉住，避免上下文超限后被裁剪。

- 修复导出 DOCX 文档后无法读回内容的问题。
- 修复文档工具默认文件档位被拒绝的问题。
- 修复工作流默认值被空参数遮蔽的问题。
- 修复长会话中待审批入口不可见的问题。
- 修复客户端与智能体更新可能被失败的市场准备、证书错误、残留启动预约或缺失 Git 认证长期挡住的问题，并提供可操作恢复入口。
- 修复技能与 MCP 连接在正常授权后仍缺少凭据的问题。
- 修复关闭 MCP 连接后旧来源工具目录未立即失效的问题。
- 修复市场能力发现与安装使用来源不一致，以及合集子技能无法安装的问题。
- 修复团队添加成员或更换组长后已批准规则未覆盖新接收者的问题，并提供独立核准恢复入口。
- 修复大工作流保存可能过期且未携带精确修订说明的问题。
- 修复包含缺元数据旧运行记录时无法开始新对话的问题。
- 修复模型推理档位在单次/视觉请求、云元数据和会话偏好中被错误传递或写回的问题。
- 修复调度、运行历史和智能体 Git 分页参数被非法字符串或负数破坏的问题，以及 Grep 接受小数计数的问题。
- 修复聊天模型菜单被任务浮层遮挡的问题。
- 修复窄窗口下聊天工具栏控件过早换行的问题。
- 修复官方算力公告中供应商名称下沉错位的问题。
- 修复工作区新建页终端提示不准确，以及资源管理终端入口沿用旧偏好的问题。
- 修复首次启动时邮件服务被提前请求导致不可用，以及拼写词典下载状态显示不准确的问题。
- 修复默认 Python 版本与内置文档处理运行时组件不兼容导致首次安装失败的问题。
- 修复审批模型无可用渠道时错误提示“算力配置正确”的问题。
- 修复工作流定义非法时错误诊断被丢弃，模型只能收到泛化错误的问题。
- 修复工作流查看预检与最终提交合同不一致，导致待审内容可能丢失的问题。
- 修复工具刷新失败时仅返回泛化错误，无法定位具体工具、路径和行列的问题。
- 修复长任务期间聊天输入框失焦的问题。
- 修复团队环境中工作流前台绑定和后续工具上下文被误拒的问题。
- 修复文档保存与关闭竞态导致同时出现已保存提示和未保存确认的问题。

## 改进
- Windows 首次安装时使用预生成索引和配置，缩短等待时间。
- 优化启动流程，后移首轮维护并减少启动关键路径耗时。
- 模型选择器改为同排状态点展示可用性，点击可查看通俗说明。
- 用户全局提示词改为普通 Markdown 全文加载，编辑界面更简单直观。
