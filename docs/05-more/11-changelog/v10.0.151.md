# DesireCore v10.0.151

**发布日期**: 2026-09-09

![v10.0.151 更新概览](/img/changelog/v10.0.151.png)

## 新功能
- **工具按需披露与同轮发现激活**：当可用工具较多时，首次对话只加载基础工具集，您可以在本轮对话中按需发现并激活更多工具，减少无关上下文占用；浏览器管理、截图和操作工具现在无需先启用技能即可直接使用。

## 修复
- 浏览器接管暂停期间控制租约到期后，智能体将无法恢复的问题；现在点击“恢复智能体”会在授权仍有效时自动续期并恢复会话。
- 异步委派任务的卡片状态在刷新后可能丢失最终状态的问题。
- 多窗口场景下，一个窗口的重试通知可能错误清空其他窗口流式状态或显示重试卡片的问题。
- Linux 上媒体授权重读在文件删除并重建为相同内容时可能绕过检测的安全漏洞。
- 市场缓存“脏修复”在 Windows 上持续整树备份导致磁盘被数百万文件占满的问题，启动时会自动清理存量备份。

## 改进
- Windows 上首次启动不再因为数据目录安全加固同步执行而阻塞约 20 秒，相关加固改为后台进行，启动更快。
- 系统防休眠逻辑现在能更准确地识别等待人工输入、同步委派、工作流轮询等状态，避免任务执行期间错误进入休眠。
- 底层依赖升级至最新安全版本，提升整体稳定性和安全性。
