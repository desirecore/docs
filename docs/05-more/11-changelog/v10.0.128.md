# DesireCore v10.0.128

**发布日期**: 2026-08-29

![v10.0.128 更新概览](/img/changelog/v10.0.128.png)

## 新功能
- **多引擎求解与通用求解器团队平台能力**：新增多引擎求解架构，支持 LP、MILP、QP、MIQP、QCP、MIQCP 与声明式 CP 模型，可接入 MindOpt、SCIP、CP-SAT 等求解引擎，并提供候选解校核与证据账本，让智能体团队完成更复杂的优化任务。
- **全局任务板迁移为受保护内置应用**：全局任务板现在作为内置应用显示在“我的应用”中，主导航入口固定位于第2位，使用方式与之前一致，并更稳定地与其他应用集成。

## 修复
- 修复自动升级倒计时结束后应用不退出也不安装更新的问题，现在倒计时归零后会正确执行退出并安装。
- 修复 Windows 上 electron-mcp-server 启动时错误打开 VS Code 的问题，现在能正常启动 MCP 服务。
- 修复消息发送被拒绝后排队重试时可能卡死或刷新后丢失的问题。
- 修复 Agent 同步过程中冲突事务处理不当导致的同步异常。
- 修复空闲会话首次提交 /steer 时原草稿丢失的问题，并隔离不同输入面的草稿恢复。
- 修复运行中断后用户看不到任何中断提示的问题，现在系统会显示明确的回收提示消息。
- 修复服务重启或跨窗口复用会话时对话可能卡住、消息发不出去的问题。
- 修复市场线稿技能图标被错误渲染为实心方块的问题。
