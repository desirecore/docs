# DesireCore v10.0.144

**发布日期**: 2026-09-04

![v10.0.144 更新概览](/img/changelog/v10.0.144.png)

## 新功能
- **Agent 依赖技能自动安装**：从市场安装或更新 Agent 时，会自动装齐其声明的依赖技能，无需再手动到市场逐个勾选。
- **求解器多引擎证据加固**：优化求解结果现在包含更严格的可行性/不可行性证明和独立验证，三个求解网关返回的证据更可靠，避免误判。

## 修复
- 修复智能体列表宽度较窄时加号菜单偏左且显示不全的问题，菜单会自动在列表边界内对齐。
- 修复通过合集向 Agent 私有技能目录安装技能后，可能导致该 Agent 永久无法更新或卸载的问题。

## 改进
- 市场技能安装、卸载及 Agent 依赖技能预置现在统一走安全的摘要基线流程，依赖技能装不上不会影响 Agent 安装成功，也不会破坏后续更新或卸载。
- 加强长时间运行任务在恢复、继续对话、派生和回退等环节的归属校验与审计追踪，提升任务执行的安全性和可靠性。
