# DesireCore v10.0.188

**发布日期**: 2026-10-25

![v10.0.188 更新概览](/img/changelog/v10.0.188.png)

## 修复
- 修复文档审阅提交后仍误报“尚未保存”以及从失败恢复后编辑器显示旧内容、可能导致已接受改动被回滚的问题。
- 修复中断的对话回复中已生成的流式正文丢失、显示为“无输出”的问题。
- 修复智能体首次通过 Write 创建文档后工作区不显示文件标签的问题。
- 修复桌面启动可能因系统钥匙串授权等待而阻塞的问题。
- 修复 Windows 下系统环境变量在 Git Bash 中因键名大小写被改变而取值为空的问题。
- 修复运行环境页在窄窗口下系统工具卡片内容溢出的问题。
- 修复开发模式下默认登录对新版控制面协议不生效、导致无法自动登录并加载算力的问题。
- 修复环境检测失败时智能体丢失已识别的运行时路径和 Git 版本等信息的问题。
- 修复工具调用出错时错误信息未显示在运行记录中的问题。
- 修复近期工具调用记录在活动日志中状态和时间显示不一致的问题。

## 改进
- 优化任务计划与动作上下文的语义描述，避免智能体将父计划引用误解为对子任务计划的限制，并明确动作状态中计划准入信息的可见范围。
- 升级 Markdown 渲染、YAML 解析与图标组件库，提升文档渲染稳定性和兼容性。
