# DesireCore v10.0.167

**发布日期**: 2026-09-17

![v10.0.167 更新概览](/img/changelog/v10.0.167.png)

## 修复
- 修复了从 Windows 或外置盘迁移数据后，因目录权限过宽或使用符号链接导致应用卡在“暂时无法进入 DesireCore”恢复页、无法启动的问题。
- 修复了通知功能可能因文件权限异常或读取失败而被永久禁用的问题，现在会在下次启动时自动重新检测并恢复。
- 修复了启动过程中因内部文件权限设置过宽而失败的问题，现在会自动收紧到安全权限并继续启动。
- 修复了跨重启后提供方重放（Provider replay）可能失效的问题，现在重启后重放功能可以按预期工作。

## 改进
- 显著提升启动速度：从启动到可交互约快 230 毫秒，到完全就绪约快 220 毫秒，启动阶段改为按需加载部分组件。
- 启动失败时，主日志会记录一条脱敏的失败详情（包含阶段、错误码、原因和调用栈），方便排查和反馈启动问题。
