# DesireCore v10.0.118

**发布日期**: 2026-08-25

![v10.0.118 更新概览](/img/changelog/v10.0.118.png)

## 修复
- **Delegate 调用**：修复合法的持久 Delegate 调用因省略幂等键而被拒绝、仅显示泛化错误的问题，现在系统会自动从会话与工具调用信息派生稳定的幂等键。
- **连接断开状态**：修复手动断开连接后"已断开连接"状态很快被误报的"离线"信息覆盖的问题——断开状态现在会稳定保持，且不会对已断开的连接自动重连。
- **已授权客户端名单**：修复配对成功后"已授权的客户端"名单不实时刷新、需关闭重开设置面板才能看到新设备的问题；名单读取失败时也不再误显示"还没有其他客户端接入"。
- **受限操作提示**：修复对所属实例之外的已接入智能体执行置顶等操作时，错误提示"操作失败，请重试"的问题，现在会明确提示"请在该智能体所属的实例中管理"。
- **界面状态一致性**：修复离线分组内的智能体仍显示绿色"在线"状态点、读屏也报"在线"的问题；重启后未成功获取到设备清单前，也不再显示误导性的条目数"0"。
- **模型匹配准确性**：修复基础模型名称可能被错误匹配到更具体的日期或预览版本规格（如 Qwen 预览版、DeepSeek 四位日期规格）的问题。
- **视频生成工具可用性**：修复没有已启用且具备有效凭据的视频生成供应商时，视频生成工具仍暴露给智能体、导致调用失败的问题，现在无可用服务时该工具不再出现。

## 改进
- **视频下载**：生成的视频下载不再受普通媒体 50 MB 大小上限的限制，大体积视频可以正常下载。
