# DesireCore v10.0.183

**发布日期**: 2026-10-15

![v10.0.183 更新概览](/img/changelog/v10.0.183.png)

## 新功能
- **内置通用助手**：新增系统内置的“通用助手”智能体，支持问答、写作、分析、编程与工具调用，并默认开启手动多会话；离线市场同步提供该助手及透明头像。
- **浏览器自动化与受控启动**：新增浏览器外部启动工具，经用户审批后，Agent 可启动本机已安装的浏览器并打开指定网页；离线环境下自动预置浏览器自动化所需的运行环境。
- **Webhook 管理**：支持配置 Webhook 所有者、启停/删除与共享密钥轮换，并在算力凭据列表中直接查看可用的本地模型代理地址。
- **任务板发现**：Agent 现在可以通过只读工具发现当前权限范围内的任务板，无需依赖旧计划中的任务板编号。
- **内网部署登录**：企业内网部署版支持手机号密码登录、首次登录强制修改密码、会话恢复与失效恢复，并按部署策略展示可用的模型与功能。

## 修复
- 修复打开聊天记录时在 macOS 上可能出现灰屏/无法退出，以及大量或超长历史记录渲染卡顿的问题。
- 修复会话转交给其他 Agent 后，原会话仍可继续发送消息并可能重复执行任务的问题。
- 修复解散父团队时子团队暂存内容被丢弃的问题，并避免团队工作目录在并发创建、解散、补缺时发生抢占或产生孤儿绑定。
- 修复 AI 审批服务无响应时被错误显示为“安全拒绝”的问题，现在会明确显示“AI 审批不可用/未执行”。
- 修复审批卡片中原始请求被平台参考截断的问题，现在完整保留实际请求内容。
- 修复小 SVG 等图片格式进入模型协议导致后续请求失败的问题，现在会生成兼容预览并支持恢复。
- 修复从任务板查看数据源时只打开隐藏聊天文件工作台、没有可见文件页的问题。
- 修复从内置应用查看文件后返回时，之前打开的子页面、选中对象和内存草稿丢失的问题。
- 修复从编辑入口返回阅读视图时，原有缩放与平移视角丢失的问题。
- 修复运行环境版本读取失败被误报为“未安装”的问题，现在会显示“读取失败”并保留上次已知状态。
- 修复决策工作区中符合有效技术依据的节点仍被重复审阅阻断，以及局部业务例证因非目标约束被误判为不可行的问题。
- 修复自动压缩完成后，同一次运行中的其他会话缺少摘要的问题。
- 修复已结算工具轮的用量在后续请求失败或中断时丢失的问题。
- 修复网络断连导致 Agent 被误显示为关机的问题。
- 修复嵌入式进程单次操作超时导致整个通道被关闭的问题。
- 修复工具参数解析失败时无有效反馈、以及模型暂不可用或冷却时无法在原有预算内等待恢复的问题。
- 修复离线 Office 技能在中文 XML 校验和离线依赖上的缺陷。
- 修复打包时缺少目标平台离线运行目录仍继续生成客户端的问题，现在会直接阻止打包并提示准备运行时。

## 改进
- 优化聊天记录查看体验：首次仅加载最近记录，滚动分页加载，搜索分批处理，消息列表虚拟化并合并窗口快照更新。
- 优化离线运行时准备：首次使用时不再依赖额外下载，离线引导更完整，并修正 Node 版本支持范围，避免不同工具链版本冲突。
- 聊天执行过程中隐藏 Agent 正在内部恢复的工具调用失败提示，减少用户干扰；审批恢复与中断提示保持不变。
- 保留纯衍生产出前的原始数学证据、旧摘要与审计记录，确保决策工作区成果可追溯、可核验。
