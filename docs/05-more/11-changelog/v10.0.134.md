# DesireCore v10.0.134

**发布日期**: 2026-08-31

![v10.0.134 更新概览](/img/changelog/v10.0.134.png)

## 新功能
- **GitHub Copilot 订阅算力**：新增 GitHub Copilot 订阅算力接入，通过 GitHub Device Flow 登录后可自动发现并使用订阅下的最多 29 个模型，凭证会自动刷新并适配不同模型端点。
- **Kimi WebBridge 市场条目**：市场新增 Kimi WebBridge 第三方浏览器集成条目，可查看权限边界并跳转官方 Chrome/Edge 商店页面，仅作收录展示，不会自动安装或执行。
- **应用返回栏**：从“我的应用”“聊天关联应用”“应用资源”打开应用时，顶部会显示返回栏，可一键回到原来源页面。
- **更完整的 Git 冲突解决**：智能体同步遇到 Git 冲突时不再受 200 个文件上限限制，可逐侧选择解决方案，并在受限或失败时提供可复制的替代提示词。

## 修复
- 修复正式安装包在全新数据目录首次启动时因缺失运行依赖而进入连接恢复、智能体服务无法启动的问题。
- 修复 Windows 上市场缓存每轮同步误判“本地偏离”，反复备份约 10.7 MB 且不收敛、磁盘持续增长的问题。
- 修复内置技能点击卸载无反应、无法实际卸载的问题；现在可正常卸载，并解冻了旧版内置技能的更新通道。
- 修复切换智能体再切回时，其他客户端删除的消息仍显示为僵尸气泡、需整页刷新才消失的问题。
- 修复手动会话中草稿与标题丢失、删除/分页交错可能破坏数据，以及关闭手动模式后可能看到其他用户历史记录的问题。
- 修复跨实例会话在服务重启或会话被接管后恢复闸门只能等超时、无法及时收敛的问题。
- 修复 Bash 命令占用共享宿主名额导致终端最多只能开约 750 个，与承诺的 1000 个终端上限不一致的问题。

## 改进
- 技能目录现在会提示加载技能后可解锁的专用工具，并按需注入机制说明，帮助智能体在代码导航等场景优先使用技能而不是退化为文本检索。
