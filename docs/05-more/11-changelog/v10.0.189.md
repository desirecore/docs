# DesireCore v10.0.189

**发布日期**: 2026-10-26

![v10.0.189 更新概览](/img/changelog/v10.0.189.png)

## 新功能
- **Markdown 主动审阅**：Markdown 编辑器现在默认展示最新可信正文，审阅改为由用户主动进入独立标签页进行，历史决策与回退操作仍然可用。
- **委派卡片后台结局**：同步委派转入后台时，卡片会显示“已转入后台”，并在后台任务结束、停止或中断后自动更新最终状态。
- **派单运行弹窗审批**：派单运行弹窗现在可以直接回答结构化问题并处理服务审批，不再只能等待超时。

## 修复
- 新建会话在发送首条消息前创建 Git 工作树时，会先登记草稿和所选项目，避免从默认目录错误创建或持续报错。
- 收紧求解引擎配置写入与探测的权限，防止智能体绕过界面直接修改引擎清单或发起凭据探测。
- 代码仓库自动修复的后台监控现在只保留一个调度器；修复中途退出后重启时会提示人工核对，避免静默回退或重复派发。
- 对话导出正文中的会话日期、消息时间和导出时间现在会按请求时区显示，跨时区使用不再出现筛选与显示不一致。
- 聊天记录定位现在可以找到本次会话实时产生、尚未写入历史的消息；找不到时会给出明确提示，不再无响应。
- 设置页的导出、导入、备份恢复和迁移到新设备现在会正确包含任务板、工作流和审计日志；恢复任务板与工作流改为默认不勾选，避免覆盖已有数据。
- 存量市场智能体更新改为先联网后占位，缓慢或不可用的网络不再阻塞用户消息发送。
- 内置技能周期同步后现在会即时刷新技能缓存，同一批更新只维护一次监听，减少桌面端同步时的卡顿风险。
- 修复内嵌浏览器在长轮询超时或会话终止时误判状态的问题：超时后会先验证连续性，终止后会按实际情况说明状态并回收旧页面。
- 修复 Markdown 行内审阅恢复草稿后保存可能回滚已接受改动的问题，并确保 emoji、组合字符等完整字符不会被拆分或显示为乱码。
- Worker 记录对敏感信息的遮蔽和分页序号保持一致，合法交付回填后不会误隐藏安全摘要。
- 修复白板“另存为”仍在进行时就提前提示“结果未知”的问题。
- 更新内容安全过滤组件，消除相关安全公告。

## 改进
- 桌面安装包体积显著减小，减少磁盘占用和下载负担。
- 算力初始化与输入框就绪解耦：启动后可以先输入，模型选择器独立加载、失败可重试，发送后再由实际消费者等待算力准备。
- 外部浏览器自动化运行时改为在系统空闲时预热、首次实际使用时按需准备，不再每次启动都占用大量资源。
- 启动诊断和关联应用管理改为按需加载，减少启动阶段不必要的准备工作。
- 细化服务启动阶段的耗时观测，并约束后台任务对 CPU 的争用，降低启动期间的资源争抢。
- 移除启动时的算力注册引导弹窗，减少对用户的打扰。
