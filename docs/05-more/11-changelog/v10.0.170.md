# DesireCore v10.0.170

**发布日期**: 2026-09-19

![v10.0.170 更新概览](/img/changelog/v10.0.170.png)

## 新功能
- **Skill 优先应用安装与核验记账**：应用安装、升级和卸载现在由智能体技能驱动，只在真实核验结果后记录安装状态，避免界面预写虚假的中间状态。
- **DesireCore Control 市场交付**：市场新增 DesireCore Control 应用，可供外部智能体安装后控制 DesireCore。
- **数字员工分类与团队展示**：市场中的“智能体”分类统一更名为“数字员工”，团队卡片直接展示组长和成员头像，详情页展示完整成员名册与角色。

## 修复
- 修复切换界面语言后市场目录内容不立即刷新的问题，现在切换语言后会重新读取本地化目录。

## 改进
- 优化市场浏览体验：改进筛选、键盘导航、窄屏布局和中文输入法兼容性，并将团队完整成员姓名与 ID 纳入搜索范围。
