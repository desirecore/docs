# DesireCore v10.0.111

**发布日期**: 2026-08-16

![v10.0.111 更新概览](/img/changelog/v10.0.111.png)

## 新功能
- **使用统计开关**：设置中新增“发送使用统计”开关，可随时关闭匿名使用数据收集。
- **协议版本管理**：隐私政策与用户协议现已版本化，更新后需重新同意。

## 修复
- 自动待办消息现在会立即显示在对话中，刷新后保持正确样式，不再被误认为用户消息。
- 修复了自动待办消息在算力校验被拒时可能错误归属到前台会话的问题。
