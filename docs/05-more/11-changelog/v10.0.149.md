# DesireCore v10.0.149

**发布日期**: 2026-09-07

![v10.0.149 更新概览](/img/changelog/v10.0.149.png)

## 修复
- 修复了智能体已有真实会话时，问候初始化仍会另建问候会话并遮蔽历史记录的问题，现在会直接恢复真实会话。
- 修复了未声明输入契约的智能体因配置存在历史遗留字段而无法收到直接消息、插入或转接消息的问题，现在不会再被静默拦截。
- 修复了聊天消息中不同目录下同名 Markdown 文件链接被错误解析到同一文档的问题，现在会优先按完整路径打开正确文件。
- 修复了清除聊天记录时总会误报“调度回执未清理”并截断后续收尾的问题，现在调度回执清理、用量复位、话题清理和问候重建都能正常完成。
- 修复了智能路由在连续遇到 529 错误时可能自动切换其他厂商模型的问题：固定模型不再自动切换，智能路由仅在当前厂商内依次尝试未用过的同级模型，候选耗尽后提示手动切换。

## 改进
- 聊天工作区右侧「文件」面板的目录树现在默认收起，避免自动打开文档时被目录树挤压；折叠偏好与资源页分开保存，空态新增“显示文件目录”入口。
