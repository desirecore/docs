# DesireCore v10.0.142

**发布日期**: 2026-09-03

![v10.0.142 更新概览](/img/changelog/v10.0.142.png)

## 新功能
- **多账号凭据管理**：资源管理器中的密钥面板升级为可管理多组账号密码的凭据库，密码默认遮罩可查看，智能体可通过占位符读写，旧扁平密钥保留为只读可删除。
- **启动失败兜底与诊断**：应用启动失败时不再无提示退出，而是显示带修复指引的专用窗口，可导出本地诊断压缩包并引导发送给支持邮箱，主进程日志同时开始自动落盘。
- **浏览器安全填密**：浏览器自动化支持在网页表单中填入密钥占位符，真实凭据在填入时不会经过模型上下文、会话记录或日志。

## 修复
- 定时任务与网络钩子任务中的技能门控工具恢复可用：此前即使智能体成功激活技能，浏览器自动化工具也会被静默清空。
- 子智能体在团队委派中向用户提问或发起服务审批时，界面现在能正常弹出可回答的卡片，不再永久停在「进行中」。
- 已打开或引用的文件被删除后，不再让整条会话每次发送都失败；失效引用会自动从待发条目和输入框移除，支持重试发送。
- Windows 更新安装不再需要反复点击退出安装，进度收尾不再停在 99% 或持续重扫安装目录。
- 心跳回执等时间戳损坏时不再显示成“NaN:NaN”或“not-a-date”，统一显示为占位符。
- 思考型模型执行智能审批时不再因思考内容耗尽预算而错误提示后端不可用。
- 浏览器命令结果未知不再被当成命令未发生，避免浏览器会话永久无法恢复和标签页泄漏。
- 技能合集安装完成后现在能正确显示可更新状态并一键更新，首次安装会默认勾选可安装子技能，且不会跨作用域误装。
- 高负载设备上智能体服务启动时间过长不再被误判为启动失败而反复重启。
- 补齐密钥写入口的权限治理，避免本机任意进程覆盖已配置的模型供应商密钥或删除浏览器登录状态。

## 改进
- 智能体面板首次打开时将多个数据请求合并为单次聚合请求，慢链路或连接远程服务器时加载更快。
