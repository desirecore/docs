# DesireCore v10.0.168

**发布日期**: 2026-09-17

![v10.0.168 更新概览](/img/changelog/v10.0.168.png)

## 修复
- 修复在数据目录权限偏宽、外部属主或符号链接数据根等常见布局下，决策工作区、决策树、画板、工作流启动与重发等多个功能不可用或报错的问题；现在这些功能会尽量收紧权限并继续运行。
- 修复 Windows 上用户目录或祖先目录存在不安全 ACL（如 Everyone 完全控制）时应用拒绝启动并要求执行 icacls 的问题；现在改为降级启动，核心功能可用，仅停用多实例管理。
- 修复聊天区在 Markdown 文件路径索引缺失时可能出现的更新循环，避免界面卡死或渲染异常。
- 修复浏览器工具对 page.element 与 input.click 边界说明不清导致智能体误用的问题；现在明确指引点击通过 input.click 完成。

## 改进
- 已声明工具的完整参数契约现在会全量呈现给智能体，包括条件必填、参数规则和合法值，减少调用委派、发送消息、决策树等工具时反复试错；报错提示也会指明禁用字段、合法值和正确参数名。
- 任务板现在会自动记录任务创建、更新、认领和提交所对应的运行与轮次来源，便于追溯任务与执行上下文。
