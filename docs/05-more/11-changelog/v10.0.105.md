# DesireCore v10.0.105

**发布日期**: 2026-08-11

![v10.0.105 更新概览](/img/changelog/v10.0.105.png)

## 新功能
- **全局任务看板**：支持创建和管理多 Agent 协作任务，可分配、评论、验收，进度跨会话持久保存。
- **界面接管**：Agent 可经审批后接管 DesireCore 界面执行自动化操作；接管期间窗口边缘显示辉光提示与接管者标识。
- **导入不限大小**：导入智能体或团队包时不再有 100MB 限制，并支持进度展示和随时取消。
- **工作上下文**：委托（Delegate）时可选择继续、隔离或分支的工作上下文，同时提供跨运行时序的连续时间线视图。

## 修复
- 修复左侧智能体列表偶尔出现横向滚动条的问题。
- 修复 Windows 工作台工具面板不显示工具短名称（如“终端”“浏览”）的问题。
- 修复 Windows 更新进度窗口在慢机器上探活超时导致更新完成后应用重复打开的问题。
- 修复 Windows 上手动重启任务宿主（Task Host）偶发失败且入口消失的问题。
- 修复 Windows 上使用 Git-Bash 终端时，停止任务后子进程残留无法回收的问题。
- 修复非空白工具白名单会错误拦截 OAuth MCP 服务首次授权，导致无法连接的问题。
- 修复终端面板从半屏切换到底部停靠后，终端内容尺寸不适应、溢出窗口边界的显示问题。

## 改进
- 市场合集安装对话框的操作按钮改为带边框的“全部选择/取消全部”，并增加“已勾选 N/M”实时计数，交互更明确。
- 智能体列表宽度现可通过分隔条拖动调整，设定会自动保存，适应不同窗口与工作习惯。
- 工具白名单新增 `serverId__*` 通配符支持，可一次放行或屏蔽整个 MCP 服务的工具，权限配置更灵活。
- 优化工作流代码执行环境与运行时资产，macOS 包签名合规性增强，应用启动更稳定可靠。
