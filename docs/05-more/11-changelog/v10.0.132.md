# DesireCore v10.0.132

**发布日期**: 2026-08-30

![v10.0.132 更新概览](/img/changelog/v10.0.132.png)

## 新功能
- **现代化市场**：市场首页及 Agent、技能、应用、服务卡片与详情页全新改版，新增可信来源展示，浏览、搜索和安装流程更清晰直观。
- **数字人个性化偏好**：可为不同 Agent 分别保存数字人形象与语音偏好，重启后自动恢复。

## 修复
- 修复停止一轮后继续对话时，Agent 可能重复发送已经送达的消息的问题。
- 修复实时消息中同一次交付同时显示为工具行和独立卡片、造成重复观感的问题。
- 修复上下文恢复时同一轮对话被记录两次、导致恢复内容重复的问题。
- 修复导出对话时同一对话的历史版本被重复导出、文件体积异常膨胀的问题。
- 修复浏览器工作台未显示 Agent 已打开页面的问题，现在会正确聚焦最新页面。
- 修复沉浸式交互中语音、数字人与文档等模块运行不稳定或显示模拟数据的问题。
- 修复全新环境下首次智能路由误报无可用模型的问题。

## 改进
- 智能体档案与运行状态合并为单一入口的居中大浮窗，减少弹窗碎片，信息查看更集中。
- 应用冷启动速度与稳定性显著提升，桌面服务运行更轻量、隔离更完善。
- 浏览器中用户点击、键入等操作改为暂停 Agent 而非完全接管，操作完成后 Agent 可继续原有任务。
- 后台 Agent 更新检测静默化，仅通过角标提示，不再频繁弹出通知打扰。
- 统一了应用内品牌标识与产品名的显示方式，确保所有界面一致。
