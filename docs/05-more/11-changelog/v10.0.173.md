# DesireCore v10.0.173

**发布日期**: 2026-09-22

![v10.0.173 更新概览](/img/changelog/v10.0.173.png)

## 新功能
- **市场卡片详情统一体验**：市场中的智能体、技能、团队和应用详情页统一为卡片式布局，提供更清晰的人类用途概览、完整成员展示、文档章节导航，并合并展示相同参数、支持复制完整值；同时移除虚假的星级和硬件要求信息，风险描述更加真实。
- **内置应用呈现优化**：内置应用名称统一为“智能体社会化关系”，并优化了应用卡片、导航栏和溢出菜单中的图标与名称显示，长名称自动换行，隐藏不支持的操作。

## 修复
- 修复 Windows 上应用启动因系统权限检查或身份读取超时而缓慢甚至进入恢复页的问题，启动速度显著提升。
- 修复智能体面板中长 URL 特质标签导致弹窗出现横向滚动条的问题。
- 修复会话排队中多个附件或冲突选项被覆盖丢失的问题，以及委派运行结束后卡片错误暗示任务成功的问题。
- 修复关闭隐私开关后安装遥测仍可能继续发送数据的问题。

## 改进
- 升级底层模型交互运行时，改善显式空参数处理、会话转录兼容性和生产依赖加载，提升模型交互稳定性。
- 升级浏览器调试协议支持，提升内置浏览器自动化功能的兼容性和稳定性。
