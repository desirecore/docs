# DesireCore v10.0.133

**发布日期**: 2026-08-31

![v10.0.133 更新概览](/img/changelog/v10.0.133.png)

## 新功能
- **全局任务板能力开关**：全局任务板现在是默认启用的受保护内置应用，固定在主导航第二位且不参与自定义应用排序；你可以在“我的应用”中关闭或重新开启它，关闭后智能体将无法发现或执行全局任务板的七个相关工具，但个人文件式计划/任务能力不受影响，重新开启后原有看板、任务、评论、历史与自动化定义都会完整恢复，不会被删除。
- **通栏消息样式**：设置 → 外观 → 消息样式新增“通栏”呈现方式并设为默认，助手消息不再显示头像和气泡壳、正文宽度更大，用户消息改为中性深色对称胶囊；原有“气泡”样式仍可切换保留。

## 修复
- 修复手动多会话切换回已缓存话题时，其他客户端删除的消息仍会以“僵尸气泡”显示的问题；现在会以后台权威历史重新对账，并确保删除后的消息在会话重建或恢复时不会再次出现。
- 修复用户消息头像始终显示写死的绿色“我”字而不读取个人资料头像的问题，现在会正确显示已上传的头像。
- 修复用户消息附件占位文字在亮色主题下因白色文字压在浅色背景上而不可见的问题。

## 改进
- 内置 DesireCore 智能体资源更新至 1.12.0，新增 24 个真实场景的决策树 Web，并同步验证书 Web 源码与校验器。
