# DesireCore v10.0.190

**发布日期**: 2026-10-26

![v10.0.190 更新概览](/img/changelog/v10.0.190.png)

## 新功能
- **系统浏览器启动与离线自动化**：浏览器自动化支持启动系统已安装的浏览器，并可在内网离线环境中自动准备运行环境，不再依赖本机预装解释器或联网。
- **普通聊天任务进度同步**：普通聊天中创建的任务现在可以报告进度并同步到任务清单与完整任务板。
- **删除凭据文件确认**：删除包含 .env 凭据文件的技能或智能体时，会先列出待删除文件并要求二次确认。

## 修复
- 修复任务绑定运行缺少计划时被误报为无权限，导致智能体误认为没有审核或认领权限并放弃的问题。
- 修复大型任务板启动恢复长时间阻塞，导致主界面与连接超时的问题。
- 修复技能安装运行后因本机生成文件被误判为内容已偏离，导致无法更新、收敛或卸载的问题。
- 修复团队导入意外中断后恢复记录被误判为冲突，导致服务重复启动失败的问题。
- 修复跨身份迁移后部分有效对话历史不可见的问题。
- 修复部分系统升级后配置缓存被误判为无效，导致初始化失败的问题。
- 修复桌面安装包中伴生组件因签名校验不一致，导致未预装该组件的用户自动安装失败的问题。
- 修复特定部署模式下已登录用户仍无法加载算力套餐列表的问题。
- 修复撤销浏览器共享授权后重新授权，在等待清理周期内仍被拒绝的问题。
- 修复迁移确认页在选择“保留本机”后仍显示为“将被覆盖”，或导入个人/团队数据时缺少覆盖提示的问题。

## 改进
- 安装包体积减小约 49 MB，下载与安装更轻量。
- 浏览器工作台的环境、更多操作、标签分组和操作记录浮层支持按 Esc 键关闭并恢复焦点。
