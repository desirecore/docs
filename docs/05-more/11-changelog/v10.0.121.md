# DesireCore v10.0.121

**发布日期**: 2026-08-25

![v10.0.121 更新概览](/img/changelog/v10.0.121.png)

## 新功能
- **备份设置**：在"数据与隐私"设置中新增备份子页，支持启用/重设加密口令、添加本地目录或 S3 对象存储备份目标、按类别手动备份，并在备份列表中标注每份备份的认证状态与未通过原因；导入备份时也能正确识别加密备份包而不再误报损坏。
- **运行中心**：导航栏的"活动记录"与"任务管理器"合并为统一的"运行中心"，以任务、活动、系统、诊断四个分区呈现，并保留原有深链跳转与提醒角标。
- **克隆智能体**：新增 clone-agent 内置技能，可通过对话直接克隆已有智能体的配置。

## 修复
- 修复了部分 Windows 电脑因系统重装或用户目录迁移后残留无效权限记录，导致应用在窗口创建前就静默退出的问题；现在会在"设置 → 关于"中给出提示，并提供"修复并重新检测"操作，修复前会备份原权限配置并弹窗确认影响范围。
- 修复了安装大量技能（如 200 余个）后市场页面加载严重卡顿、连接中断和重复全量扫描的问题，市场接口响应时间由约 13 秒降至亚秒级。
- 修复了文件工作台目录树在嵌入右侧工具面板的覆盖形态下背景半透明，底层代码正文、行号与语法高亮透过文件名叠成一团、难以阅读的问题。
- 修复了 Windows 上因路径格式不兼容导致内置市场包无法加载的问题，现在支持包含盘符、空格与特殊字符的路径。

## 改进
- 运行中心改为首次进入时才加载，并仅在页面可见时定期刷新，隐藏后不再持续轮询；活动记录改为分页加载，显著降低后台资源占用。
- 智能体管理与团队管理工具的场景说明迁移至按需加载的内置技能，模型上下文占用减少超过一半，对话响应更轻快、成本更低。
