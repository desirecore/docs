# DesireCore v10.0.164

**发布日期**: 2026-09-16

![v10.0.164 更新概览](/img/changelog/v10.0.164.png)

## 新功能
- **多发行版实例管理**：实例选择器现在按发行版分组显示本机所有 DesireCore 及其他发行版的实例，支持查看运行状态、打开、切换到已运行窗口和移除实例，并按实例所属发行版启动对应版本应用。
- **数据目录归属保护**：每个数据目录只会由所属发行版打开，误用其他发行版打开时会进入兜底页或要求确认接管，避免跨发行版误写数据。
- **OAuth 与 Outlook 回调精准投递**：多个实例同时运行时，浏览器授权回调只投递给发起授权的实例，不再逐个广播；仅用于路由回调的冷启动进程不会打开主窗口。
- **任务板深链跨实例交接**：本机有多个同协议实例时，任务板链接会带上实例标识，打开后直接导航到任务所属实例；目标未运行时会按所属发行版自动拉起。
- **多发行版并装与升级隔离**：Windows 安装器、升级流程和 Linux AppImage 安装脚本均按发行版身份工作，不同发行版可并装、独立升级和卸载，升级时不会误结束其他发行版进程或覆盖协议。
- **Claude 订阅工具恢复**：Claude 模型直接调用未声明工具时不再整轮失败并重复计费，而是按“工具不存在”交回，由模型自行发现工具并继续。

## 修复
- 修复从实例选择器重新打开曾异常退出的独立实例时首次必然失败、需要再开一次的问题。
- 修复界面上下文准入故障被误判为“清除会话进行中”，导致消息提交后停车并需要手动确认的问题。
- 修复 InspectCurrentAppContext 的界面快照被写入会话记录，可能让恢复后的模型误判界面包含密钥的问题。
- 修复任务板与决策工作台界面上下文目标频繁重建，导致模型读取的快照很快过期、后台对象无限增长的问题。
- 修复 Smart 529 换模未遵循模型级协议覆盖，以及直连会话换模可能把旧凭据发往被修改端点的问题。
- 修复委派子任务未继承委派者固定模型、已安装团队成员需要更新时被跳过的问题。
- 修复开发实例和次要实例可能将产品用量统计发送到生产端点的问题。
- 修复旧工具缓存可能被非默认发行版或非 owner 实例迁移、改写生产数据根的问题。
- 修复工作流与决策树在并发发布或原子写入时偶发完整性误报和子进程崩溃的问题。

## 改进
- 打包版不再每次启动都无条件接管 dc 协议，仅在没有处理程序、处理程序失效、未登记、版本过旧或位置变化时接管，避免多实例互相抢占。
- 实例更新门禁改为按安装位置判断，生命周期锁按发行版分区，不同发行版之间的启动、更新和关闭不再互相阻塞。
- Windows 升级时只结束本安装目录内的进程，升级前会核对下载安装包与当前发行版是否匹配，防止装错版本。
- Linux AppImage 安装脚本增强身份解析、旧运行时回退、失效处理程序识别与错误提示，安装过程更稳健。
- 产品用量统计上报范围收紧，只有打包版默认实例会上报，开发实例与次要实例默认不上报。
