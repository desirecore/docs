# DesireCore v10.0.127

**发布日期**: 2026-08-28

![v10.0.127 更新概览](/img/changelog/v10.0.127.png)

## 新功能
- **定时备份任务管理**：设置中新增定时备份任务区，可创建、编辑、启停、删除每日备份任务，并支持立即执行，查看下次执行、上次成功与失败原因。
- **恢复前自动预备份**：从备份恢复时默认先为当前数据创建回滚点，成功后进入恢复，失败会阻断恢复且只能手动取消勾选继续。
- **智能体更新风险确认**：检测到智能体更新前风险后，可在风险提示和菜单中点击“仍要更新”，继续进入既有更新与冲突解决流程。
- **委派交付边界**：被委派的子任务只向主对话交付最终结果和经授权的文件/媒体，思考过程与中间输出仅可在“查看完整过程”中访问。
- **确定性操作守卫**：委派、子任务等长任务具有最多执行一次的保障，避免重试或并发导致重复执行，并取消过低的隐式任务轮数限制。

## 修复
- 修复智谱 GLM 等模型将内置“工具搜索”误认为延迟加载标志、隐藏其余工具而无法创建文件的问题，该工具已更名为“工具目录”。
- 修复浏览器会话被资源配额终止后智能体仍报告“已打开”的问题，现在会如实告知会话已终止、原因及可恢复或需新建的建议。
- 修复清除对话窗口时因跨通道竞态导致手动话题被误删、或重连后消息丢失的问题。
- 修复思考违规自动重试被显示为英文技术告警卡片的问题，自动恢复类提示改为友好文案并按普通信息展示。
- 修复市场缓存本地落后远端时被误判为大量本地提交、导致技能缓存无法自动同步更新的问题。
- 修复 AI 审批请求超过 30 秒后晚到结果被丢弃的问题，晚到的 AI 批准或拒绝现在仍可成为有效终态。
- 修复英文界面下审批卡与中断结果仍显示中文的问题，审批卡随界面语言切换，中断结果按生成时的语言落盘。
- 修复子任务继承主会话画布、当前应用上下文和对话/界面交互能力的问题，子任务只能返回受治理的文件引用。
- 修复模型历史中的旧工具轮污染新请求、导致部分兼容网关拒绝会话的问题。
- 修复模型列表刷新时后续刷新请求被丢弃、或云端模型请求被配置同步阻塞的问题，刷新现在更加及时流畅。

## 改进
- 多实例共享一个后台代理进程，正式包与开发环境分别共享，降低资源占用并提升多实例启动与连接稳定性。
- 设置入口统一为“实例与连接”，新建实例与系统权限状态集中到该面板，移除“关于”中的旧入口。
- 头像右下角钱包标记改为紧凑的浅灰次级徽标，提升在亮色头像上的可读性。
- 话题摘要、会话摘要与只读深度摘要统一使用配置中心指定的轻量摘要模型，摘要更稳定、更轻量。
