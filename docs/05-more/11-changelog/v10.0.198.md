# DesireCore v10.0.198

**发布日期**: 2026-11-03

![v10.0.198 更新概览](/img/changelog/v10.0.198.png)

## 新功能
- **内置插件与开源声明**：插件页新增“内置插件”分组，支持管理内置 FFmpeg 套件（开关、卸载、重新添加），关于页新增开源许可与第三方声明入口，当前版本尚未实际附带 FFmpeg。
- **MiniMax 语音合成适配器**：新增 MiniMax 语音合成协议适配器，配置密钥后可使用其语音合成模型。
- **官方市场内联应用定义**：支持通过官方市场安装使用内联定义的应用，修复了部分应用无法从市场安装的问题。

## 修复
- **任务板单板隔离**：任务板列表与查询会跳过无法读取的单块任务板，不再整体报 500，并显示跳过的板数。
- **流式落盘性能**：流式增量不再逐条开关会话日志文件，大幅降低 Windows 下文件系统过滤驱动造成的滞后，最高可提升上千倍吞吐。
- **模型静默切断提示**：模型请求被静默切断后，下一次请求会附带事实提示，帮助智能体调整策略，减少无意义重试。
- **MCP 工具参数校验**：MCP 工具参数不再被自动强转，类型不符会返回校验错误，审批通过的参数与发送至服务端的参数保持一致。
- **应用启动/停止审批**：修复应用启动/停止审批上下文传递，错误码不再被覆盖，并发等待者能收到正确原因。
- **技能相对路径**：技能加载结果中写明技能目录，模型可正确解析技能自带的相对路径脚本。
- **团队工件证据账本**：团队工件超过原先上限后，证据账本不再永久失败，恢复证明仍可生成。
- **手动话题恢复**：页面重载后，手动话题的空闲执行可正确恢复，不会因并发写入而失效。
- **默认模型语音选择器**：语音识别/合成选择器只列出能力检查通过的模型，避免选中不可用模型。
- **Git 技能导入**：Git 导入根技能时保留嵌套目录，Agent 技能列表遵守技能目录边界，不再多出 `<id>/<sub>` 条目。
- **深树投影与预览滚动**：修复合法深树投影被误报 413 的深度计算问题，并修复决策树预览内容无法在网格内滚动的问题。
- **本地模型恢复**：优化本地模型恢复与离线请求体验，修复恢复竞争、超时覆盖与等待展示，并区分输出不完整与通道故障。
- **MCP 连接稳定性**：多项 MCP 关闭、健康探测与 stdio 进程回收的稳定性修复，包括普通取消、闸门代际、Windows 关停诊断与任务结束方式。

## 改进
- **内置工具命名与加载**：内置工具名称更清晰，职责明确，发现调用改为显式加载，消息投递模式互斥，收件箱删除独立。
- **脚本资源保护**：脚本占用过多内存、CPU 或大量输出时，Agent Service 不再崩溃；会降低脚本优先级、有界收集输出，并在 Windows 上提供提交内存守护，同时在工具结果或横幅中说明原因。
- **MCP 不可用工具展示**：MCP 工具发现时，不可用工具会单独列出并显示诊断码，商店服务详情页展示具体原因。
- **语音选择器体验**：语音选择器显示检查状态与重试，已选模型标记不可用原因，检查失败时不显示假空列表。
- **内置市场技能更新**：内置市场技能更新，watch 技能在无字幕时优先使用语音转写工具，探测脚本输出 JSON 时对路径进行转义。
