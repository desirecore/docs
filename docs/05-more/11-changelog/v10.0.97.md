# DesireCore v10.0.97

**发布日期**: 2026-07-31

## 新功能
- **内置文件工作台**：支持在资源中心直接浏览、编辑和预览工作目录中的各类文件，提供接近 VS Code 的编辑体验，支持 Office 文档（Word/Excel/PPT）高保真预览、PDF 阅读、图片查看和常见代码/配置文件编辑。
- **Agent 间消息全面升级**：向忙碌的 Agent 发送消息时，不再强制起跑新任务，而是将消息放入收件箱并告知发送方对方正在做什么，由发送方自行决定等待、放弃或使用新增的“插话”和“打断”功能干预对方运行。
- **短信验证码人机验证**：所有短信发码入口接入腾讯云验证码，防止恶意刷码，保障服务稳定。
- **合规手机号绑定**：邮箱注册用户登录后，如未绑定手机号，将弹出不可跳过的强制绑定弹窗，满足实名合规要求。
- **聊天记录安全保障**：Agent 或用户手动清除聊天记录时，会自动生成 ZIP 备份文件，防止重要对话意外丢失。
- **上下文压缩可视化**：自动压缩对话历史后，聊天区会显示轻量的可展开分隔线，底部状态栏新增“上下文占用度”指示器，让智能体记忆使用情况一目了然。
- **任务进行中禁止休眠**：电脑有任务（如 Agent 对话、工作流、终端命令）正在执行时，系统将阻止自动闲置休眠（屏幕正常熄灭），避免长任务因休眠中断。可在设置中关闭。
- **终端视口统一**：所有终端标签（包括后台和 Agent 使用的隐藏终端）的分辨率将跟随当前活跃标签的尺寸自动调整，避免切换时 TUI 界面重排或排版错乱。
- **终端标签数字角标**：按住 Cmd/Ctrl 键可在终端标签上显示数字快捷键提示，方便快速切换。
- **终端可读性增强**：提升终端最低对比度，补齐缺失的 ANSI 16 色调色板，修复浅色主题下部分 CLI 工具文字不可见的问题。
- **排队消息队列可视化**：Agent 忙碌时发送的新消息，不再直接消失于对话流，而是以列表形式显示在输入框上方，支持编辑、删除或“中止当前并改发此条”等操作。
- **下一个未读会话导航**：点击左侧会话列表图标，可快速定位并滚动到下一个有未读消息的智能体，方便逐个查看。
- **Agent 列表忙碌指示器**：会话列表和智能体列表中，正在执行任务的项目会显示流动的 `›››` 动画和实时活动文字（如“使用 Bash”），比之前的小圆点更易察觉。
- **Agent 可自主管理团队仓库**：新增 `ManageAgent` 的克隆和 `ManageTeam` 的列表、拉取、推送等操作，Agent 可自主完成从克隆专家到组建团队并推送代码的完整闭环。
- **Agent 可自主管理自身会话**：新增 `ManageConversation` 工具，允许 Agent 标记未读或清除自身聊天记录（含备份）。
- **API Key 安全加固**：所有 API Key 在本地磁盘加密存储，防止被 shell 命令直接读取；Agent 请求 Key 时需经专属的 `ComputeCredential` 工具走审批流程。
- **macOS 完全磁盘访问权限引导**：macOS 首次启动时会主动引导用户授权“完全磁盘访问”，确保文件操作和系统终端等功能正常工作。
- **升级完整性校验（Windows）**：Windows 后台更新安装后，会自动校验核心原生模块是否完整写入，防止安全软件拦截导致的启动崩溃。

## 修复
- **清空聊天记录后消息丢失**：修复了清空聊天记录后立即发送的第一条消息，会被随后的问候语覆盖并消失的问题。
- **委托卡片失败状态缺失**：修复了 `DelegateCard` 在子任务真正失败时，会一直卡在“处理中”或错误显示为“已完成”的问题，现在会正确显示红色“已失败”状态。
- **资源管理器 Agent 状态显示错误**：修复了资源管理器中“智能体”列表与详情页的状态徽标恒为“离线”的问题，现在能实时正确反映在线/忙碌/离线状态。
- **Markdown 列表序号不显示**：修复了聊天气泡、通知中心预览和邮件正文中有序/无序列表的序号和项目符号完全不渲染的问题。
- **排队消息停止后不丢失**：修复了 Agent 流式输出时发送新消息，点击停止后新消息气泡会消失，但实际上 Agent 仍会回复该消息的问题。
- **上下文压缩破坏对话记忆**：修复了 Agent 使用 `ManageContext(reset)` 后，可能导致近期对话记忆永久丢失或早期摘要逐渐消失的问题。
- **暂停按钮失效**：修复了点击“停止生成”按钮时，可能因内部错误导致堆栈溢出而暂停失败的问题。
- **追问卡片高度失控**：修复了 Agent 追问多道选择题时，内容卡片可能过高将输入框完全挤出窗口的问题。
- **追问提交按钮误导**：改进了多题追问时，“提交回答”按钮不再错误地显示为灰色禁用态，而是变为可点击的“去回答”，引导用户跳转到未答题。
- **视频重启后变破图**：修复了工具生成的视频首次显示正常，重启应用后却渲染成破裂图片的问题。
- **侧栏窄屏下删除按钮遮挡**：修复了在较窄窗口下，自动化详情页底部的“删除”按钮会被悬浮聊天按钮完全遮挡、无法点击的问题。
- **自动化面板标题竖排**：修复了拖窄自动化面板时，标题文字会逐字竖排的问题。
- **斜杠命令面板误触发**：修复了在输入框中间输入类似“2: /”的文本时，会意外弹出斜杠命令面板的问题。
- **`RUN_BRANCH_BUSY` 错误消息丢失**：修复了因会话冲突报错时，用户刚发送的消息会直接消失且无法恢复的问题。
- **Agent 间消息显示发送方身份**：修复了 Agent 收到另一 Agent 的消息时，聊天记录里只显示自己的回复、看不见对方发来的消息的问题。
- **团队导出技能与对话丢失**：修复了团队数据导出时，全局技能和对话记录可能被错误归类或遗漏，导致接收方团队无法正常工作或隐私泄露的问题。
- **Markdown 相对路径图片无法预览**：修复了在 Markdown 编辑器或预览中，以相对路径引用的本地图片无法正常显示的问题。
- **续写状态文案生硬**：优化了 Agent 继续生成被中断的回答时，状态栏和按钮的措辞，使其更加友好易懂。
- **通知角标不自动刷新**：修复了在通知中心标记已读后，侧边栏的通知角标不自动消失，需重启应用才能同步的问题。
- **Canvas 多 Agent 共用一个窗口**：修复了多个智能体同时使用网页渲染工具时，会相互覆盖页面内容、截图串台的问题。
- **`running` 状态卡死锁死会话**：修复了某些极端情况下，Agent 运行状态卡死为 `running`，导致该会话无法再发送新消息的问题。

## 改进
- **AgentFS 刷新覆盖团队维度**：对智能体文件系统的任何变更（如拉取团队 git 仓库），现在会自动同步刷新前端的团队工作目录和成员状态，无需手动切换页面。
- **工作目录管理增强**：允许用户在 UI 上完全移除 Agent 的所有工作目录（包括系统默认的）；同时加固了无工作目录时相对路径的安全管控，避免工具回退到进程目录执行。
- **团队仓库安全防护**：撤下了旧的文本式 git 命令拦截，改为在 git 协议层加固（禁止远程传输）结合提示词自查，为 Agent 操作团队仓库提供更健壮的安全措施。
- **终端色彩主题自适应**：新增终端配色方案上报通道，使得在一些会自动检测背景色的 CLI 工具（如 Claude Code 的部分界面）中，能更好地适配应用的深色/浅色主题。
- **后台更新完成全局提示**：选择“后台更新”后，下载完成时会弹出全局提示 toast，提醒用户重启应用，不再静默无感知。
- **Agent 创建/修改前强制加载技能**：Agent 通过 `ManageAgent` 创建或修改自身配置前，现在需要先加载对应的内置技能指引，避免跳过关键步骤。
- **Agent 错误信息可见性增强**：Agent 通过 `InspectRuns` 查看历史记录时，现在能看到明确的失败标记（如 ✗）和错误代码，不再是完全无差别的文本。
- **恢复上下文错误信号保留**：应用重启或崩溃恢复后，Agent 不再丢失之前轮次失败的错误信息，能正确认知到“上次操作失败了”。
- **任务活动中电源管理**：新增独立于 Agent 会话的“任务进行中禁止休眠”全局开关，并优化了后台任务的计算逻辑。
- **上下文占用度显示过滤**：底部状态栏的上下文占用度指示器现在只反映用户当前这一轮的上下文占用情况，不会被后台任务的数据干扰。
- **升级依赖至最新版本**：更新了 TypeScript 7.0 等核心开发依赖，提升系统底层稳定性和性能。
