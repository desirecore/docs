# DesireCore v10.0.97

**发布日期**: 2026-07-31

![v10.0.97 更新概览](/img/changelog/v10.0.97.png)

## 新功能
- **文件工作台**：新增内置文件工作台，支持浏览、编辑和预览工作目录中的各类文件（含高保真 Office 文档预览）。
- **Agent 间消息改进**：向忙碌的 Agent 发消息时，不再并发启动多个会话，而是将消息投递至对方收件箱并返回对方状态，由发送方决定等待、放弃或打断。
- **干预 Agent 运行**：新增 `interject`（插话）和 `interrupt`（打断）两个干预动作，让 Agent 可以干预其他正在执行任务的 Agent。
- **对话管理工具**：新增 `ManageConversation` 内置工具，Agent 可自主管理未读、标记已读及清除聊天记录；清除聊天记录前会自动创建 ZIP 备份。
- **Agent 自主管理团队仓库**：扩展 `ManageAgent` 和 `ManageTeam` 工具，Agent 现可自主完成克隆专家、管理团队仓库、推送更改等完整闭环操作。
- **排队消息可视化**：在输入框上方新增队列面板，用户可直观查看、编辑、删除或干预排队中的消息，同时支持中止当前回复并优先发送指定排队项。
- **macOS 完全磁盘访问权限引导**：macOS 启动时自动检查并引导用户授予完全磁盘访问权限。
- **防止任务中断**：新增“任务进行中禁止计算机休眠”总开关，默认开启，避免长任务因系统闲置休眠而中断。
- **短信人机验证**：短信发送接入腾讯云人机验证（TCaptcha），提升账户安全性。
- **API Key 加密存储**：API Key 加密落盘，并新增 `ComputeCredential` 受控读取通道，堵住通用 Shell 直接读取密钥的路径。
- **邮箱账号强制绑定手机号**：未绑定手机号的邮箱账号登录后，须完成合规要求的手机号绑定。
- **团队导出/导入改进**：补齐全局技能的导出/导入，修复对话记录与工作区文件归属错误的问题。
- **终端标签数字角标**：按住 Cmd/Ctrl 时，终端标签栏显示对应数字角标，方便快速切换。
- **终端视口统一**：后台终端与隐藏终端的分辨率会自适应窗口尺寸，避免切换标签时 TUI 强制重排。
- **会话入口定位下个未读**：点击左侧会话图标可滚动定位到下一个未读 Agent。
- **上下文压缩改进**：压缩范围由锚点精确定义，历史摘要改为按时间顺序链式保留，并在聊天界面新增可展开的压缩痕迹分隔线。
- **GitHub CLI 安装检测**：算力设置-运行环境页新增 GitHub CLI (gh) 安装检测卡片。
- **Canvas 窗口会话隔离**：修复多个智能体并发调用 Canvas 时共用同一窗口互相覆盖的问题，现按会话隔离窗口。

## 修复
- **Agent 列表状态恒显离线**：修复资源管理器中 Agent 列表恒定显示“离线”的问题，现在会正确显示实时在线/忙碌/离线状态。
- **暂停按钮失效**：修复在生成过程中点击暂停按钮因循环引用导致栈溢出而无法停止的问题。
- **Markdown 列表序号不显示**：恢复有序/无序列表的数字序号和项目符号（此前因样式冲突未渲染）。
- **媒体类型错误导致视频变破图**：修复重启后工具生成的视频被错误渲染为“裂开图片”的问题。
- **覆盖导入后清空聊天记录无备份**：更新模式导入已有 Agent 后清空聊天记录时，默认自动备份。
- **目标 run 正在执行时消息丢失**：修复因目标 run 正忙导致新消息刷新后消失的问题，现会暂存消息并在 run 空闲后自动发送。
- **清空聊天记录后首条消息被吞**：修复清空历史后立刻发送的消息被异步返回的 greeting 覆盖丢弃的问题。
- **追问多题场景下提交按钮语义不清**：增加“去回答”按钮和上下题翻页箭头，引导用户跳转到首个未答题目。
- **追问卡片高度失控挤走输入框**：限制追问卡片最大高度为 `420px` 并改为三段式布局，确保输入框常驻可见。
- **窄屏下自动化面板的布局问题**：修复删除按钮被悬浮聊天按钮遮挡及标题逐字竖排的问题。
- **通知已读后角标不刷新**：修复标记通知已读后前台角标不自动消失的问题。
- **团队仓库 git 防护的加固**：将易被绕过的命令文本拦截，替换为更底层的 git 配置加固与提示词自查。
- **斜杠命令面板误触发**：收紧触发条件，仅当 `/` 出现在整条输入开头时才弹面板，不再误弹。
- **Agent 创建的 persona.md 内容为 JSON**：修复工具创建的 Agent 人格文件被存为 JSON 文本而非 markdown，导致提示词失效的问题。
- **续写状态文案生硬**：将“续写(length)”等暴露内部枚举的文案改为“正在处理”，并将具体原因弱化展示。
- **Markdown 相对路径图片预览**：修复以当前文档为基准解析相对图片路径，并补齐文件来源校验和权限边界。
- **Agent 无法感知运行报错**：为 InspectRuns 工具转写补上失败标记，并在恢复上下文中保留错误信号。
- **委派失败后卡片无终态**：为委派卡片补上红色“已失败”终态，修复其一直停在“处理中”的问题。
- **Windows 升级的完整性校验**：增加原生模块完整性校验，防止安装被安全软件拦截后误报升级完成。
- **关闭 IPC 事件透传**：修复暂停按钮将 React 事件对象透传到 Socket.IO 中导致爆栈的问题。
- **终端对比度不足**：补齐终端对比度下限、ANSI 调色板和 `COLORFGBG` 环境变量，确保在纯黑/白背景下的文字始终可读。
- **running 卡死永久锁死会话**：新增孤儿逃生门，修复因异常导致对话发不出消息、只能重启应用的问题。

## 改进
- **Agent 列表忙碌状态更直观**：用动态流动的 `›››` 箭头和实时活动文字（如“使用 Bash”）替换原先静态的忙闲圆点。
- **子智能体与被委派 Agent 的区分**：右上角状态栏准确区分临时子智能体（显示为灰色“子”头像）和被委派的完整 Agent（真实头像与名称）。
- **Agent 间来信展示来信方头像与名称**：在目标 Agent 聊天中清晰显示消息来源。
- **后台更新完成全局提示**：后台更新下载完成后弹出持久 Toast 提示重启，不再静默让用户错过。
- **工作目录打开功能可用且失败可见**：统一各入口的工作目录“在文件夹中打开”交互，并在失败时提示具体原因。
- **允许删除 Agent 默认工作目录**：支持将工作目录清空，并收紧无工作目录时的路径兜底与权限控制，防止文件操作越界。
- **一条会话支持两路并发流**：前端支持在同一会话正确处理用户前台和 Agent 后台来信两路并发流，避免它们串字或抢占停止按钮。
- **Agent 生命周期强制加载技能**：要求 Agent 在执行创建/更新/删除操作前先加载对应内置技能，避免跳过关键步骤。
- **文件系统刷新覆盖团队维度**：文件系统刷新扩展至团队目录，团队配置变化会实时同步至前端。
- **上下文占用度显示改进**：过滤掉后台运行产生的上下文占用度，确保状态栏显示的仅属于当前用户会话。
- **消息收发语义的明确声明**：SendMessage 的 `notify_only` 和 `wait` 参数改为显式声明，让决策权回归调用方。
- **AgentFS 的上下文刷新**：团队配置与工作目录的变化会实时同步至前端 AgentFS 面板。
