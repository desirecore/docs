# DesireCore v10.0.108

**发布日期**: 2026-08-13

![v10.0.108 更新概览](/img/changelog/v10.0.108.png)

## 新功能
- **后台任务自动跟进**：后台任务（异步委派或子任务）完成后，Agent 会自动接手处理回报，无需等待用户再次发消息；自动触发的消息会标注为系统自动消息，与用户发言明确区分。

## 修复
- 修复登录时腾讯验证码无法加载、发送验证码卡死的问题。
- 修复安装包内置 Git 因模板目录安全拒绝导致 Agent 自动提交及市场、注册表、配置中心 Git 同步失败的问题。
- 修复退出 DesireCore 后可能遗留 HostAgent 进程的问题，关闭次级实例窗口也会正确停止所属 HostAgent。
- 修复终端同时出现在聊天区底部和工作台两处、以及工作台终端快捷键失灵（如切换标签误切智能体、关闭标签无响应、新建标签无效）的问题；现在终端只在一处显示，打开文档时终端退为后台标签而会话不断，全新安装也不会自动创建多余终端。

## 改进
- 模型路由的人工确认弹窗文案更易懂，取消切换模型不再误报“保存失败”；打开模型面板确认一次后，短时间内调整模型无需重复确认，云账号相关操作也减少了重复弹窗。
