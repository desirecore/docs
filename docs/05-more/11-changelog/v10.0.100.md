# DesireCore v10.0.100

**发布日期**: 2026-08-09

![v10.0.100 更新概览](/img/changelog/v10.0.100.png)

## 新功能
- **浏览器集成**：智能体现在可以操控内置浏览器，进行网页搜索、浏览和表单填写等操作。
- **内置终端**：新增终端面板，支持在应用内直接执行 shell 命令，并保留会话历史。
- **文件工作台**：统一管理项目文件，支持创建、编辑、预览多种文件格式，并提供目录树浏览。
- **任务管理器**：新增任务管理视图，可查看后台异步任务（如自动化、工作流）的进度与结果。
- **委派运行详情**：支持查看子智能体委派运行过程的完整消息记录和转写。
- **数据迁移引导**：提供从其他 DesireCore 实例导入数据的逐步向导，简化过渡流程。
- **手机验证码登录**：新增手机号注册、登录和绑定功能，支持短信验证。
- **应用内支付**：集成支付功能，可直接在应用内完成套餐购买与续费。
- **后台更新与静默下载**：支持后台自动下载更新，并在可用时通过通知提示重启。
- **上下文窗口指示**：聊天界面显示当前上下文窗口使用情况，方便感知剩余容量。
- **弱网检测与提示**：自动检测网络连接状态，弱网时给出明确提示。
- **模型推理强度显示**：模型选择器内展示推理强度等级，方便按需选择模型。
- **审批策略设置**：支持配置智能体执行操作的审批策略（如始终询问、自动执行等）。
- **代码审查工作台**：智能体产生的文件变更可以以并排 diff 形式审查并支持一键回退。
- **会话分组与手动会话**：支持手动创建和管理会话分组，灵活整理多主题对话。
- **公告推送**：运营公告可在应用内弹窗展示，及时传递重要通知。
- **团队发布向导**：简化团队协作中的发布流程，让共享智能体配置更便捷。
- **Canvas 卡片消息**：对话中可直接展示可交互的 Canvas 画布卡片。
- **记忆卡片增强**：记忆卡片展示更多元数据，管理长期记忆更直观。
- **批量删除消息**：支持一次性删除多条对话记录，方便清理历史。

## 修复
- 修复审批卡片与问答弹窗在特定场景下的交互异常。
- 修复对话导出时 Markdown 格式丢失或内容错乱的问题。
- 修复 Markdown 代码块渲染时内容溢出或显示混乱。
- 修复 IMAP 邮件同步偶尔失败及离线队列处理异常。
- 修复自动更新在某些 Windows 系统上提示错误或无法重启的问题。
- 修复环境检测向导中部分项误报或界面卡死的问题。
- 修复长对话中回撤操作可能导致消息显示不一致的问题。

## 改进
- 优化大量消息列表的滚动性能，降低内存占用。
- 改进模型选择器的供应商分组和搜索体验。
- 终端色彩保真度和输入响应得到提升，支持更多键盘快捷键。
- 邮件服务的离线队列和重试机制更加稳定。
- 登录页增加密码强度校验和更清晰的错误提示。
- 系统设置增加数据隐私、电源管理等细粒度选项。
- 从市场安装智能体时可指定工作目录，灵活组织文件。
- 对话流式响应时的连接恢复能力增强，弱网环境下更鲁棒。
- 对话界面支持更丰富的卡片式消息展示，如文件变更、委派状态等。
