# DesireCore v10.0.130

**发布日期**: 2026-08-30

![v10.0.130 更新概览](/img/changelog/v10.0.130.png)

## 新功能
- **决策工作区**：任务板新增受治理的人机决策工作区，你可用业务语言描述决策并让智能体提案，再亲自确认、要求修改或最终批准，全程保留版本、证据与可靠性校验。
- **算力服务治理**：智能体能在授权范围内查看、启停模型服务并同步模型，你也可以为自管服务配置凭据，密钥全程不会泄露给智能体。
- **外部浏览器确定性打开**：智能体打开外部网页前会先探测本机浏览器安装与端口状态，仅在浏览器就绪且获得短期授权后直接打开；若未安装或端口未开启，会明确提示你手动处理，不会误执行系统命令。

## 修复
- 新建或更新项目时选中的目录会立即出现在工作目录根下拉中，团队共享目录也会同步；删除当前选中目录后，文件工作台不再误显示“没有工作目录”的空状态，聊天输入区与资源面板也会同步刷新。
- 修复本地有未提交修改的智能体点击“仍要更新”后仍被阻止的问题，现在可“保存并更新”，只有真实冲突才会打开冲突解决器；同步中断后支持继续恢复，同步期间普通写入、提交和运行请求会安全拒绝。
- 修复苹果系统启动时“完全磁盘访问”授权弹窗可能阻塞智能体服务启动的问题。
- 修复外部浏览器脚本在总预算收紧时最后一条命令可能被误报失败，以及跨轮对话中技能专属工具偶发丢失或授权范围意外扩大的问题。
- 修复无密钥模型服务的状态与模型可选性显示异常，并补全错误提示。
- 修复工作目录相关接口的路径校验缺陷，防止已登录用户越界写入配置文件。

## 改进
- 密钥与敏感参数现在会在审批、日志、回执、会话记录和工具卡片中自动脱敏，未经你主动允许，智能体无法读取明文。
- 智能体同步的风险判断与状态刷新在顶栏、更多菜单、市场和发布入口保持一致，多窗口操作后也能收敛到同一状态。
- 外部浏览器打开与读取网页的权限已分离，端口关闭时只提示手工启动，不会触发系统命令或重复模型请求。
