# DesireCore v10.0.155

**发布日期**: 2026-09-10

![v10.0.155 更新概览](/img/changelog/v10.0.155.png)

## 修复
- 修复了会话历史中包含无效时间戳的消息导致整个会话无法继续发送的问题，这些会话现在可以正常使用。
- 修复了 Windows 版本构建失败导致 Windows 用户无法升级的问题，Windows 用户现在能够收到该版本更新。
- 修复了市场项目团队名单同步信息不准确的问题，显示的团队名册更正确。
- 修复了工具输出预算单位不一致导致中文等多字节字符内容可能被错误截断的问题，工具输出现在按字节正确计量。
- 修复了浏览器自动化输入围栏在窗口最小化或隐藏、拖拽路径检查及显示器查询异常时的漏洞，提升了自动化控制的可靠性。
- 修复了 Windows 任务执行时可能被工作目录中的恶意程序劫持的安全漏洞，同时任务降级原因现在会明确展示，不再静默。
- 修复了版本化数据并发锁可能误报完整性错误导致操作失败的问题，并发场景下操作更稳定。

## 改进
- 优化了长会话恢复历史的加载方式，恢复速度更快、内存占用更低。
- 减少了应用模块加载数量，提升了应用启动和界面切换的响应速度。
