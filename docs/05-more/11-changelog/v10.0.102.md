# DesireCore v10.0.102

**发布日期**: 2026-08-11

![v10.0.102 更新概览](/img/changelog/v10.0.102.png)

## 新功能
- **智能模型路由**：智能体现在可根据任务需求自动选择最合适的模型（轻量 / 均衡 / 旗舰），并在创建、团队协作、委派等场景下持久化当前模型选择，让任务在成本与效果之间自动取得平衡。

## 修复
- 修复了桌面正式版中终端因依赖缺失无法启动，数秒后直接显示“已关闭”的问题。
- 修复了工作区面板隐藏后重新展开时，终端之前的会话无法恢复的问题。
