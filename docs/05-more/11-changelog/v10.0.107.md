# DesireCore v10.0.107

**发布日期**: 2026-08-12

![v10.0.107 更新概览](/img/changelog/v10.0.107.png)

## 新功能
- **HostAgent 本机自动连接**：macOS 客户端随包分发并管理已签名、公证的 HostAgent 0.3.0，本机自动安装、校验并建立安全连接，算力资源中可查看状态和管理入口。
- **按服务商范围受控的智能路由**：模型选择器统一为一个“智能路由”选项，可多选允许参与路由的服务商；系统在每次实际运行前按策略实时确定服务商、模型和推理强度。
- **侧边栏搜索升级**：支持拼音全拼、首字母和混合搜索，结果按相关度排序并高亮命中片段，搜索范围扩大至聊天记录、技能和市场，并新增 Mod+Shift+K 快捷键聚焦搜索框。

## 修复
- 修复侧边栏搜索中方向键高亮与回车打开不一致、仅命中简介时键盘操作完全失效、无结果时 Esc 无法退出搜索的问题。
- 修复 /subtask 在团队会话中提示“已在后台启动”但实际静默失败，以及嵌套检测误判导致会话无法再次发起子任务的问题。
- 修复 /subtask 和 /reset 在无可用会话时静默吞掉输入与附件的问题，现在会给出提示并回填输入内容。
- 修复任务管理器中“智能体正在生成”条目在真实使用中从不出现、停止按钮缺失或失效的问题；回撤、分叉和长会话续聊后也能正确显示并停止对应运行。
- 修复 Windows 下常驻终端宿主进程继承已退出主进程的调试端口，导致重启后端口被异常占用的问题，并支持端口自动避让。
- 修复内嵌浏览器视图遮挡升级弹窗等全局模态框的问题，模态框打开期间浏览器自动让位，关闭后恢复。
- 修复模型在工具调用之间夹带普通内容时，部分 Anthropic 兼容网关误报缺少工具结果、导致请求失败的问题。

## 改进
- 子任务在界面中与子智能体保持一致：归入“子智能体”分组、显示为“子任务”、可点击查看运行记录，并计入后台进行中数量。
- 子任务继承的历史不完整时会明确告知子任务，避免其基于残缺背景直接操作文件；子任务不再显示为“自己发给自己”，开始和结束状态也能正确配对与收尾。
- 智能体/团队导入改为事务化处理，失败或中断后会安全回滚，不再留下半导入状态；智能路由策略存储受保护，缺失或损坏时安全拒绝，防止工具或自动化流程越权修改。
