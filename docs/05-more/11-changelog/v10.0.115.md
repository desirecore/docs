# DesireCore v10.0.115

**发布日期**: 2026-08-21

![v10.0.115 更新概览](/img/changelog/v10.0.115.png)

## 新功能
- 终端 URL 可点击并经横幅确认在内置浏览器打开 (#2111)
- 执行载体换成独立子进程 + Node 权限模型 (#2121)
- 智能体/团队导入导出支持携带外部工作目录 (#2079)

## 修复
- 恢复团队成员安装残留 (#2129)
- 支持 fixed 调用方创建智能体 (#2124)
- 记账过期时自愈重试一次，补 #2120 只改同步时机的漏洞 (#2126)
- sessions 缺 bounds 时点名字段 + 审计事件区分闸门放行来源 (#2072) (#2116)
- 等待 async 委派的后台续体，消除 gate 偶发 Unhandled Rejection (#2033) (#2119)
- 端口发现文件发布与实例控制面解耦 (#2115)
- navigate 失败路径也同步 documentEpoch，修 skip 后续用例撞 EPOCH_STALE (#2120)
- input.* 在 embedded 离屏标签页视口 0×0 时快速失败而非挂满 30s (#2091)
- 绑定文件化 Plan 到 canonical Task (#2107)
- preserve automation next run across resume and restart (#2104)
- 提升任务板流程与关联入口可发现性 (#2105)
- 绑定 Task 工具到运行时工作上下文 (#2103)
- 澄清任务板与任务归档恢复体验 (#2102)
- 修复 Task 引用草稿实时回填并补全真机验收 (#2100)
- agent-actor 标签页改挂专用不可见宿主窗口 (#2093)
- CDP 通道加固——sendSession 收口 + 解析前大小上限（#2070） (#2076)
