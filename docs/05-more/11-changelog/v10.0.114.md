# DesireCore v10.0.114

**发布日期**: 2026-08-18

![v10.0.114 更新概览](/img/changelog/v10.0.114.png)

## 新功能
- **统一文件与文档工作区**：聊天工作区一级工具收敛为终端、浏览、文件、审阅，所有文件（Markdown、代码、文本、图片、PDF、Office 等）统一从"文件"入口打开、由格式自动选择内容模式，无需再区分"文件"和"文档"。

## 修复
- 内嵌浏览器不再遮挡浮层：弹窗、菜单、面板等界面元素现在可以正常显示在内嵌浏览器页面之上，不会再被"切掉一半"或完全盖住。
- 内置浏览器读取网页正文恢复可用：默认模式下 Agent 提取页面文本不再必然失败，页面元素交互也不再因通道错误而失败。
- 内置浏览器长等待与大数据结果修复：长时间等待不再被 30 秒固定超时误杀或中断同页面其他加载，大结果的计量与截断现在与实际传输大小一致。
- 空闲会话点击"重试"不再出现假排队，重试命令会真正执行并生效。
- 消息渲染与编辑更可靠：聊天消息中的美元金额（含带空格、正负号、前导小数等写法）不再被误解析为公式，编辑含附件的历史消息也能正确派生新回答并跨重启保存。
- Agent Service 冷启动不再误报连接故障：应用现在能区分正常的冷启动与真实故障，恢复页会在本地启动期间自动重试连接。
- 稳定性修复：并发浏览器子任务遭遇网络错误、超时或模型过载时应用不再异常退出，macOS 上权限模块不可用时安全降级，模型服务预设配置不再出现同版本误报不一致。

## 改进
- 终端跨重启恢复更安全可靠：重启后接回的终端会校验身份与当前工作目录，身份不确定的终端进入隔离态等待显式 Ctrl-C 重新同步，健康终端在被点击时重新验证目录，避免在过期目录或错误会话中执行。
