# DesireCore v10.0.175

**发布日期**: 2026-09-23

![v10.0.175 更新概览](/img/changelog/v10.0.175.png)

## 新功能
- **Agent 自主安装与维护应用**：智能体现在可以依据应用的说明、源码、SQL、配置和环境自主完成安装、验证、更新与卸载，无需预先提供固定安装脚本；应用市场支持委托安装、精确打开/移除实例，并显示上次验证时间。
- **团队任务板创建**：智能体新增创建团队任务板的能力，可在团队上下文中显式建立用于多人协作的任务板。

## 修复
- 修复了包含历史消息的智能体会话因缺少用量信息而无法响应的问题，特别是带有默认问候语的场景。
- 修复了 Windows 和 Linux 的 ARM64 安装包缺少必要组件，导致安装后可能无法正常启动的问题。

## 改进
- 升级了常用外部模型服务的接入组件，提升与最新模型服务的兼容性和稳定性，并加强了邮件草稿的校验逻辑，缺失必要信息时会给出明确提示。
