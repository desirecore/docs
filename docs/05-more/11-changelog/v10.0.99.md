# DesireCore v10.0.99

**发布日期**: 2026-08-05

![v10.0.99 更新概览](/img/changelog/v10.0.99.png)

## 新功能
- **模型按供应商分组**：模型选择列表现在按供应商（如智谱、DeepSeek 等）分组展示，带有供应商 Logo 和名称，方便快速定位所需模型。
- **接口审计刷新**：接口审计页面新增刷新按钮，无需整页刷新即可获取最新审计请求与统计记录。
- **贝壳 Wings 需求澄清门禁**：为贝壳 Wings 运筹场景新增需求澄清流程，业务时间等关键信息确认前必须先通过事实门禁，避免基于未确认假设进入模型求解。

## 修复
- **工具执行实时可见**：长耗时工具（如后台脚本）现在从执行开始就显示运行中卡片并带有状态动画，不再等到执行完毕才突然出现。
- **测试实例数据隔离**：修复了 dev 和测试实例中 Agent 记忆、密钥文件错误写入生产目录的严重问题，测试实例不再污染或读取生产环境的私有数据。
- **Windows 发布构建失败**：修复了 Windows 平台因 BrowserHost 原生程序未签名导致发布构建失败的问题，三平台构建现已全部可用。

## 改进
- **终端标签图标**：终端标签栏现在显示终端图标，一眼可区分终端与其他标签；按住 Cmd/Ctrl 时数字快捷键角标会顶替图标，标签标题不再左右抖动。
- **终端 Alt+方向键**：恢复了终端中 Alt/Option+← → 按词移动光标的功能，修复了 macOS 下 Option+方向键无响应的问题。
- **安全漏洞清零**：npm audit 安全漏洞从 4 个降至 0，61 个依赖包升级至最新稳定版本。
