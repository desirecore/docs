# DesireCore v10.0.129

**发布日期**: 2026-08-29

![v10.0.129 更新概览](/img/changelog/v10.0.129.png)

## 新功能
- 团队内容核准：团队规则与成员列表变更需用户核准后才会注入智能体，防止未确认的远端更新静默影响所有成员。
- 发布版 GUI 接管多实例：发布版现默认启用 GUI 接管，多实例间独立分配 CDP 端口并隔离身份，开箱可用且仅限本机回环访问。

## 修复
- 修复会话标题栏在长名称或多徽章时内容遮挡右侧按钮的问题，并优化导航加号间距及移除冗余工具提示。
- 修复文件工作台预览失败原因在中文界面下仍显示英文、以及新增工作目录后根目录下拉列表不刷新的问题。
- 修复智能体编辑自身配置文件时可能绕过 ManageAgent 工具的问题，同时对用通用文件工具直接修改智能体配置增加了人工确认。
- 修复旧版 git 传输防护残留配置导致的手动 git pull/push 失败问题，现已自动清理。

## 改进
- 优化智能体生命周期提示词与审批判据，降低模型绕过管理工具的概率，并减少每次审批请求的 token 消耗。
