# DesireCore v10.0.112

**发布日期**: 2026-08-16

![v10.0.112 更新概览](/img/changelog/v10.0.112.png)

## 新功能
- **发送失败恢复与超时撤回**：消息发送失败后，输入内容会自动回填到输入框；当本地服务连接中断超过 30 秒且消息尚未被服务端接纳时，可安全撤回该未发送消息，避免内容丢失。
- **浏览器元素级操作命令**：内置浏览器新增九种页面元素操作（填写、选择、勾选、取消勾选、获取属性、获取边界框、计数、获取所有文本、滚动到元素），让智能体能够直接操作网页表单和元素。
- **浏览器快照文本树与分页**：页面语义快照改为带层级的文本树展示，并支持元素数量与大小双预算截断及分页游标，即使页面很大也能稳定获取结构信息，不再因结果过大而报错。

## 修复
- 修复 Windows 上强制停止任务后状态不同步的问题，任务行会正确显示“已退出”，导航栏徽标只显示活动用户任务数量，并确保相关进程被完全终止。
- 统一聊天、团队、人员、资源、技能、自动化等多处界面的实体头像渲染，图片头像加载失败时回退到稳定字符标识，并修复技能与自动化管理中头像丢失的问题。
- 修复客户端升级时无法使用差量更新的问题，部署脚本恢复上传 blockmap 文件后，跨版本升级下载量从整包约 447 MB 降至差量约 50 MB，大幅提升升级速度。

## 改进
- 优化主界面标签切换性能，隔离 React 订阅、暂停非活动页轮询，降低卡顿和资源占用，同时修复人员工具栏在中等宽度下的裁切问题以及沉浸模式返回后的界面残影。
- 改进内置浏览器的网络域管理，通过引用计数租约避免多个功能同时使用网络监听时被意外关闭，提升浏览器自动化的稳定性和可靠性。
