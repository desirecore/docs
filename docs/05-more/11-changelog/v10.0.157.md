# DesireCore v10.0.157

**发布日期**: 2026-09-12

![v10.0.157 更新概览](/img/changelog/v10.0.157.png)

## 新功能
- **市场智能体统一更新规则**：市场安装的智能体改为 Git 派生方式管理，更新时会合并本地与上游修改，不再因本地内容被改过而无法更新或被强制覆盖；卸载前若检测到本地修改会先要求确认。
- **重置到上游**：市场智能体详情页新增“重置到上游”操作，可在确认后丢弃本地修改并恢复到上游最新版本。
- **存量安装自动升级与周期检测扩展**：旧版市场智能体会在启动时自动转换为新的 Git 管理方式；自动更新检测现在覆盖所有声明上游的智能体，而不仅是核心智能体。

## 修复
- 修复市场“全部”页因智能体与团队排序问题导致看不到团队的问题。
- 修复定时调度、心跳和 Webhook 后台任务未遵循智能体思考深度设置的问题。
- 修复 AI 审批遇到瞬时网络失败时被直接判为审批不可用，导致后台命令被拒的问题。
- 修复生成本机配对码时，之前发出的状态读取可能清掉刚生成的明文码的问题。
- 修复服务重启后同步浏览器事件时因整份深拷贝状态导致 CPU 占满、无响应的问题。
- 修复市场详情页切换智能体时在途的卸载或重置请求可能误操作到另一个智能体的问题。

## 改进
- 定时任务账本体积大幅缩减（实测从 312 MB 降至 1.8 MB），显著加快调度恢复与启动速度。
- 当当前客户端版本低于要求时，更新、重置或修复智能体会明确提示所需最低版本，而不再笼统失败。
