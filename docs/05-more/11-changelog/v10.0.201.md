# DesireCore v10.0.201

候选说明，尚未发布。

## MCP 连接与工具目录

- stdio 与 Streamable HTTP 自动兼容新旧协议服务器。遇到旧服务器探测兼容问题时，可对该服务器设置 `version_negotiation: "legacy"` 后重连。
- 工具、资源与 Prompt 目录按服务器的有效期刷新。`ttlMs: 0` 每次重新发现，列表订阅断开后自动恢复重试。
- 修复后续对话的凭据归属、并发失效时目录意外为空，以及订阅从低频退避恢复的问题。
- OAuth 补授权增加跨请求额度与退避，并分别说明回调地址拒绝和授权服务器身份不匹配。
- 显式授权的 Sampling 按发起请求与服务器计额，串行处理相关调用，停止发起轮会取消在途采样。
- MCP Tasks 和 MCP Apps 暂不可用。

## 配置兼容

发布使用非默认 `version_negotiation` 的智能体时，将 `requiredClientVersion` 至少设为 `10.0.201`。SSE 连接保持旧协议。

从旧版升级时，含未知键的手写或导入 MCP 配置首次经过新的规范化可能改变权限来源摘要。引用这些配置的定时任务与 Webhook 需要重新注册。
