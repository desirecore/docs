# DesireCore v10.0.192

**发布日期**: 2026-10-28

![v10.0.192 更新概览](/img/changelog/v10.0.192.png)

## 新功能
- **任务板工作区整合**：任务板原「当前任务板 / 自动处理 / 流程 / 关联」四个顶层标签收进统一的工作区，以概况、列表·看板、自动处理、流程、关联图子标签展示，并可记录返回目标。
- **任务步骤进度自报**：执行智能体可自报任务步骤进度，委派总览与任务详情显示分步进度条，并在执行结束时显示停在第几步。
- **结构化验收标准**：委派人可设定结构化验收标准，执行智能体提交时逐条自评，返工可勾选未满足条目，验收面板逐条展示标准与自评结果。
- **任务执行结束通知**：任务执行结束而未提交时通知任务板所有者，新建任务板默认启用该通知策略。
- **工作流人工节点并入委派总览**：工作流运行到人工节点时，委派总览「待你决定」会显示对应卡片，不再只在活动列表中可寻。
- **任务板启动受治理工作流**：任务板可关联并启动受治理工作流，运行参数表单可按触发任务预填参数。
- **团队归档与恢复**：解散团队时自动归档，支持随时从归档中恢复团队。
- **ManageTeam 归档能力**：团队管理工具新增查看归档与从归档恢复团队的动作，智能体可直接处理团队归档。
- **跨 Agent 已归档话题列表**：新增跨 Agent 的已归档会话话题列表接口，为后续归档页提供会话分段。
- **委派与后台运行结局写回**：委派与后台运行结束后将执行结局写回任务认领，任务不再一直显示「执行中」，并支持启动对账补写。
- **责任变更后自动唤醒**：改派、移交与指定审核人后可自动 @ 新负责人或审核人开始处理，新委派也直接登记唤醒，派单失败会显示「未能通知」。
- **团队导入覆盖确认**：重复导入团队包前会先确认再覆盖，确认交互与智能体导入一致，对话记录冲突时给出「取消勾选后重新导入」的明确说明。
- **决策树真人输入体验优化**：真人回答界面将当前问题、帮助、单位与回答放入主卡片，支持多行文本输入，可选问题提供「我已看到」与「暂不回答」独立动作。
- **布尔问题单选按钮**：真人布尔问题改为直接可点的单选按钮，无需打开原生下拉菜单即可选择是或否。
- **发行版 App 图标**：启动页与连接恢复页按发行版显示对应 App 图标，无品牌发行版不再露出默认图标。
- **审批「全部放行」说明**：「全部放行」选项增加说明表，明确其适用范围，侧聊只管理所属主连接的审批设置。
- **应用工作提案预算**：应用连接时可获知宿主对完整 UTF-8 提案的实际字节限额，避免按字符裁剪中文上下文时误判。
- **应用开发草稿来源会话**：智能体开发应用时可从平台取得可信的草稿来源会话 ID，发布到「我的应用」不再因来源猜测失败而中断。

## 改进
- **内置技能启动加速**：内置技能同批写入只做一次 fresh Git 来源复核，冷启动与技能同步耗时显著缩短。
- **委派总览跨板查询性能**：跨板任务查询改用专用读取并分段让出事件循环，大板与多板场景不再长时间阻塞服务。
- **任务板旧板读取优化**：无索引旧任务板读取当前板只读最新提交，启动与 Run 结束写回不再被整段历史卡住。
- **依赖升级与安全修补**：核心组件更新至安全修补版（TypeBox、PDF 预览引擎、WebSocket 插件、Hono、IP 地址库、CDP 协议、白板编辑依赖等），提升稳定性与安全性。
- **市场与内置技能同步**：同步市场内容，邮件操作与发票整理助手更新到 1.2.0，独立 Office 技能补齐依赖入口，watch 技能改为可安装。
- **MCP 连接结构优化**：外部 MCP 连接构造与 SDK 加载收拢到统一模块，进程内只保留一份 SDK 实例，减少重复加载。
