# DesireCore v10.0.171

**发布日期**: 2026-09-20

![v10.0.171 更新概览](/img/changelog/v10.0.171.png)

## 新功能
- **会话持久化恢复**：重启或异常退出后，原对话会保持原会话身份，并自动恢复已激活技能、工具声明、权限范围与运行状态，不再重新执行技能或重发上一条消息。

## 修复
- 修复主聊天与独立资源面板并存时附件操作串扰，以及丢弃工具结果后文件清单和交付入口消失的问题。
- 修复凭据列表/设置操作的结果摘要被误标为“含凭据明文”，导致后续轮次丢失服务商清单和覆盖旧密钥信息的问题。
- 修复并发审计对自委派和旧后台任务误报冲突的问题。
- 修复直接编辑人格/原则文件后派生状态不刷新，以及异步删除通知可能误删重建实例或新授权的问题。
- 修复备份目标失败后归档与加密流未及时清理的问题，并提升多个底层组件的安全性。
- 修复未公开版本的更新日志提前出现在客户端更新弹窗中的问题。

## 改进
- 重构语音处理内核并修复同步回调顺序，使语音响应更稳定可靠，兼容现有语音能力。
- 更新分发改为按版本和平台固定发布快照并完整校验制品，避免补传版本信息混用，提升更新可靠性。
- 开发调试模式下将隔离缓存收纳入指定实例目录，清理更干净，不影响正式用户数据。
