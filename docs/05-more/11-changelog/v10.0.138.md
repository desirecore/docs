# DesireCore v10.0.138

**发布日期**: 2026-09-01

![v10.0.138 更新概览](/img/changelog/v10.0.138.png)

## 新功能
- **市场团队资产分发**：市场新增“团队”类型，支持浏览、搜索、查看详情并一键安装多 Agent 团队。
- **安装后待办清单**：团队安装完成后，在详情页以常驻区块展示规则核准、成员执行授权和共享工作目录绑定等需要用户确认的待办事项。
- **文件摘要工具（FileDigest）**：Agent 可生成文件 SHA-256 摘要与顺序无关的聚合摘要，无需使用 Bash，并遵循与文件读取相同的访问边界。
- **对话任务自动登记**：在对话中交办执行性任务时，会自动在任务板登记一条任务并随进度更新，无需用户明确要求记录。
- **团队成员远程来源**：支持将团队成员标记为远程来源，使组建好的团队可发布并安装到其他设备。

## 修复
- 修复团队规则与名册核准始终返回 400 错误、导致团队协作规则无法启用的问题。
- 修复未初始化 Git 的团队在设置面板看不到规则待核准提示、也没有核准入口的问题。
- 修复开启工作目录限制的成员读不到所属团队共享知识包的问题，现在团队知识包对成员只读可见且不可写入。
- 修复团队成员会被引导主动读取未核准团队规则的问题，未核准的规则正文不会被视为可执行指令。
- 修复初始化 Agent 仓库时未写入 .gitignore，导致 Agent 间消息被纳入版本历史、发布后可能泄漏对话内容的问题。
- 修复通过 Git 安装私有仓库资产时认证失败或凭据未被注入导致安装失败的问题。
- 修复市场团队安装时版本锁定不生效的问题：声明的版本引用或分支会被兑现并在安装后复核，不满足则拒绝安装；成员提交锁也只接受完整提交哈希。
- 修复成员解析失败时错误回显会泄漏 Git 仓库地址或凭据的问题，回显前会进行脱敏。
- 修复升级后旧市场索引缺少团队字段导致市场页报错，以及团队详情时间格式导致接口异常的问题。
- 修复 Windows 上启动时恢复页停留过久的问题，缩短冷启动等待时间。
- 修复 Git 查询失败被静默当作“已是最新”导致市场/配置同步停止更新的问题。

## 改进
- 聊天模型列表手动刷新不再弹出成功、部分失败或失败提示，后台云模型同步失败保持静默并保留重试入口。
- 市场团队搜索支持按组长名和成员名查找团队。
- 团队安装过程显示“正在克隆团队仓库并逐个安装成员”的进行中状态，失败时提供错误信息与重试入口。
