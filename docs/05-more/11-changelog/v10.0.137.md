# DesireCore v10.0.137

**发布日期**: 2026-09-01

![v10.0.137 更新概览](/img/changelog/v10.0.137.png)

## 新功能
- **统一目录元数据与获取收据**：市场中的智能体、技能、应用和服务现在统一展示更完整的来源、更新时间与兼容性信息，并让安装、重装和卸载流程更可靠。

## 修复
- Windows 自动更新安装未结束时不再允许提前启动半安装应用，99% 阶段会明确显示“正在完成安装”并阻止误入连接恢复页。
- 修复实时输出与历史刷新后的交付卡片不一致，以及同一轮多次交付时第二条不可见或被误认领的问题。
- 修复生成中断后继续对话时，已交付结果可能重复提醒或丢失的问题；系统会准确提示上一轮已完成的内容。
- 修复纯文本回复在中断轮次恢复后可能重复出现、被保存两次的问题。
- 修复手动停止生成后短时间内发起新一轮对话时，新回复事件可能被误过滤的问题。
- 修复生成出错后继续对话可能被误判为已终止或重试预算未复位的问题。

## 改进
- 优化市场/商店的浏览体验，返回时保留筛选状态和详情滚动位置，减少重复查找。
- 统一生成轮次完成、出错、中断后的清理与收尾逻辑，提升中断恢复和错误恢复后的稳定性。
