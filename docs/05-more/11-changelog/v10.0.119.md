# DesireCore v10.0.119

**发布日期**: 2026-08-25

![v10.0.119 更新概览](/img/changelog/v10.0.119.png)

## 新功能
- **会话列表极简头像态**：窗口变窄时会话列表不再整体隐藏，而是收缩为一条 62 像素宽的头像栏，持续展示各智能体的工作状态——当前会话忙碌时头像显示描边呼吸环和橙色圆点，智能体忙其他事务时仅显示橙色圆点，未读徽标缩小并以 9+ 封顶；同时支持手动固定展开或折叠，头像栏上的搜索、折叠聊天等操作会自动先展开列表再执行。
- **工具工作区快捷开关**：新增 Ctrl/⌘+⇧+B 快捷键，可快速开合工具面板。

## 修复
- 修复思考模式下经第三方网关调用 GLM 等模型时，工具调用在「上游不合规」与「网关断流」交替出现的情况下自动降级永不触发、对话最终中断报错的问题；现在会话内第二次出现不合规响应即自动关闭思考模式，工具可继续正常执行。
- 修复备份在开始写入就失败时可能残留不完整临时文件的问题。
- 修复极简头像态相关的三处使用问题：列表让出的宽度未归还导致窗口最右留白约 157 像素、头像栏头部按钮在桌面版可能点击无响应、拖动工具区与聊天区的分隔条会意外改变会话列表宽度偏好。

## 改进
- 工具面板在四种工作台布局下始终保持为最右一列，关闭按钮固定在面板标题栏右端、样式统一并带无障碍标签，不再随窗口宽度变化而改变位置或跑到面板外部；点击关闭总是直接收起整个面板，不再对终端做「换个工具继续开着」的特殊处理；全新安装默认关闭工具工作区，首屏不再出现空态面板。
- Windows/Linux 下工具面板动作区与窗口控制按钮之间新增分隔线，避免两个「关闭」图标相邻造成误点；工具面板打开时中间聊天列不再为窗口控制按钮预留宽度，可额外获得约 110 像素的可用宽度。
