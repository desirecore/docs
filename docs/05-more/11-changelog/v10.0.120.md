# DesireCore v10.0.120

**发布日期**: 2026-08-25

![v10.0.120 更新概览](/img/changelog/v10.0.120.png)

## 新功能
- **延后重试**：支持选择"当前任务结束后重试"，将消息重试安排在当前任务完成后再执行，该意图会持久保存，应用重启后仍能恢复并继续执行

## 修复
- 修复快速双击重试按钮会重复发送消息的问题，现在双击只会触发一次重试，第二次点击会收到明确的"待处理"提示
- 修复应用重启后待重试消息恢复异常的问题，现在重启后只会恢复出唯一的一条后续消息，排队面板正确清空、重试按钮恢复正常可用
- 修复清空对话时可能误删或复活待重试消息的问题，确保清空操作与延后重试状态保持一致

## 改进
- 立即重试、延后重试、新消息排队与对话引导保持严格顺序，消息不会再出现乱序
- 重试恢复失败改为有界退避，无主会话会及时释放占用资源，避免恢复流程长期卡住
