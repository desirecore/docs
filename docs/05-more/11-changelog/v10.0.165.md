# DesireCore v10.0.165

**发布日期**: 2026-09-16

![v10.0.165 更新概览](/img/changelog/v10.0.165.png)

## 修复
- 修复 IMAP 邮箱中名为「垃圾邮件」或「垃圾郵件」的文件夹被错误归入“已删除”的问题，历史邮件已自动迁移到“垃圾邮件”分类。
- 修复浏览器在 macOS 后台运行数小时后自动化操作会挂起的问题，现在可自动恢复，无需手动更换窗口。
- 修复点击“停止”后某些情况下查询或后续消息仍会继续发送的问题，停止操作现在更可靠。
- 修复当系统未安装 fd 命令时，文件搜索会每次都失败回退的问题，现在会正确使用内置缓存中的 fd。
- 修复从 1Password 导入凭据时，应用锁定或超时被误报为网络故障的问题，现在会提示解锁 1Password 后重试。

## 改进
- 浏览器自动化登录过程中遇到 CAPTCHA、滑块、短信验证码等验证时，会停止自动填写并等待用户处理，不再尝试绕过。
- 从 1Password 导入的凭据会记录来源条目，审计日志可追溯，满足双向对账要求。
