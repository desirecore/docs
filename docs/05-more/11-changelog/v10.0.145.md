# DesireCore v10.0.145

**发布日期**: 2026-09-04

![v10.0.145 更新概览](/img/changelog/v10.0.145.png)

## 新功能
- **连接恢复页诊断导出**：连接恢复页新增“导出诊断日志”操作，可一键保存包含主进程日志和启动诊断信息的压缩包，便于排查连接问题。
- **Agent 使用说明**：市场中的 Agent 详情页现在会展示 Agent 提供的 USAGE.md 使用说明，帮助用户了解如何正确使用该 Agent。

## 修复
- **Windows 升级标记**：修复 Windows 升级过程中安装标记可能缺失的问题，现在会使用备用空目录标记确保升级进度正确显示。
- **慢启动误判**：优化本机 Agent 服务的启动超时判定，在有进展时自动延长等待时间，保留 5 分钟硬性截止，避免慢设备被过早判为启动失败。
- **求解器校验**：修复优化求解器因未绑定实际编译配置而误判结果、导致 Agent 重复求解的问题，并确保更新求解器服务后正确重启。
- **Pointer 条目可安装**：修复指针类型的 Agent、技能和团队在市场中无法被声明为可安装的问题，现在满足条件的条目可以正常安装。
- **市场安装校验**：修复从市场安装 Agent 时可能生成不合法配置、导致后续无法编辑的问题，现在安装前会严格校验配置并提示错误。

## 改进
- **心跳记录清理**：自动保留每个 Agent 最近一定数量的心跳运行记录，定期清理旧记录，减少长时间运行时的磁盘占用。
