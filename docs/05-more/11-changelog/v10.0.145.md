# DesireCore v10.0.145

**发布日期**: 2026-09-04

![v10.0.145 更新概览](/img/changelog/v10.0.145.png)

## 新功能
- **连接恢复页诊断导出**：连接恢复页（如本机服务启动超时）现在可导出包含主进程日志的诊断压缩包，方便用户排查问题。
- **市场 Agent 使用说明**：市场 Agent 详情页新增“使用说明”区块，展示条目提供的 USAGE.md 内容。

## 修复
- 修复了市场 pointer 类 Agent/Skill/Team 因结构限制无法声明为可安装的问题，符合条件的条目现在可以正常安装。
- 修复了市场内联 Agent 安装时未校验配置导致装完后无法管理的问题，现在不合法配置会在安装时直接报错。
- 修复了求解器验证因绑定信封不一致导致的假失败和重复求解问题，并确保 SCIP 服务升级后正确重启。
- 修复了 Windows 升级标记可能缺失及慢启动设备被过早判定失败的问题，启动判断更稳定。

## 改进
- 心跳临时运行目录现在会按数量自动保留最近记录，避免磁盘占用随运行时间无限增长。
