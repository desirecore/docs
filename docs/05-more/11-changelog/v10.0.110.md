# DesireCore v10.0.110

**发布日期**: 2026-08-16

![v10.0.110 更新概览](/img/changelog/v10.0.110.png)

## 新功能
- **会话独立窗口支持内置浏览器**：现在可以在独立会话窗口中直接使用浏览器工具，画面会正确显示在该窗口内，并可在占位页一键收回主窗口。
- **Agent 可见界面理解与受控操作**：智能体能够感知当前可见的应用界面（包括资源页与工作台等 12 个区域），并在用户可见的接管动画和操作反馈下安全地执行界面操作，敏感信息自动遮罩。
- **网页正文读取能力**：新增 page.extract-text 与 browser.observe.text 能力，智能体在无人值守时也能按授权范围读取网页正文，并支持分页、格式与字节预算控制。
- **通知已读管理**：智能体可以主动清理属于自己的过时通知；在用户当前请求明确授权时，还可标记当前用户域内其他通知为已读。

## 修复
- 修复清空会话后，已清空的旧请求或迟到的流式内容可能重新写回并污染新会话的问题。
- 修复智能体在无人值守浏览器会话中遇到 alert/confirm 等弹窗时卡死的问题，现在会自动按取消语义关闭弹窗。
- 修复后台委派或来信运行期间会话不显示忙碌、长时间静默的后台任务被误判为已结束的问题。
- 修复流式助手消息身份无法与磁盘匹配、批量删除与历史搜索位置不准确的问题。
- 修复系统自动切换亮暗模式时，已打开的终端仍保留旧配色的问题。
- 修复 Windows 安装程序在任务栏快捷方式路径包含空格时构建失败的问题。
- 修复浏览器导航超时后，旧导航的授权状态可能影响新导航重试的问题。

## 改进
- 优化浏览器自动化中的元素定位与选择器解析，提升定位精度和隔离执行安全性。
