# DesireCore v10.0.187

**发布日期**: 2026-10-25

![v10.0.187 更新概览](/img/changelog/v10.0.187.png)

## 新功能
- **跨设备邮件访问与可靠发送**：现在可以从其他设备访问内嵌邮件服务，发送前会保存准入见证，重复或未知结果不会自动重复外发，并补充任务板创建上下文、存储条件删除和关系单边校验能力。
- **工作空间增量升级**：发行版内置的种子智能体与团队可通过 AgentFS/Git 增量合并，保留本机模型选择、记忆和不冲突的用户修改；冲突仅暂缓相关仓库。不重导入凭据、连接配置或业务工作区，也不恢复已删除实体。
- **图片读取完整性校验**：读取图片时可校验期望摘要，摘要不匹配时不生成视觉补全，避免基于错误图片继续分析。

## 修复
- **新对话上下文隔离**：使用 `/new` 开始新对话后，首个请求不再带回此前的消息、工具调用和旧错误，旧时间线仍可回看。
- **消息删除更可靠**：修复多选删除无响应或失败、刚收到消息缺少地址导致删除静默无效的问题；删除后会刷新默认会话和手动话题，并正确重定位流式锚点与支撑长历史分页。
- **多账户安装不再误拦**：多账户电脑上，普通权限账户安装到自己的目录时不再被其他账户运行的同名程序阻断；若本目录程序确实在其他账户或会话中运行，会给出明确提示并引导退出或使用管理员身份运行。
- **市场技能安装恢复**：技能安装元数据波动不再导致校验中断，安装中断后市场卡片和详情会显示“安装未完成”，并可通过原入口重试。
- **模型目录手动刷新恢复**：聊天模型选择器旁恢复手动刷新按钮，目录为空时也能操作，刷新时防重复点击、失败后允许重试，并保留当前搜索、筛选和选中模型。
- **工具批量点名加载**：智能体一次点名多个工具时，会处理全部点名且已授权的工具，不再只取前 5 个；达到保留上限时会明确列出未加载项，不再静默截断。
- **安装与退出稳定性修复**：修复安装器将原生组件误判为需要重建、退出清理过早报告成功以及文件监听器关停异常等问题。
- **空会话提示与浮框交互**：空会话提示文字不可选中，环境状态浮框点击外部会自动收起并记住折叠偏好。
- **资源管理器界面修正**：统一资源管理器在各入口的命名和图标，并将浮动菜单改为不透明材质，避免底部消息透出。

## 改进
- **启动与首次输入更顺畅**：精简首次启动和首次输入的配置准备，减少重复读取、目录编译和首屏错峰等待，并优化服务入口加载。
- **内置浏览器访问技能更新**：系统浏览器显式路径审批说明仅在客户端声明时使用，高级交互改用随包离线解释器，登录态说明更准确。
