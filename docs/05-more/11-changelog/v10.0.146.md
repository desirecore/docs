# DesireCore v10.0.146

**发布日期**: 2026-09-05

![v10.0.146 更新概览](/img/changelog/v10.0.146.png)

## 新功能
- **OFD 文档解析**：Read 工具支持读取 .ofd 格式的中国电子发票文档，自动提取文档概览、结构化发票字段（含 2024 数电票）和逐页文本
- **邮件附件直接落盘**：MailOperations 新增 save_to 参数，可将邮件附件（如发票 PDF/OFD）直接保存为文件，只返回保存回执，附件内容不再进入模型上下文
- **Outlook/IMAP 邮件搜索**：为 Outlook 和 IMAP 账户补齐邮件搜索能力，可按关键词、发件人、附件、日期范围等条件精准检索邮件，无需再拉取整个邮箱

## 修复
- **桌面端邮件工具恢复可用**：修复了 MailOperations 在桌面端因跨进程 capability 获取失败而完全不可用的问题，Agent 现在可以正常访问和处理邮件
- **邮件自动处理不再重复触发或静默失效**：修复了 Outlook 轮询将同一封邮件反复触发 Agent、agent_handle 回退路由 404 导致规则静默失效、IMAP 标记已读后本地状态不更新的问题；规则执行失败现在会弹出错误提示
- **市场条目治理信息不再被静默掩盖**：市场条目的治理元数据被拒绝时不再静默回落，详情页和列表卡片现在会明确显示诊断信息和角标；同时修复了大型合集条目因诊断数据过多导致详情页打不开的问题
- **邮件搜索的读盘与分页修复**：搜索不再每次读取全部命中邮件的完整内容，深翻页不再重复读取已跳过的邮件；日期筛选的时区边界、非法参数、损坏索引等边界情况也得到修复

## 改进
- **邮件附件保存更安全可靠**：附件落盘增加完整性校验、原子写入和路径安全防护，损坏的附件不会再被静默写成坏文件；超大附件返回明确错误
- **市场条目可信度信息更透明**：Agent/技能详情页的可信度区新增提示，说明当前治理事实来自旧版回落值
