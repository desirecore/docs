# DesireCore v10.0.104

**发布日期**: 2026-08-11

![v10.0.104 更新概览](/img/changelog/v10.0.104.png)

## 修复
- 修复 macOS 打包版新建终端后立即显示“已退出”的问题，终端现已可正常创建并持续运行。
- 修复切换聊天智能体时，内嵌文件工作区上下文未及时更新的问题，并优化了未保存文件时的确认流程，避免文件打开请求被永久卡住。
- 修复 SuperDoc 编辑器导出 PDF 时可能包含陈旧内容的问题，现在导出的 PDF 会与编辑器最新内容保持一致。
- 修复 SuperDoc 编辑器在保存空文档或关闭窗口时可能出现的卡死与数据丢失问题。
- 修复 SuperDoc 在 600px 宽度附近响应式布局语义错误，确保界面在不同窗口尺寸下正确显示。
- 恢复 SuperDoc 并排对比审查功能，并修复进行部分审查决策后无法切换行内与并排视图的问题。
