# DesireCore v10.0.196

**发布日期**: 2026-11-02

![v10.0.196 更新概览](/img/changelog/v10.0.196.png)

## 新功能
- **本地音视频转写**：新增内置音频转写工具，Agent 可以把本地音频或视频转成带时间戳的文字，并使用已配置的识别服务；已配置的识别目的地会直接放行并在结果中披露。
- **移动端文件编辑与审阅**：手机端现在可以安全地编辑工作区文本、查看差异和回滚，操作带授权与可追溯回执。
- **移动端浏览器资源只读查看**：认证用户可以在手机端以只读方式浏览浏览器资源目录和 JPEG 视口截图，管理密钥与租约不会下发到手机。
- **大型优化模型文件与工件引用**：优化编译、工件发布和关联工具支持通过文件和工件引用传入大规模模型数据，大型模型无需逐字生成参数也能完成编译和求解。
- **市场 MCP 服务更新**：已安装的市场 MCP 服务会显示已审核的新版本，升级时保留环境变量、工作目录、停用状态和协议偏好，失败时回退原配置。
- **Agent 归档服务端事务**：新增 Agent 归档、恢复、永久删除、列表和详情接口，为后续删除改为归档做准备；当前界面与删除入口仍保持硬删除。

## 修复
- **超长单轮续接**：超过 16MiB 的长单轮子任务现在可以按合并后的真实内容续接，无法恢复时会如实说明缺少收尾记录、损坏行或写入中断，而不是误报“历史为空”。
- **任务板大板与卡死恢复**：任务板单提交读取上限提高到 16MiB，超限时返回明确错误；曾被打断的写入会在读取前自动收尾，建任务和查看任务板不再整体失败。
- **旧任务板目录激活与查重优化**：旧安装的历史索引补建完成后会自动激活通知和关系外发，建板查重只读首个提交，避免启动恢复和建任务长时间阻塞。
- **历史分页并发删除漏读**：普通历史向上翻页遭遇并发删除或回撤时不再跳过幸存消息；恢复失败会保留当前窗口和位置，等待明确的向上操作后重试。
- **回撤完整历史与搜索范围**：手动话题回撤失败后保留完整历史投影和恢复入口；纯删除不再改变对话活动时间，同一搜索范围内的幸存结果不会消失。
- **归档话题续写拦截**：已归档或已删除的手动话题会在调用模型前被拒绝，返回明确原因，不再复用已有运行写入消息。
- **工具输出缺失恢复**：工具完成后若模型输出或来源状态投影缺失，会从同一运行中完全一致的完整副本恢复；本地云同步未就绪时不会误报为上游 API 错误。
- **审批策略实时同步**：当审批策略目录在首次读取之后才出现时，系统会自动补建监听，外部修改策略文件能实时更新到界面，不再显示旧档位。
- **审批模式排序与不可读提示**：审批模式改为按服务端纪元与修订号排序，多窗口、外部修改和重连时不会用旧状态覆盖新状态；策略文件无法解析时界面会提示原因并给出修复入口。
- **Python 运行时修复**：首启离线导入留下的 Python 来源记录会自动改写成正确地址，Python 安装、删除和展示不再失败。
- **MCP 兼容与连接清理**：MCP 配置会容忍未来新增字段，不会整份校验失败；连接测试、健康探测和关闭流程有明确超时和错误码，并会清理完整子进程树。
- **任务工具成组与范围收窄**：任务创建、更新和评论现在成组加载与保留，长会话中不会再连续误建垃圾任务；Agent 也不再看到只有真人能执行的任务动作。
- **工具声明顺序持久化**：工具的最近使用和失败关闭记录会随会话保存，重建后按最近使用淘汰，避免刚调用过的工具被提前淘汰。
- **白板初始化诊断**：白板新建、检查、接管失败时给出具体原因、位置和下一步；完整 Schema 可在创建前通过工具目录获取。
- **语音识别可用性**：修复不可选择的语音识别预置，新增可用的识别模型；自动语言不再固定按中文识别，而由服务端自动判断。
- **市场技能更新与路径修正**：单技能指针源前移后会正确提示可更新并拿到新内容；内置运行时技能路径说明更新，Agent 不会再用系统包管理器重复安装已内置的 Node 或 Python。
- **团队规则不静默失效**：发行版种子升级后，团队规则如果确实由新种子带来会自动续期，其他未核准变更会进入通知中心，不再静默不注入。
- **团队成员状态与安装回执**：团队设置不再把本地已有成员误报为缺失，真正缺失的成员会按可补齐、需解析或无来源给出去路；成员要求更高客户端版本时团队安装不再失败。

## 改进
- **MCP 服务关闭体验**：外部 MCP 的 stdio 子进程改由平台自行派生和回收，关闭或重启时能按进程树结束包装启动的服务，减少残留。
- **任务板性能与后台外发**：旧库存补建目录后按需激活，按指纹跳过无新提交的板，V4/V5 策略板历史事件只补一次，空闲 CPU 明显下降。
- **底层依赖与安全升级**：升级了桌面运行时、图表渲染、模型推理等基础依赖，并修复若干 HTTP 解析与渲染安全问题；使用 x64 架构的 Mac 上不支持的离线人像抠图会直接提示原因。
- **历史分页交互**：分页重试增加键盘入口与滚动位置保持，旧来源或清除前的迟到回执会被隔离，避免跳到底部或串用窗口。
