# DesireCore v10.0.166

**发布日期**: 2026-09-16

![v10.0.166 更新概览](/img/changelog/v10.0.166.png)

## 新功能
- **本地 HTML 预览**：内置浏览器支持以安全的本地预览面打开 Agent 生成的 HTML 文件，无需再退回源码或 Canvas 卡片。
- **精确资源查看器**：工作台新增文件、看板、目录、图片和 PDF 的只读查看能力，可在不修改内容的情况下检查精确文件字节、目录结构和看板历史。
- **任务审批链接管理**：任务看板支持稳定的审批引用管理、编辑与恢复，避免审批链断裂。
- **工作流定义查看**：支持在只读模式下查看工作流定义，无需加载执行状态即可检查定义内容。
- **决策树引用面板**：决策树工作区新增引用面板，支持精确选择与查看决策定义。

## 修复
- **委派失效**：修复团队协作中委派给固定模型的 Agent 时，因调用方模型配置覆盖目标模型而导致子任务失败的问题，同时参数校验报错会带出缺失字段帮助 AI 自纠错。
- **模型服务回退凭证混用**：修复特定配置下模型服务回退时，可能把 A 服务商的密钥发送到 B 服务商端点的问题。
- **邮件并发写入**：修复邮件存储并发操作可能导致已删除邮件被写回复活、或邮件与索引状态不一致的问题。
- **会话恢复工具结果截断**：修复重启后继续对话时，大型工具结果只提供 2000 字预览且未标注不完整、导致模型把截断内容当成完整结果的问题。
- **重发分支工具预览缺失**：修复重发分支引用的外部工具结果文件丢失时，预览被误当作完整结果的问题。
- **界面数据隐私**：修复 ControlDesireCoreGui 读取的界面快照被写入会话记录、导出与备份历史的问题，瞬时界面数据不再持久化扩散。
- **消息发送误判**：修复网络请求中三种非清空冲突被误判为“清空窗口冲突”，导致消息被错误停成“需用户确认”的问题，现在会按同 ID 进行传输层重试。
- **智能体导入冲突误判**：修复导入智能体时任何后端 409 都被当作同名冲突、可能生成多余后缀副本的问题，非同名冲突现在会展示后端原文。
- **对话结果归属**：修复未知工具调用 ID 按位置回落导致其他工具的结果、错误与元数据被污染的问题，导出时正文与工具结果的交错顺序也会正确保留。
- **并发 follow-up 误终结**：修复同一会话中另一轮仍在运行时，follow-up 被确定性拒绝会误终结正在运行的那一轮的问题。
- **市场 Agent 自动更新受阻**：修复市场安装的 Agent 因心跳清单未被提交而让工作树变脏、导致无人值守更新一直返回 409 的问题。
- **Windows 决策工作区初始化**：修复 Windows 上因 POSIX 权限位误判导致决策工作区种子验证失败的问题。
- **GUI 动作失败原因**：修复 AI 执行界面操作失败时故障被折叠成通用错误、无法区分“宿主窗口不可见”与“用户暂停”的问题。
- **邮件界面上下文失效**：修复邮件列表刷新或详情加载时界面快照引用无谓变化、导致 AI 读取的界面上下文快速过期的问题。

## 改进
- **启动性能**：Agent 服务不再在启动时加载所有 LLM 提供商 SDK，改为首次调用时才加载，启动时间约减半且常驻内存降低。
- **编译缓存**：启用 Node 编译缓存，Agent 服务再次启动时跳过冷编译，启动耗时进一步下降。
- **内置工具懒加载**：UI 上下文工具的执行逻辑改为首次使用时才加载，降低模块注册成本。
- **图标按需加载**：图标库改为按需导入，减少应用与测试的加载负担。
- **停机速度**：退出时后台远端同步、Agent Git 批量迁移与市场同步现在会响应关停信号，退出不再长时间卡顿。
- **达摩院深色主题品牌**：达摩院发行版在暗色主题下使用反色 Logo，避免黑字在深色背景上难以识别。
