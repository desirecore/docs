# DesireCore v10.0.154

**发布日期**: 2026-09-10

![v10.0.154 更新概览](/img/changelog/v10.0.154.png)

## 修复
- 修复内嵌浏览器在偶发内部事件丢失后可能永久不可用、只能重启应用才能恢复的问题，现在可自动恢复并继续执行浏览器自动化任务。
- 修复页面加载失败或出现特殊地址时浏览器标签页状态可能被整体丢弃，导致 Agent 误以为页面仍然正常的问题。
- 修复个别异常截帧会连带丢失上一帧并中断整个浏览器通道的问题，现在会跳过异常帧继续工作。
- 修复已失效的浏览器会话可能被迟到的旧事件重新激活、导致状态不一致的问题。

## 改进
- 浏览器操作命令失败时，现在会记录明确的失败事件，便于后续定位和排查。
- 优化浏览器内部事件处理，无效事件不再清空其他已就绪的事件，减少浏览器能力的中断。
