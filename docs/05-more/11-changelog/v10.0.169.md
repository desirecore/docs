# DesireCore v10.0.169

**发布日期**: 2026-09-19

![v10.0.169 更新概览](/img/changelog/v10.0.169.png)

## 新功能
- **账号生命周期管理**：新增注册闸门、邮箱绑定/换绑和账号合并功能，用户可将邮箱与手机号注册的账号合并，登录设置更灵活。
- **DesireCore Control**：外部控制功能独立为可单独安装的应用，ChatGPT、Codex 等外部智能体可通过 MCP 控制本机 DesireCore。

## 修复
- 修复 Windows 上受管画板完全无法创建、读取和保存的问题。
- 修复应用每次启动后决策工作区第一次“保存为新版本”必失败的问题。
- 修复有心跳执行的 Agent 工作树每次运行都变脏、导致无人值守更新被挡住的问题，心跳历史现已迁移到用户目录。
- 修复优化求解服务在不可行/无界模型上必崩或无法正确区分、整数二次模型返回错误最优解以及混合整数线性规划诊断字段虚报的问题，现在会正确区分不可行/无界、禁用不可靠的 MIQP 并回填真实的最佳界与相对间隙。
- 修复智能体面板“角色定位”卡中较长的特质标签横向撑破弹窗的问题，标签现在会自动折行。
- 修复数据根目录为符号链接、宽权限或属主不同时，“重启应用”、受管实例启动和 CDP 端口发布失效的问题。
- 修复工具敏感结果占位文案不准确的问题，避免模型在恢复对话时凭空编造凭据。

## 改进
- 普通数据文件不再被强制修改权限，新建文件权限遵循系统 umask，密钥和命令端点仍保持私有，更适配多账户共享和 NAS 场景。
- Claude 能力集成升级至 Agent SDK 0.3.273，增加请求级隔离与缓存适配，提升稳定性和兼容性。
- 升级 Electron 至 43.7.1 及 React、Vite、TanStack Query 等核心依赖，提升应用整体性能和稳定性。
