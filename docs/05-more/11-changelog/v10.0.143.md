# DesireCore v10.0.143

**发布日期**: 2026-09-03

![v10.0.143 更新概览](/img/changelog/v10.0.143.png)

## 修复
- **技能符号链接告警**：修复了使用符号链接安装技能时被静默跳过的问题，现在会在错误日志中给出明确提示和修复命令，帮助用户排查技能未加载的原因。
- **子任务审批与问答显示**：修复了多步骤委派任务中子任务的审批请求和问答卡片不显示的问题，现在可以正常查看和处理子任务中的交互请求。
- **长安装超时误中断**：修复了从市场安装大型团队仓库等耗时操作被固定 120 秒超时提前中断的问题，超时时间会跟随业务超时自动延长并留出余量，避免长任务被误杀。
- **Git 远程拉取错误**：修复了指定拉取非 origin 远程时可能静默拉错仓库的问题，确保代码仓库集成功能准确拉取目标远程。
- **Claude 订阅模型不可用**：修复了使用 Claude 订阅登录时所有 Claude 模型发送消息均返回 400 错误、完全无法使用的问题，现在可正常对话。
- **浏览器会话永久锁死**：修复了无人值守任务中浏览器会话异常残留导致 persistent BrowserSpace 永久锁死、需重启才能恢复的问题，现在会自动回收失效会话，避免后续任务持续失败。
- **无人值守浏览器操作失败**：修复了无人值守场景下 Agent 使用内置浏览器无法点击按钮或提交登录表单的问题，关闭后台节流后页面操作恢复正常。
