# DesireCore v10.0.113

**发布日期**: 2026-08-17

![v10.0.113 更新概览](/img/changelog/v10.0.113.png)

## 新功能
- **跨源嵌入框架访问**：智能体现在可以读取和操作网页中嵌入的跨域子页面内容，不再跳过这些区域
- **稳定元素定位符**：浏览器快照为可交互元素附带稳定定位符（如数据测试标识、唯一编号、名称、链接和角色），让智能体跨快照可靠地找到元素
- **多种条件等待命令**：新增等待命令，支持等待加载完成、网络空闲、元素出现、地址变化、请求响应等多种条件，减少智能体重复尝试
- **浏览器脚本工具**：智能体可以在人工审批后执行浏览器脚本，完成复杂操作，安全级别等同于执行系统命令
- **自主能力发现与安装**：智能体现在可以按需查找并安装技能或智能体，官方市场自动安装，其他来源需审批，安装来源和内容更安全可追踪

## 修复
- 修复 Windows 普通用户权限下应用启动后自动退出的问题，现在普通用户能正常运行
- 修复多题问答中草稿串题风险：切换问题时不再把上一题的草稿误提交到新题，并改用紧凑步骤条显示题目进度和完成状态
- 修复后台标签页未激活时截图挂起 30 秒或视口为零的问题，截图会快速返回明确错误
- 修复角色定位器在真实浏览器中始终匹配不到元素的问题，按角色名或中文名定位现在可正常工作
- 修复 macOS 上浏览器快捷键（如全选）静默失效的问题，快捷键现在可以正常触发

## 改进
- 点击、按键、导航和填写等命令支持内联等待，一条指令即可完成“操作并等待结果”，避免操作与等待之间的竞态
- 无障碍快照支持深度控制和分页，大页面超限时自动截断翻页，不再直接失败，输出格式也更统一
- 带等待语义的命令自动延长执行时限，不再被默认 30 秒超时截断；等待超时后不会强制停止页面加载
- 内置网络访问技能更新到 v3.0，移除需要手动启动调试浏览器和 Python 回落脚本的旧路径，批量取文、截图等说明更准确
- 移除已停用的旧浏览器工具和内部代理组件，精简工具目录，减少应用体积和潜在干扰
