# DesireCore v10.0.131

**发布日期**: 2026-08-30

![v10.0.131 更新概览](/img/changelog/v10.0.131.png)

## 新功能
- **Ollama 一键配置**：新增专用 Ollama 配置入口，可自动探测本地服务、发现可用模型并完成免密接入，配置成功后即可开始对话。

## 修复
- 修复关闭 Git 同步冲突弹窗后当前 Agent 被误注销、聊天界面消失的问题，现在关闭操作只收起弹窗，对话和冲突角标保持可见。
- 修复 Ollama 等本地模型因上下文窗口与输出预算不一致导致工具调用后无法继续生成的问题。
- 修复技能触发词误将“不适用于 / Do not use”等否定描述识别为触发条件的问题，并支持中英文多行触发词列表。
- 修复无密钥模式下仍可能读取残留密钥或发送伪造认证头的问题，无密钥提供商现在严格不接触任何密钥。
- 修复仅大小写不一致的工具名称被错误拒绝的问题，当当前工具集内唯一且无歧义时自动规范化。
- 修复通过代理访问本地模型时长时间请求可能中断的问题，已鉴权的本机请求会保持连接并减少超时或内部重试干扰。

## 改进
- Ollama 配置流程会先完成服务探测和模型发现，失败不会残留不完整配置，成功只广播一次变更。
- 无密钥提供商的界面展示与真实密钥信息保持一致，不再显示多余的密钥标记。
- 通过智能体新增的本地模型地址仅允许环回地址，已有的人工配置局域网或容器端点仍可复用，降低安全风险。
