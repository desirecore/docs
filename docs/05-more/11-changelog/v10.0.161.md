# DesireCore v10.0.161

**发布日期**: 2026-09-14

![v10.0.161 更新概览](/img/changelog/v10.0.161.png)

## 新功能
- **手动会话排序新增“创建时间”**：手动多会话侧栏的整理菜单新增“创建时间”排序方式，并默认按创建时间排列，未读消息不再改变话题位置。
- **新增 DeepSeek V4.1 Flash 模型支持**：算力服务模型库新增 DeepSeek V4.1 Flash 及别名规格，便于用户接入使用。

## 修复
- 修复使用 API Key 直连官方 Anthropic 或第三方中转接入时，Claude Opus 4.7 及以上、Sonnet 5、Fable 5.1 等新模型开启思考会被 400 拒绝的问题，现在会按 adaptive 代际自动改写思考参数。
- 修复 Claude Opus 4.7 及以上、Sonnet 5、Fable / Mythos 等模型因自动携带 temperature、top_p、top_k 或强制工具选择被官方 400 的问题，请求时会自动移除被拒绝的采样参数并降级或归一化工具选择。
- 修复 Claude 订阅兼容性预检将省略思考参数的 claude-opus-5 等模型误判为未知模型而返回 400 的问题。

## 改进
- 统一 Anthropic 模型代际识别规则，现在可更稳定地兼容下划线、点号、日期后缀、Vertex 前缀等模型 ID 写法，减少不同功能间判定不一致。
