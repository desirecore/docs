# DesireCore v10.0.101

**发布日期**: 2026-08-11

![v10.0.101 更新概览](/img/changelog/v10.0.101.png)

## 新功能
- **智能模型路由**：Agent 可根据任务量级（轻量/均衡/旗舰）自动匹配合适的模型，并记住分配结果。
- **Subtask 子体任务**：新增子体任务模式，可继承发起方的对话上下文并行探索多个方向，无需重复交代背景。
- **会话独立窗口**：支持将会话弹出到独立窗口，经主窗口中继流量而无需额外连接后端，主窗口关闭后子窗口自动回收。
- **终端进程跨重启自恢复**：终端进程可在应用重启后自动接回，即使整机重启也能恢复标签页与历史输出。
- **沉浸式 ASR/TTS 模型接入**：沉浸式语音交互现在直接从算力模型清单选择可用语音模型，并接入新协议适配。
- **网页搜索优化**：补齐结果缓存与全局超时预算，搜索子 Agent 自动使用快速模型以缩短等待时间。
- **技能合集支持**：市场技能支持合集勾选式安装，一个条目可装多个子技能，含可选的 Agent 私有目录安装。
- **内置浏览器身份一致性**：浏览器 UA 与系统指纹从真实内核派生，消除因 Electron 标识易被判定为机器的特征。
- **Agent 输入行为拟真**：浏览器内 Agent 的鼠标移动、点击、滚轮等操作模拟人类运动轨迹，减少被站点判定为机器人的风险。
- **Drawnix 脑图与白板预览**：文件工作台支持 `.drawnix` 格式的只读预览，并可导入 XMind、MindNode 等主流脑图格式。
- **Canvas 展示画布收敛**：画布默认产出消息流卡片，旧卡自动降级为历史快照海报，并加固展示与回读边界。
- **专业三栏工具工作台**：宽屏下聊天与工具以可拖拽的三栏布局展示，终端、浏览器、文件、审阅统一纳入工作区。
- **审阅工作台（Review）**：按对话轮次展示文件差异，支持行级/片段/文件级回滚操作。
- **指挥权约束**：可在智能体配置中限制其可交互的目标 Agent，防止委派到未授权对象。
- **安全 Token 通道**：Agent 拿到的是可吊销的安全句柄而非真实 Key，避免凭据泄露进上下文或落盘。
- **安全 Token 中继**：支持非 Chat 接口（图片/视频/语音等）经安全 Token 中继访问上游 API。
- **安全 Token 管理面板与审计**：算力设置页可查看与吊销已发放的安全 Token，并查阅凭据操作记录。
- **凭据被拒入口直达**：Agent 因权限不足被拒时，工具卡片直接提供“打开配置”入口。
- **算力白名单开关与可视化选择**：新增白名单独立开关，提供商选择改为从算力配置拉取的多选清单。
- **用户侧上下文管理 `/reset` 与 `/recall`**：斜杠命令支持重置上下文与召回话题，补齐用户自主控制能力。
- **TL 成员收纳显示**：侧栏支持将团队成员缩进挂在组长名下，可展开/收起并持久化。
- **会话已读管理与右键菜单**：新增全局标记已读、Agent 行右键菜单（置顶/标记未读/折叠/独立窗口）。
- **15 条主菜单与智能体切换快捷键**：新增数字键直达、上下循环、搜索面板等快捷键，并建立让位终端/编辑器的作用域模型。
- **代码块与表格复制按钮**：消息中的代码块与表格增加一键复制按钮，Mermaid 图表支持导出 SVG/PNG 及复制源码。
- **增强图片预览**：预览支持同一组图片左右切换、方向键导航与缩放。
- **合并相邻审批为牌组**：连续多个命令审批卡合并为扑克牌式牌组，可逐张处理。
- **折叠聊天排序改进**：折叠的聊天按内部最新消息时间参与专业段排序，并改为下钻子列表视图。
- **Worktree 基点选择**：创建隔离工作树时需显式选择基点（当前 HEAD/远端默认分支/指定引用），增加可选 fetch 参数。
- **CDP 发布自身调试端口**：实例启动后在数据目录发布调试端口文件，Agent 与多实例选择器均可读取。
- **多实例 OAuth 深链修复**：新建实例连接代码仓库的授权回调现在可跨实例投递给发起方。

## 修复
- **Windows 启动崩溃**：修复因 `http-request` 工具模块循环依赖导致 Windows 下进程启动阶段崩溃。
- **Windows 终端创建失败**：修复 Windows 下交互终端创建后立即报错退出。
- **Windows 更新进度窗重叠与截断**：修复缩放显示器上文字被进度条压住、底部提示行被截断。
- **浏览器因鼠标经过误判接管**：鼠标划过内置浏览器不再触发 Agent 被“踢出”会话。
- **截图后 Agent 看不到图**：截图像素现在作为可读图片直接交还给模型，同时支持裁剪、放大。
- **审批等待阻塞全局并发**：等真人审批时不再占用全局并发槽，AI 不可用时不再空等 30 秒。
- **数据导出后消息积压**：修复数据导出/迁移重启后 socket 断连导致排队消息无法发送。
- **导入智能体的工作目录污染**：修复导入跨设备/跨实例的数据包时工作目录路径沿用源机绝对路径的问题。
- **多个 contextReset 时已遗忘内容回流**：修复多次重置后边界解析错误导致旧上下文被重新注入。
- **压缩分隔线穿透 reset 边界**：修复压缩分隔线下界未考虑重置标记，以及派发环节可能静默丢弃分隔线。
- **归档安全性加固**：话题归档时校验 runId 归属，防止 Agent 越权读取其他用户的会话消息。
- **工具调用结果完整性**：修复历史恢复时工具调用与结果配对不一致导致请求非法的问题。
- **空工具白名单语义**：清空白名单改为不限制工具（与“从没填过”区分），显式禁止写为 "none"。
- **同份 Home 目录不再可绕过锁**：废除跳过实例锁的漏洞，共用数据目录不再被允许。
- **中断摘要不再倒出技能文档**：Agent 被中断时最终回复不再包含大段技能说明或工具输出。
- **同一消息中的全部委派卡片**：修复含多次委派调用时仅渲染首张卡片的问题。
- **终端 StrictMode 下自动复活**：修复开发模式下 React 双重渲染导致终端重启后显示“已退出”。
- **任务管理器角标误报**：运行中任务不再显示角标，仅异常需要用户介入时才亮红色角标。
- **runs-index 静默丢失 run**：修复索引重建时跳过部分 run 目录导致用量统计缺失。
- **self-evolve 技能写死生产目录**：技能文档路径改为派生而非硬编码，隔离实例不再污染生产目录。
- **market 同步死循环与陈旧 zip**：修复市场数据因内嵌 git 历史分叉而永远无法更新。
