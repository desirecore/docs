# DesireCore v10.0.163

**发布日期**: 2026-09-15

![v10.0.163 更新概览](/img/changelog/v10.0.163.png)

## 新功能
- **求解器智能体发行版**：首次打开自动安装内置求解器智能体、团队、求解器连接器配置与决策工作区，并支持与 DesireCore 并装运行。
- **1Password 凭据源接入**：账号管理页支持连接、浏览、link 与断开 1Password 源；并新增桌面集成导入通道，可搜索 1Password 条目并复制进内置凭据库。
- **浏览器用户显式接管与对话恢复**：内置浏览器新增「我来操作」按钮供用户显式接管，去掉「恢复 Agent」按钮，用户操作完可直接在对话中说“你继续”让 Agent 恢复。
- **Claude 订阅界面上下文**：Claude 订阅用户可开启可见界面上下文，Agent 能查看当前界面并执行界面动作。
- **多实例名录 v2**：每个实例拥有权威记录，多实例环境下的识别、删除与生命周期管理更可靠。

## 修复
- 修复 macOS 隐私权限声明（通讯录、日历、照片、位置等）未写入打包 Info.plist，导致 macOS TCC 拒绝访问受保护资源。
- 修复内置浏览器冷启动时用户身份未能恢复、选择自己拥有的 BrowserSpace 时出现 403 的问题。
- 修复开启界面上下文后，输入框发送时准入引用被丢弃、聊天页有历史时界面动作不可见或执行失败的问题。
- 修复求解器与受管凭据可被 Agent 按名引用的安全漏洞，并修复登记判定在同一时间粒度内被改写时漏读的竞态。
- 修复并发安装系统缓存工具时可能产出损坏二进制或安装失败的问题。
- MindOptSolve 审批摘要现在写明凭据发往的连接器与地址。
- 修复检查点定时器泄漏导致轮次结束后无谓空转的问题。
- 修复结构校验在 CPU 高负载下误报超时的问题。
- 修复 Smart 路由连续 529 换模时，经代理会话错误直连上游导致 401 的问题。
- 修复种子迁移完成后源用户作用域留下空目录的问题。
- 修复 fork-for-resend 并发发布时，正常竞态被误判为记录损坏的问题。
- 修复品牌锁定时核心智能体在会话、历史、搜索、通知等界面仍显示 DesireCore 而非发行版名称的问题。
- 修复 Windows 签名证书问题，恢复 Windows 安装包发布（v10.0.162 因签名失败跳过）。
- 修复开发分支重复导入导致 `npm run dev` 无法启动的问题。

## 改进
- 界面上下文裁剪策略保留动作目录与焦点节点，并将可见修订与动作修订拆分，避免 Agent 自身输出导致界面动作快照失效。
- 系统缓存工具安装改用每进程独占暂存目录并原子替换，提升并发首启的安装可靠性。
- 数据根按发行版拆分，非默认发行版使用独立数据目录，为与 DesireCore 并装运行铺路。
- Claude 订阅运行时改用线上画像查表，内部请求归一迁入传输层，提升订阅会话稳定性。
- 非默认发行版的更新检查、下载文件名与上报按发行版隔离，与 DesireCore 更新流程独立。
