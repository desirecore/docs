# DesireCore v10.0.163

**发布日期**: 2026-09-15

![v10.0.163 更新概览](/img/changelog/v10.0.163.png)

## 新功能
- **内置浏览器显式接管与对话恢复**：内置浏览器新增「我来操作」显式接管入口，Agent 可在用户发起新一轮对话后经对话继续执行，不再依赖手动恢复按钮。
- **1Password 凭据源集成**：账号管理页新增 1Password 源，支持连接、浏览和关联条目，并可搜索、勾选条目复制到内置凭据库，导入后与 1Password 后续变更脱钩。
- **多实例名录 v2**：实例选择器改为基于每实例权威记录列出，删除运行中或状态不明的实例会被拒绝并提示原因。
- **Claude 订阅界面上下文开放**：Claude 订阅会话现在可以查看界面快照，并在同一轮声明、调用界面查看与动作工具。
- **达摩院求解器发行版（OEM）**：新增发行版专属品牌、数据目录、更新频道与上报，首次打开自动预置求解器智能体、团队、连接器配置与决策工作区。
- **OEM 发行版 Linux 并行安装**：非默认发行版统一 Linux 桌面身份，可与默认 DesireCore 同时安装，桌面入口和任务栏分组互不覆盖。

## 修复
- 修复冷启动后用户身份未及时恢复，导致选择自己拥有的浏览器空间时被误判为外部用户并返回 403 的问题。
- 修复 macOS 打包时隐私权限声明未正确写入 Info.plist，可能导致摄像头、麦克风、通讯录等访问被系统拒绝或终止的问题。
- 修复多进程并发安装同一系统缓存工具时可能产生损坏二进制或安装失败的问题。
- 修复受管凭据与求解器连接器凭据可被 Agent 通过占位符、技能连接注入、工作流模板等路径间接读取的安全漏洞，并封堵凭据引用登记的竞态窗口。
- 修复 MindOptSolve 发起求解时审批卡不显示凭据发往连接器与地址的问题。
- 修复聊天页有历史时模型看不到也无法执行界面动作，以及输入框发送时丢失界面上下文准入引用的问题。
- 修复发行版锁定品牌后，会话气泡、历史、搜索、通知等界面仍显示默认品牌名称与问候语的问题。
- 修复智能路由连续 529 换模时可能携带本机令牌直连上游、绕过代理与审计的问题。
- 修复 fork-for-resend 并发发布时读取方偶发误报记录损坏的问题。

## 改进
- 结构校验 worker 在启动阶段预编译内置描述符 Schema，避免高负载机器上误报校验超时。
