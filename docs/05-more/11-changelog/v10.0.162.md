# DesireCore v10.0.162

**发布日期**: 2026-09-14

![v10.0.162 更新概览](/img/changelog/v10.0.162.png)

## 新功能
- **1Password 凭据源**：支持连接 1Password Service Account 作为凭据源，并提供连接、健康检查、条目浏览、刷新、链接与断开等管理能力。

## 修复
- 修复沉浸式语音交互中连续语音首段快发、语音打断、播放交接及语音识别模式选择等问题，提升语音交互稳定性。
- 修复会话恢复过程中旧请求可能错误结算或播报当前请求的问题，确保查询事件携带正确请求身份并正确取消挂起响应。
- 修复通知持久化的一致性问题，统一使用 v2 信封与强校验，避免服务端错误被误报为成功。

## 改进
- 账号资源卡片改用元数据端点加载，避免拉取完整凭据敏感信息，并统一“+N 更多”显示样式，提升隐私与界面一致性。
