# DesireCore v10.0.172

**发布日期**: 2026-09-21

![v10.0.172 更新概览](/img/changelog/v10.0.172.png)

## 新功能
- **项目快速新建会话**：在手动多会话的项目分组行新增快捷入口，点击即可直接创建并选中绑定该项目的会话，创建后输入框自动获得焦点。

## 修复
- 修复多窗口同时操作不同智能体时，消息队列、草稿和工作目录选择可能相互覆盖或错归的问题，现在各窗口与会话状态相互隔离，刷新后也能正确恢复。
- 修复后续消息被确定性拒绝后，会话可能永久停留在“生成中”、新消息只排队不发送的问题。
- 修复手动多会话中某些项目或工作树会话仍显示智能体默认工作目录，与实际执行目录不一致的问题，现在界面统一展示真实路径及来源。
- 修复部分系统环境下多实例启动后立即退出时，后台扫描与迁移任务无法及时取消导致关停阻塞的问题，同时避免迟到错误窗口打断关闭流程。
- 修复部分系统环境下进程身份查询超时被误判为身份不匹配从而阻止启动的问题，超时现在会做有界重试，成功后继续启动。
- 修复暗色主题下部分定制发行版侧栏品牌标识显示为纯白方块、内容不可读的问题。
- 修复新实例首次登记网关时可能重启共享代理进程、导致其他实例连接短暂中断的问题，现在优先在线登记以保持既有连接不中断。

## 改进
- 优化启动性能：按需编译协议校验并复用控制发布准备，使首次启动和已有缓存场景下的可交互等待时间明显缩短。
