# DesireCore v10.0.150

**发布日期**: 2026-09-08

![v10.0.150 更新概览](/img/changelog/v10.0.150.png)

## 新功能
- **沉浸式语音与数字人交互**：完善数字人对话和语音交互的配置、诊断与状态管理，新增语音画布和语音诊断面板，语音链路更稳定可控。
- **文档协同与审阅增强**：增强超级文档审阅和协同能力，新增文档协作操作、沉浸式审阅来源追踪和审阅事务保护，文档评审更安全可靠。
- **市场团队使用指南**：市场团队详情页展示团队提供的使用说明，安装前即可查看用法；内置市场同步合同审查团队最新版本，新用户可直接发现并安装。

## 修复
- 修复 Windows 上应用因实例租约残留或系统缺少 PowerShell 而彻底打不开的问题；启动失败页和更新被拦提示会显示占用进程并提供“强制解除占用并重启”，无 PowerShell 环境也能正常启动并让 Agent 列出目录。
- 修复 Claude 订阅多轮对话从第二轮起恒定报 400 的问题，连续多轮请求现在正常并命中会话缓存。
- 修复 Agent 更新被阻止时看不到具体原因和出路的问题：现在会说明阻断原因，遗留合并冲突可直接打开冲突解决器，未配置远程仓库时不再误报有更新。
- 修复切换 Agent 后用户手动收起的工作区会自动重新展开的问题。
- 修复委派子智能体完成后仍显示“工作中”的状态残留。
- 修复云端 Qwen 模型通过兼容通道时因思考预算参数冲突导致请求失败的问题。
- 修复打包版多实例互控链路失效的问题：远程调试端口重新发布，并能区分未开启、正在发布、端口不匹配等状态。
- 修复 ZIP 上传时应用自身模块加载失败被误判为“包损坏”并删除用户文件的问题。
- 修复启动回退路径上的多个问题：服务已就绪会更快返回业务页，恢复页等待不会从头计时，成功加载不会被误报为启动失败，长时间无会话也会给出明确出口。
- 修复多个界面显示与无障碍缺陷：团队弹窗背景全透明、部分按钮与标题对比度不足、代码编辑器语法高亮不生效、蓝色主按钮键盘焦点不可见、状态颜色和读屏语义丢失等。
- 修复待发消息编辑与复制规则不一致的问题，支持完整复制长文本；失败项提示改为可重试、复制或删除。

## 改进
- 大幅提升冷启动速度：业务主界面不再等待后端服务完全就绪，显示时间显著提前；Windows 上多项启动检查合并或取消，Agent 服务就绪和可输入状态更快到达。
- 优化聊天界面的加载方式，图表等重组件按需加载，首次打开聊天更轻快。
- 统一全应用视觉风格与组件层，状态颜色、按钮层级、暗色模式对比度和键盘可访问性整体改善。
- 决策树工具的模型声明体积缩减超过 95%，降低普通请求 token 占用，需要时仍可按需获取精确动作契约。
- 升级遥测新增下载耗时与是否差量下载等数据，便于定位升级慢的原因。
- Windows 更新源不再包含约 1GB 的双架构合并安装包，避免误下大包；发布校验可识别对象存储归档态，防止差量更新静默失效。
