# DesireCore v10.0.136

**发布日期**: 2026-08-31

![v10.0.136 更新概览](/img/changelog/v10.0.136.png)

## 修复
- **技能安全**：修复了同名 project/agent 技能可静默覆盖官方安全流程技能的问题，现在官方安全技能默认优先，覆盖会被披露且需审批确认。
- **交付配对与提醒**：修复同一轮中多次发送用户消息时交付回填错配到最后一条同名条目的问题问，并确保崩溃恢复后防重复提醒在标记链断裂时仍能生效。
- **委派恢复**：修复委派恢复指引缺少必填参数 `contextMode="continue"` 导致照抄调用失败的问题。
- **市场 Agent 详情**：修复市场 Agent 详情可能显示分支 HEAD 的内容或版本、错误缓存版本或客户端门槛，导致误报更新/升级要求的问题。
- **待办提示**：修复已消费的任务回报仍跨多轮显示在待办提示中，造成新旧待办混淆的问题，现在消费后会自动移入历史区。
- **Git 认证错误**：修复 Git 认证错误检测对 SSH 错误和类型化错误漏判，并将连接类弱信号误判为认证失败的问题，使错误分类更准确。
- **Provider 审计**：修复审计日志将工具 schema 的 `reasoning` 参数错误脱敏，导致故障重放时请求体非法而失败的问题，现在保留正文原样以便重放排障。

## 改进
- **技能安全与审批**：为策略关键技能增加来源披露、遮蔽可见化，并提供显式选择来源和审批确认机制，使定制更透明可控。
- **随包 Git 供给**：改进随包 Git 在开发、本地打包和容器部署三种形态下的检查与版本管理，本地打包缺失时立即失败，容器启动时校验版本，避免误杀正常容器。
- **团队、PDF 与安装审阅**：固定团队数据来源、改进 PDF 页面渲染方式、明确团队安装与审阅目标，提升相关功能的准确性和一致性。
