# DesireCore v10.0.148

**发布日期**: 2026-09-07

![v10.0.148 更新概览](/img/changelog/v10.0.148.png)

## 新功能
- Claude 订阅复用 claude-cac 隔离环境登录，来源可选且只列真正可用的环境 (#2690)
- messages/fetch 接出 offset 分页，响应回带分页信息 (#2672)
- ManageSchedule 支持按 IANA 时区表达触发时刻 (#2637)
- 增加受治理媒体导出并修正文件回撤准入 (#2646)
- 补齐 remote/clean 能力，业务模块裸调加固句柄归零 (#2604)

## 修复
- 热点依赖排行不再整张打码——module id 在 reporter 侧转成仓库相对路径 (#2708)
- native 通道校验凭据可用性，登出后的死条目不再显示为已连接 (#2707)
- guard empty runtime combinator schema
- 安全快进官方 bootstrap seed
- ack 记账不再逐字节比对全局 outstanding；流 ID 配额按存活数计 (#2702)
- 手动触发调度增加并发闸门 / gate concurrent manual schedule triggers (#2685)
- 崩溃清理失败不再吞掉 child 死因 / stop swallowing the child's cause of death when crash cleanup fails (#2683)
- 合并 browser-control generation 测试里重复的 capabilities 属性，修复 dev typecheck 红 (#2703)
- 对齐两份资源测试夹具与委派输入准入，修复 dev 基线红 (#2700)
- 外部浏览器能力跨 Utility 边界，修复恒定 host_unavailable (#2631)
- 展示去重改按目标会话、归属判据补上对话维度 (#2612)
- exclusive 租约不再让同一主体自我抢占 / stop exclusive leases from preempting the same principal (#2686)
- sanitize startup avatar model paths
- integrate trusted delegation and conditional document context (#2680)
- accept current market team entries
- extend default agent service startup timeout (#2677)
- 嵌套 if/then + anyOf 的校验错误按可纠错性排序，anyOf 分支合并成「二选一」 (#2674)
- folder 查询侧与入库侧共用归一化，fetch 的 limit 支持 body (#2670)
- IMAP `:uid` 路由接受列表返回的 `imap:<uid>`，非法 id 不再静默失败 (#2669)
- IMAP 接入显式短超时、并行测试并支持仅收信接入 (#2666)
- 异步写路径等待维护租约而非 250ms 即失败，消除慢 runner 上的锁超时假红 (#2668)
- rrule-parser 全程按目标时区墙钟计算，消除对宿主时区的隐藏依赖 (#2667)
- 市场 Agent 更新 409 分类为「本地已修改」与「归属无法证明」并补强制更新入口 / classify market agent update 409 and add force-update path (#2665)
- 去掉 rebuildIndex 里重复的 index.agents.push，消除每次同步的假 duplicate-id 诊断 (#2664)
- 修正 PR #2629 两处测试的 AskUserQuestion answers 形状，恢复 dev typecheck (#2663)
- Claude 订阅默认全量工具集 400——工具 schema 按 SDK 子集投影，预检违规 63→0 (#2650)
- 修复 Windows Bash cmd 回退三层故障与插话被挂起目标吞掉 (#2629)
- 打开被残留进程占用的实例时给出可操作提示 (#2653)
- 收口 abortSession mock 实现泄漏导致的随机红 (#2655)
- 修复历史技能条目永久冻结，无法更新到新版 (#2632)
- 受信写入后同步重新基线 Agent 包指纹 / rebaseline agent package digest after trusted writes (#2645)
- 导出遇到读不了的文件时跳过并记账，失败不再静默产出坏包 (#2619)
- 修复带凭据 fill 被脱敏守卫误杀，并让无合成表面的指针派发快速失败 (#2652)
- 团队目录的只读授权扩到全部顶层子目录，不再只放行 shared/ (#2651)
- 后台 Run 的用户交付不再静默丢弃 / background run deliveries no longer silently dropped (#2624)
- 打包洁净判据覆盖被 .gitignore 忽略的产物 (#2644)
- 市场 Agent 重启后无法卸载与更新 / unblock market agent uninstall & update after restart (#2617)
- 清空已发送文件引用 (#2618)
- 内置浏览器原生视图在 presentation 通道失效时可撤离与重连 (#2594)
- handle Windows cursor-key persistence and custom update paths (#2640)

- session/store 惰性加载标题生成器，占位标题拆为轻量叶子 (#2695)
- ToolExecutor 惰性加载 checkpoint 服务，切断到 session/runtime 重图的静态导入 (#2694)
- 精简启动失败兜底页并开启 renderer 产物压缩 (#2687)
- 打断 server.ts ↔ socket-server ↔ handlers 的静态导入环 (#2678)
- app/lib 按职责域分目录，纯搬迁不改功能 (#2681)
- lib/main 按职责域分目录，纯搬迁不改功能 (#2661)

- separate local startup preparation from remote refresh (#2649)
