# DesireCore v10.0.122

**发布日期**: 2026-08-25

![v10.0.122 更新概览](/img/changelog/v10.0.122.png)

## 新功能
- **百炼万相 3.0 视频生成**：视频生成工具现支持百炼万相 3.0（wan3.0-video / wan3.0-video-prime），可传首尾帧、参考图/视频/音频、网页链接、智能时长、音轨、种子、提示词扩写与水印等参数。
- **Agent 模型配置委派**：Agent 现在可以经审批修改其他 Agent 的模型来源（如更换模型或提供商），此前这类请求会被直接拒绝。

## 修复
- 修复在智能路由与固定模型之间切换后，已设置的 Provider 白名单会静默消失的问题。
- 修复通知中心打开时会遮挡 Windows/Linux 自绘最小化、最大化/还原、关闭按钮的问题。
- 修复 Agent 清空会话历史时，当前运行未结束期间新消息可能写入待删除会话的问题；清除意图重启后仍会恢复，清除完成后可正常开始新会话。
- 修复心跳偏好保存的多个问题：系统默认值不再污染用户设置，只修改单个开关不会意外恢复已静音的告警，切换 Agent 不再串写设置，关闭面板前会可靠保存。
- 修复 Solver 连接器「读取→修改→保存」因多余字段被整份拒绝的问题。
- 修复克隆使用固定模型的 Agent 时，其模型配置被意外改写为智能路由的问题。
- 修复 Agent 设置弹窗可见但点击会穿透到下层档案页的问题。
- 修复治理接口可被 URL 编码变体绕过鉴权的安全漏洞，并防止审批摘要被模型注入误导性文案。

## 改进
- 移除治理操作中的「确认人类治理操作」弹窗，系统自动识别来自可信界面的操作，减少日常打扰。
- 弹窗焦点管理升级：最上层弹窗独占焦点循环与 Esc 关闭，下层弹窗自动失活，减少误操作。
- LLM 路由配置的读写逻辑全面收口，模型切换、白名单与固定模型之间的行为更一致稳定。
