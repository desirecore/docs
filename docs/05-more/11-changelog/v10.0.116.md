# DesireCore v10.0.116

**发布日期**: 2026-08-23

![v10.0.116 更新概览](/img/changelog/v10.0.116.png)

## 新功能

- **我的应用与应用资源管理**：新增「我的应用」区域，可统一查看并启动已安装的应用，应用运行在下载、弹窗与脚本执行均受限的隔离内嵌视图中，资源面板同步新增应用与服务管理入口，市场可统一发现智能体、技能、应用与服务。
- **智能体浏览器标签页枚举**：桌面端内置浏览器补齐了标签页列表命令，智能体现在可以在多标签页、无活动标签页等此前会报错的场景下列出会话内全部标签页，且清单按当前授权范围过滤、不显示越权的标签。

## 修复

- 修复正式版首次启动时载入页误报「无法读取恢复状态」、连接恢复页在发布包中整体失效的问题，连接故障时现在能正常进入可操作的恢复界面。
- 修复设置、资源、浏览器、商店等域共 59 处弹窗被内嵌浏览器视图遮挡一半的问题。
- 修复智能体档案面板偶尔同时出现两个、其中一个钉在窗口左上角无法关闭的问题。
- 修复审阅工作台部分撤销在刷新或重启后丢失完成状态与统计、无法继续操作的问题。
- 修复审阅工作台在来源任务结束后仍永久锁定、必须刷新页面才能继续撤销的问题，涵盖服务端已稳定但本地仍显示运行中、以及操作预检后监听未恢复等场景。
- 修复团队智能体安装器把已存在但配置损坏的智能体目录（连同记忆与工作区）误判为残留并整体删除的问题。
- 修复在智能体设置界面切换固定/智能路由模型后实际不生效的问题。
- 修复 Windows 普通权限用户因目录权限校验需要特权而在启动约 4 秒后退出的问题。
- 修复启动目录经软链指向时实例控制面静默降级、日志误报「伴生口启动失败」的问题。
- 修复断线重连后仍在运行的前台任务未正确接管会话，导致历史刷新、用量重载、流式占位与重试/编辑全部指向旧任务的问题。
- 修复非空间 owner 接管浏览器会话后收不到浏览器事件与截屏流、看不到自己正在操控的会话状态的问题。
- 修复市场应用中用户自定义应用缺少安装状态导致详情页崩溃、服务批准/拒绝后资源列表不刷新、智能体关联应用缺少解绑入口，以及部分返回/关闭按钮缺少可访问名称的问题。
- 修复同一服务在不同提供商下身份串台、相互覆盖的问题，市场智能体的安装与卸载现在精确绑定一次性人类授权。
- 修复邮箱授权结果处理错误、已有账号重新授权超时及部分服务商授权失败无反馈的问题，并移除无实际作用的误导性按钮。
- 修复自定义 OpenAI 兼容端点在开发者角色与最低推理力度参数下不兼容的问题。
- 安全修复：堵住通过 URL 百分号编码绕过人类审批治理门、未经审批即创建或删除智能体、修改模型配置的漏洞。
- 安全修复：修复任意已鉴权客户端可借助发送特定错误事件导致服务进程崩溃的问题。

## 改进

- 智能体的模型选择现在直接写入配置文件并随目录克隆、导入、导出同步，升级时自动迁移旧的固定绑定与白名单，固定与智能路由来回切换时已选范围不再丢失。
- 更新弹窗新增版本信息加载状态与完整骨架屏，版本列表与当前版本并行获取并保证最短展示时长避免闪动，过期请求不会再覆盖最新状态。
- 当「立即重启」因多实例运行或独立实例窗口被安全门禁阻止时，现在会明确提示原因，不再静默无响应。
- 邮箱界面整体升级，账户、列表、会话与详情阅读区采用更紧凑专业的布局，同步状态改为不占空间的悬浮提示，列表悬停不再引起虚拟行抖动。
- 自定义模型新增模型级能力配置入口，可为推理力度等参数设置默认值。
- 桌面端启动流程移除了重复的本地服务构造，冷启动更快、瞬时内存占用更少。
- 载入页不再自行判定故障，慢启动时按时间分阶段显示中性的加载提示，只有主进程明确回报失败才显示红色告警，载入文案同步去除了内部术语。
- 市场对缺少许可、不可变来源校验、品牌或审核证据的第三方条目默认仅展示、不允许一键安装。
