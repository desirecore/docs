# DesireCore v10.0.156

**发布日期**: 2026-09-11

![v10.0.156 更新概览](/img/changelog/v10.0.156.png)

## 新功能
- **微信自动续费与购买页重做**：算力包购买页改为三列套餐网格和独立结账弹窗，符合条件的套餐默认通过微信委托代扣签约，账户页可查看、管理和取消自动续费，购买和签约均需确认协议。
- **定时任务完成判据**：定时任务可设置必须生成的产出文件，未完成时会在同一会话中自动继续一次，若仍不满足则记为失败并通知，暂停或取消不再误报失败。
- **批量字符串核验**：Grep 新增一次提交多个字面量进行批量核验的能力，并返回同一文件快照的摘要信息。
- **决策树与工作台闭环**：可从治理活动和运行中心精确跳转到对应决策树运行，Board 提供正式的创建、检查与接管能力，工作流完成后会及时释放连接。
- **市场页导航整合**：同步状态移到页头右上角，团队并入“智能体”标签，排序移到标签行，列表区更紧凑。
- **智能体配置表单改版**：配置编辑改为通用 JSON Schema 表单，分组、说明、校验错误展开和窄屏布局更完善。

## 修复
- 换过模型的核心 Agent 现在能正常收到后续更新，未换过模型的会跟随上游推荐模型配置。
- 覆盖导入不再丢失版本历史，失败时会保留旧内容和恢复副本；已受影响安装可通过“修复仓库关联”恢复更新。
- 内嵌浏览器在大量命令后不会永久失效，触发资源限额或权限封存后可自动恢复。
- Claude 订阅用户在界面多轮对话时不再从第二轮起持续出现 400 错误。
- Windows 上 PowerShell 5.1 异常时自动回退到 PowerShell 7，并修复非交互命令可能挂起和终端任务收口失效的问题。
- 调度器在暂停、恢复或更新定时任务时不再永久丢失兼容演进的内置工具。
- 修复沉浸式语音中相关文件打开后被语音遮罩遮挡、继续语音按钮覆盖保存/更多按钮，以及 Agent 配置表单复选框不可见的问题。
- 修复自动续费和购买链路中的状态问题：签约失败不再误报为购买成功，已开通自动续费的套餐仍可再次购买，换套餐后不再沿用旧套餐的签约码。
- 修复差量升级基本从不成功的问题，现在可正常使用差量包，减少大版本整包下载。
- FileDigest 在收到字符串形式的批量路径时会明确提示应传入原生数组，而不是当作单一路径。

## 改进
- 空闲状态下大幅减少后台更新检测与市场同步的进程创建，降低 CPU 与内存占用，并减少 Windows 空闲实例的周期性卡顿。
- 应用启动关键路径并行化，并将部分后台预热任务延后到交互就绪后执行，提升进入可用状态的速度。
- 委派任务会把可继续执行的上下文 ID 展示给父 Agent，便于后续接续子任务。
