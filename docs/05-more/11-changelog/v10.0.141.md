# DesireCore v10.0.141

**发布日期**: 2026-09-02

![v10.0.141 更新概览](/img/changelog/v10.0.141.png)

## 新功能
- **工作目录侧栏可拖拽调宽与折叠**：文件工作台的工作目录侧栏现在支持拖拽调整宽度、拖拽折叠和双击分隔条复位，用户可自定义侧栏宽度并快速收起、展开。

## 修复
- 修复了在定制品牌环境下界面部分位置仍显示默认产品名称的问题，确保审批卡片和就绪预览的品牌显示一致。
- 修复了自动更新时可能因残留的死实例锁定信息而误报“仍有其他实例运行”并阻止更新的问题，更新过程更加可靠。
