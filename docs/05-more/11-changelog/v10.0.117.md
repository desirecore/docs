# DesireCore v10.0.117

**发布日期**: 2026-08-24

![v10.0.117 更新概览](/img/changelog/v10.0.117.png)

## 新功能
- **多实例连接管理**：设置页新增「本机其他实例」接入管理与「允许其他客户端接入」配对功能，可搜索并配对同机其他实例、查看各连接状态、生成配对码并管理或撤销已授权客户端。
- **会话侧栏按实例分段**：接入多个实例后，会话侧栏按实例分组展示各自的智能体，附带连接状态提示与折叠记忆，并支持跨实例连续编号的快捷键切换。
- **跨实例会话交互**：向其他实例的智能体发送消息、重试、继续生成、追问与审批回执等操作都会正确路由到其所属实例；实例不可达时给出明确提示，不再误发到本机。
- **对话导出筛选与预览**：导出对话时可选择日期范围、发言方与消息内容类型，并在导出前实时预览命中的会话数和消息数，空结果时禁用导出按钮。
- **PDF 对话气泡布局**：PDF 导出改为左右气泡对话排版——用户的消息靠右、智能体靠左、系统消息居中，长消息跨页更自然。
- **内置浏览器自动展示**：智能体执行浏览器任务时，内置浏览器会自动切换到用户面前；用户正在使用其他工具时仅显示一个可点击的提示，不强行打断。
- **图片处理环境健康检查**：算力资源卡片、算力页与运行环境页新增图片处理原生模块的运行状态检查（Windows 正式版），可提前发现图片功能不可用问题，且不修改任何系统权限。

## 修复
- 修复内置浏览器中点击任何页面的任何元素都没有反应的问题。
- 修复智能体执行浏览器任务后，一个不可见窗口盖住整个桌面、导致用户对所有应用的点击与滚动全部失效的问题。
- 修复消息重试的多处失效：刚完成的消息需刷新页面才能重试、长对话中重试/编辑判定错误，以及重试可能误作用于其他会话或实例。
- 修复手动断开某实例连接后，应用仍在后台每 30 秒无限重试连接的问题。
- 修复连接类错误在聊天界面显示“Error invoking remote method…”等内部技术细节的问题，现在显示可读的说明文案。
- 修复图片处理原生模块加载失败会拖垮整个应用启动的问题，现在该故障只影响图片相关功能。
- 修复低配置设备上启动多实例时子实例因就绪超时过早退出的问题；多实例选择器在子进程启动后立即收起，迟发失败改为通过系统通知告知。
- 修复同一实例解除配对并重新配对后，侧栏该实例段落保持折叠状态、导致“配对成功却看不到智能体”的问题。

## 改进
- 恢复通过 web-access 技能操控本机外部浏览器的能力，并修正相关工具描述——智能体不再用内置浏览器冒充外部浏览器交差，两种浏览器按用户意图区分。
- 设置页会提示指向同一实例的多条冗余连接（例如复制 HOME 目录后重复配对），帮助发现“配对成功却看不到智能体”这类静默故障。
- 最终提示词增加 Token 硬预算：超出预算时在调用模型之前明确报错，避免超长上下文引发调用失败或隐性裁剪。
- 强化提示词注入防护，并移除与实际能力不符的记忆能力声明，首轮对话的提示内容与运行时真实状态保持一致。
- 委派任务时冻结受信任来源的会话权限范围：子智能体读取被委派的任务可正常鉴权，同时模型无法自行扩大权限。
- 任务看板旧版数据升级后自动迁移到新版格式，迁移过程原子且可安全重试，无需手动处理。
