# DesireCore v10.0.135

**发布日期**: 2026-08-31

![v10.0.135 更新概览](/img/changelog/v10.0.135.png)

## 新功能
- **PDF 显式页面图像读取**：阅读 PDF 时可选择以图像方式读取指定页面，适合图文混排、旋转页或图片型文档，同时保留原有文字阅读与续读位置。
- **团队仓库固定版本安装**：团队仓库安装现在可从侧栏进入，并支持按指定来源引用或提交版本固定到可复现版本，多团队同名时的安装与审阅目标也更准确。

## 修复
- 修复外部浏览器操作时，内置浏览器快照会静默返回其他浏览器或其他对话内容的问题；现在会阻止错误读取，并在快照中标注实际来源。
- 修复创建首个外部浏览器标签后，智能体服务可能反复重启并卡在托管租约或安装阶段的问题。
- 修复团队包导入时把“跳过已存在全局技能”等正常保护行为误报为严重告警的问题，现在只有真正需要处理的情况才告警。
- 修复生产版升级被开发实例误判阻挡、倒计时停在 0 秒或被反复重置、无人值守升级不自动启动等一系列升级链问题。
- 修复流式回复期间导出或读取会话会提前把半截输出定稿，导致重复消息或检查点丢失的问题。
- 修复用户中断后界面和重启历史中会显示两条“用户已停止本轮任务”的问题。
- 修复云端模型输出上限识别区间，支持更大输出上限（如 131072），并在超限时当轮自动降低重试。
- 修复官方市场同步在符号链接被替换为普通文件等文件类型变化时可能永久卡住的问题。
- 修复 Windows 新建实例卡顿、受管启动握手不稳和路径输入竞态的问题。
- 修复内置工具参数校验不足：非法数组或对象参数不再被静默过滤或回退，而是给出明确错误与可选值。
- 修复通用代理类工具（如邮件操作）在无消息预览时被误提示“已成功送达”的问题，改为提示核对实际调用结果。
- 修复技能启用、禁用、创建、删除、导入后界面不立即刷新的问题。
- 修复联网 Git 操作可能被仓库自带钩子、凭据助手或本机 Git 配置劫持执行任意命令的问题，并隔离宿主配置、限制仓库地址与重定向。

## 改进
- 心跳面板从每 30 秒轮询改为事件驱动实时刷新，历史回执查询改用增量索引，速度显著提升并降低资源消耗。
- 智能体面板在流式输出时收窄订阅、共享计时器并缓存重复请求，减少卡顿和网络开销。
- 技能列表使用缓存发现并去除了面板双层背景模糊，打开和操作更轻快。
- 活动胶囊放宽模型名显示宽度并在窄窗下自适应收缩，避免模型名被截断或界面溢出。
- 团队安装后的列表刷新失败会被保留，并允许只重试刷新而不重复安装。
