# DesireCore v10.0.98

**发布日期**: 2026-08-05

![v10.0.98 更新概览](/img/changelog/v10.0.98.png)

## 新功能
- **内置浏览器工作台**：新增受治理的内置浏览器，支持多智能体并发隔离、Cookie/存储导入、鼠标轨迹与拖拽可视化、网络诊断及严格的权限与租约控制。
- **子智能体对话记录可查看**：委派给其他智能体的子任务、以及临时 Worker 的对话过程，现在都可以通过只读浮层直接查看完整的对话历史，无需切换会话。
- **失败的委派任务可续跑**：委派给子智能体的失败任务，现在可以承接原有的上下文与工具结果继续执行，不必从零重新委派。
- **记忆卡片一键撤销**：智能体写入或更新记忆的卡片上新增撤销按钮，可一键精确回滚（删除新增文件或恢复修改前内容），并告知智能体该记忆已撤销。
- **每轮自动展示修改文件清单**：每轮对话末尾自动展示本轮修改文件汇总卡片（如“已编辑 3 个文件 +20 −3”），并支持将本轮产出文件一键发送给用户。
- **终端面板快捷键**：新增 `Ctrl+`` 快捷键（与 VS Code 一致），可快速打开或关闭当前智能体的终端面板。
- **终端工作目录失配警告**：当终端的工作目录与当前会话的工作树不一致时（如智能体切换了 Git 工作树），终端顶部会显示明确警告并支持一键同步。
- **智能体可发现模型及思考档位**：智能体现在可以查看所有可用模型及其支持的推理深度；尝试设置不支持的深度档位会被明确拒绝并给出合法选项。
- **审批策略管理工具**：新增 `ManageExecApprovals` 内置工具，智能体可以查看并请求修改执行审批模式与规则（修改需用户本人确认）。
- **审批功能支持移动端**：新增 HTTP 审批接口，使移动端等非持久连接客户端也能拉取待审批事项并完成审批。
- **MindOpt 求解器连接器**：新增受治理的 MindOpt 运筹求解器连接器与独立网关部署方案，支持通过 HTTPS 提交数学优化任务。
- **退出前确认自动化任务**：关闭应用时，如存在定时任务、心跳自检或运行中的会话，会弹出确认窗口，避免意外停止自动化服务。
- **后台任务管理器**：新增独立的全局任务管理器，可查看所有后台任务与系统进程的资源占用、实时输出，并支持一键停止或强制重启。
- **Agent 忙态实时显示**：智能体执行任务时，资源管理器与左侧会话列表会正确显示“工作中”的状态，并实时广播变更。
- **会话列表头像辨识**：头像角标可明确区分智能体的本地/远程运行位置，并提供在线、忙碌、离线等状态提示。
- **可恢复的多智能体优化流水线**：支持创建可持久化的运筹优化流水线（预测、编译、求解、验证），中断后可基于断点恢复，不重复调用模型。

## 修复
- 修复流空闲超时导致智能体陷入无限静默重试循环的问题，并优化了网络异常时的重试提示。
- 修复跨会话轮次自动压缩导致上下文被静默丢弃的问题，确保摘要覆盖范围与丢弃范围严格对齐。
- 修复从大窗口模型切换到小窗口模型后、早期对话被永久压缩且切回大模型无法恢复的问题。
- 修复同一智能体上可能并发运行多路会话的问题，用户可见会话现已严格串行执行。
- 修复工具执行结果因按位置配对导致归属混乱、文件修改清单在审批模式下丢失等问题。
- 修复“清除聊天记录”操作进行期间发送的消息会被静默丢弃且无法恢复的问题。
- 修复重启应用后部分智能体长时间卡在“工作中”假状态，以及侧栏最后一条消息预览不更新的问题。
- 修复历史消息中视频被错误识别为图片导致破图、以及部分包含工具的纯附件消息不渲染的问题。
- 修复从聊天“更多菜单”打开的远程仓库、团队历史等面板按钮点击无效、弹窗立即消失的问题。
- 修复 GitHub App 未安装或缺少仓库写权限时，界面仍错误显示“已连接”并验证成功的问题。
- 修复工作目录路径含软链时，文件修改清单从第二轮起退化为冗长的绝对路径。
- 修复并发修改审批策略时可能静默丢失“总是允许”规则的问题。
- 修复 `ManageTeam` 工具传递 `null` 移除父团队设置时抛出错误的问题。
- 修复 MCP OAuth 授权失败时所有错误均归为一句通用提示、无法诊断具体原因的问题。
- 修复上游模型网关因误计图片 token 返回上下文超限错误时，系统错误地缩减输出上限而导致回复被截断的问题。
- 修复终端面板在后台隐藏期间滚动区计算错误，切回后无法滚动到最新输出的问题。
- 修复复制工具时因溯源元数据字段未在 Schema 中声明而导致工具无法加载的问题。
- 修复手动多会话模式在外部被开启/关闭时，聊天界面侧栏不实时跟随的问题。
- 修复异步委派失败时，委派卡片永久卡在“处理中”状态，不显示“已失败”的问题。
- 修复接口审计详情中模型交互正文默认不记录的问题，并增加自动清理与备份排除机制以保护隐私。
- 修复 Windows 升级进度窗口在高 DPI 缩放下文字重叠与截断的问题。
- 修复原生组件完整性清单包含非目标架构文件，导致 Windows 全量更新时被误判为校验失败的问题。
- 修复文件工作台界面宽度塌陷、右侧大片空白以及代码编辑器出现横向滚动条的问题。
- 修复智能体注册多个工作目录时，Markdown 预览中引用的跨目录图片无法显示的问题。
- 修复追问输入区切换不同问题时，可能将未操作的新问题错误标记为“已读”的竞态问题。
- 修复多实例选择器窗口无法关闭的问题（新增关闭按钮）。

## 改进
- 手动“压缩对话”的菜单与命令现在会清晰提示：该操作仅影响模型看到的上下文窗口，完整的原始聊天记录不受影响且可随时回看。
- 模型选择列表中，对于上下文窗口小于当前会话占用的模型，增加了非阻塞的橙色预警标识。
- `agent.json` 资源管理器表单得到全面完善：补齐了手动多会话模式、作者、头像等缺失字段的标题与可视化控件。
- 接口审计的请求与响应正文记录现已默认开启，同时新增自动过期清理与数据导出排除规则以保障隐私。
- MCP OAuth 授权失败的错误提示现在包含结构化的错误码与可操作的修复建议，并严格脱敏敏感凭证。
- 网络流空闲超时阈值现已根据首字节和字节间隔分别生效，避免长思考模型初期静默阶段被误判为超时。
