# DesireCore v10.0.98

**发布日期**: 2026-08-05

![v10.0.98 更新概览](/img/changelog/v10.0.98.png)

## 新功能
- **内置浏览器工作台**：新增受治理的内置浏览器，支持多智能体并发隔离、可视化操作、Cookie/存储导入及策略管控
- **后台任务管理器**：新增系统任务管理器，可查看系统进程、资源指标、终止任务和重启独立任务宿主
- **MindOpt 求解器连接**：新增运筹求解连接器，Agent 可直接调用 MindOpt 求解并获取结果
- **审批 HTTP 接口**：新增审批 HTTP 同步面与决策面，支持移动端等非持久在线客户端查看和处理审批
- **子智能体对话记录**：委派子 run 和临时 worker 的完整对话过程可在只读浮层中查看，目标智能体被删除后仍可回看
- **审批策略管理工具**：新增 ManageExecApprovals 工具，Agent 可查看和修改执行审批策略，写操作强制真人确认
- **模型发现与思考校验**：Agent 可通过 InspectModels 工具查询可用模型及其支持的思考档位，设置档位时自动校验并拒绝不支持的配置
- **本轮文件修改清单**：每轮对话末尾自动展示 Agent 本轮修改的文件及增减行数，并支持一键将文件发送给用户
- **关闭前自动化确认**：关闭应用前弹出确认框，列出将暂停的定时任务、心跳和 Webhook，避免意外停摆
- **委派续跑**：Delegate 工具新增 resume 动作，可让失败的委派子 run 承接原有历史与工具结果继续执行
- **运筹优化团队流水线**：新增预测、编译、求解和验证等多智能体协同流水线，支持人效优化场景
- **记忆撤销**：记忆卡片新增一键撤销按钮，可将 Agent 写入/更新的记忆精确回滚至修改前状态
- **终端快捷键**：支持使用 Ctrl+` 快捷键快速开关终端面板，适配多种键盘布局
- **终端工作目录警告**：当终端工作目录与会话当前工作树不一致时，顶部给出提示并支持一键创建正确目录的终端

## 修复
- 修复清除聊天记录期间发送的消息被静默丢弃、不可恢复的问题
- 修复跨 run 会话压缩导致部分上下文被永久丢弃的问题，摘要覆盖范围与丢弃范围现已对齐
- 修复同一智能体上可能同时运行两路回复的并发准入漏洞
- 修复重启后部分会话停留在假工作状态，以及侧栏最后一条消息不实时更新的问题
- 修复流式空闲超时后陷入无限重试循环、界面无提示的问题
- 修复历史消息中视频等媒体类型被误判为图片导致无法渲染的问题
- 修复工具执行结果按位置配对，导致走审批的工具在实时视图中丢失结果或挂错归属的问题
- 修复 GitHub App 未安装或权限不足时仍显示“已连接”，403 错误谎报令牌失效的问题
- 修复异步委派失败时卡片永久停留在“处理中”的问题
- 修复 ManageTeam 移除父团队时抛出 TypeError 的问题
- 修复 MCP OAuth 授权失败时所有错误都归一为同一句话、无法定位原因的问题
- 修复上游 token 计数异常时错误地降低输出上限导致回复被截断的问题
- 修复软链工作目录下文件修改清单从第二轮起路径退化为绝对路径的问题
- 修复追问 Dock 切换时错误地将新问题标记为已读的问题
- 修复从聊天更多菜单打开团队远程仓库/历史/发布面板时按钮无法点击、弹窗立即关闭的问题
- 修复 agent.json 表单缺少手动多会话模式开关，以及多个字段缺少中文标题的问题
- 修复 session_mode.manual 在外部修改后，侧栏不实时跟随的问题
- 修复 Agent 无法通过 ManageAgent 正确设置思考深度的问题
- 修复接口审计面板中模型交互正文默认不记录，导致详情为空的问题
- 修复同一智能体注册多个工作目录时，Markdown 预览中跨工作目录的图片无法显示的问题
- 修复复制工具后因溯源字段缺失导致工具无法加载的问题
- 修复文件工作台宽度塌陷且编辑器出现横向滚动条的问题
- 修复会话列表头像角标在本地运行时不显示的问题，本地/远程现在均有明确标识
- 修复多实例选择器窗口无法关闭的问题
- 修复 Windows 升级进度窗在高 DPI 缩放下文字重叠/截断的问题
- 修复原生完整性清单未按目标架构过滤，导致升级时误判安装校验未通过的问题

## 改进
- 手动压缩对话的按钮与命令现在清楚说明覆盖范围、持久性及聊天记录本身不受影响
- 模型列表对上下文窗口偏小的模型显示橙色提示，切换模型时自动记录压缩量纲，切回大窗口可恢复早期对话
- 记忆撤销后对话历史原样保留，并在系统提示中明确告知 Agent 已撤销状态
- 审批策略写入增加串行锁，防止并发操作导致规则静默丢失
- 压缩锁键提升到会话级，并发兄弟 run 不再重复调用摘要 LLM
- 接口审计的请求与响应正文恢复默认记录，新增保留期自动清理且从数据备份中排除
- 上游 token 计数异常时改为原样重发而非降低输出上限
- 工具结果归属改用 tool_id 精确匹配，乱序执行时结果正确挂载
- 终端隐藏期间滚动区被算短一屏的问题已修复，切回可见时自动纠正
- 关闭应用前会列出受影响的自动化任务，系统关机/重启/更新时自动跳过确认
