# DesireCore v10.0.109

**发布日期**: 2026-08-16

![v10.0.109 更新概览](/img/changelog/v10.0.109.png)

## 新功能
- **图片头像全面支持**：Agent、团队和市场条目现已全面支持图片头像，用户可通过选择器上传、拖放或由智能体生成专属头像，核心智能体也换上了全新形象。
- **远程 Agent Service 实例连接**：支持在设置中连接远程 Agent Service 实例，可配置 HTTPS 与安全凭据，并在本地与远程运行环境之间整体切换。
- **管理员权限提权交互**：当智能体需要管理员权限执行命令时，会弹出审批卡片请求真人授权，获批后通过系统原生授权框安全执行提权命令。
- **Agent 管理独立 DesireCore 实例**：智能体现可通过命令打开、关闭和列出独立的 DesireCore 实例，并可指定专属数据目录与 CDP 端口。
- **内置浏览器控制权交接**：智能体遇到需要登录的网站时，可主动将浏览器控制权交给用户，并在用户完成登录后自动等待取回控制权。
- **Markdown 编辑器 Esc 退出**：内置 Markdown 编辑器新增 Esc 快捷键退出，未保存时会先弹出丢弃确认，且不会干扰其他 Esc 行为。
- **图标按钮悬浮提示**：为所有仅有图标的按钮补充全局悬浮提示，鼠标悬停或键盘聚焦时会显示明确的功能说明。

## 修复
- 修复 Windows 上 agent-service 启动即失败、应用界面恒显“重试”、对话/终端/智能体全部不可用的 P0 级问题。
- 修复标准/远程浏览器画面永远停在第一帧、声音和标题正常但画面不刷新的问题。
- 修复 Windows 系统 NUL 设备不可用时应用在启动阶段崩溃的问题。
- 修复 Windows 上 TypeScript 语言服务冷启动被过早判定失败、跳错误报告的问题。
- 修复输入框文字在会话切换或按 ↑ 历史回溯后被悄悄清空、无法找回的问题。
- 修复流式助手消息的持久身份与磁盘记录不一致，导致搜索跳转、回撤等操作静默失效的问题。
- 修复 Agent 待办队列因一条缓存缺失就永久失去自动接手能力、且没有任何报错的静默失效问题。
- 修复任务宿主崩溃后永久占用全局名额、最终导致终端无法创建而必须重启应用的泄漏问题。
- 修复 worker 模式子任务超时后终局结果缺少可靠回流路径、完成或失败都无法归档的问题。
- 修复后台任务集中完成时，状态栏“运行中”计数被挤出、掉到真实运行数以下甚至归零的问题。
- 修复子运行计数漏算 subtask 类型，导致智能体状态摘要少算任务数量的问题。
- 修复官方界面正常登录、退出或同步云模型时仍被弹窗询问“是否允许模型路由或算力配置变更”的问题。
- 修复内置浏览器 7 个设置弹窗背景过透、聊天内容可透过面板清晰读出，以及长标题下关闭按钮竖排的问题。
- 修复多开实例在云端配额用尽后同时重试形成风暴、彼此踩踏并持续延长限流窗口的问题。
- 修复 Anthropic thinking 模式中空正文但携带有效签名被误判为不可回放，以及自动重试只回滚失败尾部、不重做已完成工具的边界问题。
- 修复内置浏览器原生视图与工作台外壳之间三处遮挡/失灵：缩放或拖动后画面停留旧矩形、标题栏按钮点不动、布局下拉被浏览器画面盖住。
- 修复未开启任何心跳时，系统仍默默替核心智能体自动开启 30 分钟心跳的问题。
- 修复浏览器临时元素引用可被写入站点知识笔记，导致几天后按过期引用操作“看似成功、实际做错事情”的问题。
- 修复智能体通过脚本在内置浏览器中读不到任何页面字符串的问题，现在换用脚本读取页面内容不再整体被脱敏挡掉。
- 修复子任务在会话发生过回撤或编辑重发后，每次都被虚假告知“历史不完整”的问题。
- 修复市场头部技能统计把合集条目只算 1 个、与实际已安装数量不符的问题。
- 修复同一 Agent 在侧栏与通讯录等不同位置可能显示成不同颜色或首字母大小写不一致的问题。

## 改进
- 终端布局归属统一收敛到工作台状态管理，切换停靠/分屏时不再出现双重终端、独立会话窗口空白栏或被陈旧配置悄悄回滚。
- 内置浏览器快照的元素引用改为短序号并引入快照代际校验，单次快照体积最多可降低约 80%，大幅减少模型上下文占用。
- 市场头部与详情页的安装统计改为按子技能实际分布计算，跨全局与各 Agent 私有目录去重，不再出现计数相互矛盾。
- 待发送队列样式更精简，视觉干扰更少。
- 算力请求在未显式配置并发上限时默认限制为 12 个并发，显式设为 0 仍表示不限流。
- 心跳改为必须由用户主动开启，避免系统默认写入用户从未表达过的偏好。
- 升级退出安装被延后时，会以原生对话框说明具体原因（受管实例、其他活动实例或安装器错误），系统关机/注销时则保持静默不弹窗。
- 后台任务展示改为优先排列正在运行的任务，长跑任务不再被终态任务淹没。
