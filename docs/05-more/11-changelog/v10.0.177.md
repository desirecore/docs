# DesireCore v10.0.177

**发布日期**: 2026-09-27

![v10.0.177 更新概览](/img/changelog/v10.0.177.png)

## 新功能
- **工作区一级实例标签**：文件、终端、网页和审阅目标现在合并为一排工作区标签，可直接创建、切换和关闭具体资源；同时新增统一的工作区标签快捷键，并优化了 Windows 顶栏入口。
- **单团队组长默认进入团队作用域**：只属于一个团队且担任组长的 Agent，其新会话默认进入该团队工作目录，团队决策工作区流程更易走通；手动选择个人目录后不会被默认值覆盖。
- **云端模型原生搜索声明**：云端模型现可接受服务端下发的原生搜索能力声明，使具备条件的云端模型直接进入原生网络搜索流程。

## 修复
- **Windows 残留锁与孤儿进程导致无法启动**：修复 Windows 上因机器 ID 或进程启动身份无法读取而无法接管残留实例锁、导致应用一直无法启动的问题；残留的 Agent Service 进程现在会被自动回收或经用户确认后处理。
- **流式长回复中吞字与界面死循环**：修复长回复期间快速键入被静默吞字、界面更新死循环导致审批卡注册丢失或发送失败的问题。
- **重载后在途消息卡住或重复执行**：修复页面重载或崩溃后已发送消息被长期标为“结果未知”、手动重试又可能重复执行的问题；现在会按请求 ID 对账，并在确认未执行且 24 小时内自动以原 ID 恢复发送。
- **委派内消息误开新会话**：修复被委派执行时向委派方发送消息会另起一轮、造成第二个不可见会话的问题；待委派方确认的事项现在写回最终回复并经委派结果返回。
- **子任务预算超限后的恢复路径**：修复委派子任务因系统提示词预算超限失败后，回执建议的恢复方式不可用、需要多轮绕路的问题；现在会直接给出可继续执行的重发调用。
- **决策工作区补问与开关隔离**：修复决策补问卡读取、作答和停止自动续办不可用的问题，并让决策工作区不再受全局任务板开关关闭影响，资源绑定写入仍会按开关拦截。
- **特定模型订阅下 AI 审批自动拒绝**：修复部分模型订阅通道下，关闭思考参数不合法导致 AI 审批每次都失败并自动拒绝中风险操作的问题。
- **网页搜索恒超时与失败原因缺失**：修复浏览器快照在特定验证页恒定超时、失败回执不保留原因的问题；云端模型的搜索能力声明也会被正确解析。
- **连续模型求解限制延迟拒绝**：修复连续模型误带仅适用于混合整数模型的限制时，先审批后到远端才被拒绝的问题，现在会在本地编译或审批前给出清晰错误。
- **CP 模型相对间隙被静默丢弃**：修复 CP 模型设置相对间隙后不生效、可能一直求解到时间上限的问题；达到间隙后会按要求提前停止。

## 改进
- **Windows 启动与实例接管更顺畅**：进程身份读取优先使用系统进程指标并减少额外系统命令调用，残留锁接管改为异步探测，减少启动等待与界面卡顿。
- **界面可读性与布局一致性**：统一工作区顶栏高度、不透明背景和整体圆角布局，并提升亮色模式下未选中标签、菜单悬浮、网址框焦点和错误提示的对比度。
- **能力门禁一致**：统一用户级能力开关在前端、系统应用和任务工具中的判定，能力关闭时相关入口表现更一致，已加载内容不会被突然清空。
- **文档解析与编辑组件升级**：升级安装器、代码编辑器、图表渲染和文档解析组件，改善表格解析错误提示、演示文稿坏页处理和图表渲染兼容性。
