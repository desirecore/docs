# DesireCore v10.0.176

**发布日期**: 2026-09-25

![v10.0.176 更新概览](/img/changelog/v10.0.176.png)

## 新功能
- **用户自助开票**：资料页新增“发票”入口，可为已支付订单申请发票，支持抬头管理、开票记录查看与多订单逐单批量申请。

## 修复
- 修复预置团队首次委派时因缺少共享工作目录而失败的问题，应用启动时会自动补齐默认绑定。
- 修复委派在子运行创建前失败后残留工作上下文、导致同意图重试冲突的问题，失败预留会自动撤回。
- 修复带交叉项的二次规划问题在部分求解引擎上出现数值不稳定、错误判定无解或崩溃的问题。
- 修复模型服务端 HTTPS 证书无效时被误报为本地网络问题并反复重试的问题，现在会明确提示证书错误并停止重试。
- 修复求解器连接器自动审批对已登记端点误拒的问题，审批摘要现在包含登记来源与凭据绑定事实。

## 改进
- 求解失败时会透传引擎原始终止状态与脱敏错误信息，便于了解失败原因并决定是否显式切换引擎重试。
