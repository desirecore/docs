# DesireCore v10.0.140

**发布日期**: 2026-09-02

![v10.0.140 更新概览](/img/changelog/v10.0.140.png)

## 新功能
- **长驻输出事件流**：当后台长驻命令持续输出内容时，现在可以按行自动触发智能体，并支持缺失内容补读、断点续传和限流保护，适用于日志跟踪、持续集成监控等场景。

## 修复
- 修复 Windows 上点击“退出应用并自动升级”后旧版应用可能不退出、升级进度窗口不显示的问题，确保更新流程可见并能正常退出旧版本。
- 修复 Markdown 编辑器全屏后按 Esc 键无反应的问题：现在第一次按 Esc 退出全屏，第二次按 Esc 关闭文档。
- 智能体右上角“…”菜单中的导入项由“导入智能体包”改为“导入更新（智能体名）”，避免与左上角的新建导入入口混淆。
- 修复从市场安装或更新智能体时可能触发配置校验警告、并掩盖真实配置错误的问题。

## 改进
- 市场中的飞书 CLI 技能合集补充 lark-meeting 技能，并将 lark-vc、lark-vc-agent、lark-minutes、lark-note 等已降级为兼容壳的技能描述改为“仅当显式指定时使用”，避免用户按旧描述误装无业务能力的技能。
- 工具组件下载增加 SHA-256 完整性校验，无法获得摘要或校验不通过时默认阻止下载，降低第三方镜像或传输过程被篡改的风险。
