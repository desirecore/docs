# DesireCore v10.0.139

**发布日期**: 2026-09-02

![v10.0.139 更新概览](/img/changelog/v10.0.139.png)

## 新功能
- **人机共管数据工作台**：新增任务板、决策树、白板编辑器和多种可视化投影（表格、树图、时间线、证据差异、图表等），用户与 Agent 可在同一界面查看、编辑并审计结构化数据。
- **决策工作区闭环与图共管**：非专家用户可通过补问和真实确认澄清决策语义，中断后可恢复续办；决策图支持筛选、折叠、定位与高亮，确认后的决策树可一键启动工作流并保留完整来源。
- **Ollama 算力零配置接入**：启动时自动探测本机 Ollama，首次在线自动创建并启用 Provider、自动发现本地模型；未命中精确规格的本地模型也能按参数量级参与 Smart 智能路由。
- **豆包搜索与工具后端优先级**：新增豆包搜索作为 WebSearch 备选 Provider，并支持在工具后端界面编辑各 Provider 的优先级，数值越小越先尝试。
- **技能外部二进制依赖检测**：技能可声明所依赖的外部命令行程序，缺失时 Agent 会如实说明并提供安装指引，不再反复重试或虚报成功。
- **隐藏 DAMO 演示品牌切换**：按 Alt+Shift+B 可在 DAMO 演示品牌（含 Logo、“总调度”核心智能体及专用头像）与默认品牌间切换，选择会保留在当前实例。

## 修复
- 修复深度推理任务在长时间无事件时被空闲 watchdog 误杀并反复重试的问题：超时后会先检测连接是否可用，连接正常则继续等待推理完成。
- 修复旧版决策工作区因缺少新版审计字段而在迁移后无法打开的问题。
- 修复切换 Agent 再切回时，手动会话中的残留消息未对账磁盘的问题，外部截断的消息不再显示。
- 修复 Agent 委派任务被拒后虚报“已指派”的问题：现在会遵循“指派 → 委派时携带任务引用 → 对方认领”的正确链路，并给出可操作的修复指引。
- 修复重启应用后自定义 SAPI 地址未恢复、回退到生产地址的问题。

## 改进
- Windows 桌面启动速度大幅提升：各阶段等待时间显著缩短，进入完全就绪状态约比上一版本快 23.5%。
- 文件工作台根目录列表请求做在途去重，避免一次刷新触发重复请求。
- 工具二进制缓存迁移至操作系统标准缓存目录，跨实例共享，避免写入实例数据目录并减少重复下载。
- Git 操作统一使用系统原生 Git；当环境无可用 Git 时，应用会明确报错并快速结束启动，而不是降级或挂起。
