# DesireCore v10.0.158

**发布日期**: 2026-09-13

![v10.0.158 更新概览](/img/changelog/v10.0.158.png)

## 新功能
- **结构化文件验证**：智能体新增对授权的 JSON/YAML 文件按 JSON Schema 进行只读验证的能力，并记录文件、模式与报告的内容哈希来源。
- **文件摘要 JSON 批量输入**：文件摘要工具支持用 JSON 字符串批量指定文件，智能体处理多文件时更稳定，避免将序列化路径数组误当作单个路径。
- **团队共享工作目录设置**：团队设置面板新增共享工作目录配置入口，可填写路径或选择同一主机上的目录，便于未绑定目录的团队委派正常启动。
- **市场新增“MiMo 模型余量检测”智能体**：市场仓库新增官方智能体条目，可用于 MiMo 模型余量检测。

## 修复
- 修复单个智能体配置文件损坏（如合并冲突）会导致整个服务无法启动的问题：现在该智能体显示“配置损坏”徽章并引导修复，其他智能体照常可用。
- 修复停止委派子任务时结果丢失、以及团队后续跟进落入个人目录的问题：中断结果会保留在父智能体收件箱，团队跟进在正确的共享目录中运行。
- 修复导入更新弹窗打开期间切换会话可能覆盖其他智能体的问题：弹窗打开时会冻结更新目标，避免误覆盖。
- 修复 Windows 上 CDP 端口发布每次启动失败且退出时不清理文件的问题：受影响的安装首次运行新版即可自愈。
- 修复市场仓库新增或更新时允许非法配置写入、导致下次启动仓库列表加载失败的问题：现在会先校验配置再保存。
- 修复内嵌浏览器导航失败时错误提示笼统、且失败后页面权限可能过宽的问题：智能体可区分页面跳转、网络与平台故障，失败后权限自动收紧。
- 修复文件摘要工具将序列化路径数组误当作单个路径导致多文件摘要失败的问题：现在会引导使用 JSON 批量路径输入并提供更准确的错误提示。

## 改进
- 优化启动阶段的资源调度：身份校验改为异步执行，后台周期同步任务延后到本地就绪后启动，减少主界面阻塞。
- 统一启动页与连接恢复页的章鱼品牌标识，优化准备页卡片层次、背景动效和窄屏布局。
