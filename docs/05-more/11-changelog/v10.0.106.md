# DesireCore v10.0.106

**发布日期**: 2026-08-12

![v10.0.106 更新概览](/img/changelog/v10.0.106.png)

## 新功能
- **任务板多智能体协作**：支持为任务分配责任代理人，实现多智能体之间的委派、交接和持久化分批派发，并新增审核面板用于跟踪责任状态。
- **任务板全局工作台**：新增统一的全局任务工作台，可同时查看所有看板的任务，支持看板、列表、卡片三种视图，并可通过桌面深度链接快速定位任务。
- **任务板自动化**：允许为任务板设置定时或条件触发的自动化规则，智能体可按预设逻辑自动执行任务操作。
- **任务板工作流**：任务板深度集成持久化工作流，可在任务详情中直接触发工作流运行、查看运行历史与任务关系图。
- **全局多智能体指挥中心**：新增跨看板的指挥中心视图，按智能体或团队分组汇总所有任务，帮助快速了解工作负载和需要关注的事项。
- **来源敏感的 Agent 引用**：在聊天中使用 `@Agent` 时，仅作为纯上下文引用，不再自动派发执行任务；任务板中的提及则仍然作为直接的协作请求，提供更安全的沟通方式。

## 修复
- 修复上下文压缩结束后，状态栏可能永久显示“正在整理上下文…”而不恢复的问题。
- 修复用户消息卡片在特定编辑操作后，可能触发界面无限刷新的问题。
- 修复文件工作台中，同一资源被重复打开时会产生多个重复标签页并导致控制台警告的问题。
- 修复 SuperDoc 文档编辑与审查过程中，异步保存、关闭或切换文档时可能发生事务冲突或状态不一致的问题。
- 修复 macOS 安装包因签名前后校验不匹配，导致完整性验证失败的问题。
- 修复 Windows 和 Linux 平台因缺少必要的运行时依赖，导致应用构建失败的问题。
