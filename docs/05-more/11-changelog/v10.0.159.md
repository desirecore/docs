# DesireCore v10.0.159

**发布日期**: 2026-09-13

![v10.0.159 更新概览](/img/changelog/v10.0.159.png)

## 新功能
- **结构组合校验**：智能体现在可以在同一次受限文件读取中同时校验结构化产物、规则文件与原文引用，并支持读取 DOCX 的规范文本表示。

## 修复
- 修复了结构文件校验在处理小文档时可能因启动时限包含依赖加载而超时失败的问题，现在初始化与校验分开计时，校验更可靠。
- 修复了 FileDigest 工具在批量文件参数错误时提示混淆的问题，现在会明确引导使用 paths_json 并说明它与 paths 互斥。
