# DesireCore v10.0.160

**发布日期**: 2026-09-13

![v10.0.160 更新概览](/img/changelog/v10.0.160.png)

## 新功能
- **账号系统与凭据授权**：新增账号资源视图，可统一查看和管理凭据条目，并针对每个条目设置“允许/每次询问/拒绝”的授权策略；Agent 读取受保护凭据时需先通过审批卡授权，支持批量授权、删除确认和密码默认遮罩。
- **Agent 主导的应用关联与独立卸载**：应用现在作为 Agent 的可选入口，可由多个 Agent 共享；删除 Agent 时默认保留应用并提示其他使用者，仅在你明确选择时才按条目独立卸载，且卸载应用不会删除 Agent。
- **委派前文件汇总校验**：源智能体可声明委派前置校验策略，在派发前对文件汇总进行结构与数量校验，不匹配会被拒绝，并向模型返回可核验的校验结果；未声明策略时保持原有行为。
- **受信任脚本快照输入输出**：受信任脚本工具新增可选的快照输入输出配置，执行前会读取并记录授权文件，执行后只发布经过哈希校验的新增结果，避免路径越界，并防止非零退出被运行输出中的成功消息掩盖。
- **运行中委派的实时进度**：进行中的委派子任务会显示有界的实时摘要与工具计数，且在子任务真正结束前不会提前显示为已完成，方便分辨正在执行和已经卡住。
- **核心 Agent 缺失告警**：当系统未检测到核心 Agent 时，会显示一条可关闭的提示条，提醒你检查核心 Agent 是否缺失，同时不会对零个非核心 Agent 的正常状态误报。

## 修复
- 修复 Claude 订阅中 Opus 5 在自动推理档位下被误判为未知模型而报错，以及官方 Anthropic 端点在跳过思考的工具轮上被无谓重试并导致缓存失效的问题，相关对话现在都按自适应思考语义正常运行并减少不必要请求。
- 修复 Grep 搜索会把正则表达式当作字面文本执行的问题，现在给模型的说明会明确要求显式标记正则搜索，搜索结果更符合预期。
- 修复覆盖导入智能体时会覆盖你已选择的模型路由的问题，导入覆盖现在会保留原有路由配置，并在配置损坏时避免误报为缺少配置。
- 修复更新单个智能体后旧工具定义仍被缓存、新工具结构不能立即生效的问题，更新完成后现在会自动刷新相关工具与技能缓存。
- 修复合同链路中结构化校验每次重新加载依赖、可能触发 5 秒启动超时的问题，现在会复用校验 Worker，校验响应更快更稳定。
- 修复 Chromium 下多个弹层因半透明背景与溢出裁剪冲突，导致最后一项浮出面板且没有背景的问题，审批模式等下拉菜单现在显示完整且背景正常。
- 修复 Windows 从种子包解压后因缺少 git 索引导致市场同步误判本地偏离、整仓归档一次的问题，现在解压后会按需重建索引，首次同步不再被误判。
- 修复后端配置恢复后会话仍持续显示“配置损坏”标记的问题，刷新现在会采用后端最新健康状态，恢复后自动清除旧错误标记。
- 加固无人值守会话在 RUN_BRANCH_BUSY 状态下的恢复流程，补充阻塞原因与稳定回执凭据，使后台任务结果在重启后也能可靠提升，减少卡住和丢失。

## 改进
- Windows 自动升级在旧目录已被移走时改为直接写入安装目录，省去临时解压和复制，升级明显加快；安装文件不完整或磁盘写满时会自动回滚，并在旧版本启动时提示恢复，失败不再静默留下损坏应用。
- Claude 订阅改为按请求物化命令行会话，长时间空闲、重启、切换模型或上下文压缩后不再导致多轮对话报错，续接体验更稳定。
