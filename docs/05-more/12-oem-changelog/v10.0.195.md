# 达摩院AgentOS v10.0.195

**发布日期**: 2026-10-29

![v10.0.195 更新概览](/img/changelog/oem/v10.0.195.png)

## 新功能
- **统一归档页**：设置中新增“数据与隐私 → 归档”入口，可查看、恢复已归档团队和已归档会话，并提供撤销解散、冲突补填等能力。
- **会话普通消息免打扰**：支持按收件人、Agent 和会话设置普通消息免打扰，审批与问答提醒继续保留。
- **决策页作用域显式选择**：决策页新增个人/团队作用域下拉，用户选择后会持久保留，不再随进入其他任务板而变化。
- **个人任务板发现与排队原因**：普通对话中智能体可发现并写入个人任务板；派单排队时界面会说明是在等哪条对话以及等待原因。
- **Agent 间委派不限层**：智能体之间的委派取消层级上限，子任务只允许创建同级子任务，委派链更灵活。
- **后台 thinking 回传配置**：支持按模型管理思考内容回传开关，关闭后不会影响工具续轮。

## 修复
- 修复本地用户资料读取失败时误弹出协议同意页，并确保已同意记录的同一版本不会被重复覆盖。
- 修复草稿冷恢复入口丢失、附件恢复后重复上传以及历史时间线多选回缩的问题。
- 修复大工具输出可能导致任务中断或会话恢复不完整的问题，现在支持流式保存并精确恢复。
- 修复旧任务板每次写入卡顿数十秒的问题，后台会自动补建历史索引。
- 修复浏览器工具报错信息不明确，现在会返回可操作的修改说明。
- 修复技能发现会把技能目录内的嵌套技能误登记为独立技能的问题。
- 修复技能依赖检测对 python3 等命令的误判，并补全内置运行时命令。
- 修复审批策略文件带 BOM 或解析失败时可能清空策略或无法写入的问题。
- 修复偏好文件路径包含冒号等特殊字符时的错误处理。
- 修复 Smart 新会话缺少冻结路由决策时延迟到副作用落地后才失败的问题，现在会在请求前拒绝。
- 修复绑定任务的运行无法读取或修改同板新创建任务的问题。
- 修复委派总览会把智能体提问误显示为“等你批准”，现在正确显示“等你回答”。
- 修复消息时间显示不一致、跨板任务刷新漏接以及更新恢复状态竞争的问题。
- 修复消息样式预览与真实聊天不一致的问题。
- 修复退出确认可能被取消后仍授权其他退出操作的问题。
- 修复 Windows 下链接数据根的运行索引 IO 异常。
- 修复通知回复提醒在不同 Agent 或会话间身份冲突导致通知丢失的问题。
- 修复应用发布清单校验失败时只返回错误码，现在会附带具体字段错误。
- 修复路由规范化把团队成员配置仅因键序不同就重写并自动提交的问题。
- 修复多个底层安全漏洞。

## 改进
- 优化跨板任务查询分页性能，委派总览等页面加载更快。
- 减少新建文件 Write 对模型的重复回显，降低上下文占用。
- 优化工具使用指引，减少模型在委派续接、任务取消、计划查找等场景的调用错误。
- 升级若干安全依赖。
