# 达摩院AgentOS v10.0.188

**发布日期**: 2026-10-25

![v10.0.188 更新概览](/img/changelog/oem/v10.0.188.png)

## 修复
- 修复文档行内审阅提交成功后仍误报“尚未保存”的问题，并在恢复路径按已提交结果重建编辑器，避免后续保存回滚已接受的改动。
- 修复首次由智能体创建文档后工作区只显示“新标签页”、不建立文件标签的问题，现在会自动打开并激活新建文档。
- 修复中断回复回执丢失已生成文本、显示“无输出”的问题，现在会保留已流式生成的正文内容。
- macOS/Windows 的受保护状态读取改用异步系统调用，避免同步阻塞桌面启动，并改进受保护存储故障诊断；系统授权仍由操作系统正常处理。
- 修复 Windows 运行环境页在窄窗口下系统工具卡片内容溢出，长路径、版本号和 Git 来源控件现在可以正确收缩和换行。
- 修复 Windows Git Bash 子进程中系统环境变量键名被强制大写导致变量为空的问题，现在保留原始拼写。
- 修复开发模式下官方控制面使用 deployment-v1 时默认账号无法自动登录的问题；该开发默认登录仍仅限官方控制面地址。
- 修复环境检测中工具探测无结论时丢失已确认的运行时路径、Git 信息与提醒的问题，新会话会保留这些信息。
- 修复运行时未声明工具调用的错误信息未被保留的问题，现在保留工具错误以便后续诊断。
- 修复显式指定目标平台时，非 Windows 缓存路径可能沿用当前宿主系统路径语义的问题。
- 修复近期工具调用记录身份与状态投影不一致的问题，使近期工具调用记录更准确一致。

## 改进
- 澄清父 Plan 引用与 Task 动作快照的范围，避免子任务错误沿用父计划限制，或把 full.availableActions 当作当前工作目录的动作准入。
- 升级 Markdown、YAML 解析及图标组件，提升相关渲染与处理的稳定性。
- 保留原始未声明工具错误，并追加明确标注为当前请求运行时补充说明的授权与声明状态提示；不改历史回执或工具权限。
