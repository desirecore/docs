# 达摩院AgentOS v10.0.192

**发布日期**: 2026-10-29

![v10.0.192 更新概览](/img/changelog/oem/v10.0.192.png)

## 新功能
- **任务板工作区**：将任务板应用整理为“委派总览”“决策”两个顶层视图，原“当前任务板、自动处理、流程、关联图”统一收进单个任务板工作区，并在委派总览集中展示需要你处理的工作流人工节点。
- **任务步骤进度**：执行智能体可自报任务步骤进度，委派总览与任务详情会显示步骤进度条、上报时间和“停在第 N/M 步”等状态。
- **结构化验收标准与逐条自评**：委派人可为任务设置结构化验收标准，智能体提交时逐条自评；验收面板和任务详情展示标准、证据与最近一次自评，返工时还可勾选未满足条目。
- **任务执行结束通知**：智能体执行结束但未提交验收时，任务板会通知任务板所有者；任务板策略升级到 V5，可在页头开启或更新任务通知。
- **责任变更自动唤醒**：改派、移交或指定审核人后，系统会自动在任务上下文中“提到”新的负责人或审核人；新委派建任务时也会登记唤醒，并在任务卡上显示“未能通知”。
- **团队归档与恢复**：解散团队会保留可恢复的归档，智能体可通过团队管理工具列出并恢复已归档团队，同时提供跨智能体的已归档话题列表服务能力。
- **系统浏览器自动化**：支持从系统浏览器路径启动，并可在内网或离线环境下使用随包资源准备外部浏览器自动化运行时。
- **派单运行弹窗增强**：在派单运行弹窗中可以直接回答结构化问题、处理服务审批，无需跳转到其他入口。
- **决策树真人确认体验**：决策树问题在界面中优先展示，支持多行输入、可选题的“我已看到问题”和“暂不回答，继续”，布尔问题改为直接点选“是/否”。
- **Markdown 主动审阅**：Markdown 文档默认展示最新可信正文，用户可主动进入独立审阅标签页查看历史并回退到真实保存版本。
- **应用开发辅助**：智能体在开发应用时可从平台取得可信的草稿来源会话，减少因来源填写错误导致无法发布到“我的应用”。

## 修复
- 修复自动更新下载中途失败可能导致应用直接退出的问题。
- 修复部分设备升级后配置缓存初始化失败、进入恢复页而无法正常启动的问题。
- 修复发行版种子内容升级阻塞启动的问题，升级任务已移到启动完成后的后台队列执行。
- 修复导出对话 PDF 时汉字被提取成部首、等宽代码字体缺失的问题。
- 修复聊天记录检索无法定位本次会话实时新消息，以及历史预览命中可能留在裁剪区外的问题。
- 修复拉取请求自动化保存冲突只显示“保存结果未确认”而不说明具体原因的问题。
- 修复团队包重复导入会静默覆盖已有团队的问题，现在会先确认覆盖，对话记录冲突会给出明确下一步。
- 修复团队导入中断可能导致服务无法再次启动的问题，并支持在本地存储写满后保留原来源重试。
- 修复团队导入会带入导出者机器本地配置的问题。
- 修复浏览器中关闭查看的页面在任务结算后又被自动加回、冻结的空个人浏览器会话无法新开网页、撤销共享授权后观察者记录残留等问题。
- 修复浏览器长轮询超时后错误隔离全部内嵌浏览器会话的问题。
- 修复聊天截图确认时崩溃和选区覆盖层残留的问题。
- 修复“全部放行”审批说明容易被误读，以及切档竞态、附加侧聊可能产生与界面设置不一致行为的问题。
- 修复取消加密备份恢复后明文临时包仍留在本机，以及异常退出后明文包遗留的问题。
- 修复全量传输对话框中任务板、工作流和审计日志类别缺失，导致设置页导出或恢复漏掉数据的问题。
- 修复导出遇到空间不足只提示“导出失败，请重试”、文件跳过提示不准确的问题。
- 修复迁移覆盖摘要不按实际归并决策显示的问题。
- 修复跨身份迁移后部分智能体对话历史不可见的问题。
- 修复同一实例迁移包恢复旧任务快照可能与新历史混合导致不一致的问题。
- 修复取消导入取包时缺少入口、旧请求可能干扰新导入的问题。
- 修复文件工作台保存时原有文件权限被收窄的问题。
- 修复直发 /steer 在清除过程中可能将文本注入正在被取消或封存运行的问题。
- 修复流式响应中途超时可能误发成功回执的问题。
- 修复包内配套应用因安装包被签名而校验失败、自动安装不成功的问题。
- 修复技能安装目录因本机运行状态与包内容混淆而无法更新或卸载的问题，删除含敏感环境文件的技能或智能体前会先确认。
- 修复新建任务缺少方案被误报为无权限、任务写入并发版本自竞争、同行审核后人工验收无审核人、页头升级和归档按钮消失等问题。
- 修复任务板“今日完成”静默丢弃部分任务、任务加载请求可能叠加，以及服务被旧任务板大历史阻塞的问题。
- 修复任务板关联并启动受治理工作流时绑定固定到旧路径、运行参数表单无法提交的问题。
- 修复拉取请求自动化后台存在双监控导致重复派发，以及重启后不提示被中断修复的问题。
- 修复求解引擎清单调整和核验无法由智能体直接请求的问题，恢复为按所用工具审批约束。
- 修复应用草稿来源会话缺失，导致智能体开发的应用发布不到“我的应用”的问题。
- 修复同机工作台备份恢复时旧快照与新提交混合、白板与工作流等对象恢复不一致的问题。
- 修复本地服务重启后独立聊天窗中的浏览器会话仍被失败状态挡住的问题。

## 改进
- 显著缩小桌面安装包体积：仅打包必要产物，去除重复资源和仓库源码，减少大量未压缩资源占用。
- 算力初始化与页面、输入框就绪解耦，启动后可先输入并发送，实际消费模型时再等待算力准备完成。
- 外部浏览器运行时改为启动收口后的空闲预热与首次使用前准备，减少启动高峰等待和单次准备成本。
- 内置技能同步在同一批次内只做一次完整来源复核，明显缩短必需和剩余阶段的同步耗时。
- 任务板跨板查询、旧板读取和恢复扫描分段释放事件循环，减少服务长时间无响应或频繁断连。
- 对话导出时间跟随请求时区，跨时区导出时正文、消息时刻和文件名日期保持一致。
- “全部放行”审批选项旁增加说明表，明确适用和不适用场景。
- 浏览器工作台内嵌浮层支持用 Esc 关闭并恢复焦点。
- 关闭查看的浏览器页面记录按会话和分区隔离，同一会话后续新页仍可正常展示。
- 通知面板关闭后可正确将焦点恢复到原触发位置。
- 通用单选按钮支持键盘导航和可访问描述，布尔问题回答更直观。
- 升级多个核心依赖并修补安全公告，提升整体安全性和兼容性稳定性。
- 移除启动时的算力注册引导弹窗，减少新老用户首次启动干扰。
- 启动与恢复页面按当前发行版显示正确的应用图标，避免显示其他品牌或默认图标。
- 系统浏览器自动化在空闲时自动预热，用户活动期间自动让位，降低首次高级浏览器交互的等待。
- 任务板工作区返回按钮和路由记录更加明确，离开后再次进入同一任务板仍可正常响应。
