# AI优化建模平台 v10.0.211

**发布日期**: 2026-11-23

![v10.0.211 更新概览](/img/changelog/oem/v10.0.211.png)

## 新功能
- 文件工作台支持可编辑演示文稿与 PowerPoint 导出 / Editable presentations and native PowerPoint export (#6345)
- 五个字段最低版本填为 10.0.204，编辑器调用时限本地化与范围拦截 / Fill minClientVersion 10.0.204 for five MCP fields and localize the timeout inputs with range checks (#6341)
- 按现有审批记录本机 MCP 启动信任 (#6323)
- 支持 Codex 会话速度选择与继承 / Add per-conversation Codex speed (#6324)
- 增加跨平台桌面开机自启动设置 (#6320)
- 桌面一键发布与跨架构扫码运行时 (#6306)
- 严格重发新后继写入v2并登记208兼容要求 (#6278)

- 修复 OEM 发布说明的 Git 历史读取 / Restore OEM release note history reads (#6349)
- 按界面语言加载按需技能正文 (#6344)
- 加固 Windows 升级交接与手动版本选择 (#6332)
- 统一重试预算并恢复重连等待 (#6329)
- 跳过旧团队导入恢复中多余的目录指纹读取 (#6334)
- 修复聊天输入框在换行临界点持续抖动 (#6316)
- 关闭普通界面输入的原生拼写检查 (#6225)

- 恢复卡住的目录服务安装重试 (#6322)
- 补丁变更强制全量，映射采集测试加载的依赖包 (#6308)
- 修复 Windows 更新启动失败的降级与重试 (#6318)
- 修复工作树 PR 监控显示与查询提示 (#6319)
- 允许本地4K视频按路径交付并保持读取预算 (#6317)
