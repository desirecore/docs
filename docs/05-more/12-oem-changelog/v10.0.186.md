# 达摩院AgentOS v10.0.186

**发布日期**: 2026-10-22

![v10.0.186 更新概览](/img/changelog/oem/v10.0.186.png)

## 新功能
- **分层阅读思考与工具过程**：长思考默认收起，生成期间显示“正在思考”和连续扫光；同一轮运行内的连续工具执行会归并为动作摘要，用户可逐层展开查看详情，避免长思考或工具结果撑满聊天窗口。
- **简化模型选择与自动选择设置**：聊天输入区直接展开完整模型列表，支持跨来源搜索和筛选；自动选择可直接点击，并可在独立设置中配置来源范围与优先顺序，且按当前智能体保存。

## 修复
- 切换模型或重新选择当前智能体时，输入框不再被卸载重建，未发送草稿和正在进行的输入法组词得以保留。
- 受限网络环境下，公共网络探测失败不再导致正在进行的推理被中止或误判为离线，网络重试可正常恢复。
- 部分模型服务返回仅含心跳事件、响应头前长时间无响应，或停止生成后立即追问时，不再出现报错或消息未发出的情况。
- 窗口重建后，即使任务已经完成，聊天界面也会自动恢复状态与历史，不再一直显示“运行中”。
- 跨用户轮恢复历史时，未加载工具的失败说明得以保留，模型不会再否认上一轮的真实执行结果。
- 首次打开时，内置求解器智能体不再因早期文件残留而被跳过安装，已有内容只补缺、不覆盖。
- 重新显示保活的原生应用时，等待期间会显示加载提示，成功后恢复原编辑器，不再空白。
- 登录界面会按照认证配置显示手机验证码、注册和找回密码等入口，邮箱验证码登录暂时隐藏并禁用。

## 改进
- 聊天顶部模型管理入口收敛为工作目录与资源管理器入口，模型选择后菜单保持展开，交互更简单且切换更稳定。
- 模型保存和配置补读期间保持列表亮度与选中标记稳定，减少闪烁和文字跳动。
- 错误分类、空响应标记和限流重试按每次请求的实际情况处理，重试提示与流中断说明更准确。
- 限流冷却在释放并发槽前发布，排队中的会话会等待冷却结束再发起请求，减少连续触发限流。
- 内置技能同步与安装现在只在真正需要更新时合并操作，减少无更新时的额外开销和部分桌面环境下的界面卡顿。
- 安装程序更准确识别占用进程和安装目录，安装与升级过程更可靠。
