# 达摩院AgentOS v10.0.196

**发布日期**: 2026-11-02

![v10.0.196 更新概览](/img/changelog/oem/v10.0.196.png)

## 新功能
- **Agent 归档与恢复**：新增 Agent 归档、恢复、永久删除与查看能力，并保留团队组长关系与调度状态。
- **本地音视频转写**：新增音频转写工具，智能体可将本地音频或视频转成带时间戳的文字，并复用已配置的语音识别服务。
- **大优化模型文件与工件引用**：优化建模工具支持通过文件或工件引用提交大规模模型，避免参数逐字生成导致超时，可稳定走完编译与求解。
- **移动端文件编辑与查看**：移动端支持安全的文本编辑、文件差异回滚、工具审阅，以及认证后的只读目录和截图查看。
- **MCP 服务更新与升级保护**：已安装的 MCP 服务有已审核新版本时可提示更新，并在升级时保留环境变量、工作目录、停用和协议偏好等用户配置。
- **技能更新感知**：内置、内联和部分对话模型技能支持内容摘要感知更新，保留本地修改与运行状态。

## 修复
- **超长单轮续接**：超过 16MiB 的长时间单轮任务现在可以继续，不再误报“历史为空”；对无收尾或损坏的记录会如实说明原因。
- **历史分页可靠性**：修复会话历史翻页在并发删除、回撤或切换话题时漏读幸存消息、串用窗口或跳回底部的问题，并恢复顶部键盘重试。
- **归档话题防续写**：已归档的手动话题不再能通过已有运行记录继续写入，恢复后才能继续，错误信息也不再显示为通用 API 错误。
- **任务板恢复与读取上限**：任务板写入被打断后不再卡死建任务和查看，重启后也能自动收尾；单提交读取上限提高到 16MiB，超限返回明确错误。
- **团队安装回执**：团队成员要求更高客户端版本时，团队安装或按地址分叉团队不再返回 500，安装回执可正常落地。
- **团队成员状态判断**：团队设置不再把本机已存在的本地成员误报为缺失，并对真正缺失的成员提供补齐、解析或移出等可操作路径。
- **团队规则升级保留**：发行版种子升级后团队规则不再静默失效，需要复核时会发出通知并可直接打开团队设置。
- **Python 运行环境修复**：首次离线导入留下的 Python 来源记录会被改写为官方地址，运行环境页可以重新安装和删除 Python。
- **工具输出恢复**：工具调用结束后模型原文或状态投影缺失时，可从同一运行记录的完整副本恢复；本地云同步刷新错误不再被误报为上游 API 错误。
- **语音识别语种**：默认自动语音识别不再固定按中文识别，未指定语言时由模型自动判断，英文音频不再被错误转写。
- **语音识别预置可用化**：不可用预置被移除，新增可用模型，本地语音识别模型按无需凭据兼容。
- **审批策略实时同步**：审批策略目录出现后可自动补建监听，外部修改审批文件会实时同步，界面不再卡在旧档位。
- **MCP 进程回收**：MCP 标准输入输出服务关闭时能完整回收进程树，避免通过包装器启动的服务端残留。
- **应用启动错误提示**：应用缺少启动合同时会报告确切原因，并在委派时走正确的修复路径，而不是反复派发无用的“检查并打开”任务。
- **任务进度工具**：长会话收尾时，任务进度相关工具按组加载、保留和淘汰，Agent 不再连续创建“占位/忽略”等垃圾任务。
- **回撤与搜索范围**：手动话题回撤失败时保留完整历史与恢复入口；删除旧消息不再让同一搜索范围中的剩余结果整体退出活动窗口。

## 改进
- **工具调用提示**：内置工具门面参数会标出适用动作，未知参数会指出正确层级，任务更新工具对模型收窄并给出替代写法，减少无效调用。
- **白板错误说明**：白板初始化失败时给出具体原因和文档内位置，新建前也能正确获取结构定义。
- **任务板性能**：旧任务板历史补建完成后自动激活目录，建板查重只读首个提交，打开超大任务板和启动恢复更快。
- **工具声明持久化**：工具声明的最近使用和失败关闭记录会随会话持久化，重建后仍按最近使用淘汰工具。
- **MCP 连接语义**：MCP 连接测试与健康探测统一超时、清理与错误分类，失败说明更明确并脱敏。
- **MCP 前向兼容**：严格校验路径容忍 MCP 配置中的未知字段，来源摘要排除未识别键，避免定时任务和网络回调的工具被静默剔除。
- **审批模式同步**：审批模式按服务端纪元与修订号排序，外部变化实时到达，策略文件不可读时在界面显示警告和修复入口。
- **内置技能市场同步**：修正 Python 与 Node.js 环境技能旧路径说明，避免智能体重复用系统包管理器安装环境。
- **安全补丁升级**：升级桌面运行时、HTTP 解析、校验与图表渲染等安全修复版本，保持原生能力与视觉效果不变。
