# 达摩院AgentOS v10.0.187

**发布日期**: 2026-10-25

![v10.0.187 更新概览](/img/changelog/oem/v10.0.187.png)

## 新功能
- **原生应用邮件与业务接口**：现在可以从其他设备访问达摩院AgentOS的内嵌邮件服务；发送前保存准入见证，重复或未知发送结果不会自动再次外发，并补充任务板创建上下文、存储条件删除和关系单边校验能力。
- **图片内容完整性校验**：读取图片时可校验期望内容摘要；摘要不一致时不返回图片或视觉补全，避免基于错误图片继续分析。
- **内置智能体与团队增量升级**：本版内置种子为 20261025.1。内置智能体与团队可通过 AgentFS/Git 按仓库增量合并，保留本机模型选择、记忆和不冲突的用户修改；冲突仅暂缓相关仓库。不重导入凭据、连接配置或业务工作区，也不恢复已删除实体。

## 修复
- **新建对话隔离**：使用 `/new` 开始新对话后，第一条消息不再带上旧的消息、工具调用或错误，手动话题的旧时间线仍可回看。
- **聊天消息删除**：修复多选删除失败或无响应的问题，刚发送或接收的消息也能正常删除；删除后会话与手动话题会正确刷新，长历史分页更稳定。
- **市场技能安装恢复**：市场技能安装遇到文件元数据波动时会自动重试；安装中断后会显示“安装未完成”，可继续重试安装。
- **Windows 安装误拦**：多账户电脑上将达摩院AgentOS安装到自己的目录时，不再因其他账户运行了同名程序而被误判为占用并阻断安装。
- **原生生命周期稳定性**：修复 Windows 安装对终端组件的误判、macOS 文件监听关闭导致退出挂起等问题，并完善启动诊断。
- **模型选择器手动刷新**：聊天模型选择器旁恢复手动刷新入口，可重新加载官方算力目录并查看最新模型。
- **环境状态浮框交互**：点击环境状态浮框外部即可收起；空会话提示不再被鼠标选中。
- **基础任务收尾**：基础任务的提交审核和释放认领动作现在会在动作视图中明确声明所需的当前认领令牌（`claimToken`），避免 Agent 因缺少该既有参数而无法完成已认领任务的收尾。

## 改进
- **启动与首次输入性能**：减少达摩院AgentOS启动与首次输入可操作前的等待时间，并优化服务入口加载。
- **资源管理器与菜单视觉**：统一资源管理器的名称和图标，浮动菜单改为不透明材质，避免底层内容透出影响阅读。
- **内置浏览器访问技能更新**：仅在客户端声明系统浏览器或可执行路径启动能力时提供显式路径审批说明；高级交互改用随包离线解释器，并修正登录态说明。
- **工具加载效率**：智能体一次点名多个工具时，会处理全部点名且已授权的工具，不再只取前 5 个；达到保留上限时会明确列出未加载项，不再静默截断。
