# 达摩院AgentOS v10.0.181

**发布日期**: 2026-10-14

![v10.0.181 更新概览](/img/changelog/oem/v10.0.181.png)

## 新功能
- **智能体开发工作台**：现在可让智能体在授权工作目录中开发、预览并发布应用到“我的应用”，支持静态网页、原生任务托管与容器运行，并可导出固定版本分发材料。
- **内网分发与离线种子**：支持通过统一配置将市场、配置中心、注册目录和核心智能体来源切换到内网代码仓库，并支持离线种子打包。
- **紧凑工具提示与单层思考记录**：折叠工具过程时，以动作、对象和可验证回执逐条展示工具调用，同时将思考记录统一为单层卡片并记住展开偏好。

## 修复
- 修复导出 Word 文档后无法读回、默认文件档位导致部分文件工具被拒绝、工作流默认值被空参数遮蔽，以及长会话待审批入口不可见的问题。
- 修复客户端与智能体更新可能被失败的市场准备、证书错误、残留启动预约或缺失 Git 认证长期挡住的问题，并提供恢复入口。
- 修复关闭 MCP 连接后旧来源工具目录未即时失效的问题。
- 修复技能/MCP 凭据在正常授权下缺少有效审批来源导致连接失败的问题，并恢复持久会话与继续生成的连接复用。
- 修复市场发现与安装使用不同来源导致内容身份不一致，以及合集子技能无法精确安装的问题。
- 修复团队新增成员后已批准规则未覆盖新接收者、无 Git 时无法恢复核准的问题。
- 修复大工作流保存时摘要可能过期、修订说明丢失的问题。
- 修复团队环境下合法的前台工作流绑定和后续工具上下文被误拒，以及显式绑定历史被显示为 0 条的问题。
- 修复分页参数可被非法字符串或负数破坏、Grep 计数参数误接受小数的问题，并同步工具参数说明。
- 修复缺失元数据的历史运行记录阻断新对话的问题。
- 修复工具刷新失败只提示泛化错误的问题，现在会返回具体工具 ID、文件路径、YAML 原因和行列。
- 修复模型推理档位在单次/视觉调用、云合同和会话偏好中未正确生效或回写旧值的问题。
- 修复长任务或浏览器展示时聊天输入框失焦的问题。
- 修复聊天模型菜单被任务浮层遮挡、工具栏控件过早换行，以及官方算力公告中供应商名错位的问题。
- 修复保存文档时已保存提示与未保存确认同时出现、后台草稿版本不一致的问题。
- 修复默认 Python 版本与 Office 运行时不兼容导致相关依赖安装失败的问题。
- 修复 Linux 首次启动时邮件服务不可用，以及拼写词典下载失败未如实展示状态的问题。
- 修复上下文超预算时长文档 Schema 只剩前缀、本轮结果无法可靠钉住的问题，并提供分页续读和同轮钉住。
- 修复 L2 最终工具集与模拟边界不一致，以及定时会话身份缺失的问题。
- 修复运行时资产缓存完整性校验不足，导致截断或篡改正文仍可能被复用或打包的问题。

## 改进
- 优化 Windows 首次安装与启动关键路径，缩短 Git 初始化和输入就绪等待时间。
- 模型选择器将可用性状态改为同行状态点与通俗说明，减少可见模型数量被提示挤占。
- 全局提示词改为普通 Markdown 全文加载，不再解释全局 L0/L1/L2 标题。
- 终端创建提示更清晰，资源管理入口会直接打开当前会话的工作区终端。
- 工作流定义校验会提供安全、具体的诊断，减少模型重复生成无效定义。
