# AgentOS v10.0.181

**发布日期**: 2026-10-14

![v10.0.181 更新概览](/img/changelog/unbranded-agentos/v10.0.181.png)

## 新功能
- **应用开发工作台与分发**：智能体现在可在授权工作目录中创建、预览并运行应用，将其发布到“我的应用”或市场分发，支持静态网页、原生任务宿主与 Docker 容器等运行方式，并提供应用数据、工作协作、版本历史与成果检查。
- **内网与离线分发配置**：支持通过统一配置将市场、配置中心、Registry 与核心智能体来源切换到 Gitea 内网仓库，并支持离线种子、私有仓库读取及切换失败时的备份恢复。
- **紧凑工具调用提示**：工具过程收起时直接展示每个操作的动作、对象与结果摘要，例如“读取文件 report.md”“计算结果：156”，不再只显示“已返回”。

## 修复
- **文档读写与文件工具**：修复导出 Word 后无法读回、默认文件档位拒绝文件工具的问题，并保留精确授权与敏感路径限制。
- **工作流参数与审批入口**：修复工作流默认值被空参数遮蔽的问题，并在长会话中提供常驻的待审批入口，可准确定位并聚焦审批卡片。
- **客户端与智能体更新**：修复更新可能被失败的市场准备、证书错误、残留启动预约或缺失 Git 认证长期阻挡的问题，团队升级与拉取会绑定用户实际批准的版本。
- **模型推理偏好**：修复单次与视觉请求可能发送不支持的推理档位、模型表单与会话偏好写回旧选择的问题。
- **MCP 工具目录时效**：关闭 MCP 连接后立即使旧来源工具目录失效，避免切换后继续出现过期工具或错误来源。
- **上下文与工具结果可达性**：修复上下文超预算时工具 Schema 只留下前缀、本轮完成结果无法可靠钉住的问题，并提供按版本分页的续读方式。
- **文档保存竞态**：修复同时保存与关闭时误报未保存、已发出的写入无法被取消表示的问题，保存回执不再因切换会话或视图丢失。
- **聊天输入焦点**：修复窄窗口自动展示浏览器会话会抢占聊天输入焦点的问题，长任务期间输入框保持可用。
- **旧运行历史发现**：修复缺少元数据的旧运行目录会阻断新对话的问题，独立新对话现在可正常开始，历史文件保持原位。
- **团队规则与市场安装**：修复团队规则接收遗漏、市场发现与安装来源不一致、所选合集子技能无法精确安装，以及凭据连接缺少授权上下文等问题。
- **邮件服务与拼写词典**：修复 Linux 首次启动时邮件服务误报不可用的问题，并准确展示拼写词典的下载与就绪状态。
- **界面层级与排版**：修复聊天模型菜单被任务浮层遮挡、官方算力公告中供应商名下沉错位、聊天工具栏控件过早换行等问题。
- **分页与工具参数校验**：严格校验分页参数和 Grep 计数等工具参数，避免非法输入导致查询错误或后端异常。
- **终端创建提示**：修复新建终端时的提示不准确问题，区分没有可用目录与目录读取失败两种场景。

## 改进
- **模型可用性展示**：模型可用性改为同排状态点展示，点击后以通俗说明和适用操作浮层呈现，不再为每个模型增加额外提示行。
- **过程与思考展示**：统一将主聊天和子记录中的思考记录收敛为单层卡片，默认收起并记住阅读偏好，工具完成提示更加具体。
- **全局提示词编辑**：用户全局提示词改为普通 Markdown 全文加载与编辑，不再按全局标题层级解释，原内容升级后也会全文生效。
- **默认 Python 版本**：默认 Python 版本调整为 3.13.9，与内置 Office 运行组件兼容，避免首次安装依赖时被拒绝。
- **启动与首次安装体验**：缩短 Windows 首次安装中的 Git 准备时间，并后移首次维护任务，减少启动关键路径的等待。
- **终端与资源管理入口**：终端创建提示区分目录缺失与读取失败，资源管理面板统一打开当前会话对应的工作区终端标签。
