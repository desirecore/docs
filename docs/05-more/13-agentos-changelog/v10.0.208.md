# AgentOS v10.0.208

**发布日期**: 2026-11-18

![v10.0.208 更新概览](/img/changelog/unbranded-agentos/v10.0.208.png)

## 新功能
- 支持准备式配对凭据与持久化失败恢复 (#6264)
- 自我认知列出已接入的 MCP 服务端，ToolCatalog 可按服务端 ID 检索 / List connected MCP servers in self-awareness and look them up by server ID (#6255)
- 启用新 fork Run meta v2 写入 (#3506) (#6250)

## 修复
- 修复可选功能关闭后的资源总览排版 (#6275)
- 兼容严格重发后继的 v2 恢复读取 (#6266)
- 修复历史来源复验阻塞与待办超时恢复 (#6262)
- 发布 HTTP 伴生口实际绑定端口 (#6252) (#6260)
- 优化智能体更新来源与相邻操作弹窗 (#6257)
- 修正新 fork writer 的 canonical home 与跨重启夹具 (#6259)
- 让模型能查到目录省略的 MCP 技能 / Let the model find MCP skills omitted from the catalog (#6217)
- 移除资源管理器重复的插件入口 (#6249)
- 取消模型冷却等待并按实际错误停止或重试 (#6247)
- 完善应用接入、参数续读与本机文件交付 (#6213)
- 统一命令收尾并回收 Windows 后台后代 / Bound shell finalization and stop Windows task descendants (#6221)

## 改进
- 对齐 Run 快照格式与生命周期注释 (#6263)
- 运行时加载映射收窄 unit 选测（ADR-367 决策 4） (#6251)
- 区域兜底只接住 import 图看不见的文件（ADR-367 决策 3） / Narrow the area fallback to files the import graph cannot see (#6242)
