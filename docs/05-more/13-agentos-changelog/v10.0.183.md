# AgentOS v10.0.183

**发布日期**: 2026-10-15

![v10.0.183 更新概览](/img/changelog/unbranded-agentos/v10.0.183.png)

## 新功能
- **内网控制面接入**：支持手机号密码登录内网部署，按部署策略展示可用模型与功能，并隐藏未开放的商业入口。
- **内置通用助手**：新增系统内置「通用助手」智能体，支持问答、检索、写作、分析、编程与工具任务，并默认启用手动多会话。
- **只读任务板发现**：智能体可获取有权限的任务板列表，便于在多任务板场景中正确选择任务板。
- **Webhook 管理与公开接入**：支持配置 Webhook 所有者、保存事件、启停删除与共享密钥轮换，并在公开 API 握手中声明管理能力。
- **离线浏览器自动化与审批启动**：内网部署可离线使用浏览器自动化技能，并可在审批后启动本机浏览器完成网页操作。

## 修复
- 修复团队工作目录在创建、解散、改址等操作中的生命周期竞争，并确保解散父团队时保留子团队 Git 状态。
- 修复委托转交后来源会话可继续的问题，转交成功后来源会话状态变为已转交，后续消息被明确拒绝。
- 修复聊天记录窗口灰屏与大量历史渲染卡顿，改为分页加载、虚拟渲染与预览截断。
- 修复运行时版本读取失败误报为未安装，失败时显示“读取失败”并保留上次成功标签。
- 修复 AI 审批不可用与安全拒绝的显示混淆，仅在服务无有效结论时显示“AI 审批不可用”，并保留审批实际原请求而非平台参考截断。
- 修复工具图片的模型协议兼容问题，对 SVG 等图片生成可恢复的 PNG 预览。
- 修复内置应用查看文件后返回丢失上下文，保留原有编辑状态、子页和内存草稿。
- 修复决策工作区多处问题，包括技术依据审阅准入、数据源导航、局部例证校验以及原始数学证据保留。
- 修复自动压缩摘要未合流到同 Run 后建会话，后台压缩结果会同步到所有相关会话。
- 修复已结算工具轮用量在后续模型错误时丢失，保留已发生用量与实际模型回执。
- 修复模型格式错误后的有界恢复，提供格式反馈只重新生成未执行调用，并正确等待模型冷却。
- 修复 Agent 在传输断连后误显示关机，Socket 断连不再全局覆盖 Agent 状态。
- 修复缺少离线运行时目录时客户端打包，现在直接报错并提示准备命令。
- 修复首次上下文绑定写入失败可能覆盖旧数据，原子写入失败时保留原元数据。

## 改进
- 内置办公文档技能现在包含离线模式所需的依赖，并正确校验中文 XML 文档。
- 内置通用助手与离线市场统一显示透明头像。
- 离线市场现在直接显示内置通用助手条目，无需联网即可发现。
- 支持更多 Node 版本，并补齐 Python 环境的离线引导。
- 聊天执行过程隐藏 Agent 可自行恢复的工具调用失败提示，避免显示红色失败标题。
