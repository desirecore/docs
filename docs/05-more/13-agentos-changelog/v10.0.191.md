# AgentOS v10.0.191

**发布日期**: 2026-10-27

![v10.0.191 更新概览](/img/changelog/unbranded-agentos/v10.0.191.png)

## 修复
- 备份与传输现在会保留白板的修订历史、命令回执和审计记录，避免画布文件存在但历史与审计数据丢失。
- 修复了代码编辑器富文本净化组件的安全漏洞，防止恶意内容注入。
- 修复了身份认证依赖组件中的高危安全漏洞，降低账户与登录安全风险。

## 改进
- 更新模型接入 SDK 至 2.27.0，保持模型服务的兼容性与稳定性。
- 更新 MCP SDK 至 1.32.1，提升 MCP 服务兼容性与稳定性。
