# AgentOS v10.0.186

**发布日期**: 2026-10-22

![v10.0.186 更新概览](/img/changelog/unbranded-agentos/v10.0.186.png)

## 新功能
- **模型选择简化**：聊天输入区的模型选择器直接展示完整模型列表，支持跨来源搜索与来源/厂商筛选，筛选设置保存在本机；自动选择可像模型一样直接点击，其设置提供独立浮层，可勾选来源并拖拽排序。
- **思考与工具过程分层阅读**：思考记录默认收起，生成期间显示“正在思考”和持续扫光；同一轮连续工作归拢为动作摘要，可逐层展开查看逐项摘要与可滚动详情，详情限高并与主聊天滚动隔离；首段思考建立消息锚点。

## 修复
- 登录页面现在根据服务端认证配置正确显示密码、手机验证码、注册和找回密码等入口，并暂时禁用邮箱验证码登录。
- 切换模型或重复选择当前智能体时，输入框不再被卸载，正在输入的内容、焦点和输入法状态得以保留。
- 窗口重建后，界面不再可能一直停留在“运行中”，会自动恢复终态与历史；同步失败时提供提示和手动重试，且不会重发模型请求或工具。
- 在企业内网或屏蔽公网探测地址的环境中，不再因公网探测失败而中止正在进行的推理或误判离线。
- 修复了部分发行版首次打开时内置智能体或团队未安装、以及已有数据可能被覆盖的问题，现按标记判断首次打开，已有内容只补充缺失，冲突时不动原数据。
- 修复了模型服务返回限速时并发槽释放早于冷却发布，导致排队请求重复碰撞限速的问题，现在会在共享冷却期内正确等待。
- 修复了服务端心跳事件无数据导致对话以不可重试错误终止、直连请求响应头前挂起缺少受控超时、停止后立即追问被拒绝等多个问题。
- 修复了跨用户轮恢复时未加载工具的错误阶段事实丢失，可能导致模型否认上一轮真实回执的问题。
- 修复了模型返回内容截断或流内额度错误时分类不准确的问题：缺结束标记的截断会按流中断重试，流内额度错误不再被误认为 HTTP 错误，重试提示更准确。
- 修复了工作树准备与任务计划前置边界，避免重复创建计划，并正确读取已核实的参考计划。
- 原生应用重新显示时不再显示空白，而是显示加载提示，成功后恢复原编辑器。

## 改进
- 优化了技能同步与安装时的文件监听维护，仅在首次实际发布时按需获取租约，减少不必要的监听重建，降低卡顿风险。
- 模型选择器在保存与配置补读期间保持列表亮度和选中标记占位，避免切换时闪烁和文字跳动；固定模型失效时选择器内提供恢复入口，保留草稿和附件。
