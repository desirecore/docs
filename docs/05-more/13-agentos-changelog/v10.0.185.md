# AgentOS v10.0.185

**发布日期**: 2026-10-19

![v10.0.185 更新概览](/img/changelog/unbranded-agentos/v10.0.185.png)

## 新功能
- **委派指挥舱**：任务板默认标签改为「委派总览」，用任务/项目双视角汇总待办，按「等你批准 › 待你验收 › 执行已结束未提交 › 逾期 › 执行失败 › 自动处理连续失败」排序，并支持一步式新委派与人工验收决策面板。
- **审批卡改版**：审批卡改为紧凑五层结构，按受众拆分展示材料；审批卡与对应工具调用关联，回执紧随工具行；Bash 命令按内容分级并显示风险标签；编辑笔记本、退出工作树、运行工作流等工具提供结构化证据。
- **后台任务管理**：后台任务列表按「我在处理的 / 我发起的 / 例行」分组并支持嵌套展示，可在行内直接停止后台命令、Worker、发出的委派与子任务；运行中心纳入转入后台的 Worker。
- **Worker 运行事实**：临时 Worker 拥有服务端运行事实，刷新或断线后仍可恢复显示；转入后台的 Worker 在自然结束、被停止或重启恢复后，会把完成、失败或已停止等终态回写到委托卡片。
- **派单审批实时推送**：派单运行中产生的审批会实时送达 toast、通知中心与系统通知，打开派单运行弹窗即可处理，无需轮询或重连。
- **审计增强**：审计详情可跳转查看所属执行的详细记录，并记录每次请求的上下文 Token 估算分项。
- **服务器连接设置**：登录与连接失败时可打开服务器连接设置入口，保存前先校验目标服务是否可用，失败时保留当前配置与账号会话。
- **注册入口默认手机号验证**：注册入口默认进入手机号验证码页，并提供明确的邮箱注册入口。
- **关联应用同屏协作**：从智能体侧栏打开关联应用时，聊天与应用可在同一工作区并排或切换，保留来源话题、草稿与可信页面；应用外观同步宿主主题。
- **应用入口布局优化**：关联应用入口移至消息区右上角的环境状态浮框；应用授权移至左侧导航栏，释放内容区高度。
- **运行环境 FFmpeg 套件检测**：运行环境页可检测 ffmpeg/ffprobe 的版本与路径，并列出依赖它们的已安装技能。
- **外部服务官方 Skill 安装与检测**：市场新增官方 Skill 安装与连接检测入口，安装前校验包内容，安装后检测本机服务与扩展连接状态。
- **平台后台任务受理前阻塞**：平台后台任务依赖未就绪时在受理前阻塞，并在调度详情中显示原因，不再空跑并记录为无原因成功。
- **无进展重复调用熔断**：当模型对同一工具连续发出相同参数的相同结果时，按阶梯提示并最终进入无工具收尾，不再无限空转。
- **停止后暂缓自动接手**：用户停止生成后，该会话不会立即被异步回报自动拉起新一轮；回报保留在收件箱，待用户再次开口后注入。
- **模型无进展预算与早期提示**：请求长时间无新进展时按可配置上限进入流式重试；界面从「深度思考中」切换为「等待模型响应 · N 分钟无新进展」，有真实增量后恢复。
- **图片保留与拒收重试**：已消费的图片按轮数与张数移出模型请求，单请求设置张数与大小上限；上游拒收图片时，将上游原文写到图片位置并当轮立即重试，而不是整轮失败。
- **会话模型预算收窄**：会话侧窗口与输出上限取规格、接入条目与用户覆盖中的最小值，避免发送超出接入条目声明的请求。
- **持久会话历史图片恢复**：持久会话从快照恢复时还原历史用户图片，上次贴的图在追问中仍会携带。
- **搜索路径可读性**：Glob/Grep 搜索时，读到存在但无权限的目录或文件会保留已有结果并说明原因，不再返回看似完整的空结果。
- **工作台关闭行为优化**：关闭工具工作区最后一个标签时会收起工作区，而不是立即补一张看似「关不掉」的新标签页。

## 修复
- 修复 Windows 升级时结束安装目录进程树依赖脚本环境、被安全软件拦截后失效的问题，改为在安装器进程内直接完成。
- 修复 Windows 安装器把「没有进程」误判为「应用正在运行」的问题，提示框现在会列出仍占用安装目录的进程。
- 修复 Windows 环境探测在强制终止后清理确认预算过短的问题，放宽到 10 秒。
- 修复邮件草稿保存成功后附件丢失、恢复时无法找回的问题。
- 修复快捷回复失败时草稿丢失或重复，以及异步发送结果归属错误的问题。
- 修复邮件本地搜索只检查首屏 30 封的问题，现在覆盖已同步的本地邮件并明确展示范围。
- 修复已发送邮件保存到不可选择目录的问题，改为按可选择的已发送特殊用途目录保存与同步。
- 修复邮件详情迟到结果覆盖当前预览、回复错用其他邮件的问题。
- 修复邮箱账户名称修改后频率同步回退旧名称、无法保存空名称的问题。
- 修复长请求处理期间 HTTP/2 会话被中途关闭导致响应正文读取中断的问题（邮件服务与主要 HTTPS 服务）。
- 修复侧聊没有可用工作目录时回退到服务启动目录、或侧聊不遵守智能体文件访问档位的问题。
- 修复主对话显式引用的相对路径以服务启动目录为基准、可能授权启动目录的问题。
- 修复会话工作目录选中当前系统用户无权进入的目录，导致终端与 Bash 启动失败的问题。
- 修复白板合法大文件保存在主线程上阻塞数秒至数十秒、可能让前端掉线的问题。
- 修复某个工作目录打开时卡住会冻结整个服务事件循环的问题。
- 修复继续生成轮执行器事件回调未换绑，导致审批卡、问答题、消息交付等事件丢失的问题。
- 修复继续生成轮重复计入被中断那一轮用量，导致费用与用量虚高的问题。
- 修复工具上报用量检查点发往首轮管线，导致后续轮部分回执缺少搜索用量的问题。
- 修复 Smart 子会话未携带冻结路由决策，首轮使用工具后第二次模型调用失败的问题。
- 修复部分云模型固定路由下的思考档位可能超出合同范围，间歇返回错误的问题。
- 修复冷却可恢复时刻在跨整秒时出现一秒漂移的问题。
- 修复模型选择面板顶部列出已撤回模型的问题，现在不再显示。
- 修复重连后算力配置未补读、模型菜单与胶囊沿用陈旧的移除提示的问题。
- 修复任务详情派单未同时指派负责人时，派单执行无法认领任务、任务一直待认领的问题。
- 修复查看任务背景后返回不到原任务的问题，现在关闭历史窗口会回到来源任务并保留未发送草稿。
- 修复普通消息被排队上限拒绝时输入框被清空、草稿被删的问题，现在原文与附件会保留一份。
- 修复在途消息重试可能在原请求仍在执行时重复执行的问题，改为应用内弹窗确认。
- 修复审批策略文件写入非原子、写入中断会截断半份文件的问题，改为原子写并在写入门面内完成。
- 修复未闭合围栏会吞并后续分层提示词的问题。
- 修复开发服务器意外退出时原因丢失、兜底页只给通用错误的问题。
- 修复开发版渲染进程开发服务器被豁免连接数上限导致冷启动偶发失败的问题。
- 修复共享迁移占用启动执行槽、可降级预热让服务无限等待的问题。
- 修复启动快照恢复、索引准入与运行登记租约在异常边界下的错误处理问题。
- 修复 Windows 原地更新的原子卸载把自己误判为忙文件而触发恢复的问题。
- 修复五份内置启动包未按实体路径打包与校验的问题。
- 修复委派卡片在 Worker 转入后台时错误显示为「子任务失败」的问题。
- 修复同步等待的子任务在等待期间卡片先显示后台任务、随后才跳到协作状态的问题。
- 修复团队并发创建与成员模型配置结算在部分失败时不一致的问题。
- 修复备份目标与任务在引用保护、异步核验与删除回执下的生命周期问题。
- 修复白板另存结果不明时可能丢失操作或重复创建的问题。
- 修复决策工作区原生窗口关闭时草稿与待结算提交没有保护的问题。
- 修复开发验收报告被打入发行包的问题，并保留工具拒绝的真实原因。

## 改进
- 界面文案全面去掉面向开发团队的说明与内部术语，统一为用户可直接行动的表述。
- 内置工具描述改写为面向调用方的写法，减少发给模型的无效体积并保留全部约束。
- 启动性能优化：按需加载隐藏界面、市场与正文等模块，延后非必要初始化，并限制启动预热等待。
- 后台任务列表与侧栏卡片共用聚合逻辑，状态栏与环境部件口径一致。
- 委派指挥舱去掉解释设计与数据模型的说明文案，只保留用户可执行的操作。
- 审批卡参数表对大载荷只写「已省略 · N 字」，工作目录下路径显示相对路径；证据区默认收起「AI 看到的审批材料」。
- 白板保存减少重复整链校验与冗余序列化，短历史白板保存更快。
- 模型请求无进展时自动重试次数收敛，并区分连接层故障与无进展故障。
- 运行环境删除指定运行时版本改为走真实运行时管理链，并按任务真实终态反馈成功或失败。
- 开发版只接入属于当前数据根的本地服务，避免残留端口文件把浏览器写进错误数据目录。
