# AgentOS v10.0.195

**发布日期**: 2026-10-30

![v10.0.195 更新概览](/img/changelog/unbranded-agentos/v10.0.195.png)

## 新功能
- **统一归档页**：设置中的“数据与隐私”新增归档页，可统一查看、恢复已归档的团队和会话，解散后可撤销或处理冲突恢复。
- **大结果流式保存**：命令行等工具产生超大输出时不再因体积限制中断任务，输出会保存为可校验的会话原文并支持分页读取，冷恢复后依然完整。
- **会话消息免打扰**：可为指定会话关闭普通消息提醒，审批与智能体提问仍会照常提醒。
- **思考回传策略**：支持按模型配置思考内容的回传开关与空签名策略，关闭回传后工具续轮不再被误拦截。
- **不限层级委派**：智能体之间可以多级委派，子任务只允许展开同级子任务，避免递归过深。
- **个人任务板发现与排队说明**：未绑定任务的对话也能发现用户的个人任务板；派单排队时会明确说明正在等待哪条对话、是否需要你去处理。

## 修复
- 修复审批策略文件带字节顺序标记或无法解析时可能被当作未设置或写入异常的问题；坏文件写入会被安全拒绝，含冒号的路径也会直接返回错误。
- 修复用户资料首次读取失败时，已同意协议的用户会再次看到同意页的问题；同一协议版本现在只保留首次同意时间。
- 修复智能路由新会话缺少冻结路由决策时，会在产生工具副作用后才失败的问题，现在会在首个请求前阻止。
- 修复草稿冷启动恢复后入口丢失、维护重试重复上传附件，以及历史多选时旧页内容回缩的问题。
- 修复退出确认授权可能被后续退出操作误用的问题，确认现在只对发起的那一次退出有效。
- 修复部分设备上使用目录链接数据根时，运行索引初始化和临时文件写入失败的问题。
- 修复消息时间显示、跨任务板列表刷新和更新失败后下载恢复状态被覆盖的问题。
- 修复技能安装时技能目录内部的嵌套技能被错误登记为独立技能，以及技能依赖检测在占位程序或缺少可执行入口时误判的问题。
- 修复仅因智能体配置文件键顺序不同就改写团队配置并产生多余提交的问题。
- 修复回复提醒在不同用户或会话间因标识冲突而丢失通知的问题。
- 修复委派总览把智能体提问显示为“等你批准”的问题，现在会显示为“等你回答”。
- 修复消息样式预览与真实聊天外观不一致的问题。
- 修复已获委派能力的智能体在工具发现中仍被告知不能继续委派的问题。
- 修复邮件解析、邮件发送、重定向处理和加密签名等依赖组件中的已知安全漏洞。

## 改进
- 旧任务板会在后台自动补建历史索引，写入任务时不再长时间阻塞。
- 任务板跨板查询只为返回页计算可用操作与认领状态，大列表打开和翻页更流畅。
- 模型新建文件时不再重复回显整份正文，减少上下文占用，同时完整保留审计与恢复内容。
- 任务板决策页作用域改为手动选择并记住选择，不再随当前任务板悄悄切换。
- 浏览器工具出错时会给出可照着修改的说明，并支持按显示文字选中选项、直接使用快照中的定位符。
- 完善委派续接、任务取消和计划查找的提示，智能体更容易给出正确调用。
- 应用发布清单不合格时会返回具体字段和规则，便于快速修正。
- 内置应用开发技能更新，新装客户端离线首启即可使用。
