# AgentOS v10.0.190

**发布日期**: 2026-10-26

![v10.0.190 更新概览](/img/changelog/unbranded-agentos/v10.0.190.png)

## 新功能
- **系统浏览器离线自动化**：浏览器高级交互现在支持使用系统已安装的浏览器，并能在内网离线时自动准备所需运行时，不再要求预先配置受管 Python 环境。
- **普通聊天任务进度写回**：在普通聊天中创建的任务可以随进展更新状态，聊天任务清单与完整任务板会保持一致。
- **迁移后对话历史恢复**：跨身份迁移后原本不可见的智能体对话历史可以恢复，并提供离线维护入口修复已验证的迁移记录。
- **技能删除前确认**：删除包含 `.env` 凭据的技能或智能体时，会列出待删除文件并要求确认后再执行。

## 修复
- 已登录用户购买算力包时，套餐列表不再为空。
- 浏览器工作台的内嵌浮层支持按 Esc 关闭，并将焦点恢复到入口。
- 撤销浏览器共享授权后立即重新授权，不再遇到无权限打开页面的问题。
- macOS 上未预装伴生应用的用户现在可以正常自动安装伴生应用。
- Windows 升级后不再因配置缓存字节差异导致初始化失败，有效配置得以保留。
- 团队导入中断后不会再把自身写入误判为冲突，AgentOS 服务可正常启动。
- 迁移确认页会按归并决策显示覆盖摘要，不再错误提示“保留本机”的内容将被覆盖。
- Task 绑定运行缺少 Plan 时会单独提示需要计划，而不是误报为没有权限。
- 包含大量任务的任务板在启动恢复时不再长时间卡顿或导致连接断开。

## 改进
- 桌面安装包移除了重复的大资源副本，安装包体积显著缩小。
- 市场技能安装目录现在区分包内容与本机运行状态，更新、卸载和内置同步不再因 `.venv`、锁文件等本地文件而失败。
