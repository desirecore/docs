# AgentOS v10.0.192

**发布日期**: 2026-10-29

![v10.0.192 更新概览](/img/changelog/unbranded-agentos/v10.0.192.png)

## 新功能
- **任务板工作区**：当前任务板、自动处理、流程和关联图统一收进任务板工作区，顶层只保留「委派总览」和「决策」入口。
- **结构化验收标准**：委派人可在新建、委派和编辑任务时逐条设置验收标准与证据要求，执行智能体提交时逐条自评，验收面板可查看自评并在返工时勾选未满足条目。
- **智能体步骤进度**：委派总览卡片和任务详情会显示执行智能体自报的步骤进度，并标注上报时间与是否已结束。
- **工作流人工节点与受治理工作流**：需要人工处理的流程节点会进入委派总览「待你决定」，任务板也能关联并启动受治理工作流，运行参数自动预填任务引用。
- **团队归档与恢复**：团队解散后可列出并恢复归档团队，智能体也能通过团队管理工具查看和恢复团队归档。
- **跨智能体已归档话题列表**：新增跨智能体的已归档手动话题列表，便于后续归档入口统一查看和恢复。
- **任务执行与责任变更通知**：任务执行结束未提交时会通知任务板所有者；改派、移交或指定审核人后可自动唤醒新的负责人或审核智能体，并支持失败后重新通知。
- **返工续办绑定任务**：返工后继续任务会绑定原任务，同一智能体再次被唤醒时会在已有的工作上下文中继续处理或审核。
- **决策树人工输入确认优化**：决策树的人工回答与确认界面突出当前问题，支持多行输入、可选确认/跳过、可读结果与布尔问题直接点选。

## 修复
- 修复智能体开发应用时无法取得可信草稿来源会话，导致应用无法发布到「我的应用」的问题。
- 支持恢复带 UTF-8 前导字节标记的本地会话，避免历史会话无法打开或在恢复时被错误替换。
- 修复流式响应已有部分内容后仍可能误报成功，以及模型接口长时间没有新进展时仍返回成功的问题。
- 修复同名会话重建后，旧请求的回调可能影响新会话、主会话恢复可能误清附加对话状态的问题。
- 外部 MCP 配置要求更高客户端版本时会先提示升级；替换配置会保留同服务的旧选项与 OAuth 授权记录。
- 重复导入团队包会先确认再覆盖，对话记录冲突时给出下一步，不再静默直接替换已有团队和成员。
- 团队导入不再写入导出者的本机信任配置，避免误信导出方的本地路径、冲突标记或本机仓库连接。
- 导入支持取消并清理未交付来源；团队导入因空间不足失败后会保留原来源，可直接重试。
- 关闭查看的智能体网页不再被同一会话自动加回；冻结且无存活页的个人浏览器会话也可再次新开网页。
- 恢复历史检索的阅读位置并定位预览命中；原生历史预览保留本机媒体地址，避免图片显示为破图。
- 修复聊天截图确认在部分系统上导致客户端退出或截图选区残留的问题。
- 保存文件时保留既有权限，导出的 PDF 保留中文文字层与代码等宽字体。
- 取消备份恢复会释放明文临时包，主进程启动时也会清理上次异常退出留下的恢复临时文件。
- 备份恢复按完整对象恢复任务板、工作流、白板等工作台快照，保留原身份和权限，避免旧备份与较新提交混用。
- 明确「全部放行」审批的适用范围并补充说明，修复审批模式切档竞态与附加侧聊审批设置归属问题。
- 启动等待页和连接恢复页现在按当前发行版显示应用图标，不再显示默认图标。
- 修复活动记录和执行详情过滤后分页重复、空页无法继续加载，以及「今日完成」超出 50 条被静默截断的问题。
- 修复底层 URI 解析等组件中的安全漏洞，并同步更新相关依赖。

## 改进
- 任务板跨板查询改为查询专用读取并分段让出事件循环，旧版任务板只读最新提交，显著降低委派总览加载时间和启动卡顿。
- 内置技能同批写入只做一次来源复核，发行版种子内容升级移出启动关键路径，加快本地服务就绪速度。
- 外部 MCP 连接处理更一致，减少进程中重复加载，连接错误也会明确指出具体字段问题。
- 内置技能市场同步更新，邮件处理、发票整理等技能与场景更新到最新版本。
