# 委派与协作问题

## 委派和直接对话有什么区别？

| 对比项 | 直接对话 | 委派 |
|--------|---------|------|
| 执行者 | 当前 Companion 自己完成 | 交给专业 Companion 或团队 |
| 适用场景 | 简单问答、单步操作 | 多步骤任务、需要专业能力 |
| 结果交付 | 即时在对话中回复 | 通过回执（Receipt）交付 |
| 进度可见性 | 实时看到回复 | 委派卡片 + 进度更新 |

简单来说：如果任务需要另一个智能体的专业能力或需要并行处理，就使用委派。

## 委派后如何查看进展？

1. 委派发出后，对话中会出现一个蓝色的**委派卡片**
2. 在左侧对话列表中找到被委派的专业 Companion
3. 点击切换到该 Companion 的对话，查看实时进展
4. 任务完成后，回执会出现在发起委派的对话中

:::tip
你也可以在通知中心查看委派任务的状态更新。
:::

## 如何取消正在执行的委派任务？

- 在被委派 Companion 的对话中，点击正在执行的消息旁的**停止**按钮
- 或者切换到该 Companion，发送"停止当前任务"

已完成的步骤不会被撤销，但后续步骤会停止执行。

## 回执（Receipt）在哪里查看？

回执是 Companion 完成任务后交付的执行证据。查看方式：

| 方式 | 操作 |
|------|------|
| 对话内 | 任务完成后，回执卡片直接出现在对话流中 |
| 委派卡片 | 点击委派卡片展开，查看关联的回执 |
| 行动记录 | 在 Companion 档案中查看历史执行记录 |

回执包含：执行了什么操作、调用了哪些工具、最终产出物、耗时和 Token 消耗。

## 团队成员之间如何通信？

DesireCore 团队中的智能体通过以下方式通信：

- **委派（Delegate）** --- 组长向成员分配任务
- **消息（SendMessage）** --- 成员之间或向组长发送通知/提问
- **任务板（Task）** --- 共享任务进度，标记完成/阻塞

你作为用户，只需要与组长（supervisor）对话即可，组长会协调团队内部通信。

## 如何创建团队？

直接告诉 DesireCore 你的需求，例如：

> "帮我组建一个团队来完成这个数据分析项目"

DesireCore 会自动：
1. 创建所需的专业智能体（如果不存在）
2. 组建临时团队并指定组长
3. 分解任务并分派给成员

你也可以手动管理：在智能体列表中选择多个智能体，点击"组建团队"。

## 委派的任务执行失败了怎么办？

1. 查看回执中的错误信息，了解失败原因
2. 常见原因：API 额度不足、网络中断、工具执行出错
3. 可以重新委派并补充更多信息
4. 如果是权限问题，检查审批设置是否允许对应操作

:::warning
如果任务执行到一半失败，已完成的文件修改不会自动回滚。检查回执中的操作列表，手动确认哪些更改需要保留。
:::
