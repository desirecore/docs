# AgentOS v10.0.195

**Release Date**: 2026-10-30

![v10.0.195 更新概览](/img/changelog/unbranded-agentos/v10.0.195-en.png)

## New Features
- **Unified archive page**: A new archive page in Settings > Data & Privacy lets you view and restore archived teams and conversations in one place, and supports revoking dissolution or handling conflict recovery after dissolution.
- **Streaming save for large results**: When command-line and other tools generate extremely large output, tasks are no longer interrupted by size limits. The output is saved as verifiable conversation text and supports paginated reading, remaining complete after cold restoration.
- **Conversation message muting**: You can mute regular message notifications for a specific conversation, while approval and agent question reminders still arrive as usual.
- **Thinking content return policy**: Supports per-model configuration for returning thinking content and an empty-signature policy. When return is disabled, follow-up tool turns are no longer mistakenly blocked.
- **Unlimited delegation levels**: Agents can delegate across multiple levels. Subtasks can only expand same-level subtasks, preventing excessive recursion.
- **Personal task board discovery and queuing details**: Conversations that are not bound to tasks can also discover the user's personal task board. When dispatching is queued, it clearly states which conversation is being waited on and whether you need to handle it.

## Bug Fixes
- Fixed an issue where approval policy files with byte-order marks or unparseable content could be treated as not configured or cause write exceptions; invalid file writes are now safely rejected, and paths containing colons return an error directly.
- Fixed an issue where users who had already accepted the agreement would see the consent page again when the initial profile read failed; for the same agreement version, only the first acceptance time is now retained.
- Fixed an issue where a new smart-routed conversation without a frozen routing decision would fail only after tool side effects had already occurred; it is now blocked before the first request.
- Fixed issues where draft entries were lost after cold-start recovery, maintenance retries repeatedly re-uploaded attachments, and old page content collapsed during multi-select in history.
- Fixed an issue where an exit confirmation authorization could be misused by a later exit action; the confirmation is now valid only for the exit that initiated it.
- Fixed an issue where runtime index initialization and temporary file writes failed on some devices when a directory-link data root was used.
- Fixed issues with message time display, cross-task board list refresh, and download recovery state being overwritten after an update failure.
- Fixed an issue where nested skills inside a skill directory were incorrectly registered as standalone skills during skill installation, and skill dependency detection misjudged placeholder programs or missing executable entry points.
- Fixed an issue where team configuration was rewritten and extra commits were created simply because the order of keys in an agent configuration file differed.
- Fixed an issue where reply reminders lost notifications due to identifier conflicts between different users or conversations.
- Fixed an issue where the delegation overview displayed agent questions as “Waiting for your approval”; it now displays “Waiting for your answer.”
- Fixed an issue where the message style preview did not match the actual chat appearance.
- Fixed an issue where agents that had been granted delegation capability were still told in tool discovery that they could not continue delegating.
- Fixed known security vulnerabilities in dependency components used for email parsing, email sending, redirect handling, encryption, and signing.

## Improvements
- Legacy task boards now automatically backfill historical indexes in the background, so writing tasks no longer blocks for long periods.
- Cross-board task queries now calculate available actions and claim status only for the returned page, making large lists open and paginate more smoothly.
- When a model creates a new file, it no longer echoes the entire body back, reducing context usage while fully preserving audit and recovery content.
- The task board decision page scope now uses manual selection and is remembered, instead of silently switching with the current task board.
- Browser tools now provide actionable instructions on errors, support selecting options by displayed text, and can directly use locators from the snapshot.
- Improved prompts for delegation resumption, task cancellation, and plan lookup, making it easier for agents to make the correct calls.
- When an app publishing manifest is invalid, specific fields and rules are returned to help you fix it quickly.
- Built-in app development skills have been updated and are available on the first offline startup of newly installed clients.
