# AgentOS v10.0.190

**Release Date**: 2026-10-26

![v10.0.190 更新概览](/img/changelog/unbranded-agentos/v10.0.190-en.png)

## New Features
- **System browser offline automation**: Advanced browser interactions now support using the system-installed browser and can automatically prepare the required runtime when offline on an internal network, no longer requiring a preconfigured managed Python environment.
- **Progress write-back for regular chat tasks**: Tasks created in regular chats can update their status as they progress, keeping the chat task list consistent with the full task board.
- **Conversation history recovery after migration**: Agent conversation history that was previously invisible after cross-identity migration can be recovered, and an offline maintenance entry is provided to repair verified migration records.
- **Confirmation before skill deletion**: When deleting a skill or agent that contains `.env` credentials, the files to be deleted are listed and confirmation is required before proceeding.

## Fixes
- The package list is no longer empty when signed-in users purchase compute packs.
- The browser workbench's embedded overlay can now be closed by pressing Esc, with focus returned to the entry point.
- After revoking browser sharing authorization and immediately reauthorizing, users no longer encounter an issue where pages cannot be opened due to lack of permission.
- Users on macOS without the preinstalled companion app can now automatically install the companion app normally.
- After a Windows upgrade, initialization no longer fails due to byte differences in cached configuration, and valid configuration is preserved.
- After an interrupted team import, writes to itself are no longer misidentified as conflicts, and the AgentOS service can start normally.
- The migration confirmation page now displays an overwrite summary according to the merge decision, and no longer incorrectly warns that content marked “Keep local” will be overwritten.
- When a Task-bound run lacks a Plan, it now prompts that a plan is required instead of incorrectly reporting insufficient permission.
- Task boards with a large number of tasks no longer experience prolonged freezing or connection drops during startup recovery.

## Improvements
- The desktop installer has removed duplicate copies of large resources, significantly reducing the installer size.
- Market skill installation directories now distinguish between package content and local runtime state, so updates, uninstalls, and built-in sync no longer fail due to local files such as `.venv` and lock files.
