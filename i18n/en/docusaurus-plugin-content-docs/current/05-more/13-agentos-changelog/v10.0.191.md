# AgentOS v10.0.191

**Release Date**: 2026-10-27

![v10.0.191 更新概览](/img/changelog/unbranded-agentos/v10.0.191-en.png)

## Bug Fixes
- Backup and transfer now preserve whiteboard revision history, command receipts, and audit records to prevent cases where canvas files exist but history and audit data are lost.
- Fixed a security vulnerability in the code editor's rich-text sanitization component to prevent malicious content injection.
- Fixed a high-severity security vulnerability in an authentication dependency component to reduce account and login security risks.

## Improvements
- Updated the model integration SDK to 2.27.0 to maintain model service compatibility and stability.
- Updated the MCP SDK to 1.32.1 to improve MCP service compatibility and stability.
