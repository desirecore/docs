# DesireCore v10.0.192

**Release Date**: 2026-10-28

![v10.0.192 更新概览](/img/changelog/v10.0.192-en.png)

## New Features
- **Task board workspace integration**: The four top-level tabs previously on the task board — Current task board / Automatic processing / Flows / Associations — are now consolidated into a unified workspace, shown as Overview, List · Board, Automatic processing, Flows, and Association graph sub-tabs, with return targets recorded.
- **Self-reported task step progress**: Executing agents can self-report task step progress. Delegation Overview and task details show step-by-step progress bars and indicate which step was reached when execution ends.
- **Structured acceptance criteria**: Delegators can set structured acceptance criteria. Executing agents self-assess each criterion when submitting; during rework, unsatisfied items can be checked; and the acceptance panel shows each criterion alongside the self-assessment result.
- **Task execution end notification**: Notifies the task board owner when task execution ends without submission. New task boards enable this notification policy by default.
- **Workflow human steps incorporated into Delegation Overview**: When a workflow reaches a human step, the corresponding card appears under “Awaiting your decision” in Delegation Overview, instead of only being findable in the activity list.
- **Task boards can launch governed workflows**: Task boards can associate with and launch governed workflows, and the run parameter form can pre-fill parameters from the triggering task.
- **Team archiving and restoration**: Teams are automatically archived when disbanded, and can be restored from the archive at any time.
- **ManageTeam archiving capability**: The team management tool adds actions to view archives and restore teams from archives, allowing agents to handle team archiving directly.
- **Cross-agent archived topic list**: Added a cross-agent API for archived conversation topics to provide conversation segmentation for the upcoming archive page.
- **Delegation and background run outcome write-back**: After delegation and background runs finish, the execution outcome is written back to the task claim, so tasks no longer remain stuck in “Running”, and reconciliation backfill can be triggered.
- **Automatic wake-up after responsibility changes**: After reassignment, transfer, or reviewer assignment, the system can automatically @-mention the new owner or reviewer to start processing. New delegations are also registered for wake-up directly, and dispatch failures show “Could not notify”.
- **Team import overwrite confirmation**: Before re-importing a team package, the system asks for confirmation before overwriting. The confirmation interaction matches agent import, and when conversation records conflict, it gives the explicit instruction: “Uncheck and re-import”.
- **Improved human input experience for decision trees**: The human response interface now places the current question, help text, unit, and answer in the main card, supports multi-line text input, and provides separate actions for optional questions: “I have seen this” and “Answer later”.
- **Radio buttons for boolean questions**: Human boolean questions now use directly clickable radio buttons, so users can select Yes or No without opening a native dropdown menu.
- **Distribution-specific app icons**: The launch page and connection recovery page now show the corresponding app icon for each distribution, and unbranded distributions no longer show the default icon.
- **Clarification for approval “Release all”**: Added an explanatory note to the “Release all” option clarifying its scope; side chats only manage approval settings for their parent connection.
- **App work proposal budget**: When an app connects, it can learn the host’s actual byte limit for a complete UTF-8 proposal, avoiding misjudgment when trimming Chinese context by character.
- **App development draft source session**: When developing an app, agents can obtain a trusted draft source session ID from the platform, so publishing to “My Apps” no longer fails due to source guessing.

- Fixed an issue where an interrupted auto-update download caused an unhandled rejection in the main process and made the app exit directly in development mode.
- Fixed an issue where a leading BOM in existing Windows session JSON blocked recovery, and recovery failures silently switched to a new Run.
- Fixed an issue in the native history search window where local image URLs were sanitized and caused broken images.
- Fixed an issue where a frozen personal browser Session with no recoverable pages could not open new pages.

- Fixed an issue where unindexed legacy task boards synchronously read the entire history, causing the service to hang repeatedly and host channel timeouts.
- Fixed an issue on multi-person responsibility boards where after peer review passed, the human acceptance stage had no reviewer and could not be accepted from within the column.
- Fixed an issue where continuing after rework did not bind the task, and a second wake-up of the same agent was rejected.

- Fixed an issue where opening another decision tree after completing a run caused a projection canvas selection synchronization crash and the workbench navigated to an error page.
- Fixed an issue where resizing a textless rectangle on the whiteboard snapped back and could not be saved.
- Fixed an issue where returning from the task board workspace to Delegation Overview left deep links to the same board unresponsive, and archiving the current board showed an inappropriate prompt.
- Fixed an issue where after canceling encrypted backup recovery, plaintext temporary packages remained for a long time, and plaintext ZIP files left by crashes were only cleaned up on the next startup.
- Fixed an issue where legitimate log records slightly over 32 MiB wrote successfully but failed snapshot replay.

- Fixed an issue where directly sending /steer still injected text when the session was cleared during UI context pre-admission.
- Fixed an issue where closing the notification panel for the first time moved keyboard focus to the body, preventing continued navigation from the original bell icon.

- Fixed an issue where saving in the file workbench narrowed existing file permissions according to umask.

- Fixed an issue where after a local service restart, the browser in a standalone window was stuck behind a failed state and could not recover.
- Fixed an issue where export on insufficient space only prompted “Failed, please retry”, and file-skip prompts were all attributed to files being locked by other programs.
- Fixed an issue where some 409 rejection codes during PR automation saving were reported as “Save result unconfirmed”.
- Fixed an issue where under Linux dev, an error when Electron Main was terminated by a signal was silently folded into exit code 1.
- Fixed an issue where invoking the packaging script with tsx caused agent service packaging to fail, and connecting to the service exited immediately because Task Host was missing.

- Fixed an issue where distribution seed content upgrades blocked startup, and on slow git machines the startup deadline was exceeded and a recovery page appeared.
- Fixed an issue where valid human answers in decision trees were rejected due to summary mismatch, and the Run did not add new events.
- Fixed an issue where restoring a Task snapshot from a same-instance migration package mixed an older version with a newer history tail, causing inconsistent continuation.
- Fixed an issue where replacing an MCP service configuration did not check the version first, causing overwrites to lose old entries or accidentally delete OAuth records.
- Fixed an issue where during peer-review rework and responsibility-change wake-up, a second wake-up of the same agent was rejected due to a conflict.
- Fixed an issue where the same assistant message calling TaskUpdate and TaskComment concurrently caused a version self-race.

## Improvements
- **Built-in skill startup acceleration**: Built-in skills written in the same batch now perform only one fresh Git source check, significantly reducing cold startup and skill sync time.
- **Delegation Overview cross-board query performance**: Cross-board task queries now use dedicated reads and yield to the event loop in segments, so large-board and multi-board scenarios no longer block the service for long periods.
- **Legacy task board read optimization**: Unindexed legacy task boards now read only the latest commit for the current board, so startup and post-Run write-back are no longer blocked by the entire history.
- **Dependency upgrades and security patches**: Core components were updated to security-patched versions, including TypeBox, the PDF preview engine, WebSocket plugin, Hono, IP address library, CDP protocol, whiteboard editing dependencies, and others, improving stability and security.
- **Marketplace and built-in skill sync**: Synced marketplace content; updated Mail Operations and Invoice Organization Assistant to 1.2.0; added missing dependency entry points for standalone Office skills; and made the watch skill installable.
- **MCP connection structure optimization**: Construction of external MCP connections and SDK loading are consolidated into a unified module, keeping only one SDK instance in the process and reducing duplicate loading.
