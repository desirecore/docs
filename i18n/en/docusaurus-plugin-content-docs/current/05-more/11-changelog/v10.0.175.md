# DesireCore v10.0.175

**Release Date**: 2026-09-23

![v10.0.175 更新概览](/img/changelog/v10.0.175-en.png)

## New Features
- **Agent Autonomous Application Installation and Maintenance**: Agents can now autonomously install, verify, update, and uninstall applications based on their descriptions, source code, SQL, configuration, and environment, without requiring a fixed installation script in advance. The app marketplace supports delegated installation, precise opening/removal of instances, and displays the last verification time.
- **Team Task Board Creation**: Agents now support creating team task boards, allowing explicit creation of task boards for multi-person collaboration in a team context.

## Fixes
- Fixed an issue where agent sessions containing historical messages could fail to respond due to missing usage information, especially in scenarios with default greeting messages.
- Fixed an issue where Windows and Linux ARM64 installation packages were missing required components, which could prevent normal startup after installation.

## Improvements
- Upgraded integration components for commonly used external model services, improving compatibility and stability with the latest model services, and strengthened validation logic for email drafts, providing clear prompts when required information is missing.
