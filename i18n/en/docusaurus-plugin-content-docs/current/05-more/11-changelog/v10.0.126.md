# DesireCore v10.0.126

**Release Date**: 2026-08-28

![v10.0.126 更新概览](/img/changelog/v10.0.126-en.png)

## New Features
- enable cross-instance conversations (#2328)
- ADR-106 P2 后端——定时任务调度、GFS 保留与 JSONL 截断 (#2296)
- 同机实例免配对直接接入（ADR-111 D7） (#2312)
- 优化多文档工作台与 Markdown 命令层级 (#2316)
- 补齐 Provider 审计可解释清单与门禁 (#2305)
- 内置智能体社会应用与可定制主导航 (#2314)
