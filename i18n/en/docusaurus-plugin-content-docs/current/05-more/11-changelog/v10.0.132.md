# DesireCore v10.0.132

**Release Date**: 2026-08-30

![v10.0.132 更新概览](/img/changelog/v10.0.132-en.png)

## New Features
- **Modernized Marketplace**: The marketplace home page, as well as Agent, Skill, App, and Service cards and detail pages, have been fully redesigned. Trusted source information is now displayed, and the browsing, searching, and installation flows are clearer and more intuitive.
- **Digital Human Personal Preferences**: You can now save digital human avatar and voice preferences separately for different Agents, and they are automatically restored after restart.

## Fixes
- Fixed an issue where an Agent could resend messages that had already been delivered when continuing a conversation after stopping a turn.
- Fixed an issue where the same delivery in real-time messages was displayed both as a tool row and as a standalone card, creating a duplicated impression.
- Fixed an issue where the same conversation turn was recorded twice during context restoration, causing duplicate restored content.
- Fixed an issue where exporting a conversation repeatedly exported historical versions of that same conversation, causing the file size to balloon abnormally.
- Fixed an issue where the browser workspace did not show pages that the Agent had opened. It now correctly focuses on the latest page.
- Fixed an issue where modules such as voice, digital human, and documents ran unstably or displayed simulated data during immersive interactions.
- Fixed an issue where the first smart routing attempt in a brand-new environment incorrectly reported that no models were available.

## Improvements
- Agent profiles and running status have been merged into a single centered large floating window, reducing popup fragmentation and providing a more centralized view of information.
- Application cold start speed and stability have been significantly improved, and the desktop service now runs lighter with better isolation.
- User actions in the browser such as clicks and typing now pause the Agent instead of fully taking over, allowing the Agent to continue its original task after the action is completed.
- Background Agent update detection is now silent, indicated only by a badge, and no longer frequently interrupts with popup notifications.
- Unified the display of in-app brand marks and product names to ensure consistency across all interfaces.
