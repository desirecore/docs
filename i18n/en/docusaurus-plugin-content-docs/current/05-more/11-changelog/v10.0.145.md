# DesireCore v10.0.145

**Release Date**: 2026-09-04

![v10.0.145 更新概览](/img/changelog/v10.0.145-en.png)

## New Features
- **Connection recovery page diagnostic export**: The connection recovery page (for example, when the local service startup times out) can now export a diagnostic archive containing main process logs, making it easier for users to troubleshoot issues.
- **Marketplace Agent usage instructions**: The Marketplace Agent details page now includes a "Usage Instructions" section that displays the USAGE.md content provided by the entry.

## Fixes
- Fixed an issue where marketplace pointer-type Agent/Skill/Team entries could not be declared installable due to structural limitations. Eligible entries can now be installed normally.
- Fixed an issue where Marketplace inline Agent installation did not validate configuration, causing installed Agents to become unmanageable after installation. Invalid configurations now report an error immediately during installation.
- Fixed false failures and duplicate solves in solver validation caused by inconsistent binding envelopes, and ensured that the SCIP service restarts correctly after an upgrade.
- Fixed an issue where the Windows upgrade marker could be missing and slow-starting devices were prematurely marked as failed. Startup detection is now more stable.

## Improvements
- The heartbeat temporary run directory now automatically keeps recent records by count, preventing disk usage from growing indefinitely with runtime.
