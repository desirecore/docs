# DesireCore v10.0.177

**Release Date**: 2026-09-27

![v10.0.177 更新概览](/img/changelog/v10.0.177-en.png)

## New Features
- **Workspace-level instance tabs**: Files, terminals, web pages, and review targets are now merged into a single row of workspace tabs, allowing direct creation, switching, and closing of specific resources; unified workspace tab shortcuts were also added, and the Windows top bar entry point was optimized.
- **Team leads in a single team default to team scope**: For Agents that belong to only one team and serve as its lead, new sessions now default to that team's working directory, making the team decision workspace flow easier to follow; a manually selected personal directory is not overridden by the default.
- **Native search declaration for cloud models**: Cloud models can now accept a server-delivered native search capability declaration, allowing eligible cloud models to directly enter the native web search flow.

## Fixes
- **Windows residual locks and orphan processes preventing startup**: Fixed an issue on Windows where the machine ID or process launch identity could not be read, preventing takeover of residual instance locks and leaving the app unable to start; residual Agent Service processes are now automatically recycled or handled after user confirmation.
- **Swallowed characters and UI infinite loops during long streaming replies**: Fixed an issue where rapid typing during long streaming replies caused silent character loss and UI update loops, leading to lost approval card registrations or send failures.
- **In-flight messages stuck or duplicated after reload**: Fixed an issue where sent messages remained marked as "result unknown" for a long time after a page reload or crash, and manual retry could execute them again; messages are now reconciled by request ID and, if confirmed not executed and within 24 hours, are automatically resumed with the original ID.
- **Messages within delegation incorrectly opening a new session**: Fixed an issue where sending a message to the delegator during delegated execution would start another turn and create a second invisible session; items pending confirmation from the delegator are now written back into the final reply and returned through the delegation result.
- **Recovery path after subtask budget exceeded**: Fixed an issue where, after a delegated subtask failed because the system prompt budget was exceeded, the recovery method suggested in the receipt was unusable and required multiple workarounds; it now directly provides a resend call that can continue execution.
- **Decision workspace follow-ups and toggle isolation**: Fixed issues where decision follow-up card reading, answering, and stopping automatic continuation were unavailable, and made the decision workspace no longer affected by the global task board toggle being off; resource binding writes are still intercepted according to the toggle.
- **AI approval auto-rejection under certain model subscriptions**: Fixed an issue where, under some model subscription channels, an invalid thinking parameter when disabled caused AI approval to fail every time and automatically reject medium-risk operations.
- **Web search always timing out and missing failure reasons**: Fixed an issue where browser snapshots consistently timed out on certain verification pages and failure receipts did not retain the reason; cloud model search capability declarations are now also parsed correctly.
- **Delayed rejection of continuous model solving constraints**: Fixed an issue where continuous models that mistakenly carried constraints applicable only to mixed-integer models were approved first and only rejected remotely; a clear error is now given locally before compilation or approval.
- **CP model relative gap silently discarded**: Fixed an issue where setting a relative gap for a CP model did not take effect and could keep solving until the time limit; solving now stops early as requested once the gap is reached.

## Improvements
- **Smoother Windows startup and instance takeover**: Process identity reading now prioritizes system process metrics and reduces extra system command calls; residual lock takeover has been changed to asynchronous probing, reducing startup waiting and UI lag.
- **Interface readability and layout consistency**: Unified workspace top bar height, opaque background, and overall rounded-corner layout, and improved contrast for unselected tabs, menu hover, URL field focus, and error messages in light mode.
- **Consistent capability gating**: Unified how user-level capability toggles are checked across the frontend, system applications, and task tools; when a capability is disabled, related entry points behave more consistently, and already-loaded content is not suddenly cleared.
- **Document parsing and editing component upgrades**: Upgraded the installer, code editor, chart rendering, and document parsing components, improving table parsing error messages, handling of damaged presentation pages, and chart rendering compatibility.
