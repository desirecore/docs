# DesireCore v10.0.106

**Release Date**: 2026-08-12

![v10.0.106 更新概览](/img/changelog/v10.0.106-en.png)

## New Features
- **Task Board Multi-Agent Collaboration**: Task board now supports assigning responsible agents to tasks, enabling delegation, handoffs, and persistent batched dispatch among multiple agents. A new review panel has been added to track responsibility states.
- **Task Board Global Workbench**: A unified global task workbench has been introduced, allowing you to view tasks from all boards simultaneously. It supports board, list, and card views and can quickly navigate to tasks via desktop deep links.
- **Task Board Automation**: You can now set up scheduled or condition-triggered automation rules for task boards. Agents can automatically perform task operations based on predefined logic.
- **Task Board Workflows**: Persistent workflows are deeply integrated into the task board. You can directly trigger workflow runs, view run history, and inspect task relationship graphs from the task details.
- **Global Multi-Agent Command Center**: A cross-board command center view has been added. It groups all tasks by agent or team, providing a quick overview of workloads and items that need attention.
- **Context-Aware Agent Mentions**: Using `@Agent` in chat now serves only as a pure contextual reference and will no longer automatically dispatch execution tasks. Mentions on the task board remain direct collaboration requests, offering a safer communication approach.

## Fixes
- Fixed an issue where the status bar could permanently display “Organizing context…” and fail to recover after context compression finished.
- Fixed an issue where user message cards could trigger an infinite UI refresh after certain editing operations.
- Fixed an issue in the file workbench where repeatedly opening the same resource could create duplicate tabs and cause console warnings.
- Fixed an issue where transaction conflicts or state inconsistencies could occur during async saving, closing, or switching of SuperDoc documents while editing and reviewing.
- Fixed an issue where the macOS installer failed integrity verification due to a mismatch between pre- and post-signing checks.
- Fixed an issue where the application build failed on Windows and Linux platforms due to missing required runtime dependencies.
