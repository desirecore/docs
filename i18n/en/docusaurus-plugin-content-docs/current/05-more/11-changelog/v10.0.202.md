# DesireCore v10.0.202

Candidate notes. This version has not been released.

## MCP Connections and Discovery

- stdio and Streamable HTTP automatically support legacy and modern servers. For an older server with discovery compatibility problems, set `version_negotiation: "legacy"` for that server and reconnect.
- Tool, resource, and prompt discovery follows the server's TTL. `ttlMs: 0` refetches every time. Disconnected list subscriptions retry and recover.
- Fixes credential ownership in follow-up conversations, empty discovery results during concurrent invalidation, and recovery from low-frequency subscription backoff.
- OAuth step-up authorization adds cross-request quotas and backoff, with distinct diagnostics for rejected callback URLs and authorization-server identity mismatches.
- Explicitly authorized Sampling uses per-initiating-request/server quotas and serializes related calls. Stopping the initiating turn cancels in-flight Sampling.
- MCP Tasks and MCP Apps are currently unavailable.

## Configuration Compatibility

Set `requiredClientVersion` to at least `10.0.202` when publishing an agent with a non-default `version_negotiation` value. SSE connections retain the legacy protocol.

When upgrading from an older version, handwritten or imported MCP configurations containing unknown keys may receive a changed permission-source fingerprint on their first normalization. Re-register schedules and webhooks that reference those configurations.
