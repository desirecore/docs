# DesireCore v10.0.167

**Release Date**: 2026-09-17

![v10.0.167 更新概览](/img/changelog/v10.0.167-en.png)

## Fixes
- Fixed an issue where, after migrating data from Windows or an external drive, overly permissive directory permissions or symbolic links could cause the app to get stuck on the “Temporarily unable to enter DesireCore” recovery page and fail to start.
- Fixed an issue where the notification feature could be permanently disabled due to abnormal file permissions or read failures. It is now automatically re-detected and restored on the next launch.
- Fixed an issue where startup could fail because internal file permissions were set too broadly. The app now automatically tightens them to secure permissions and startup continues.
- Fixed an issue where provider replay could fail across restarts. Replay now works as expected after restarting.

## Improvements
- Significantly improved startup speed: approximately 230 ms faster from launch to interactive, and approximately 220 ms faster to fully ready. Some components are now loaded on demand during startup.
- When startup fails, the main log records a sanitized failure detail (including stage, error code, reason, and call stack) to help troubleshoot and report startup issues.
