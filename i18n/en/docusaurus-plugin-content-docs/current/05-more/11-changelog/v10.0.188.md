# DesireCore v10.0.188

**Release Date**: 2026-10-25

![v10.0.188 更新概览](/img/changelog/v10.0.188-en.png)

## Fixes
- Fixed an issue where a document review still incorrectly reported “not saved” after submission, and after recovering from a failure the editor displayed stale content, which could cause accepted changes to be rolled back.
- Fixed an issue where the already generated streamed body in an interrupted conversation reply was lost and displayed as “No output.”
- Fixed an issue where the workspace did not show a file tab after the agent created a document via Write for the first time.
- Fixed an issue where desktop startup could be blocked while waiting for system keychain authorization.
- Fixed an issue where system environment variables on Windows returned empty values in Git Bash because key name casing was changed.
- Fixed an issue where system tool card content overflowed on the runtime environment page in narrow windows.
- Fixed an issue where default login in development mode did not take effect for the new control plane protocol, causing failure to automatically log in and load compute resources.
- Fixed an issue where the agent lost recognized runtime paths, Git version, and other information when environment detection failed.
- Fixed an issue where error messages were not displayed in the run log when tool calls failed.
- Fixed an issue where recent tool call records showed inconsistent status and time in the activity log.

## Improvements
- Improved the semantic descriptions of task plans and action context to prevent the agent from misinterpreting parent plan references as restrictions on subtask plans, and clarified the visibility scope of plan admission information in action states.
- Upgraded Markdown rendering, YAML parsing, and icon component libraries to improve document rendering stability and compatibility.
