# DesireCore v10.0.187

**Release Date**: 2026-10-25

![v10.0.187 更新概览](/img/changelog/v10.0.187-en.png)

## New Features
- **Cross-device email access and reliable sending**: The embedded email service can now be accessed from other devices. An admission witness is saved before sending; duplicate or unknown outcomes are not automatically sent out again. It also adds task board creation context, conditional storage deletion, and one-sided relationship validation capabilities.
- **Workspace incremental upgrade**: Edition-seeded agents and teams can be merged incrementally through AgentFS/Git, preserving local model choices, memory and non-conflicting user edits. Conflicts defer only the affected repository. Credentials, connector configuration and business workspaces are not re-imported, and deleted entities are not recreated.
- **Image reading integrity verification**: When reading an image, an expected digest can be verified; if the digest does not match, no visual completion is generated, avoiding further analysis based on the wrong image.

## Bug Fixes
- **New conversation context isolation**: After starting a new conversation with `/new`, the first request no longer carries over previous messages, tool calls, or old errors; the old timeline can still be reviewed.
- **More reliable message deletion**: Fixed issues where multi-select deletion could become unresponsive or fail, and where a newly received message missing an address caused deletion to fail silently; after deletion, the default conversation and manual topics are refreshed, and the streaming anchor is correctly repositioned while supporting long-history pagination.
- **Multi-account installation no longer incorrectly blocked**: On multi-account computers, a standard account installing to its own directory is no longer blocked by a program with the same name running under another account; if the program in this directory is actually running under another account or session, a clear prompt is shown and the user is guided to exit or run as administrator.
- **Marketplace skill installation recovery**: Fluctuations in skill installation metadata no longer interrupt verification; after an interrupted installation, the marketplace card and details show “Installation not completed”, and it can be retried from the original entry point.
- **Manual refresh of the model catalog restored**: The manual refresh button next to the chat model selector is restored; it works even when the catalog is empty, prevents duplicate clicks during refresh, allows retry after failures, and preserves the current search, filters, and selected model.
- **Batch loading of named tools**: When an agent names multiple tools, all explicitly named and authorized tools are processed rather than only the first 5. If retention limits prevent loading some tools, those tools are explicitly reported instead of being silently truncated.
- **Installation and exit stability fixes**: Fixed issues where the installer misidentified native components as needing to be rebuilt, exit cleanup reported success too early, and file watcher shutdown was abnormal.
- **Empty conversation hint and popover interaction**: The empty conversation hint text is non-selectable, and the environment status popover automatically collapses when clicking outside and remembers the collapsed preference.
- **Explorer UI fixes**: Unified the names and icons of Explorer across entry points, and changed the floating menu to an opaque material to prevent underlying messages from showing through.

## Improvements
- **Smoother startup and first input**: Streamlined configuration preparation for first startup and first input, reducing repeated reads, directory compilation, and staggered first-screen waits, and optimized service entry loading.
- **Built-in browser access skill update**: The explicit path approval note for the system browser is used only when the client declares it; advanced interactions now use the offline interpreter included with the package, and the login state description is more accurate.
