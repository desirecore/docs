# DesireCore v10.0.153

**Release Date**: 2026-09-10

![v10.0.153 更新概览](/img/changelog/v10.0.153-en.png)

## Fixes
- Fixed the issue where the Windows version could not properly provide installation packages due to build environment problems, and where update package verification failed due to transient CDN errors, ensuring that versions on all platforms can be downloaded and updated normally.

## Improvements
- Updated the built-in macOS assistant component HostAgent to 0.3.1, improving system integration stability and compatibility.
