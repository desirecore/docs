# DesireCore v10.0.170

**Release Date**: 2026-09-19

![v10.0.170 更新概览](/img/changelog/v10.0.170-en.png)

## New Features
- **Skill-first application installation and verification-based state tracking**: Application installation, upgrades, and uninstallation are now driven by agent skills, and installation state is recorded only after actual verification results, avoiding false intermediate states being pre-written in the UI.
- **Marketplace delivery of DesireCore Control**: The marketplace now includes the DesireCore Control app, which external agents can install to control DesireCore.
- **Digital employee category and team display**: The “Agents” category in the marketplace has been renamed to “Digital Employees”. Team cards now directly display team lead and member avatars, and the detail page shows the full member roster and roles.

## Fixes
- Fixed an issue where marketplace catalog content did not refresh immediately after switching the interface language. The localized catalog is now reloaded after a language switch.

## Improvements
- Improved the marketplace browsing experience: better filtering, keyboard navigation, narrow-screen layout, and Chinese input method compatibility. Full team member names and IDs are now included in search.
