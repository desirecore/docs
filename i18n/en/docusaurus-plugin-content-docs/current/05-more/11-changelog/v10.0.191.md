# DesireCore v10.0.191

**Release Date**: 2026-10-27

![v10.0.191 更新概览](/img/changelog/v10.0.191-en.png)

## Fixes
- **Backup & Transfer**: Fixed an issue where whiteboard revision history, command receipts, and audit records were not included during backup and migration. Whiteboard history is now fully preserved after restoration.
- **Security Hardening**: Fixed a high-severity vulnerability in the account authentication component and updated the content sanitization component built into the code editor to strengthen protection against malicious content.
