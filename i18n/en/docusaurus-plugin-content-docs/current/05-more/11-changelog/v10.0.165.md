# DesireCore v10.0.165

**Release Date**: 2026-09-16

![v10.0.165 更新概览](/img/changelog/v10.0.165-en.png)

## Fixes
- Fixed an issue where IMAP folders named “Junk Mail” in Simplified or Traditional Chinese were incorrectly categorized as “Deleted”; historical emails have been automatically migrated to the “Junk Mail” category.
- Fixed an issue where browser automation would hang after the browser had been running in the background on macOS for several hours. It now recovers automatically without requiring a manual window switch.
- Fixed an issue where, in some cases, queries or subsequent messages would continue to be sent after clicking “Stop.” The stop action is now more reliable.
- Fixed an issue where file search would fall back and fail on every attempt when the fd command was not installed. It now correctly uses the bundled fd from the built-in cache.
- Fixed an issue where a locked or timed-out 1Password app was incorrectly reported as a network failure when importing credentials. It now prompts you to unlock 1Password and try again.

## Improvements
- During browser automation login, when CAPTCHA, slider verification, or SMS verification codes are encountered, automatic filling stops and waits for the user to handle them instead of attempting to bypass them.
- Credentials imported from 1Password now record their source item, making audit logs traceable and meeting two-way reconciliation requirements.
