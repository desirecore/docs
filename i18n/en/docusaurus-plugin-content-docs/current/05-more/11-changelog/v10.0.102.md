# DesireCore v10.0.102

**Release Date**: 2026-08-11

![v10.0.102 更新概览](/img/changelog/v10.0.102-en.png)

## New Features
- **Intelligent Model Routing**: It intelligently selects the most suitable model (Lightweight / Balanced / Flagship) based on task requirements, and persists the current model selection across scenarios like creation, team collaboration, and delegation, automatically balancing cost and performance for each task.

## Fixes
- Fixed an issue where the terminal in the desktop release version failed to start due to missing dependencies and directly displayed “Closed” after a few seconds.
- Fixed an issue where the terminal’s previous session could not be restored when the workspace panel was re-expanded after being hidden.
