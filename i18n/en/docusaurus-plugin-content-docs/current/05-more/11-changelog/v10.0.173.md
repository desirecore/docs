# DesireCore v10.0.173

**Release Date**: 2026-09-22

![v10.0.173 更新概览](/img/changelog/v10.0.173-en.png)

## New Features
- **Unified Marketplace card detail experience**: Detail pages for agents, skills, teams, and apps in Marketplace now use a unified card layout, providing a clearer overview of intended human use, full member display, and documentation section navigation. Identical parameters are merged into a single display and support copying complete values. Fake star ratings and hardware requirement information have been removed, and risk descriptions are more realistic.
- **Improved built-in app presentation**: The built-in app name is standardized as “Agent Socialization Relationships,” and the icons and names in the app card, navigation bar, and overflow menu have been optimized. Long names wrap automatically, and unsupported actions are hidden.

## Fixes
- Fixed an issue on Windows where app startup could be slow or even enter the recovery page due to system permission checks or identity reading timeouts. Startup speed is significantly improved.
- Fixed an issue in the agent panel where long URL trait labels caused horizontal scrollbars in popups.
- Fixed an issue where multiple attachments or conflicting options in the session queue could be overwritten and lost, and an issue where cards incorrectly implied task success after a delegated run ended.
- Fixed an issue where installation telemetry could continue sending data after the privacy toggle was turned off.

## Improvements
- Upgraded the underlying model interaction runtime, improving explicit empty parameter handling, session transcript compatibility, and production dependency loading for more stable model interactions.
- Upgraded browser debugging protocol support, improving compatibility and stability of built-in browser automation.
