# DesireCore v10.0.151

**Release Date**: 2026-09-09

![v10.0.151 更新概览](/img/changelog/v10.0.151-en.png)

## New Features
- **On-demand tool disclosure and same-turn discovery activation**: When many tools are available, only the base tool set is loaded in the initial conversation. You can discover and activate more tools on demand within the current turn, reducing irrelevant context usage. Browser management, screenshot, and operation tools can now be used directly without first enabling a skill.

## Fixes
- Fixed an issue where the agent could not resume after the control lease expired during a browser takeover pause. Clicking “Resume Agent” now automatically renews and resumes the session while authorization is still valid.
- Fixed an issue where the card status of asynchronous delegated tasks could lose its final state after refresh.
- Fixed an issue in multi-window scenarios where a retry notification for one window could incorrectly clear another window’s streaming state or display a retry card.
- Fixed a security vulnerability on Linux where media authorization re-reading could bypass detection when a file was deleted and recreated with identical content.
- Fixed an issue where the marketplace cache “dirty repair” continuously backed up the entire tree on Windows, filling the disk with millions of files. Existing backups are automatically cleaned up at startup.

## Improvements
- On Windows, first startup no longer blocks for about 20 seconds due to synchronous data directory security hardening. The hardening now runs in the background, making startup faster.
- The system sleep-prevention logic now more accurately identifies states such as waiting for human input, synchronous delegation, and workflow polling, preventing the system from incorrectly entering sleep during task execution.
- Underlying dependencies have been upgraded to the latest secure versions, improving overall stability and security.
