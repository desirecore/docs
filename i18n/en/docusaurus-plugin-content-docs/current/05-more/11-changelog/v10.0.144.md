# DesireCore v10.0.144

**Release Date**: 2026-09-04

![v10.0.144 更新概览](/img/changelog/v10.0.144-en.png)

## New Features
- **Automatic installation of Agent dependent skills**: When installing or updating an Agent from the marketplace, its declared dependent skills are automatically installed, eliminating the need to manually select them one by one in the marketplace.
- **Solver multi-engine evidence hardening**: Optimized solve results now include stricter feasibility/infeasibility proofs and independent verification. Evidence returned by the three solve gateways is more reliable, helping avoid misjudgment.

## Fixes
- Fixed an issue where the plus menu shifted left and was not fully displayed when the Agent list width was narrow. The menu now automatically aligns within list boundaries.
- Fixed an issue where installing skills to an Agent's private skill directory via a collection could cause the Agent to become permanently unable to update or uninstall.

## Improvements
- Marketplace skill installation, uninstallation, and Agent dependent skill provisioning now uniformly follow a secure digest baseline process. Failure to install dependent skills will not affect Agent installation success, nor break subsequent updates or uninstallation.
- Strengthened ownership validation and audit trail for long-running tasks during resume, continue conversation, derivation, and rollback, improving task execution security and reliability.
