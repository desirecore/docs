# DesireCore v10.0.154

**Release Date**: 2026-09-10

![v10.0.154 更新概览](/img/changelog/v10.0.154-en.png)

## Fixes
- Fixed an issue where the embedded browser could become permanently unavailable after occasional internal event loss and could only be recovered by restarting the app. It now recovers automatically and continues executing browser automation tasks.
- Fixed an issue where the browser tab state could be discarded entirely when a page failed to load or a special address appeared, causing the Agent to mistakenly believe the page was still normal.
- Fixed an issue where an occasional abnormal frame capture could also cause the previous frame to be lost and interrupt the entire browser channel. It now skips abnormal frames and continues working.
- Fixed an issue where an already invalidated browser session could be reactivated by late-arriving old events, leading to inconsistent state.

## Improvements
- Browser operation command failures now record explicit failure events, making later diagnosis and troubleshooting easier.
- Improved internal browser event handling so invalid events no longer clear other ready events, reducing interruptions to browser capabilities.
