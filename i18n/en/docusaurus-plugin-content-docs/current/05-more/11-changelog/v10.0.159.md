# DesireCore v10.0.159

**Release Date**: 2026-09-13

![v10.0.159 更新概览](/img/changelog/v10.0.159-en.png)

## New Features
- **Structural combination validation**: The agent can now validate structured artifacts, rule files, and original text references in the same restricted file read, and supports reading the canonical text representation of DOCX.

## Bug Fixes
- Fixed an issue where structural file validation could time out on small documents because the startup time limit included dependency loading. Initialization and validation are now timed separately, making validation more reliable.
- Fixed an issue where the FileDigest tool showed confusing messages when batch file parameters were incorrect. It now clearly guides users to use paths_json and explains that it is mutually exclusive with paths.
