# DesireCore v10.0.108

**Release Date**: 2026-08-13

![v10.0.108 更新概览](/img/changelog/v10.0.108-en.png)

## New Features
- **Automatic follow-up for background tasks**: After a background task (asynchronous delegation or subtask) completes, the Agent automatically takes over and handles the report, without waiting for the user to send another message. Automatically triggered messages are marked as system automatic messages, clearly distinguishing them from user messages.

## Fixes
- Fixed an issue where the Tencent CAPTCHA could not load during login and sending the verification code would freeze.
- Fixed an issue where the Git bundled with the installer failed during Agent auto-commit and Git sync for Marketplace, Registry, and Configuration Center due to template directory security denial.
- Fixed an issue where a HostAgent process could be left behind after exiting DesireCore. Closing a secondary instance window now also correctly stops its associated HostAgent.
- Fixed an issue where the terminal appeared in both the bottom of the chat area and the workbench, and where workbench terminal shortcuts were unresponsive or incorrect, such as switching tabs accidentally switching agents, closing tabs not responding, and creating new tabs having no effect. Now the terminal is displayed in only one place. When opening a document, the terminal moves to a background tab while the session remains uninterrupted, and a fresh installation will no longer automatically create extra terminals.

## Improvements
- The manual confirmation dialog for model routing now has clearer copy, and canceling a model switch no longer falsely reports “Save failed.” After confirming once in the model panel, adjusting models within a short period no longer requires repeated confirmation, and cloud account-related operations also show fewer repeated popups.
