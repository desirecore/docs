# DesireCore v10.0.129

**Release Date**: 2026-08-29

![v10.0.129 更新概览](/img/changelog/v10.0.129-en.png)

## New Features
- Team content approval: Changes to team rules and member lists require user approval before being injected into agents, preventing unconfirmed remote updates from silently affecting all members.
- Release build GUI takeover for multiple instances: The release build now enables GUI takeover by default. Multiple instances independently allocate CDP ports and isolate identities, work out of the box, and are restricted to local loopback access.

## Fixes
- Fixed an issue where the session title bar content obscured the right-side buttons when the name was long or multiple badges were present, optimized the spacing of the navigation add button, and removed redundant tooltips.
- Fixed an issue where file workbench preview failure reasons still displayed in English under the Chinese UI, and the root directory dropdown list did not refresh after adding a new working directory.
- Fixed an issue where an agent editing its own configuration file could bypass the ManageAgent tool, and added human confirmation when directly modifying agent configuration with generic file tools.
- Fixed an issue where residual configuration from legacy git transport protection caused manual git pull/push to fail; it is now automatically cleaned up.

## Improvements
- Optimized agent lifecycle prompts and approval criteria to reduce the likelihood of the model bypassing management tools and to reduce token consumption per approval request.
