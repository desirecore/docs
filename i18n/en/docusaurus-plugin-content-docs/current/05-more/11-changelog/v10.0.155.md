# DesireCore v10.0.155

**Release Date**: 2026-09-10

![v10.0.155 更新概览](/img/changelog/v10.0.155-en.png)

## Fixes
- Fixed an issue where messages containing invalid timestamps in session history prevented the entire session from continuing to send messages. These sessions can now be used normally.
- Fixed an issue where a Windows build failure prevented Windows users from upgrading. Windows users can now receive this version update.
- Fixed an issue where synced marketplace project team roster information was inaccurate, so the displayed team roster is now more accurate.
- Fixed an issue where inconsistent budget units for tool output could cause multi-byte character content such as Chinese to be truncated incorrectly. Tool output is now measured correctly in bytes.
- Fixed vulnerabilities in browser automation input fencing when windows are minimized or hidden, during drag path checking, and when display queries are abnormal, improving automation control reliability.
- Fixed a security vulnerability where Windows task execution could be hijacked by malicious programs in the working directory. Task downgrade reasons are now also shown explicitly instead of being silent.
- Fixed an issue where concurrent locks on versioned data could falsely report integrity errors and cause operations to fail. Operations are now more stable under concurrent scenarios.

## Improvements
- Optimized how long session history restoration is loaded, making restoration faster and reducing memory usage.
- Reduced the number of application modules loaded, improving application startup and UI transition responsiveness.
