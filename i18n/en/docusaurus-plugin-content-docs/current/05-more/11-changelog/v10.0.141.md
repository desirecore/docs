# DesireCore v10.0.141

**Release Date**: 2026-09-02

![v10.0.141 更新概览](/img/changelog/v10.0.141-en.png)

## New Features
- **Draggable resizing and collapsing for the Working Directory sidebar**: The Working Directory sidebar in File Workbench now supports drag-to-resize, drag-to-collapse, and double-clicking the divider to reset. Users can customize the sidebar width and quickly collapse or expand it.

## Fixes
- Fixed an issue where parts of the interface still displayed the default product name in customized branding environments, ensuring consistent brand display in approval cards and Ready Preview.
- Fixed an issue where automatic updates could falsely report “another instance is still running” and block the update due to residual lock information from dead instances. The update process is now more reliable.
