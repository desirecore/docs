# DesireCore v10.0.162

**Release Date**: 2026-09-14

![v10.0.162 更新概览](/img/changelog/v10.0.162-en.png)

## New Features
- **1Password credential source**: Added support for connecting a 1Password Service Account as a credential source, with management capabilities including connection, health checks, entry browsing, refresh, linking, and disconnecting.

## Bug Fixes
- Fixed issues in immersive voice interaction, including the first segment of continuous speech being sent too quickly, voice barge-in, playback handoff, and speech recognition mode selection, improving voice interaction stability.
- Fixed an issue where old requests could be incorrectly settled or announce the current request during session recovery, ensuring query events carry the correct request identity and correctly cancel pending responses.
- Fixed a notification persistence consistency issue by consistently using the v2 envelope and strict validation, preventing server-side errors from being incorrectly reported as success.

## Improvements
- Account resource cards now load from the metadata endpoint to avoid pulling sensitive information from full credentials, and the “+N more” display style is unified, improving privacy and UI consistency.
