# DesireCore v10.0.189

**Release Date**: 2026-10-26

![v10.0.189 更新概览](/img/changelog/v10.0.189-en.png)

## New Features
- **Proactive Markdown review**: The Markdown editor now displays the latest trusted body text by default. Review is now user-initiated in a separate tab, while historical decisions and rollback operations remain available.
- **Delegated card background outcome**: When synchronous delegation moves to the background, the card shows “Moved to background” and automatically updates its final status after the background task finishes, stops, or is interrupted.
- **Dispatch run popup approval**: The dispatch run popup can now directly answer structured questions and handle service approvals instead of only waiting for a timeout.

## Fixes
- When creating a Git worktree before sending the first message in a new session, the draft and selected project are now registered first to avoid incorrect creation from the default directory or persistent errors.
- Tightened permissions for solver engine configuration writes and probing to prevent agents from bypassing the UI to modify engine lists or initiate credential probing.
- The background monitor for automatic code repository fixes now keeps only one scheduler. If a fix exits midway and restarts, it prompts for manual verification to avoid silent rollback or duplicate dispatch.
- Conversation dates, message times, and export times in exported conversation content now display according to the requested time zone, eliminating inconsistencies between filtering and display across time zones.
- Chat history navigation can now locate messages generated in real time during the current session that have not yet been written to history. When a message cannot be found, it gives a clear prompt instead of becoming unresponsive.
- Export, import, backup restore, and migration to a new device on the Settings page now correctly include task boards, workflows, and audit logs. Restoring task boards and workflows is now unchecked by default to avoid overwriting existing data.
- Updates for existing marketplace agents now fetch from the network before showing placeholders, so slow or unavailable networks no longer block user message sending.
- After periodic synchronization of built-in skills, the skill cache is now refreshed immediately. Only one listener is maintained per batch of updates, reducing the risk of desktop sync stuttering.
- Fixed an issue where the embedded browser misjudged status on long-polling timeout or session termination: after a timeout, continuity is verified first; after termination, the status is described based on the actual situation and stale pages are reclaimed.
- Fixed an issue where saving after restoring a draft in inline Markdown review could roll back accepted changes, and ensured that complete characters such as emoji and combining characters are not split or displayed as garbled text.
- Worker records now keep sensitive information masking and pagination sequence numbers consistent, so legitimate delivery backfill does not incorrectly hide the security summary.
- Fixed an issue where Whiteboard “Save As” showed “result unknown” while the operation was still in progress.
- Updated the content safety filtering component to resolve related security advisories.

## Improvements
- Desktop installer size has been significantly reduced, lowering disk usage and download burden.
- Decoupled compute initialization from input box readiness: after startup, you can start typing immediately; the model selector loads independently and can retry on failure, and after sending, the actual consumer waits for compute preparation.
- The external browser automation runtime now warms up when the system is idle and prepares on demand on first actual use, instead of consuming significant resources on every startup.
- Startup diagnostics and associated app management now load on demand, reducing unnecessary preparation during startup.
- Refined timing observability during service startup and constrained CPU contention by background tasks, reducing resource contention during startup.
- Removed the compute registration onboarding popup at startup to reduce user interruptions.
