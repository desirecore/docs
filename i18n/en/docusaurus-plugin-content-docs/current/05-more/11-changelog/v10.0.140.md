# DesireCore v10.0.140

**Release Date**: 2026-09-02

![v10.0.140 更新概览](/img/changelog/v10.0.140-en.png)

## New Features
- **Persistent output event stream**: When a long-running background command continuously produces output, agents can now be automatically triggered line by line, with support for backfilling missed content, resumable processing, and rate-limit protection. This is suitable for scenarios such as log tracking and continuous integration monitoring.

## Fixes
- Fixed an issue on Windows where clicking “Exit app and update automatically” could leave the old version running and prevent the update progress window from appearing, ensuring the update process is visible and the old version exits properly.
- Fixed an issue where pressing Esc did nothing after the Markdown editor entered full screen: the first Esc now exits full screen, and the second Esc closes the document.
- Changed the import item in the agent’s top-right “…” menu from “Import agent package” to “Import update (agent name)” to avoid confusion with the new import entry in the top-left corner.
- Fixed an issue where installing or updating an agent from the marketplace could trigger configuration validation warnings and mask actual configuration errors.

## Improvements
- The Feishu CLI skill collection in the marketplace now includes the lark-meeting skill, and the descriptions of lark-vc, lark-vc-agent, lark-minutes, lark-note, and other skills that have been downgraded to compatibility shells have been changed to “Use only when explicitly specified” to prevent users from mistakenly installing skills with no business capability based on outdated descriptions.
- Tool component downloads now include SHA-256 integrity verification. If the digest cannot be obtained or verification fails, the download is blocked by default, reducing the risk of tampering through third-party mirrors or during transfer.
