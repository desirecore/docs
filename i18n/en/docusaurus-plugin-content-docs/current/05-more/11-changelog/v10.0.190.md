# DesireCore v10.0.190

**Release Date**: 2026-10-26

![v10.0.190 更新概览](/img/changelog/v10.0.190-en.png)

## New features
- **System browser launch and offline automation**: Browser automation now supports launching browsers already installed on the system and can automatically prepare the runtime environment in offline intranet environments, without relying on a locally preinstalled interpreter or internet access.
- **Progress sync for regular chat tasks**: Tasks created in regular chats can now report progress and sync to the task list and full task board.
- **Confirmation for deleting credential files**: When deleting a skill or agent that contains .env credential files, the files to be deleted are listed first and a second confirmation is required.

## Fixes
- Fixed an issue where task-bound runs without a schedule were incorrectly reported as lacking permission, causing the agent to mistakenly believe it had no review or claim permission and give up.
- Fixed an issue where startup recovery for large task boards blocked for a long time, causing the main interface and connections to time out.
- Fixed an issue where locally generated files after installing and running a skill were misjudged as content drift, preventing updates, convergence, or uninstallation.
- Fixed an issue where recovery records after an unexpected team import interruption were mistaken for conflicts, causing repeated service startup failures.
- Fixed an issue where some valid conversation history was invisible after cross-identity migration.
- Fixed an issue where configuration cache was mistakenly judged invalid after some system upgrades, causing initialization failures.
- Fixed an issue where the companion component in the desktop installer failed to install automatically for users who did not have it preinstalled due to a signature verification mismatch.
- Fixed an issue where logged-in users still could not load the compute plan list in certain deployment modes.
- Fixed an issue where, after revoking browser sharing authorization and reauthorizing, access was still denied during the waiting cleanup period.
- Fixed an issue where the migration confirmation page still displayed “will be overwritten” after “Keep on this device” was selected, or lacked an overwrite warning when importing personal/team data.

## Improvements
- Installer size reduced by about 49 MB, making download and installation lighter.
- The environment, more actions, tab groups, and operation history overlays in the browser workbench now support closing with the Esc key and restoring focus.
