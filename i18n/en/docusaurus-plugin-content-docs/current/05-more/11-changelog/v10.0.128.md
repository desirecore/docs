# DesireCore v10.0.128

**Release Date**: 2026-08-29

![v10.0.128 更新概览](/img/changelog/v10.0.128-en.png)

## New Features
- **Multi-engine solving and universal solver team platform capability**: Introduced a multi-engine solving architecture that supports LP, MILP, QP, MIQP, QCP, MIQCP, and declarative CP models. It can connect to solvers such as MindOpt, SCIP, and CP-SAT, and provides candidate solution validation and an evidence ledger, enabling agent teams to complete more complex optimization tasks.
- **Global task board migrated to a protected built-in app**: The global task board now appears as a built-in app in “My Apps”, with its main navigation entry fixed in the second position. It works the same way as before and integrates more stably with other apps.

## Fixes
- Fixed an issue where the app would not exit or install the update after the automatic upgrade countdown ended. Now it exits and installs correctly when the countdown reaches zero.
- Fixed an issue where electron-mcp-server on Windows incorrectly opened VS Code at startup. The MCP service now starts normally.
- Fixed an issue where queued retries after a message send was rejected could get stuck or be lost after refresh.
- Fixed a synchronization exception caused by improper handling of conflicting transactions during Agent synchronization.
- Fixed an issue where the original draft was lost when /steer was first submitted in an idle session, and draft recovery is now isolated across different input surfaces.
- Fixed an issue where users saw no interruption notice after a run was interrupted. The system now displays a clear reclamation message.
- Fixed an issue where conversations could get stuck and messages could not be sent after service restart or when reusing a session across windows.
- Fixed an issue where the market line art skill icon was incorrectly rendered as a solid square.
