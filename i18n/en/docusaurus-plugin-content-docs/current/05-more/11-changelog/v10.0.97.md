# DesireCore v10.0.97

**Release Date**: 2026-07-31

## New Features
- **Built-in File Workbench**: Browse, edit, and preview various files in the working directory directly within the resource center. Delivers an editing experience close to VS Code, with high-fidelity preview for Office documents (Word/Excel/PPT), PDF reading, image viewing, and editing of common code and configuration files.
- **Comprehensive Upgrade of Inter-Agent Messaging**: When sending a message to a busy Agent, it no longer forcibly starts a new task. Instead, the message is placed in the recipient's inbox, and the sender is informed of what the recipient is currently doing. The sender can then decide to wait, abandon, or use the new “Chime In” and “Interrupt” features to intervene.
- **SMS Verification Code CAPTCHA**: All SMS sending entry points now integrate Tencent Cloud CAPTCHA to prevent malicious bulk sending and ensure service stability.
- **Compliant Phone Number Binding**: After logging in, email-registered users who have not bound a phone number will see an unskippable forced binding dialog, satisfying real-name compliance requirements.
- **Chat History Security**: When an Agent or user manually clears chat history, a ZIP backup file is automatically generated to prevent accidental loss of important conversations.
- **Context Compression Visualization**: After automatic compression of conversation history, a lightweight expandable separator line is displayed in the chat area. A new “Context Occupancy” indicator in the bottom status bar makes the agent’s memory usage clear at a glance.
- **Prevent Sleep During Tasks**: When tasks (such as Agent conversations, workflows, or terminal commands) are running on the computer, the system will prevent automatic idle sleep (the screen can still turn off normally) to avoid long-running tasks being interrupted. This can be disabled in settings.
- **Unified Terminal Viewport**: The resolution of all terminal tabs (including hidden terminals used in the background and by Agents) will automatically adjust to match the size of the currently active tab, preventing layout shifts or misalignment in TUIs when switching.
- **Terminal Tab Number Badges**: Holding the Cmd/Ctrl key shows numeric shortcut hints on terminal tabs, enabling quick switching.
- **Enhanced Terminal Readability**: Increased the minimum contrast, completed the missing ANSI 16-color palette, and fixed text invisibility issues for some CLI tools under light themes.
- **Queued Message List Visualization**: When new messages are sent while an Agent is busy, they no longer disappear from the conversation flow. Instead, they appear as a list above the input area, with support for editing, deleting, or “Abort current and send this” actions.
- **Next Unread Conversation Navigation**: Click the conversation list icon on the left to quickly locate and scroll to the next agent with unread messages, making it easy to check them one by one.
- **Agent List Busy Indicator**: In the session list and agent list, items running tasks now show a flowing `›››` animation and real-time activity text (such as “Using Bash”), which is more noticeable than the previous small dot.
- **Agent Can Autonomously Manage Team Repositories**: New operations added: clone via `ManageAgent`, and list, pull, push via `ManageTeam`. Agents can now autonomously complete the full cycle from cloning expert agents to forming a team and pushing code.
- **Agent Can Autonomously Manage Its Own Conversations**: The new `ManageConversation` tool allows an Agent to mark messages as unread or clear its own chat history, with automatic backup.
- **API Key Security Hardening**: All API keys are now stored encrypted on the local disk, preventing direct reading by shell commands. When an Agent requests a key, it must use the dedicated `ComputeCredential` tool, which goes through an approval process.
- **macOS Full Disk Access Permission Guidance**: On first launch on macOS, users are now proactively guided to grant Full Disk Access to ensure proper functionality of file operations and the system terminal.
- **Upgrade Integrity Check (Windows)**: After a background update installation on Windows, the system automatically verifies that all core native modules are fully written, preventing startup crashes caused by security software interference.

## Fixes
- **Message Loss After Clearing Chat History**: Fixed an issue where the first message sent immediately after clearing chat history would be overwritten and disappear due to a subsequent greeting message.
- **Missing Failure State on Delegate Cards**: Fixed an issue where `DelegateCard` would get stuck in “Processing” or incorrectly show “Completed” when a sub-task had actually failed. It now correctly displays a red “Failed” status.
- **Incorrect Agent Status Display in Resource Manager**: Fixed an issue where the agent list and detail page status badges in the resource manager always showed “Offline”. Now they correctly reflect real-time online, busy, or offline status.
- **Markdown List Numbering Not Displayed**: Fixed an issue where the numbers and bullets of ordered and unordered lists were not rendered at all in chat bubbles, notification center previews, and email bodies.
- **Queued Message Not Lost After Stop**: Fixed an issue where, if a new message was sent during Agent streaming output and then stopped, the new message bubble would disappear even though the Agent still processed and replied to that message.
- **Context Compression Breaking Conversation Memory**: Fixed an issue where after an Agent used `ManageContext(reset)`, recent conversation memory might be permanently lost or earlier summaries could gradually disappear.
- **Pause Button Failure**: Fixed an issue where clicking the “Stop Generating” button could sometimes cause a stack overflow error, resulting in the pause failing.
- **Follow-up Card Height Out of Control**: Fixed an issue where, when an Agent asked multiple choice questions, the content card could become too tall, completely pushing the input area out of the visible window.
- **Misleading Follow-up Submit Button**: Improved the multi-question follow-up experience: the “Submit Answer” button no longer incorrectly shows as a grayed-out disabled state. Instead, it changes to an actionable “Go to Answer” button that guides users to the unanswered question.
- **Video Becomes Broken After Restart**: Fixed an issue where a video generated by a tool displayed correctly initially but turned into a broken image after restarting the application.
- **Delete Button Blocked in Narrow Sidebar**: Fixed an issue where, in a narrow window, the “Delete” button at the bottom of the automation detail page was completely covered by the floating chat button and could not be clicked.
- **Automation Panel Title Vertical Text**: Fixed an issue where dragging the automation panel to a narrow width would cause the title text to stack vertically character by character.
- **Slash Command Panel Mis-triggered**: Fixed an issue where typing text such as “2: /” in the input field would unexpectedly open the slash command panel.
- **`RUN_BRANCH_BUSY` Error Message Loss**: Fixed an issue where, upon a session conflict error, the user’s just-sent message would disappear permanently with no way to recover.
- **Sender Identity in Inter-Agent Messages**: Fixed an issue where when an Agent received a message from another Agent, only its own replies were shown in the chat history, and the message from the other Agent was not visible.
- **Loss of Skills and Conversations During Team Export**: Fixed an issue where exporting team data could misclassify or omit global skills and conversation records, causing the receiving team to malfunction or leading to potential privacy leaks.
- **Markdown Relative Path Images Not Previewed**: Fixed an issue where locally referenced images with relative paths were not displayed in the Markdown editor or preview.
- **Stiff Continuation Status Text**: Optimized the wording of the status bar and buttons when an Agent resumes generating an interrupted answer, making them friendlier and easier to understand.
- **Notification Badge Not Auto-Refreshing**: Fixed an issue where, after marking notifications as read in the Notification Center, the sidebar notification badge would not disappear until the application was restarted.
- **Multiple Agents Sharing One Canvas Window**: Fixed an issue where, when multiple agents used the web rendering tool at the same time, they would overwrite each other’s page content and cause screenshot mix-ups.
- **`running` Status Stuck Deadlocking Sessions**: Fixed an issue where, under certain extreme conditions, the Agent’s status would become stuck as `running`, preventing the session from sending any new messages.

## Improvements
- **AgentFS Refresh Covers Team Dimension**: Any changes to the Agent File System (such as pulling a team git repository) now automatically sync and refresh the front-end team working directory and member status, eliminating the need to manually switch pages.
- **Enhanced Work Directory Management**: Users can now completely remove all of an Agent’s work directories from the UI (including system default directories). Additionally, relative path security when no work directory is set has been tightened to prevent tools from reverting to the process directory.
- **Team Repository Security Protection**: The old text-based git command interception has been replaced with reinforced protocol-level git security (remote transfers disabled) and prompt self-checking, providing more robust safety measures for Agent operations on team repositories.
- **Terminal Color Theme Adaptation**: A new color scheme reporting channel has been added for terminals, allowing CLI tools that automatically detect background colors (such as parts of Claude Code) to better adapt to the app’s dark or light theme.
- **Global Notification for Background Update Completion**: When choosing “Background Update”, a global toast notification will now appear upon download completion, reminding users to restart the app, instead of completing silently.
- **Enforce Skill Loading Before Agent Creation/Modification**: Before an Agent uses `ManageAgent` to create or modify its own configuration, it must now first load the corresponding built-in skill guidance to avoid skipping critical steps.
- **Enhanced Visibility of Agent Error Information**: When an Agent uses `InspectRuns` to view history, it can now see explicit failure markers (such as ✗) and error codes, rather than completely undifferentiated text.
- **Preserve Error Signals on Context Recovery**: After restarting or recovering from a crash, the Agent no longer loses the failure information from the previous turn, and correctly perceives that the previous operation failed.
- **Power Management During Task Activity**: A new global toggle for “Prevent Sleep During Tasks” has been added, independent of the Agent session, along with optimized calculation logic for background tasks.
- **Context Occupancy Display Filtering**: The context occupancy indicator in the bottom status bar now only reflects the context usage of the current conversation turn, and is no longer affected by background task data.
- **Upgraded Dependencies to Latest Versions**: Core development dependencies such as TypeScript 7.0 have been updated, enhancing underlying system stability and performance.
