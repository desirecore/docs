# DesireCore v10.0.104

**Release Date**: 2026-08-11

![v10.0.104 更新概览](/img/changelog/v10.0.104-en.png)

## Fixes
- Fixed an issue on macOS packaged builds where a newly created terminal would immediately show "Exited." Terminals now start correctly and continue running as expected.
- Fixed an issue where the embedded file workspace context would not update promptly when switching chat agents, and improved the unsaved-file confirmation flow to prevent file open requests from becoming permanently stuck.
- Fixed an issue where exporting a PDF from the SuperDoc editor could contain stale content. The exported PDF now reflects the latest editor content.
- Fixed a potential hang and data loss problem when saving an empty document or closing the window in the SuperDoc editor.
- Fixed a responsive layout semantic error in SuperDoc around 600px width, ensuring the interface displays correctly across different window sizes.
- Restored the side-by-side comparison review feature in SuperDoc, and fixed an issue that prevented switching between inline and side-by-side views after making certain review decisions.
