# DesireCore v10.0.200

**Release Date**: 2026-10-27

![v10.0.200 更新概览](/img/changelog/v10.0.200-en.png)

## Fixes
- Fixed an issue where whiteboard revision history, command receipts, and audit information could be lost when backing up or migrating data, ensuring that history is fully preserved.
- Fixed a high-severity parameter disclosure vulnerability in the login authentication component to improve account security.
- Fixed a security vulnerability in the built-in HTML sanitizer in the code editor, reducing the risk when handling untrusted content.
