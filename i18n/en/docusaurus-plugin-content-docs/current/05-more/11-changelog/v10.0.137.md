# DesireCore v10.0.137

**Release Date**: 2026-09-01

![v10.0.137 更新概览](/img/changelog/v10.0.137-en.png)

## New Features
- **Unified catalog metadata and acquisition receipts**: Agents, skills, apps, and services in the Marketplace now consistently display more complete source, update time, and compatibility information, and make install, reinstall, and uninstall flows more reliable.

## Fixes
- When a Windows automatic update installation has not finished, prematurely launching a half-installed application is no longer allowed. At the 99% stage, the system now clearly shows “Completing installation” and prevents users from mistakenly entering the connection recovery page.
- Fixed inconsistencies between live output and delivery cards after refreshing history, and fixed an issue where the second delivery in the same turn was invisible or incorrectly claimed when multiple deliveries occurred in one turn.
- Fixed an issue where, after a generation interruption, previously delivered results could be repeatedly notified or lost when continuing the conversation; the system now accurately indicates what was completed in the previous turn.
- Fixed an issue where plain text replies could appear twice and be saved twice after resuming an interrupted turn.
- Fixed an issue where new reply events could be incorrectly filtered out when starting a new conversation shortly after manually stopping generation.
- Fixed an issue where continuing the conversation after a generation error could be incorrectly treated as already terminated or the retry budget not reset.

## Improvements
- Improved the Marketplace/Store browsing experience by preserving filter state and detail scroll position when navigating back, reducing repeated searching.
- Unified cleanup and finalization logic after generation turns complete, error, or are interrupted, improving stability after interruption recovery and error recovery.
