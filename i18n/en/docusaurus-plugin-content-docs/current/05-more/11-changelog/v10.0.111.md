# DesireCore v10.0.111

**Release Date**: 2026-08-16

![v10.0.111 更新概览](/img/changelog/v10.0.111-en.png)

## New Features
- **Usage Statistics Toggle**: Added a “Send Usage Statistics” toggle in Settings, allowing you to turn off anonymous usage data collection at any time.
- **Agreement Version Management**: The Privacy Policy and User Agreement are now versioned, and updated versions require re-consent.

## Fixes
- Automatic to-do messages now appear immediately in the conversation and maintain the correct styling after refresh, so they are no longer mistaken for user messages.
- Fixed an issue where automatic to-do messages could be incorrectly attributed to the foreground session when compute validation was rejected.
