# DesireCore v10.0.181

**Release Date**: 2026-10-13

![v10.0.181 更新概览](/img/changelog/v10.0.181-en.png)

## New Features
- **Agent development workbench and My Apps publishing**: You can now let agents create applications in authorized working directories and publish them to "My Apps" as fixed versions, with support for running as static web pages, native tasks, and Docker containers, as well as version history, instance data, and device preference management.
- **Intranet repository distribution and offline seeds**: Supports switching Marketplace, Configuration Center, Registry, and core agents to an intranet Git service through a unified configuration, and supports offline seed synchronization for use in intranet environments.
- **Compact tool call prompts and single-layer reasoning records**: Tool calls are displayed directly in chat in the form of "action + object + result", reasoning records are unified into single-layer collapsible cards, and your expansion preference is remembered.
- **Paginated reading for tool descriptions and context pinning**: Long tool descriptions support bounded paginated reading by version, and completed tool results from the current round can be pinned to avoid being trimmed when the context limit is exceeded.

## Fixes
- Fixed an issue where exported DOCX documents could not be read back.
- Fixed an issue where the document tool's default file tier was rejected.
- Fixed an issue where workflow default values were masked by empty parameters.
- Fixed an issue where the pending approval entry was not visible in long sessions.
- Fixed an issue where client and agent updates could be blocked for a long time by failed marketplace preparation, certificate errors, stale startup reservations, or missing Git authentication, and added actionable recovery entry points.
- Fixed an issue where skills and MCP connections still lacked credentials after successful authorization.
- Fixed an issue where tool catalogs from old sources did not immediately become invalid after closing an MCP connection.
- Fixed an issue where Marketplace capability discovery and the installation/usage source were inconsistent, and where sub-skills within collections could not be installed.
- Fixed an issue where approved rules did not cover new recipients after adding team members or changing the team lead, and provided a separate approval recovery entry.
- Fixed an issue where saving large workflows could become outdated and did not include precise revision notes.
- Fixed an issue where new conversations could not start when old run records with missing metadata were present.
- Fixed an issue where model inference tiers were incorrectly passed through or written back in single/vision requests, cloud metadata, and session preferences.
- Fixed issues where pagination parameters for scheduling, run history, and agent Git could be corrupted by invalid strings or negative numbers, and where Grep accepted decimal counts.
- Fixed an issue where the chat model menu was covered by the task overlay.
- Fixed an issue where chat toolbar controls wrapped too early in narrow windows.
- Fixed an issue where vendor names in official compute announcements were offset downward and misaligned.
- Fixed issues where terminal prompts on the workspace creation page were inaccurate, and the resource management terminal entry retained old preferences.
- Fixed issues where the mail service was requested too early during first launch and became unavailable, and where spelling dictionary download status was displayed inaccurately.
- Fixed an issue where the default Python version was incompatible with built-in document processing runtime components, causing first-time installation to fail.
- Fixed an issue where "compute configuration is correct" was incorrectly shown when the approval model had no available channels.
- Fixed an issue where error diagnostics were discarded when a workflow definition was invalid, and the model only received a generic error.
- Fixed an issue where the workflow preview precheck and final submission contract were inconsistent, potentially causing pending review content to be lost.
- Fixed an issue where tool refresh failures returned only a generic error and could not identify the specific tool, path, row, and column.
- Fixed an issue where the chat input box lost focus during long tasks.
- Fixed an issue in team environments where workflow foreground binding and subsequent tool context were incorrectly rejected.
- Fixed an issue where a race condition between document save and close caused both a saved notification and an unsaved confirmation to appear at the same time.

## Improvements
- Windows first-time installation now uses pre-generated indexes and configurations to reduce waiting time.
- Optimized the startup process by deferring the first round of maintenance and reducing time on the critical startup path.
- The model selector now shows availability with status dots in the same row; clicking it shows a plain-language explanation.
- User global prompts are now loaded as plain Markdown full text, making the editing interface simpler and more intuitive.
