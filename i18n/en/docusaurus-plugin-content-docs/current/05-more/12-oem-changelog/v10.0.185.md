# 达摩院AgentOS v10.0.185

**Release Date**: 2026-10-20

![v10.0.185 更新概览](/img/changelog/oem/v10.0.185-en.png)

## New Features

- **委派总览**：全局任务“任务总览”升级为“委派总览”，以任务与项目双视角展示执行流水线、“待你决定”事项与运行审批，并可一步完成新委派。
- **内置通用助手**：新增离线可用的内置“通用助手”，默认启用手动多会话，可用于问答、检索、写作、分析与编程任务。
- **Kimi 官方 Skill**：市场新增 Kimi 官方 Skill 安装与服务连接检测流程，支持校验安装包内容、检测本机服务与扩展状态，并提供仅预填的试用入口。
- **FFmpeg 套件检测**：运行环境的“系统环境”新增 FFmpeg 套件检测，显示 ffmpeg / ffprobe 版本与路径，并列出依赖它们的已安装技能。
- **审批卡全新设计**：审批卡改为紧凑五层结构，改为面向用户展示结构化证据；Write / Edit / NotebookEdit / ExitWorktree / WorkflowRun 等提供可读差异、预计结果与节点核验信息。
- **Bash 命令风险分级**：审批卡按命令内容给出“删除文件”“管道进 shell”等风险标签，识别只读命令为低风险，不再一律标为高风险。
- **后台任务分组与嵌套**：后台任务按“我在处理的 / 我发起的 / 例行”分组，Worker 与委派挂在父执行下展示。
- **后台任务行内停止**：后台命令、转入后台的 Worker、发出的委派与 subtask 支持在列表内两步确认停止，结果就地提示。
- **转入后台 Worker 终态回写**：Worker 转入后台并结束后，时间线中的委派卡片会回写为完成、失败或已停止，刷新后可看到真实结局。
- **审计记录跳转与 Token 分项**：审计详情记录支持跳转到所属执行详情，并显示系统提示词、工具定义与消息的 Token 估算。
- **关联应用同屏协作**：从智能体侧栏打开关联应用时支持与聊天同屏协作，宽窗并排、窄窗切换，并保留来源话题、草稿与可信页面。
- **关联应用移到环境状态部件**：关联应用入口从手动话题列移到消息区右上角的环境状态部件，普通会话与手动多会话展示一致。
- **统一服务器连接设置**：登录与连接失败时提供“服务器连接设置”弹窗，支持自定义服务器地址并在保存前校验。
- **内网手机号密码登录**：无品牌 AgentOS 支持通过服务器连接设置接入内网控制面，使用手机号密码登录并支持首登改密。
- **派单运行审批实时推送**：派单运行中的待审批事项会实时推送到通知中心与系统通知，无需轮询或重连刷新。
- **任务派单可指派负责人**：任务详情派单执行时可同时把接收智能体设为负责人，解决未指派任务无法认领的问题。
- **应用授权移至导航栏**：应用能力授权入口移到左侧导航栏盾牌按钮，释放正式应用与创作预览的可用高度。
- **注册入口默认手机号**：点击“立即注册”默认进入手机号验证码页，并保留显式“使用邮箱注册”入口。
- **模型无进展提示与自动重试限制**：等待模型响应时显示“N 分钟无新进展”的中性提示；同一卡点自动重试至多 2 次，随后交还控制或转入长退避。
- **图片进入请求后的策略与当轮重试**：工具图片按轮次和张数移出模型请求，单请求设张数与大小上限；上游拒收时把错误原文写回图片位置并当轮重试。
- **无进展重复调用熔断**：模型无进展地重复调用同一工具时按阶梯推进，先引导换路、再向用户求助、最后无工具收尾。
- **用户停止后暂缓自动接手**：用户停止生成后，同一会话不会因排队中的异步结果自动开始新的一轮，直到用户再次发话。
- **平台任务依赖失败可见**：平台后台任务（如历史头像补全）依赖未就绪时会在调度详情说明阻塞原因，不再记录成无原因的“成功”。
- **TaskBoardList 只读发现**：新增 TaskBoardList 只读工具，让智能体可以在多板场景下发现已授权的任务板。
- **Webhook 所有者配置与公开接入**：补齐 Agent Webhook 所有者管理与公开 API 接入合同，支持启用、停止、删除与密钥轮换。

## Bug Fixes

- **会话模型预算越界**：会话窗口与输出上限不再超过接入条目声明，修正 MiniMax M3 等模型输出超限被本机拒绝的问题。
- **Smart 子会话路由缺失**：Delegate、侧聊、定时、心跳与 Webhook 等入口传递冻结路由决策，避免第二次模型调用失败并重复执行已落地的副作用。
- **继续生成用量重复计费**：继续生成重置本轮用量基线，被中断那一轮的用量不再重复计入回执与费用。
- **工具用量归属当前轮次**：工具上报的用量检查点交给当前这一轮，修复失败、中止或挂起的续接轮缺少搜索用量的问题。
- **相对路径授权错误**：主对话、侧聊与显式引用的相对路径不再以服务启动目录为基准，没有可用工作目录时失败关闭。
- **侧聊文件访问越权**：侧聊按 Agent 文件访问档位授权，受限档位不再可任意读写工作区外路径。
- **会话工作目录选择越权**：不存在或无权限访问的目录不再被选为会话工作目录或 Project 主路径。
- **搜索根权限误报**：Glob / Grep 搜索根不可读或其中有权限拒绝路径时，保留结果并说明原因，不再误报“0 个匹配”。
- **目录打开阻塞服务**：文件工作台目录打开前先异步探测，超时返回 503，不再冻结整个 Agent 服务的事件循环。
- **HTTP/2 长请求断流**：Agent 服务与邮件服务的 HTTP/2 会话只在没有在途请求时按空闲关闭，长请求不再中途收不到完整正文。
- **Windows 安装器进程处理**：运行检查与升级时结束安装目录进程树改在安装器内完成，不再派生 PowerShell，并列出卡住的进程。
- **Board 保存主线程阻塞**：消除 Board 保存时重复的整链校验与冗余序列化，大文档保存不再让全前端失去响应。
- **审批策略文件损坏**：执行审批策略文件改为原子写，写入中断不再丢失全部规则。
- **排队满时输入框被清空**：普通消息被排队上限拒绝时，输入框保留原文、图片、文件引用与提及，内容不再丢失。
- **查看任务背景后回不到任务**：从任务详情查看背景后关闭历史窗口会返回原任务，不再停在无关旧聊天。
- **决策工作区草稿丢失**：原生窗口直接关闭时会保护本地草稿与待结算写入，避免提交结果无法核对。
- **浏览器标签无法关闭**：Agent 创建的浏览器标签在查询失败时不失效，切换标签后不再残留原生网页。
- **模型选择面板撤回模型**：目录撤回的模型不再显示在选择面板中。
- **重连后模型失效提示陈旧**：服务重连后自动补读算力配置并刷新模型移除提示，不再沿用过期状态。
- **后台更新误报 API Error**：无人值守 Agent 更新执行改为离线对齐，起跑入口等待最多 10 秒，不再因网络卡顿返回“API Error”。
- **同步 subtask 卡片跳变**：wait=true 的 subtask 从首条进度起即显示为协作与正确目标，避免卡片中途从后台任务跳成协作。
- **历史用户图片丢失**：持久会话按快照恢复时还原历史用户图片，追问时模型仍能看到之前贴的图。
- **冷却可恢复时刻漂移**：冷却可恢复时刻统一取记录自身终点，消除跨整秒边界下两个会话相差一秒的问题。
- **邮件草稿附件丢失**：保存草稿后附件恢复并与服务器草稿身份核对，避免附件丢失或重复创建。
- **已发送邮件保存失败**：发送后使用可选择的已发送特殊用途目录保存副本，不再因目录不可选择而丢失。
- **邮件本地搜索只搜首屏**：邮件搜索覆盖当前账号与文件夹内已同步的本地邮件，并可主动加载更早的服务器邮件。
- **快捷回复失败丢稿**：快捷回复失败时显示安全提示并保留原稿，投递未知时提示先核实。
- **邮箱账户名称回滚**：提交显示名称后立即更新列表与表单基线，后续仅改同步频率不再回滚旧名称。
- **团队并发创建不一致**：相同团队身份的创建与成员模型配置并发结算保持一致，不再出现重复团队或部分失败不一致。
- **父团队解散丢失子团队暂存**：解散父团队时保留子团队 Git 状态，团队写操作串行化。
- **桌面窗口模态偏移**：模态面板避开 macOS 交通灯与窗控区域，矮窗口不再被顶栏遮挡页脚。
- **长链接窄窗口裁切**：安装后技能详情中的长 URL 不再被窄窗口裁切。
- **历史记录渲染卡顿**：聊天记录改为分页加载与虚拟化渲染，修复大量历史导致的卡顿与 macOS 灰屏。
- **Windows 环境探测清理误报**：放宽强制终止后的清理确认预算，不再因进程收尾慢而误报清理未确认。
- **导入技能缺少路径**：运行时环境提示词补充 Python / Node 完整路径，检测文案区分“未检测到可用命令”与检测失败。

## Improvements

- **界面文案用户化**：大量界面提示去掉内部术语与开发说明，改为用户可理解、可下一步操作的表达。
- **启动性能优化**：延后非必要依赖与界面加载，降低开发模式冷启动失败率与内存峰值。
- **Worker 转入后台文案**：委派卡片把转入后台的 Worker 显示为“已转入后台”，不再误报为“子任务失败”。
- **任务背景返回上下文**：查看任务背景后按真实关闭意图返回原任务，普通关闭保留评论草稿。
- **审批卡证据默认收起**：写给 AI 审批器的材料默认收进“AI 看到的审批材料”折叠区，卡片说明只展示面向用户的内容。
- **提示词分层保护**：结构化提示词写入前拒绝会跨层吞并后续层的内容，避免仅供参考的内容进入常驻层。
- **任务数据源导航**：任务板决策数据源“查看已授权来源”改为进入文件页，不再写入隐藏聊天工作台。
- **历史搜索可读性**：完整正文匹配后只返回有限展示预览，滚动页继续加载，长文阅读不再卡顿。
- **模态面板材质统一**：自绘模态面板与遮罩材质统一，修复亮色主题下偏透明导致底层内容透视的问题。
- **运行时删除反馈**：运行环境删除运行时版本后按真实任务终态反馈成功或失败，且可靠移除 pnpm 版本。
- **智能体更新收口**：后台更新执行不再联网，起跑等待本地写入完成而非直接拒绝，检测失败连续时自动退避。
- **工具描述面向调用方**：ManageAgent、Read、任务板系列、WebSearch 等内置工具描述改写为面向调用方的写法，减少内部术语。
- **团队成员收纳**：团队未声明成员展示时默认收纳到组长名下，多个团队按最近优先生效。
- **单向粉转后台显示**：委派卡片在 Worker 转入后台后带状态标记，不再用处理中点暗示仍在运行。
