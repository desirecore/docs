# 达摩院AgentOS v10.0.187

**Release Date**: 2026-10-25

![v10.0.187 更新概览](/img/changelog/oem/v10.0.187-en.png)

## DAMO Academy AgentOS v10.0.187

## New Features
- **Native app email and business interfaces**: The embedded email service can be accessed from other devices. An admission witness is saved before sending; duplicate or unknown outcomes are not automatically sent again. Task-board creation context, conditional storage deletion, and one-sided relationship validation are also supported.
- **Image integrity verification**: When reading an image, its expected content digest can be checked. A mismatch returns neither the image nor a visual completion, avoiding analysis based on the wrong image.
- **Built-in agent and team upgrades**: This release includes seed 20261025.1. Edition-seeded agents and teams can be merged incrementally through AgentFS/Git, preserving local model choices, memory and non-conflicting user edits. Conflicts defer only the affected repository. Credentials, connector configuration and business workspaces are not re-imported, and deleted entities are not recreated.

## Fixes
- **New conversation isolation**: After starting a new conversation with `/new`, the first message no longer carries over old messages, tool calls, or errors. The old timeline of manual topics can still be reviewed.
- **Chat message deletion**: Fixed an issue where multi-select deletion failed or became unresponsive. Messages that have just been sent or received can now be deleted normally; after deletion, conversations and manual topics refresh correctly, and pagination for long history is more stable.
- **Marketplace skill installation recovery**: Marketplace skill installation now automatically retries when file metadata fluctuates; if installation is interrupted, it shows “Installation not completed” and can be retried.
- **Windows installation false blocking**: On multi-account computers, installing DAMO Academy AgentOS to your own directory no longer gets falsely detected as occupied and blocked because another account is running a program with the same name.
- **Native lifecycle stability**: Fixed issues such as Windows installation misjudging terminal components and macOS file watcher shutdown causing exit hangs, and improved startup diagnostics.
- **Model selector manual refresh**: Restored a manual refresh entry next to the chat model selector to reload the official compute catalog and view the latest models.
- **Environment status popover interaction**: Clicking outside the environment status popover now dismisses it; empty conversation hints can no longer be selected by the mouse.
- **Basic task finalization**: The action view now explicitly declares the current claim token (`claimToken`) required to submit a basic task for review or release its claim, preventing finalization from failing because this existing input was omitted.

## Improvements
- **Startup and first-input performance**: Reduced the waiting time before DAMO Academy AgentOS becomes operable at startup and first input, and optimized service entry loading.
- **Explorer and menu visuals**: Unified the explorer name and icon, and changed floating menus to opaque material to prevent underlying content from showing through and affecting readability.
- **Built-in browser access skill update**: Explicit-path approval guidance is provided only when the client declares system-browser or executable-path launch support; advanced interactions use the bundled offline interpreter, and sign-in state descriptions are more accurate.
- **Tool loading efficiency**: When an agent names multiple tools, all explicitly named and authorized tools are processed rather than only the first 5. If retention limits prevent loading some tools, those tools are explicitly reported instead of being silently truncated.
