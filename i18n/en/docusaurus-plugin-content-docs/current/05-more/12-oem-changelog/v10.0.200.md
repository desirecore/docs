# AI优化建模平台 v10.0.200

**Release Date**: 2026-11-05

![v10.0.200 更新概览](/img/changelog/oem/v10.0.200-en.png)

## New Features
- Linux 前台命令独立分组与 POSIX 孤儿脚本回收（ADR-334）/ Per-command systemd scopes on Linux and orphan script reclaim on POSIX (#5639)
- 外部 MCP 客户端换用 SDK v2（legacy 模式）与 OAuth 必要改动（#2252 PR6） (#5632)
- 桌面 Agent Service 卡死探活与重启入口（ADR-333）/ Liveness check and restart entry for a hung desktop Agent Service (#5636)

## Bug Fixes
- 在原预算内重取完整 RSS / Reacquire complete RSS within original budget (#5678)
- 保留流读取失败的原生码 / Preserve native codes in read diagnostics (#5677)
- 保留孤儿登记并补宿主失败观测 / Retain orphan records and trace host failures (#5675)
- FFmpeg 签名工作流检出到独立子目录，不再改动 runner 默认工作区 (#5667)
- 存储安全扫描跳过并发原子写已改名或清理的 tmp 条目 (#5670)
- 澄清浏览器导入契约并补齐 MindOpt 真机验证 (#5669)
- Linux 套件归档不再提示“不得用于正式发布” (#5653)
