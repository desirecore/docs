# 达摩院AgentOS v10.0.188

**Release Date**: 2026-10-25

![v10.0.188 Release Overview](/img/changelog/oem/v10.0.188-en.png)

## DAMO Academy AgentOS v10.0.188

## Fixes
- Fixed a stale "not saved" recovery banner after a successful document inline review commit, and rebuilt the editor from the committed result only when resuming a restored review.
- Fixed an issue where the workspace only showed "New Tab" and did not create a file tab after an agent first created a document. The newly created document is now automatically opened and activated.
- Fixed an issue where an interrupted reply receipt lost generated text and displayed "No output". The streamed body content is now preserved.
- Protected-state reads on macOS and Windows now use asynchronous system calls to avoid synchronously blocking desktop startup, with clearer diagnostics for protected-storage failures. Normal operating-system authorization remains handled by the OS.
- Fixed an issue where system tool card content overflowed on the Windows runtime environment page in narrow windows. Long paths, version numbers, and Git source controls can now shrink and wrap correctly.
- Fixed an issue where system environment variable key names were forced to uppercase in Windows Git Bash subprocesses, causing variables to be empty. The original spelling is now preserved.
- Fixed development default sign-in for the official control plane when it uses deployment-v1; this development-only sign-in remains restricted to the official control-plane URL.
- Fixed an issue where confirmed runtime paths, Git information, and reminders were lost when tool detection was inconclusive during environment detection. New sessions now retain this information.
- Fixed an issue where error information for undeclared tool calls at runtime was not preserved. Tool errors are now retained for later diagnosis.
- Fixed non-Windows cache paths that could use host-platform path semantics when a target platform was explicitly specified.
- Fixed an issue where recent tool call records had inconsistent identity and status projection, making recent tool call records more accurate and consistent.

## Improvements
- Clarified the scope of parent-Plan references and Task action snapshots, so child tasks do not inherit the wrong Plan constraint and full.availableActions is not treated as action admission for the current working directory.
- Upgraded Markdown, YAML parsing, and icon components to improve rendering and processing stability.
- Preserved the original undeclared-tool error and appended a clearly labeled current-request note about authorization and declaration state, without altering history or tool permissions.
