# 达摩院AgentOS v10.0.181

**Release Date**: 2026-10-14

![v10.0.181 更新概览](/img/changelog/oem/v10.0.181-en.png)

## DAMO Academy AgentOS v10.0.181

## New Features
- **Agent Development Workbench**: Agents can now develop, preview, and publish apps to "My Apps" within authorized working directories, with support for static web pages, native task hosting, and container execution, and can export fixed-version distribution artifacts.
- **Intranet Distribution and Offline Seed**: Supports switching marketplace, configuration center, registry, and core agent sources to intranet code repositories through unified configuration, and supports offline seed packaging.
- **Compact Tool Hints and Single-Layer Thinking Records**: When tool processes are collapsed, tool calls are displayed item by item with action, object, and verifiable receipt, while thinking records are unified into single-layer cards and expansion preferences are remembered.

## Fixes
- Fixed issues where exported Word documents could not be read back, the default file tier caused some file tools to be rejected, workflow default values were masked by empty parameters, and the pending approval entry was not visible in long sessions.
- Fixed an issue where client and agent updates could be persistently blocked by failed marketplace preparation, certificate errors, lingering startup schedules, or missing Git authentication, and provided a recovery entry.
- Fixed an issue where the tool catalog from the old source was not immediately invalidated after closing an MCP connection.
- Fixed an issue where skill/MCP credentials under normal authorization lacked a valid approval source, causing connection failures, and restored connection reuse for persistent sessions and continued generation.
- Fixed issues where marketplace discovery and installation used different sources, causing content identity mismatch, and where sub-skills in a collection could not be precisely installed.
- Fixed an issue where approved rules did not cover new recipients after adding team members, and where approvals could not be recovered without Git.
- Fixed issues where summaries could become stale and revision notes could be lost when saving large workflows.
- Fixed issues where valid foreground workflow bindings and subsequent tool context were incorrectly rejected in team environments, and where explicit binding history was displayed as 0 entries.
- Fixed issues where pagination parameters could be corrupted by invalid strings or negative numbers, and Grep count parameters incorrectly accepted fractional values, and synchronized the tool parameter descriptions.
- Fixed an issue where historical run records with missing metadata blocked new conversations.
- Fixed an issue where tool refresh failures only showed a generic error; it now returns the specific tool ID, file path, YAML reason, and line and column.
- Fixed an issue where the model inference tier did not take effect correctly or wrote back old values in single/vision calls, cloud contracts, and session preferences.
- Fixed an issue where the chat input box lost focus during long tasks or browser presentation.
- Fixed issues where the chat model menu was obscured by task overlays, toolbar controls wrapped too early, and supplier names were misaligned in the official compute announcement.
- Fixed issues where the saved notification and unsaved confirmation appeared at the same time when saving a document, and background draft versions were inconsistent.
- Fixed an issue where the default Python version was incompatible with the Office runtime, causing related dependency installation to fail.
- Fixed issues where the mail service was unavailable on first Linux startup, and where spelling dictionary download failures did not accurately reflect their status.
- Fixed an issue where, when the context exceeded its budget, long document schemas were left with only a prefix and the current round's results could not be reliably pinned, and provided paginated continuation reading and same-round pinning.
- Fixed issues where the L2 final toolset was inconsistent with the simulation boundary, and where scheduled session identity was missing.
- Fixed an issue where runtime asset cache integrity validation was insufficient, allowing truncated or tampered content to still be reused or packaged.

## Improvements
- Optimized the critical path for first-time Windows installation and startup, reducing wait times for Git initialization and input readiness.
- The model selector now shows availability status as an inline status dot with plain-language descriptions, reducing the number of visible models crowded out by prompts.
- Global prompts are now loaded as plain Markdown full text, and global L0/L1/L2 headings are no longer interpreted.
- Terminal creation prompts are clearer, and the resource management entry now directly opens the workspace terminal for the current session.
- Workflow definition validation now provides safe, specific diagnostics, reducing repeated generation of invalid definitions by the model.
